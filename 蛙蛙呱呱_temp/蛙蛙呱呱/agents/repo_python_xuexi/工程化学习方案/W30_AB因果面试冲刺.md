### AB 实验设计的完整面试框架——从指标到决策

面试官: "设计一个 AB 实验——评估首页新推荐算法的效果。"

你的 6 步回答:

**Step 1——确定指标:** 核心指标(CTR/GMV/留存率)——护栏指标(页面加载时间/崩溃率/用户投诉率)。原则——核心指标不超过 3 个——护栏指标覆盖安全和体验。

**Step 2——计算样本量:** n proportional to 1/MDE^2。MDE 不是拍脑袋——问 PM——"CTR 提升多少你认为是成功的？"如果 PM 说 2%——MDE=2%——往回算样本量。alpha=0.05——beta=0.2——用 statsmodels 的 power solver。

**Step 3——随机化单元:** 用户级别随机化——不是 session 级别——因为同一个用户可能多次访问——session 间不独立。用 user_id 的 hash 值分流——确保同一个用户始终在同一组。

**Step 4——SRM 检查:** 每天自动检查处理组和对照组的用户数比例——是否偏离预期的 50/50。如果偏离——说明随机化出了问题——暂停实验——排查根因。

**Step 5——分析:** 实验结束后——CUPED 方差缩减——t-test 或 linear regression——检查 p 值——同时检查效果量是否 > MDE——且 > 实际重要性阈值。

**Step 6——决策:** 不是 p<0.05 就上线——三问——(1)效果量是否 > MDE？(2)效果量是否 > 实际重要性阈值(PM 定义的)？(3)护栏指标有没有显著恶化？三个都是 YES——上线。任一个 NO——不上线。

面试官追问你怎么防止 peeking(偷看)——"我设了三段式决策框架——实验开始后只在三个时间点做决策——(1)安全护栏检查(实验 1-2 天后)——(2)中期效果检查(样本量达到 50% 时)——(3)最终决策(样本量达到 100% 时)。中途不偷看——因为每多偷看一次——假阳性率累积——alpha 膨胀。"

**CUPED 是第一道"区分背过公式和理解原理"的面试题。**

面试官：你知道 CUPED 吗？

回答（45 秒）：
> "CUPED = 用实验前数据作为协变量，减少实验后指标的方差。公式：Y_adj = Y - θ(X - E[X])。关键点：θ 必须在对照组上估计——因为实验组的 Y 里含有实验效应，用全量数据估计 θ 会污染协变量关系，导致实验效应被高估或低估。我写过一篇关于这个的模拟——H0 为真时 p 值的分布、CUPED 前后对比——在我 GitHub 上可以看到代码。"

**如果面试官继续追问"θ 是什么"**——"θ = Cov(Y_control, X_control) / Var(X_control)——它是'实验前 X 能在多大程度上预测实验后 Y'的度量。θ 越高，方差缩减越多——缩减比例等于 ρ²。"

### p 值面试——完整四连问 + 模拟验证代码

**Q1: "p 值是什么？"**

> "在原假设为真时——观察到当前或更极端结果的概率。p = P(数据|H0)——不是 P(H0|数据)。H0 要么真要么假——不存在概率。p 值不告诉你 H0 为真的概率——它告诉你在 H0 为真的世界里——你看到的数据有多奇怪。"

**Q2: "H0 为真时——p 值服从什么分布？"**

> "[0,1] 上的均匀分布。我用 Python 模拟验证过——10000 次 A/A 实验(从同一总体抽样)——t-test 的 p 值直方图是平的——约 5% 的 p<0.05。这就是为什么 p<0.05 不意味着有 95% 概率备择假设为真——H0 为真时也有 5% 的概率得到 p<0.05。"

```python
import numpy as np
from scipy import stats

def demo_p_uniform(n_sims=10000, n_samples=1000):
    """验证 H0 为真时 p 值~Uniform(0,1)"""
    pvals = []
    for _ in range(n_sims):
        ctrl = np.random.normal(100, 15, n_samples)
        trt = np.random.normal(100, 15, n_samples)  # same population
        _, p = stats.ttest_ind(trt, ctrl)
        pvals.append(p)
    fp_rate = sum(p < 0.05 for p in pvals) / n_sims
    print(f'H0 为真时 p<0.05 的比例: {fp_rate:.3f} (期望 ~0.05)')
    return pvals
```

**Q3: "p-hacking 是什么——怎么防止？"**

> "利用'p 值在 H0 为真时服从均匀分布'这个性质——做 20 次不同的分析——期望有 1 次 p<0.05——然后只报告那 1 次。违反了分析方案必须在看到数据前确定的原则。防守——预注册分析方案、Bonferroni 校正(M 个检验时 alpha/M)、hold-out 验证集、三段式决策不偷看。"

**Q4: "p<0.05 为什么不等于有 95% 概率有效应？"**

> "P(地面湿|下过雨) != P(下过雨|地面湿)。地面湿还可能是因为洒水车。同理——P(p<0.05|H0为真) != P(H0为真|p<0.05)。p 值不告诉你 H0 为真的概率——它告诉你在 H0 为真的世界里——观察到的数据或更极端数据的概率。"

### p 值面试——四连问完整答案 + 模拟代码

**Q1: "p 值是什么？"**

> "在原假设为真时——观察到当前或更极端结果的概率。p 值不是'H0 为真的概率'——H0 要么真要么假——不存在概率。p = P(数据|H0)——不是 P(H0|数据)。"

**Q2: "H0 为真时——p 值服从什么分布？"**

> "[0,1] 上的均匀分布。我用 Python 模拟验证过——10000 次 A/A 实验——t-test 的 p 值直方图是平的——约 5% 的 p < 0.05。这就是为什么 p < 0.05 不意味着'有 95% 概率备择假设为真'——H0 为真时也有 5% 的概率得到 p < 0.05。"

```python
import numpy as np
from scipy import stats

def simulate_p_values(n_simulations=10000, sample_size=1000):
    """模拟 H0 为真时 p 值的分布——验证均匀分布性质。"""
    p_values = []
    for _ in range(n_simulations):
        control = np.random.normal(100, 15, sample_size)
        treatment = np.random.normal(100, 15, sample_size)  # 同一总体——H0为真
        _, p = stats.ttest_ind(treatment, control)
        p_values.append(p)

    false_positive_rate = sum(p < 0.05 for p in p_values) / n_simulations
    print(f'H0为真时——p<0.05的比例: {false_positive_rate:.3f} (期望约 0.05)')
    return p_values
```

**Q3: "p-hacking 是什么？"**

> "利用'p 值在 H0 为真时服从均匀分布'这个性质——做 20 次不同的分析——期望有 1 次 p < 0.05——然后只报告那 1 次。这违反了'分析方案必须在看到数据前确定'的原则。防守方法——预注册分析方案、Bonferroni 校正、hold-out 验证集。"

**Q4: "p < 0.05 为什么不等于'有 95% 概率有效应'？"**

> "P(地面湿|下过雨) ≠ P(下过雨|地面湿)。地面湿还可能是因为洒水车。同理——P(p<0.05|H0为真) ≠ P(H0为真|p<0.05)。p 值告诉你在 H0 为真的世界里——你看到的数据有多奇怪——它不告诉你 H0 为真的概率。"

### 因果推断面试追问应对——完整版

**追问 1:"DID 的平行趋势如果不成立——你怎么办？"**

> "四种应对。(1)检查是否有特殊事件(节假日/促销)——如果能在报告中解释——仍可使用 DID——但标注异常。(2)在模型中加入 group-specific time trend——允许两组有不同的时间趋势。(3)如果平行趋势完全不成立——考虑 Synthetic Control——用多个对照组的加权组合合成处理组的反事实。(4)如果也不适用——考虑 CSDID——允许多期处理——使用尚未被处理的单元作为对照组。"

**追问 2:"PSM 的 CIA 不可检验——你怎么说服我你的结论可信？"**

> "三件事。(1)匹配后 SMD 全部 < 0.1——观测到的变量被平衡了。(2)Rosenbaum 敏感性分析——Gamma=1.8 时才不显著——需要相当强的未观测混淆才能推翻结论。(3)多方法验证——DID/RDD/IV 结论方向一致——结论对方法选择不敏感。"

**追问 3:"RDD 的结论能推广到所有用户吗？"**

> "不能。RDD 估计的是 LATE——断点附近的局部效应——只对刚好在断点附近的用户有效。在鲜果多案例中——RDD 估计的是消费约 500 元的用户——ATT=+14%——不能外推到消费 200 元或 1000 元的用户。在报告中必须标注'本结论仅适用于断点附近用户'。想估计全量用户的效应——需要 PSM 或 IV 等其他方法。"

**追问 4:"IV 的外生性也不可检验——你怎么说服我？"**

> "外生性确实不可直接检验——和 CIA 一样。我做两件事来增强可信度。(1)如果有多于一个 IV——做过度识别检验(Sargan/Hansen J test)——检验不同 IV 估计的 ATT 是否一致——不一致说明至少有一个 IV 违反了外生性。(2)定性论证——在报告中解释为什么我认为这个 IV 是外生的——'是否在推广活动期间注册'——活动时间是公司统一决定的——和个人消费意愿无关——只通过'是否拿到卡'影响消费。如果面试官有疑虑——我可以展示这个论证。"

### 📖 核心原理

**面试官不会问你"什么是 DID"——他会问"DID 的平行趋势假设如果不成立怎么办？"**

每种方法的"核心假设 + 不成立时的后果 + 检验方法"——这是面试答案的铁三角。

| 方法 | 核心假设 | 不成立时的后果 | 检验方法 |

### 辛普森悖论——完整面试回答 + 检测代码

```python
def simpson_scan(df, group_col, value_col, outcome_col):
    """辛普森悖论扫描——检测分组结论和合计结论是否方向相反。"""
    grouped = df.groupby(group_col).agg(
        mean_outcome=(outcome_col, 'mean'),
        mean_value=(value_col, 'mean'),
        count=(value_col, 'count')
    ).reset_index()
    overall_mean = df[outcome_col].mean()
    overall_dir = 'higher' if overall_mean > df[outcome_col].median() else 'lower'

    # 检查所有分组方向是否和合计方向一致
    group_dirs = []
    for g in grouped[group_col].unique():
        g_mean = df[df[group_col]==g][outcome_col].mean()
        g_dir = 'higher' if g_mean > df[df[group_col]==g][outcome_col].median() else 'lower'
        group_dirs.append(g_dir)

    all_same = len(set(group_dirs)) == 1
    paradox = all_same and group_dirs[0] != overall_dir

    if paradox:
        logger.warning(f'辛普森悖论: 分组方向={group_dirs[0]} vs 合计方向={overall_dir}')

    return {'paradox': paradox, 'group_dir': group_dirs[0] if all_same else 'mixed',
            'overall_dir': overall_dir, 'group_stats': grouped}
```

        mean_value=(value_col, 'mean'),

        lambda r: 'higher' if r['mean_outcome'] > df[df[group_col]==r[group_col]][outcome_col].median() else 'lower',

    )

    # 如果所有分组方向一致——但和合计方向相反——辛普森悖论

        'overall_direction': overall_direction,
        'group_stats': grouped
