# 01 队列分析 — 团长留存热力图

---

## 一、白话理解

### 每个团长的"保质期"不一样

2024年1月注册的团长，到2024年12月还在活跃的有多少？
2024年6月注册的团长呢？是不是因为"生不逢时"（夏天淡季）存活率更低？

**队列分析把团长按注册月份分组，追踪每一组的留存率随时间的变化。**

### 热力图怎么读

```
行 = 注册队列 (2024年1月注册...12月注册)
列 = 已活跃月数 (第1个月...第12个月)
颜色 = 留存率 (深=高, 浅=低)

对角线往下 → 同一批团长随时间推移的留存变化
横向看 → 不同批次的团长在第N个月的留存率差异
```

典型模式：
- 第1列全深色(100%) — 注册当月当然全员活跃
- 越往右颜色越浅 — 时间消磨一切
- 底部比顶部浅 — 最近注册的团长还没经历时间考验

## 二、核心代码

打开 [01_cohort_analysis.py](../01_cohort_analysis.py)：

```python
cohort_matrix = df.pivot_table(
    index='register_cohort',    # 行 = 注册月份
    columns='months_active',    # 列 = 已活跃月数
    values='is_active',          # 值 = 活跃比例
    aggfunc='mean'               # 取均值 → 留存率
) * 100
```

`pivot_table` 是pandas最强大的函数之一——一键把长表转成矩阵。
