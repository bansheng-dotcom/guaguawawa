# 05 用户LTV — 获客渠道ROI对比

---

## 一、美团优选三种获客渠道

| 渠道 | 方式 | 用户质量倾向 |
|------|------|------------|
| 团长拉新 | 团长在群里发邀请码 | 高 — 团长筛选过 |
| 自然流量 | 用户自己搜/下载 | 中 |
| 促销活动 | 扫码领鸡蛋/新人0.01购 | 低 — 薅羊毛多 |

---

## 二、核心发现

团长拉新用户LTV最高（~150元）、促销用户LTV最低（~110元）。
但促销用户量大（拉新成本低） — 整体ROI取决于LTV/CAC比值。

团长拉新LTV/CAC=6-8x：最优质的渠道。
促销LTV/CAC=5-7x：量大但需要做二次筛选。

---

## 三、业务意义

BD激励应该导向"拉来多少高LTV用户"而非"拉来多少用户"——否则BD只会刷量。
