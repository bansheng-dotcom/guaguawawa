# 03 LTV建模 — 团长终身价值

---

## 一、核心公式

```
LTV (Lifetime Value) = 月均GMV × 预期存活月数
```

- **月均GMV**：活跃月份的平均GMV（排除流失后的0值月份）
- **预期存活月数**：来自生存分析的中位存活期（或城市×密度分组的预期）

---

## 二、为什么LTV重要

```
如果团长招募成本是3000元:
  LTV > 9000 (3x)  → 健康,值得大规模招募
  LTV 3000-9000    → 边际,需优化招募效率
  LTV < 3000       → 赔钱! 每招一个亏一个
```

代码里用两种方法算LTV——简单法（统一中位存活）× 精细法（分城市分密度的预期存活）。

---

## 三、团长LTV分层结果

```
超级团长(>15万): 约8% → 贡献了最多的GMV→值得BD重点跟进
高价值(10-15万): 约15%
中等(5-10万):    约40%
低价值(<5万):    约37% → 招募这批团长的ROI可能为负
```
