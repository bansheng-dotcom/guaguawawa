# 04 ARIMA vs Prophet 对比

## 评估指标

| 指标 | 含义 | 好/坏 |
|------|------|-------|
| MAE | 平均绝对误差(元) | 越小越好 |
| MAPE | 平均绝对百分比误差(%) | <10%=好,>20%=需改进 |

## 什么时候用哪个？

- **ARIMA:** 数据没有复杂节假日效应，需要精确的统计推断
- **Prophet:** 有节假日+周末效应，业务方需要可解释的组件分解
- **实操:** 两个都跑，取ensemble平均通常比单个更好
