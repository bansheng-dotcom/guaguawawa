# 02 ARIMA模型

## 核心公式

ARIMA(p,d,q) = AR(p)自回归 + I(d)差分 + MA(q)移动平均

- **p=7:** 过去7天的GMV影响今天（一周周期）
- **d=1:** 一阶差分使序列平稳（消除趋势）
- **q=1:** 过去1天的预测误差修正今天

### 滚动预测（避免数据泄露）

每次只用"到目前为止"的已知数据训练，预测下一步，然后加入真实值再训。这是时序模型的标准评估方式。

### ARIMA的MAPE约9.7%——解读

预测日均GMV约39,000元，误差约5,100元。在GMV预测中，MAPE<10%是可接受的水平。
