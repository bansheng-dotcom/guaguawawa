# 需求管理与协作复核拓扑

## 1. 目标

把已确认的 PRD 或需求转成可执行、可验收、可追溯的开发输入。

## 2. 拓扑图

```mermaid
flowchart TD
  A["已确认需求/PRD"] --> B["建立需求编号和需求卡"]
  B --> C["确认真正问题、范围、不在范围"]
  C --> D["拆下游文件和 P0/P1/P2"]
  D --> E["补验收和测试场景引用"]
  E --> F["标注关联产品需求"]
  F --> G["协作能力复核记录"]
  G --> H{"复核通过?"}
  H -- "否" --> I["修订需求卡和下游文件"]
  I --> G
  H -- "是/草稿" --> J["写工作日志和用户汇报"]
```

## 3. 输出包

| 产物 | 用途 | 生命周期 |
| --- | --- | --- |
| 需求卡 | 正式需求入口 | 长期 |
| 下游文件 | 给前端、后端、Agent、测试接手 | 开发周期 |
| 复核记录 | 标记通过/需修改/未复核 | 开发周期 |
| 工作日志 | 后续追溯 | 长期 |
