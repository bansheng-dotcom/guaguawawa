## W5D1：概率论基础

### 能力簇
**概率直觉** —— 理解随机性，建立"用数据量化不确定性"的思维框架。今天不背公式，全部用Python模拟直观感受

### 为什么今天重要
概率是统计的语言。不理解概率就去学p值和置信区间=学汉字不学拼音。今天每一节都配套Python模拟代码，让你亲眼看到"概率0.3"到底意味着"重复1000次大约发生300次"。这个直觉建立了，W5D4-D5的推断统计才能理解。

### 具体知识清单

**1. 概率是什么——三种理解方式**
- **频率派**（今天重点）：概率=长期频率。抛硬币正面概率0.5="抛无穷多次后正面约占一半"。用Python模拟验证大数定律
- **贝叶斯派**（建立直觉，不深究公式）：概率=信念程度。你先有个"硬币应该公平"的先验信念→抛了10次全是正面→更新信念→"硬币可能有问题"
- **公理化**：概率必须满足三条：①任何事件概率≥0 ②必然事件概率=1 ③互斥事件之和的概率=各自概率之和
- **Python模拟——大数定律直观验证**：
  ```python
  import random
  # 模拟抛硬币
  for n in [10, 100, 1000, 10000, 100000]:
      heads = sum(random.random() < 0.5 for _ in range(n))
      print(f"抛{n}次: 正面{heads}次, 频率={heads/n:.4f} (真实概率0.5)")
  # 输出: n=10→频率0.3或0.7(波动大), n=10000→频率0.5003(接近0.5)
  ```

**2. 条件概率——"已知X发生了，Y的概率怎么变"**
- `P(A|B)` = "在B已经发生的条件下，A发生的概率"
- 公式：`P(A|B) = P(A∩B) / P(B)`。分母=已知B发生，分子=A和B同时发生
- **直观理解**：已知B发生后，样本空间缩小为"只有B发生的情况"→看这些情况里有百分之多少A也发生了
- **Python模拟——条件概率直观验证**：
  ```python
  # 模拟10000个用户：60%男性(P=0.6)，男性中有20%购买(P(购买|男性)=0.2)，女性中有35%购买
  users = [{'gender': 'M' if random.random()<0.6 else 'F'} for _ in range(10000)]
  for u in users:
      u['buy'] = random.random() < (0.2 if u['gender']=='M' else 0.35)
  # 计算P(购买|男性) = 买了的男性/男性总数
  male_buyers = sum(1 for u in users if u['gender']=='M' and u['buy'])
  males = sum(1 for u in users if u['gender']=='M')
  print(f"男性购买率={male_buyers/males:.3f} ≈ 0.2")
  ```
- **贝叶斯直觉**（不深究公式）：先验(买之前认为产品好的概率)→看到证据(好评率95%)→更新后验(现在认为产品好的概率更高了)。这就是"先有的信念+新数据→更新的信念"
- **陷阱：条件概率的方向不能互换。P(A|B)≠P(B|A)**。P(阳性|患病)=99% ≠ P(患病|阳性)。后者取决于疾病本身的基础率(基础率忽视=常见统计陷阱，W5D6讲)

**3. 独立 vs 互斥——两个完全不同、但常被混淆的概念**
- **独立**：A的发生不影响B的概率。`P(A∩B) = P(A)×P(B)`。如：第一次抛硬币正面和第二次抛硬币正面→独立
- **互斥**：A和B不能同时发生。`P(A∩B) = 0`。如：一次抛硬币不能同时正面和反面→互斥
- **为什么常被混淆**：因为一些独立事件看起来"好像"互斥，一些互斥事件看起来"好像"独立
- **检验独立**：如果`P(A∩B) = P(A)×P(B)`→独立。用Python模拟验证：抛两次硬币→第一次正面和第二次正面→验证是否独立(是)/抽一张牌→是红心和是黑桃→验证是否互斥(是)
- **陷阱：独立≠互斥。独立事件可以同时发生。赌徒谬误=误以为独立事件之间有依赖——"已经连续5次正面了，下次反面概率更大"——不对！每一次都是独立事件，概率永远是0.5**

**4. 期望、方差、协方差——描述随机变量的三个核心量**
- **期望E[X]**：长期平均值。`E[X]=Σx·P(X=x)`。用Python模拟：掷骰子10000次→平均≈3.5(=期望)
- **方差Var[X]**：波动程度。`Var[X]=E[(X-E[X])²]`。方差大=每次跟均值差得远。方差小=每次都在均值附近
- **协方差Cov[X,Y]**：两个变量"同涨同跌"的程度。Cov>0→X涨Y也涨。Cov<0→X涨Y跌。Cov=0→无关
- **Python模拟——直观感受**：
  ```python
  # 高方差 vs 低方差
  high_var = [random.gauss(100, 50) for _ in range(1000)]  # std=50
  low_var = [random.gauss(100, 5) for _ in range(1000)]   # std=5
  print(f"高方差: mean={np.mean(high_var):.1f}, std={np.std(high_var):.1f}")
  print(f"低方差: mean={np.mean(low_var):.1f}, std={np.std(low_var):.1f}")
  # 均值接近，但波动差异巨大→画直方图直观比较
  ```
- **陷阱：期望≠"最可能的值"。在偏态分布(如收入)中，期望(均值)被极端值拉偏→远大于中位数**

**5. 大数定律——为什么样本越大越可靠**
- 随着样本量n增大，样本均值趋近总体均值(真实期望)
- 这是所有统计推断的基础：你从样本算出来的东西→样本够大→接近真实值
- **Python模拟——亲眼看到样本均值"收敛"到真实值**：
  ```python
  true_mean = 0.5  # 真实硬币正面概率
  sample_means = []
  for n in range(1, 5001):
      sample = [random.random() < true_mean for _ in range(n)]
      sample_means.append(sum(sample) / n)
  # 画图：x轴=样本量，y轴=样本均值→曲线从剧烈波动到逐渐稳定在0.5
  ```
- **大数定律的局限**：赌徒谬误=误以为大数定律说"短期会'补偿'"。实际上大数定律说的是"长期会'稀释'"，不是"该赢了"。独立事件的每次概率都相同

## W5D2：随机变量与常见分布

### 能力簇
**分布的直觉** —— 认识数据分析中最常见的5种分布，能判断"我的数据最像哪种分布"，理解每种分布回答什么业务问题

### 为什么今天重要
现实世界的数据不是"随机"的——它们服从各种概率分布。理解你的数据服从哪种分布，你才能选对分析方法。销售额服从幂律→均值没意义→要用中位数。转化率服从二项分布→方差和p挂钩→p=0.5时方差最大。不了解分布→分析方法选错→结论不可靠。

### 具体知识清单

**1. 随机变量——从"事件"到"数值"的映射**
- 随机变量=把随机事件的结果映射成一个数字。抛硬币→X=1(正面)/X=0(反面)。用户打车→X=等待时间(分钟)
- 离散型：取值有限或可数。如投骰子(1-6)、用户今天下单次数(0,1,2,...)
- 连续型：取值在一个区间内任意值。如等待时间(0-∞任意值)、消费金额
- PMF(概率质量函数，离散)：`P(X=x)`。如P(掷骰子=3)=1/6
- PDF(概率密度函数，连续)：某一点的概率密度。**PDF在某点的值不是概率！** 概率是PDF在区间上的积分(面积)
- CDF(累积分布函数)：`P(X≤x)`。"等待时间不超过5分钟的概率是多少"。离散和连续都有CDF
- PPF(百分位点函数)：CDF的反函数。"90%的人等待时间不超过X分钟→X是多少"。AB实验的样本量计算用到Zα=PPF(1-α)

**2. 离散分布——计数数据的三种形态**
- **二项分布 Binomial(n, p)**：
  - 场景：n次独立试验，每次成功概率p。"1000个用户每人独立概率0.03→下单人数"
  - 特征：取值0到n，均值=np，方差=np(1-p)。p=0.5时方差最大
  - Python：`np.random.binomial(n=1000, p=0.03, size=10000)`→画直方图看分布形状
  - **AB实验关键**：转化率/点击率的底层就是二项分布。比例指标的样本量公式用到p(1-p)→p=0.5最贵
- **泊松分布 Poisson(λ)**：
  - 场景：单位时间内随机事件发生的次数。"每小时订单数""每天投诉量"
  - 特征：取值0到∞，均值=λ，方差=λ（均值和方差相等！）
  - Python：`np.random.poisson(lam=5, size=10000)`→每小时约5单
  - 泊松的λ和平均值之间的直觉：如果10:00-11:00历史平均5单→观测到10单=异常→可能有什么事件发生
- **几何分布 Geometric(p)**：
  - 场景：直到第一次成功所需的试验次数。"打多少次电话才能约到一个客户"
  - 特点：无记忆性。"已经打了5次没成功→下次成功的概率还是一样的"
  - Python：`np.random.geometric(p=0.2, size=10000)`→平均1/p=5次

**3. 连续分布——测量数据的四种形态**
- **正态分布 Normal(μ, σ)**：
  - 场景：多个微小独立因素叠加的结果。测量误差/身高/考试成绩
  - 特征：对称、钟形、均值=中位数=众数、68-95-99.7规则(68%在μ±1σ,95%在μ±2σ,99.7%在μ±3σ)
  - Python：`np.random.normal(loc=170, scale=10, size=10000)`→身高均值170标准差10
  - **为什么正态分布这么重要**：中心极限定理→不管原始数据什么形状→样本均值的分布趋近正态→所以t检验和置信区间依赖正态假设
- **指数分布 Exponential(λ)**：
  - 场景：等待时间、两个独立随机事件之间的间隔。"下一辆车多久到""下一次系统故障多久后发生"
  - 特征：右偏、均值=1/λ、无记忆性。"已经等了10分钟→剩下的等待时间分布和刚开始的时候一样"
  - Python：`np.random.exponential(scale=5, size=10000)`→平均等待5分钟
- **均匀分布 Uniform(a, b)**：
  - 场景：每个值同等可能。"随机抽奖(1到100号等概率)""公交车每10分钟一班→等车时间均匀分布0-10分钟"
  - Python：`np.random.uniform(low=0, high=10, size=10000)`
- **幂律分布(Pareto)**：
  - 场景：80-20法则。20%用户贡献80%销售额、少数城市贡献大部分订单
  - 特征：严重右偏、长尾、**均值被极端值严重拉偏→没有太大意义**、中位数更可靠
  - Python：`np.random.pareto(a=2, size=10000)`→大部分数据在0-2，少量在100+
  - **数据分析关键认知**：现实世界的金额/粉丝数/订单量大多服从幂律→直接用均值分析=被极端值误导→必须看中位数和分位数

**4. 怎么判断"我的数据像哪种分布"**
- 画直方图→看形状
  - 对称钟形→可能是正态
  - 严重右偏/长尾→可能是幂律/指数/对数正态
  - 均匀分布→可能离散化程度高→可能是类别计数
- 看描述统计→均值vs中位数
  - 均值≈中位数→对称→大概率正态/均匀
  - 均值>>中位数→严重右偏→大概率幂律/指数
- 看QQ图(分位数-分位数图)→对比实际数据和理论分布的分位数是否在一条直线上
- **陷阱1：不能只看直方图就下结论→样本量不够时直方图形状不稳定→多画几个bins+结合描述统计**
- **陷阱2：真实数据往往是多种分布的混合→如"整体用户消费"=普通用户(指数分布)+大客户(幂律分布)→分离后再各自分析**

**4.1 🔥分布拟合与检验——"我的数据真的服从正态分布吗？"（v6.1补全）**

前面学了"通过直方图和描述统计判断分布类型"——但这是目测，不够严谨。当分析结论依赖分布假设时（如t检验假设正态），你需要**定量的分布检验**。

**Q-Q图（分位数-分位数图）——最直观的分布诊断工具**
- 原理：把实际数据的分位数和理论分布的分位数画成散点图。如果数据服从该分布→点落在对角线上
- 比直方图好在哪：直方图对bins敏感（bins不同形状完全不同），Q-Q图没有bins问题
- 读法：①点在对角线上=服从 ②点偏离对角线=不服从。S形弯曲=实际数据比理论分布更尖峰或更扁。一端翘起=该方向有肥尾
```python
import scipy.stats as stats
import matplotlib.pyplot as plt

# 对"金额"做三种变换的Q-Q图
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# 原数据→通常偏离对角线（右偏）
stats.probplot(df['金额'].dropna(), dist="norm", plot=axes[0])
axes[0].set_title('原数据Q-Q图（大概率不服从正态）')

# log变换后→更接近对角线
stats.probplot(np.log1p(df['金额'].dropna()), dist="norm", plot=axes[1])
axes[1].set_title('Log变换后Q-Q图')

# Box-Cox变换后→最优（如果数据全正数）
fitted_lambda = stats.boxcox(df['金额'].dropna() + 1)[1]
stats.probplot(stats.boxcox(df['金额'].dropna() + 1, fitted_lambda), dist="norm", plot=axes[2])
axes[2].set_title(f'Box-Cox变换后Q-Q图 (λ={fitted_lambda:.2f})')
```

**定量检验——用数字判断（但不要盲信p值）**

| 检验 | 零假设H₀ | 特点 | 什么时候用 |
|------|---------|------|-----------|
| **Shapiro-Wilk** | 数据服从正态分布 | 功效最高，但只能测正态；样本量≤5000 | 小样本（<5000）的正态性检验 |
| **Kolmogorov-Smirnov (KS)** | 数据服从指定分布 | 可检验任何分布（不只正态）；对中心差异敏感、对尾部差异不敏感 | 检验"数据是否服从某已知分布" |
| **Anderson-Darling** | 数据服从指定分布 | 对尾部差异更敏感（比KS更关注分布的尾部匹配）；推荐替代KS | 分布尾部很重要时（如金融风控关注极端值）|
| **D'Agostino K²** | 数据服从正态分布 | 结合偏度+峰度检验；大样本适用 | 快速正态性初筛（`stats.normaltest()`）|

```python
# 正态性检验实操
data = df['金额'].dropna()

# Shapiro-Wilk（最常用的小样本正态检验）
stat, p = stats.shapiro(data[:5000])  # 最多5000条
print(f"Shapiro-Wilk: p={p:.4f} → {'服从正态' if p>0.05 else '不服从正态'}")

# D'Agostino K²（不限样本量）
stat, p = stats.normaltest(data)
print(f"D'Agostino: p={p:.4f} → {'服从正态' if p>0.05 else '不服从正态'}")

# KS检验（检验是否服从指定分布）
mu, sigma = stats.norm.fit(data)  # 先拟合参数
stat, p = stats.kstest(data, 'norm', args=(mu, sigma))
print(f"KS检验: p={p:.4f} → {'服从N({mu:.1f},{sigma:.1f})' if p>0.05 else '不服从'}")

# Anderson-Darling（对尾部更敏感）
result = stats.anderson(data, dist='norm')
print(f"Anderson-Darling: statistic={result.statistic:.3f}")
for i, cv in enumerate(result.critical_values):
    sig_level = result.significance_level[i]
    print(f"  显著性水平 {sig_level}%: 临界值={cv:.3f} → "
          f"{'拒绝正态' if result.statistic > cv else '不拒绝正态'}")
```

**分布拟合——"用哪个已知分布近似我的数据"**
```python
# 自动拟合多种分布并选最优（使用scipy的fit方法）
distributions = ['norm', 'lognorm', 'gamma', 'expon', 'weibull_min']
best_fit = {'name': None, 'ks_stat': np.inf, 'params': None}

for dist_name in distributions:
    dist = getattr(stats, dist_name)
    params = dist.fit(data)         # MLE估计参数
    ks_stat, p = stats.kstest(data, dist_name, args=params)
    
    if ks_stat < best_fit['ks_stat']:
        best_fit = {'name': dist_name, 'ks_stat': ks_stat, 'params': params}

print(f"最佳拟合: {best_fit['name']} (KS统计量={best_fit['ks_stat']:.4f})")
```

- **陷阱1：大样本下所有正态检验都显著→因为现实中几乎没有"完美正态"的数据→大样本(>1万)时正态检验的实用意义不大**→更关注Q-Q图的偏离程度+偏度值
- **陷阱2：KS检验假设"分布参数已知"→如果参数是从数据估计的（而非理论值）→KS的p值不准确**→应使用专门的正态检验(Shapiro/D'Agostino)

## W5D3：描述统计 + EDA

### 能力簇
**用数字描述数据** —— 掌握中心趋势、离散度、分布形状的完整描述，学会探索性数据分析(EDA)的系统流程

### 为什么今天重要
拿到新数据后第一件事就是EDA——这不只是跑`df.describe()`，而是系统地用数字和图表回答"这个数据长什么样"。均值被拉偏了→你后面所有基于均值的分析都有偏差。方差巨大→你的数据不稳定→需要先分层。今天学的每个统计量都对应一个业务判断。

### 具体知识清单

**1. 中心趋势——"典型值"是什么。不同分布下该看哪个**
- **均值(Mean)**：Σx/n。所有值加起来除以个数。受极端值影响极大
- **中位数(Median)**：排序后正中间的值。不受极端值影响
- **众数(Mode)**：出现最多的值。类别数据唯一可用的中心趋势
- **截尾均值(Trimmed Mean)**：去掉头尾x%后再算均值。折中方案——比均值稳健，比中位数用了更多信息
- **选择决策**：偏态分布(收入/销售额)→中位数。对称分布(身高/测量)→均值。类别数据(城市/品类)→众数
- **均值被极端值拉偏的实战例子**：公司10个员工→9个薪资5K,1个CEO薪资100K→均值=14.5K→"我们公司平均薪资14.5K"→虚假繁荣→中位数=5K→真实水平
- **陷阱：只看均值不看分布→完全被误导。CEO工资把"平均工资"拉高三倍→不代表普通员工的实际水平**

**2. 离散度——"数据有多散"。同样均值的数据，波动可能差10倍**
- **方差Var=Σ(x-μ)²/n**：平均偏离程度。单位是原单位的平方→不好直接理解
- **标准差Std=√Var**：单位回到原单位。约68%(正态下)数据在均值±1std范围
- **IQR(四分位距)=Q3-Q1**：中间50%数据的范围。不受极端值影响
- **极差Range=Max-Min**：最不稳健(受极端值影响最大)
- **变异系数CV=σ/μ**：标准差÷均值。**比较不同量纲的数据时用**(比较"身高波动大还是体重波动大"→不能用σ直接比→用CV)
- **为什么离散度重要**：两个品类→A品类月均销售100万±5万(稳)→B品类月均销售100万±50万(波动大)→进货策略完全不同。A可以稳定备货，B需要灵活调整

**3. 分布形状——"不只是均值和波动，还要看偏和尖"**
- **偏度(Skewness)**：分布的左右不对称程度
  - 偏度>0(右偏/正偏)：右尾长。大部分数据在左边，少数大值在右边拖出长尾。如收入/房价/销售额。**均值>中位数**(均值被长尾拉高)
  - 偏度<0(左偏/负偏)：左尾长。大部分数据在右边。如考试分数(满分100,大部分80-100)。**均值<中位数**
  - 偏度≈0：对称。如正态分布。均值≈中位数
  - **怎么理解和记忆**：偏度正负=长尾在哪边。右偏=右边有长尾=右边有极端大值
- **峰度(Kurtosis)**：分布的尖峭程度
  - 峰度>3(尖峰/肥尾)：比正态更尖+尾部更厚(极端值比正态多)。如股市收益率→"黑天鹅"比正态预测的多
  - 峰度≈3：和正态差不多
  - 峰度<3(扁平)：比正态更扁+尾部更薄(极端值更少)。如均匀分布
- **为什么偏度和峰度重要**：单纯看均值+方差不够。两份数据均值一样/方差一样→一个正态(大部分在均值附近)→一个右偏肥尾(有小概率出大事)→用错分析方法结论完全不同

**4. 箱线图解读——一张图看懂分布五要素**
- 五个数字：最小值(须子下界)/Q1(25%分位)/中位数(50%分位)/Q3(75%分位)/最大值(须子上界)
- 箱体=Q1到Q3(中间50%数据)。箱体中间线=中位数
- 须子=1.5×IQR范围内的最远数据点。须子外=异常值(小圆点)
- 多组箱线图并排→一眼对比不同组(城市/品类)的分布差异
- **怎么读箱线图**：①箱体高矮=IQR大小→离散度 ②中位数位置→偏度(中位数离Q1近=右偏) ③须子长短→极端值范围 ④须子外圆点→有多少异常值
- **陷阱：箱线图的异常值标准是1.5×IQR→不是所有"异常值"都是错的→可能是真实的大客户**

**5. EDA(探索性数据分析)——拿到新数据后的系统流程**
1. **结构初探**：shape/dtypes/info→看规模/类型/缺失
2. **数值列描述**：describe→每个数值列的8个统计量→同时看均值/中位数差距(判断偏度)/min-max范围/标准差大小
3. **类别列分布**：value_counts(normalize=True)→每个值的占比
4. **分布可视化**：直方图(numerical)+countplot(categorical)→分布形状
5. **异常值检查**：boxplot→找离群点
6. **缺失诊断**：isna+missingno→缺失比例和模式
7. **关联初探**：两两散点图/相关性矩阵→发现变量间关系
8. **总结报告**：写200字"我发现的数据特征+需要注意的问题+下一步分析方向"

## W5D4：推断统计（上）——从样本到总体

### 能力簇
**推断的数学基础** —— 理解CLT、标准误、置信区间、bootstrap。今天全部用Python模拟验证，不盲信理论

### 为什么今天重要
描述统计(D3)是"拍照片"——描述你手里的样本长什么样。推断统计是"根据照片推断这个人的身高"——用你手里的样本来推断总体。AB实验的本质就是推断统计：用实验组和对照组的样本数据→推断"策略在总体中是否真的有效"。今天不理解CLT和置信区间→W6的样本量计算和p值直接懵。

### 具体知识清单

**1. 抽样分布——"样本统计量本身也是随机变量"**
- 总体：你关心的所有对象。如"全国滴滴用户的平均行程金额"——μ是真实值，但不可知
- 样本：你实际能观测到的一部分。如"随机抽1000个用户的行程金额"——x̄是算出来的
- 关键认知：**每次抽1000个不同的用户→算出的x̄都不同→所以x̄本身也是一个随机变量→也有它的分布→叫"抽样分布"**
- Python模拟验证：从一个已知总体(μ=25.5元)→反复抽1000个样本→算x̄→重复10000次→得到10000个x̄→画直方图→**这些x̄围绕μ=25.5形成分布**

**2. 标准误 vs 标准差——两者名字像但回答完全不同的问题**
- **标准差σ**(个体差异)："一个个用户之间的行程金额差多少"。σ大→用户之间的消费差异大
- **标准误SE=σ/√n**(对均值的把握)："你对均值的估计有多精确"。n大→SE小→你对均值更确定了
- **直观理解**：标准差描述个体的波动(我们改不了)。标准误描述我们对均值的不确定度(多抽样本可以减小)
- 公式直觉：SE=σ/√n。σ越大(个体差异大)→均值越不确定→SE大。n越大(样本越多)→均值越确定→SE小
- **为什么÷√n不是÷n**：因为"独立观测的方差可加，但标准差不是线性"。n个独立观测的均值的方差=σ²/n→标准差=σ/√n
- Python模拟验证：从一个总体→分别抽n=10/30/100/300/1000→各重复5000次→看样本均值分布→n越大分布越窄→验证SE=σ/√n

**3. 中心极限定理(CLT)——"不管原数据什么形状，样本均值的分布趋近正态"**
- **这是整个推断统计和AB实验的数学基石。所有t检验/置信区间/样本量计算的正当性都在CLT**
- CLT说：从**任意**分布(正态/指数/幂律/均匀都可!)的总体中抽样→每次抽n个→算均值→重复很多次→这些**均值的分布**趋近正态分布→n越大越正态
- 经验法则：n≥30→样本均值分布≈正态(即使原始数据严重非正态!)
- Python模拟验证——亲眼看到CLT的"魔法"：
  ```python
  # 从一个严重右偏的指数分布(λ=0.1,极不正态!)中→抽样→看均值分布
  population = np.random.exponential(scale=10, size=1000000)  # 总体:严重右偏
  sample_means = []
  for _ in range(5000):
      sample = np.random.choice(population, size=30)  # 每次抽30个
      sample_means.append(sample.mean())
  # 画直方图→均值分布≈正态！(即使原始数据是指数)
  # 再试n=100→更正态！n=5→还不够正态(CLT要求一定n)
  ```
- **CLT的三个条件**：①独立抽样(每个观测独立) ②样本量够大(n≥30) ③总体方差有限(不能是柯西分布那种方差无穷的)
- **为什么CLT这么重要**：因为CLT保证了"不管你数据什么形状→样本均值≈正态分布→你可以用基于正态的方法(t检验/置信区间)"
- **陷阱1：CLT说的是"样本均值的分布"趋近正态，不是说"原始数据"趋近正态！你原始数据该右偏还是右偏**
- **陷阱2：n≥30是经验法则。如果原始数据严重偏态→可能需要n>100。如果原始数据已经正态→n=5也行**

**4. 置信区间——"我95%确定真实值在[X, Y]之间"**
- 点估计：x̄(样本均值)。"平均行程金额=25.5元"
- 95%置信区间：[x̄-1.96×SE, x̄+1.96×SE]。"我95%确定真实均值在[24.3, 26.7]之间"
- 1.96的来历：标准正态分布的97.5%分位点(P(|Z|<1.96)=0.95)。查表可得
- CI的宽度=2×1.96×SE=2×1.96×σ/√n→n增加→CI变窄。想CI宽度减半→n增加4倍(平方关系!)
- **CI的正确解读(面试高频题)**："如果重复抽样100次，每次算一个95%CI，大约95次的CI包含真实μ"。**不能说"真实μ有95%的概率落在[24.3,26.7]这个区间里"**(μ是固定值不是随机变量!)
- Python模拟验证：从一个已知μ的总体→反复抽1000次→每次算95%CI→统计包含真实μ的比例→看是否≈95%
- **n对CI的影响**：直观感受→`n=10→CI宽`/`n=100→CI窄`/`n=1000→CI更窄`→"想更精确→需要更多样本→样本量翻4倍→精确度翻倍"

**5. Bootstrap——不需要假设正态分布,用计算力替代数学假设**
- 问题：不知道抽样分布→没法算SE→没法算CI→怎么办？
- Bootstrap解法：从样本中**有放回地**抽很多次(每次都抽n个)→算很多个x̄→这些x̄的分布≈抽样分布→计算CI
- 操作：`for _ in range(10000): bootstrap_sample = np.random.choice(sample, size=n, replace=True) → bootstrap_means.append(bootstrap_sample.mean()) → CI = np.percentile(bootstrap_means, [2.5, 97.5])`
- 为什么有效：样本是总体的proxy→有放回地从样本中抽=模拟从总体中抽→bootstrap分布≈抽样分布
- 什么时候用bootstrap：①不知道总体分布→不能用公式算SE。②样本量不够CLT。③想算非均值的CI(如中位数/相关系数)。④想验证公式法CI是否可靠
- **陷阱1：Bootstrap假设样本是总体的良好代表→样本有偏→bootstrap也有偏**
- **陷阱2：Bootstrap在小样本下效果不好→n<30时慎用**

## W5D5：推断统计（下）——假设检验与p值

### 能力簇
**用数据做决策** —— 理解假设检验的完整逻辑，彻底搞懂p值(不是"有效的概率"!)

### 为什么今天重要
p值是数据分析师每天都会用到、但最常被误解的统计概念。面试100%会问"p值是什么"。工作中p值被滥用(只看p<0.05不看效应量、p-hacking等)。今天把p值的5个常见误解逐个击破，用Python模拟让你看到"两组完全一样的数据→p>0.05"和"两组有微小真实差异+大数据量→p<0.0001"。理解这个=真正理解AB实验。

### 具体知识清单

**1. 假设检验框架——用无罪推定的逻辑做决策**
- H₀(零假设)：现状。"策略无效""两组无差异"。**H₀永远是"无效果/无差异"，不是你想证明的**
- H₁(备择假设)：你试图证明的。"策略有效""两组有差异"
- α(显著性水平)：你愿意容忍的"冤枉好人"的概率。通常α=0.05→每20次有一次冤枉
- 检验逻辑：假设H₀为真(策略无效)→在H₀下算"观测到你这样的数据(或更极端)的概率"→这个概率=p值→如果p<α→H₀下的数据太"奇怪"了→拒绝H₀→认为策略有效
- 类比(无罪推定)：H₀=嫌疑人无罪。观测数据=证据。p值=在"嫌疑人无辜"的前提下→出现这么强证据的概率。p很小→证据太强→"碰巧出现"太不可能→嫌疑人大概率有罪
- **Python模拟——直观感受假设检验**：
  ```python
  # H₀:两组无差异(来自同一个分布)
  group_A = np.random.normal(100, 15, 1000)  # 均值100
  group_B = np.random.normal(100, 15, 1000)  # 均值100→真的无差异!
  t_stat, p = stats.ttest_ind(group_A, group_B)
  print(f"p={p:.4f}")  # p>0.05→不能拒绝H₀→正确!(确实无差异)
  
  # 如果B组真的提高了5→再检验
  group_B_real = np.random.normal(105, 15, 1000)  # B组均值105→真的提高了!
  t_stat, p = stats.ttest_ind(group_A, group_B_real)
  print(f"p={p:.4f}")  # p<0.05→拒绝H₀→正确!(真的有差异)
  ```

**2. α/β/两类错误——做决策不可能不犯错,但你可以控制犯错的类型和概率**
- **第一类错误(Type I Error, α)**：H₀真(策略真的无效)但拒绝了H₀(说策略有效)→**"假阳性"。冤枉好人**
  - α=0.05→每检验20个无效策略,平均有1个被"假阳性"为有效
  - 控制：设定较小的α。α越小→越不容易"冤枉"。但代价是β变大→需要更大样本量
- **第二类错误(Type II Error, β)**：H₀假(策略真的有效)但没拒绝H₀→**"假阴性"。放过坏人**
  - β=0.2→每检验10个有效策略,平均有2个被"假阴性"为无效→错过了好策略
- **检验功效(Power)=1-β**：策略真的有效时,能检测出来的概率
  - Power=0.8→10个真有效策略能检出8个,2个被漏掉
  - Power受四个因素影响：n越大→Power越高。α越大→Power越高。误差越小→Power越高。真实效果越大→Power越高
- **α和β的trade-off**：α和β不能同时减小。减小α(更不容易冤枉)→β增大(更容易放过)→需要更大样本量来同时控制两者
- **为什么用α=0.05和β=0.2(别问为什么,这是约定俗成)**：样本量公式里Zα=1.96(α=0.05),Zβ=0.84(β=0.2)

**3. 🔥 p值——数据分析师最常被问到、也最常被误解的概念。必须彻底理解**
- **p值的正确定义**：p = P(观测到当前数据或更极端的数据 | H₀为真)。假设策略无效→在这种假设下,观测到"实验组和对照组的差异≥你观测到的差异"的概率
- **p值不是**（5大常见误解，面试逐个考）：
  1. ❌p值不是"H₀为真的概率"。p=P(数据|H₀),不是P(H₀|数据)。方向反了! P(H₀|数据)需要贝叶斯,不能用p值
  2. ❌p值不是"策略有效的概率"。p小≠策略一定有效。p小=如果无效,这数据太"奇怪"
  3. ❌p值不是"效应的大小"。p<0.0001≠效应很大。大数据量下微小差异也p很小。效应量才是"多大"
  4. ❌p<0.05不意味着"你的业务假设对了"。p只告诉你"两组有差异",不能说"差异是你的策略造成的"(需要随机化+SUTVA)
  5. ❌p>0.05不意味着"没差异"。p>0.05=不能拒绝H₀,不能排除"有微小差异但灵敏度不够"→需要看MDE(W6)
- **Python模拟——固定效应量,逐渐增大n→p值越来越小但效应量不变。直观理解p值和效应量的关系**：
  ```python
  effect = 1  # 真实差异只有1(很小!)
  for n in [30, 100, 300, 1000, 3000, 10000]:
      A = np.random.normal(100, 15, n)
      B = np.random.normal(100+effect, 15, n)
      _, p = stats.ttest_ind(A, B)
      cohens_d = (B.mean()-A.mean()) / np.sqrt((A.var()+B.var())/2)
      print(f"n={n:6d}: p={p:.4f}, Cohen's d={cohens_d:.3f}")
  # 结果: n=30→p=0.68, d=1.1 / n=100→p=0.28, d=1.0 / n=1000→p=0.001, d=1.0 / n=10000→p<0.0001, d=1.0
  # p值随n变小,但效应量d≈1不变!
  ```

**4. 效应量——p值告诉你"有没有差异"，效应量告诉你"差异有多大"**
- Cohen's d(均值类)：d = (x̄₁-x̄₂) / pooled_std。d=0.2小/d=0.5中/d=0.8大
- 相对提升%(比例类)：(p₁-p₂)/p₂×100%。"实验组转化率比对照组高15%"
- 为什么只看p值危险：大数据量下0.01%的微小差异也有p<0.0001→但这个差异在业务上毫无意义
- **面试金句**："p值告诉你'差异是否可能是随机波动引起的',效应量告诉你'这个差异在业务上值不值得做'。两者必须同时汇报"

**5. t检验——最常用的均值差异检验**
- 独立样本t检验(等方差假设)：`stats.ttest_ind(A, B)`。两组独立、方差相等→标准t检验
- Welch's t检验(不等方差)：`stats.ttest_ind(A, B, equal_var=False)`。两组方差可能不→**更通用、更稳健**
- 配对t检验：`stats.ttest_rel(before, after)`。同一批用户实验前后的对比
- **Welch's t是更安全的选择**：当两组方差相等→Welch's和标准t结果一致。当方差不等→标准t的p值有偏→Welch's才是正确的。不确定时→**永远用Welch's**
- 前提检查：①独立性(实验组和对照组不相互影响)→W7网络效应 ②正态性(大样本→CLT保证)→不需要严格正态 ③方差齐性(用Levene检验或直接Welch's绕过)

**6. 🔥非参数检验——数据不服从正态分布怎么办？（v6.1新增）**

W5前5天学的所有检验（t检验、z检验、F检验）都依赖一个假设：数据近似服从正态分布。但真实数据经常不服从正态分布——充值额（极少数人充很多）、阅读时长（幂律分布）、GMV（偏态）。这时候用t检验→p值不准确。非参数检验不假设数据分布→更稳健。

**6.1 Mann-Whitney U检验——替代独立样本t检验**
- 什么时候用：两组数据→想比较它们的"中心位置"是否有差异→数据不服从正态分布/有极端值/是顺序数据
- 和t检验的区别：t检验比较均值（mean）→受极端值影响大。Mann-Whitney比较"中位数"或"排名"→相当于是"如果把两组数据混在一起排序，一组的排名系统性地高于另一组吗？"→不受极端值影响
- `scipy.stats.mannwhitneyu(A, B, alternative='two-sided')` → 返回U统计量和p值
- **面试常问**："什么时候用Mann-Whitney而不是t检验？"→"当数据严重偏态（如充值额/用户时长）或样本量较小且不确定是否正态时。Mann-Whitney对分布假设更少→更稳健。代价是统计功效（Power）略低于t检验（当数据确实正态时）"
- **Python实操——对比t检验和Mann-Whitney在偏态数据下的表现**：
  ```python
  from scipy import stats
  # 构造偏态数据（如充值额——大部分0-100,少数>10000）
  np.random.seed(42)
  A = np.random.exponential(50, 100)   # 均值50,高度右偏
  B = np.random.exponential(55, 100)   # 均值55,右偏。真实差异10%
  # t检验→被极端值拉偏→可能不显著
  t_stat, t_p = stats.ttest_ind(A, B, equal_var=False)
  # Mann-Whitney→基于排名→受极端值影响小→更可能检出差
  u_stat, u_p = stats.mannwhitneyu(A, B, alternative='two-sided')
  print(f"t检验p={t_p:.4f}, Mann-Whitney p={u_p:.4f}")
  # 在严重偏态下，Mann-Whitney的p值通常比t检验更可靠
  ```

**6.2 卡方独立性检验——判断两个类别变量是否相关**
- 什么时候用：两个变量都是类别（如"城市×会员等级""性别×是否购买""实验组×是否转化"）
- 检验逻辑：如果两个变量独立→期望频数=行合计×列合计/总样本量。比较"实际频数"和"期望频数"的差异→差异越大→越可能不是独立的
- `stats.chi2_contingency(pd.crosstab(df['城市'], df['会员等级']))` → 返回卡方值/p值/自由度/期望频数表
- **入职场景**：PM说"北京的用户更倾向于买数码产品"→你跑一个卡方检验→城市×品类→p=0.003→确实存在关联→然后再深入看"北京在数码品类的实际购买高于期望值→北京确实偏好数码"
- **陷阱**：卡方检验要求每个格子的期望频数≥5。如果大部分格子期望频数<5→考虑合并低频类别或用Fisher精确检验

**6.3 Kruskal-Wallis检验——替代ANOVA（三组及以上）**
- 什么时候用：三组及以上的数据→比较它们是否来自同一分布→数据不服从正态
- `stats.kruskal(A, B, C)` → 三组及以上→返回H统计量和p值
- 和ANOVA的关系：ANOVA检验"多组均值是否相等"→假设正态+方差齐性。Kruskal-Wallis检验"多组数据是否来自同一分布"→不假设分布→更稳健

**6.4 参数vs非参数——选择决策表**
| 场景 | 参数检验 | 非参数替代 | 选哪个 |
|------|---------|-----------|--------|
| 两组均值比较，数据近似正态 | 独立t检验 | Mann-Whitney U | t检验（Power更高） |
| 两组均值比较，数据偏态/有极端值 | — | Mann-Whitney U | **Mann-Whitney**（不受极端值影响） |
| 两组配对比较 | 配对t检验 | Wilcoxon符号秩检验 | 同t检验的决策逻辑 |
| 三组及以上均值比较 | ANOVA | Kruskal-Wallis | 同t/M-W的决策逻辑 |
| 两个类别变量是否关联 | — | 卡方独立性检验 | 卡方（没有参数替代） |
| 大样本（>1000） | t检验 | — | **t检验**（CLT保证均值近似正态，即使原始数据偏态） |

**核心原则**：大样本+不在乎极端值→t检验OK（CLT保证）。小样本或严重偏态→非参数更稳健。不确定时→两种都跑→如果结论一致→报告哪个都行。如果结论不一致→深入分析"为什么"（极端值？分布形状？）。

### 必须覆盖的陷阱
1. **p值不是H₀为真的概率**：方向反了! p=P(数据|H₀)≠P(H₀|数据)
2. **p<0.05≠有效**：大样本下微小差异也显著→必须同时汇报效应量
3. **p>0.05≠没差异**：可能灵敏度不够→要看MDE和样本量
4. **α=0.05不是魔法数字**：高风险决策应该降低α(0.01),探索性分析可以放松
5. **不确定等方差→永远用Welch's t**(更通用更稳健)

### 具体知识清单

**1. 🔥辛普森悖论——分组趋势和总体趋势完全相反,可以真实发生!**
- 经典案例：某大学→整体录取率男>女→但分专业看,每个专业录取率女>男→为什么?因为女性更多申请了录取率低的专业(如医学),男性更多申请了录取率高的专业(如工程)
- **Python完整重现（可直接运行）**：
  ```python
  import pandas as pd
  import numpy as np
  
  # 构造大学录取数据
  np.random.seed(42)
  
  # 专业A：录取率80%（容易进）——男生申请多
  # 专业B：录取率30%（难进）——女生申请多
  major_A_male = pd.DataFrame({'性别': '男', '专业': 'A', 
                                '录取': np.random.binomial(1, 0.8, 800)})
  major_A_female = pd.DataFrame({'性别': '女', '专业': 'A', 
                                  '录取': np.random.binomial(1, 0.85, 200)})
  major_B_male = pd.DataFrame({'性别': '男', '专业': 'B', 
                                '录取': np.random.binomial(1, 0.3, 200)})
  major_B_female = pd.DataFrame({'性别': '女', '专业': 'B', 
                                  '录取': np.random.binomial(1, 0.35, 800)})
  
  df = pd.concat([major_A_male, major_A_female, major_B_male, major_B_female])
  
  # 整体录取率：男生更高！
  print("=== 整体录取率 ===")
  print(df.groupby('性别')['录取'].mean())
  # 性别
  # 女    0.400   ← 女整体40%
  # 男    0.700   ← 男整体70% → 结论：男性录取率更高？
  
  # 分专业录取率：每个专业女生都更高！
  print("\n=== 分专业录取率 ===")
  print(df.groupby(['专业', '性别'])['录取'].mean().unstack())
  # 性别     女      男
  # 专业
  # A     0.850  0.800  ← 每个专业女>男
  # B     0.350  0.300  ← 每个专业女>男
  
  # 解释：女性集中在录取率低的B专业（800人），男性集中在录取率高的A专业（800人）
  print("\n=== 申请人数分布（混淆变量） ===")
  print(df.groupby(['专业', '性别']).size().unstack())
  # 性别    女    男
  # 专业
  # A     200   800  ← 男在A专业人多
  # B     800   200  ← 女在B专业人多
  
  # 这才是真相：专业=混淆变量，同时影响"性别分布"和"录取率"
  # → 分专业看（控制混淆后），女性录取率更高
  # → 整体看（不控制混淆），男性录取率更高（因为男性"选择"了容易进的专业）
  ```
- 危害：看整体数据→"男生录取率更高→可能存在性别歧视"。分专业看→"每个专业女生录取率更高→可能对女性有优待"。**两个结论完全相反→但都是正确计算的数据!**
- 怎么避免：永远不要只看汇总数据。按关键维度拆开看→确认趋势是否一致。**分析中加入混淆变量检查**：是否有第三个变量同时在影响X和Y？
- **AB实验的辛普森悖论**：实验组整体转化率提升→但分渠道看→每个渠道转化率都下降。为什么?因为实验组里高转化率渠道的用户占比变了(流量分配变化)。分析AB实验必须分群看
- **数据分析中的检测方法**：
  ```python
  # 检测辛普森悖论：分组与整体的相关系数符号是否翻转
  overall_corr = df['feature'].corr(df['target'])
  group_corrs = df.groupby('group')[['feature', 'target']].corr().iloc[0::2, -1]
  # 如果overall_corr与各组corr符号不一致 → 大概率是辛普森悖论
  ```

**2. 幸存者偏差——只看到"活下来的"，看不到"死了的"**
- 经典案例：二战飞机→分析返航飞机的弹孔→机翼弹孔最多→建议加强机翼装甲。Abraham Wald说：不对!发动机弹孔少的飞机都没返航(被击中发动机就坠毁了)→应该加强发动机装甲
- 现代案例：我们只看到成功创业者的故事→以为"辍学+车库+坚持=成功"。看不到99%同样这么做了但失败的人
- 数据分析中的应用：分析"高留存用户"的特征→只能看到还留着的用户→流失用户的行为看不到→幸存者偏差→高留存用户的特征≠造成留存的原因
- 怎么避免：分析应该包含"失败样本"。做用户流失分析时→同时分析"留下的"和"走了的"

**3. p-hacking——数据科学家最爱犯的错误(可能不自知)**
- 什么是p-hacking：反复尝试不同的子组/指标/分析方法→直到找到p<0.05→然后只汇报那个"显著"的结果
- 常见形式：①试了10个指标→汇报第3个(p<0.05)②删了几个"异常值"→p显著了③把实验数据按子组分别看→找到p<0.05的子组④"我们还没看到第14天→等够了数据再说"
- 为什么危险：反复尝试=多重检验→假阳性率远大于α。查20个指标→至少1假显著概率=1-(0.95)²⁰≈64%
- 怎么避免：①事前注册分析计划(指定指标/方法/子组)②多重检验校正③诚实汇报所有尝试过的分析

**4. 多重检验——查的指标越多,越可能"偶然显著"**
- 问题：α=0.05→每次检验5%假阳性。查m个独立指标→至少1假显著概率=1-(1-α)^m
  - 查5个指标→至少1假显著≈23%
  - 查10个指标→至少1假显著≈40%
  - 查20个指标→至少1假显著≈64%
  - 查100个指标→至少1假显著≈99.4%
- **Bonferroni校正**(控制FWER,家庭错误率)：α/m。如查10个指标→新α=0.005→很保守(容易β变大→放过真效果)
- **BH(Benjamini-Hochberg)校正**(控制FDR,错误发现率)：允许少量假阳性,提高Power。互联网行业更推荐
  - 操作：①所有p值从小到大排序②第i小的p值和α×i/m比较③找到最大的满足p_i≤α×i/m的i④前i个为显著
- 选择：Bonferroni→不允许一个假阳性时用(医药/安全)。BH→允许少量假阳性但想提高检出率时用(互联网/探索性分析)

**7. 🔥相关性度量补全——不仅仅是Pearson（v6.1补全）**

W5D3学了"关联初探（两两散点图/相关性矩阵）"——但那是探索阶段的。当你的分析涉及"哪个特征对预测目标最重要"时，需要互补使用多种关联度量。

**Pearson vs Spearman vs Kendall——选哪个取决于数据形态**

| 系数 | 衡量什么 | 数值范围 | 对异常值 | 适用条件 |
|------|---------|---------|---------|---------|
| Pearson r | 线性相关程度 | [-1, 1] | 非常敏感 | 两个连续变量+线性关系+无极端值 |
| Spearman ρ | 单调相关（序相关） | [-1, 1] | 较鲁棒 | 任何单调关系（含非线性）+可容忍异常值 |
| Kendall τ | 一致对比例（序相关） | [-1, 1] | 最鲁棒 | 小样本+序数数据+需要更稳健的估计 |

```python
from scipy.stats import pearsonr, spearmanr, kendalltau

# 三个系数对比
r, p_r = pearsonr(df['收入'], df['消费'])
rho, p_s = spearmanr(df['收入'], df['消费'])
tau, p_k = kendalltau(df['收入'], df['消费'])

# 如果三个值差别很大→数据可能有极端值或非线性关系
print(f"Pearson r={r:.3f}, Spearman ρ={rho:.3f}, Kendall τ={tau:.3f}")
# r≈ρ≈τ → 大概率线性关系+无极端值
# r<<ρ≈τ → 存在非线性单调关系或极端值拉低了Pearson
```

**Cramér's V——分类变量×分类变量的关联强度**
- 这是列联表卡方检验的效应量版本。卡方检验告诉你"两个变量是否独立"（p值），Cramér's V告诉你"关联有多强"（0~1）
- 为什么需要：p<0.001只说明"确实有关联"→不说明关联多强。样本量大时极弱的关联也p<0.001
```python
import numpy as np
from scipy.stats import chi2_contingency

def cramers_v(confusion_matrix):
    """0=完全独立, 0.1=弱关联, 0.3=中等关联, 0.5+=强关联"""
    chi2 = chi2_contingency(confusion_matrix)[0]
    n = confusion_matrix.sum().sum()
    min_dim = min(confusion_matrix.shape[0], confusion_matrix.shape[1]) - 1
    return np.sqrt(chi2 / (n * min_dim)) if min_dim > 0 and n > 0 else 0

# 使用
contingency_table = pd.crosstab(df['城市'], df['购买品类'])
v = cramers_v(contingency_table)
print(f"城市×购买品类的Cramér's V = {v:.3f} → {'强关联' if v>0.3 else '弱关联'}")
```

**互信息（Mutual Information）——捕获任意形式的依赖关系**
- **最大优势：能发现非线性关系**。相关性=0可能=无线性关系但有完美非线性关系（如y=x²→r≈0但互信息高）
- 用途：特征选择——"哪个特征对预测目标最有信息量"→互信息天然衡量"知道X后Y的熵减少了多少"
```python
from sklearn.feature_selection import mutual_info_classif, mutual_info_regression

# 分类目标（如"是否购买"）
mi_scores = mutual_info_classif(df[numeric_features], df['购买'], random_state=42)
mi_df = pd.Series(mi_scores, index=numeric_features).sort_values(ascending=False)

# 回归目标（如"消费金额"）
mi_scores_reg = mutual_info_regression(df[numeric_features], df['消费'], random_state=42)
```
- **面试考点**："为什么不用相关性而用互信息做特征选择？"→"相关性只能捕捉线性关系→y=x²的Pearson r≈0但互信息能捕捉。而且互信息对异常值更鲁棒"

**相关性度量选择决策表**：
```
两个连续变量+怀疑线性关系 → Pearson r
两个连续变量+怀疑有非线性/异常值 → Spearman ρ
两个类别变量 → Cramér's V
连续特征对类别目标的预测力 → Mutual Information (classification)
连续特征对连续目标的预测力 → Mutual Information (regression)
需要最稳健的序相关估计（小样本）→ Kendall τ
```

**陷阱：相关≠因果**。任何相关性系数都不区分"X→Y""Y→X""Z同时导致X和Y"→需要因果推断(W11)来区分

## 🔥 W5D6.5：时间序列分析——DA最常用的统计工具

### 能力簇
**理解"带时间的数据"** —— DA每天面对的数据90%带时间戳。GMV趋势、DAU波动、留存曲线、环比同比。今天学会：分解时间序列（趋势+季节+残差）、判断"这个波动是正常的还是异常的"、用简单的预测方法做预估。不要求成为时间序列专家——但面试和工作中遇到时序问题不能只会"画个折线图"。

### 为什么今天重要
W5前6天学了概率、分布、推断——所有方法都假设数据是"独立的"。但时间序列数据**天然不独立**——今天的数据和昨天的数据高度相关。如果你用普通t检验比较"这个月和上个月的DAU"→违反了独立性假设→p值不可靠。今天学会识别和处理这种"自相关"——这是DA工作中最常被忽视的统计陷阱之一。

### 具体知识清单

**1. 时间序列的四个组分——任何时序数据都可以拆成四部分**

- **趋势（Trend）**：长期的方向性变化。GMV每年20%增长→趋势向上。新款APP上线后DAU持续下降→趋势向下
- **季节性（Seasonality）**：固定周期内的规律波动。每天18-21点DAU最高（日内）、周末GMV低于工作日（周内）、春节前电商爆单（年内）
- **周期性（Cyclicity）**：非固定周期的波动。经济周期（几年一轮）、行业周期——和季节性的区别是周期长度不固定
- **残差（Residual/Noise）**：上述三部分都无法解释的随机波动。如果残差里还有规律→说明模型漏了东西
- **乘法 vs 加法分解**：`y = Trend + Seasonal + Residual`（加法，波动幅度不随趋势变化）vs `y = Trend × Seasonal × Residual`（乘法，趋势越大季节波动越大）。互联网DAU通常用加法，电商GMV通常用乘法（GMV从1亿涨到10亿→季节波动的绝对值也跟着涨）
- **Python实操——用statsmodels一行代码做分解**：
  ```python
  from statsmodels.tsa.seasonal import seasonal_decompose
  result = seasonal_decompose(df['dau'], model='additive', period=7)
  result.trend    # 趋势分量
  result.seasonal # 季节分量
  result.resid    # 残差分量
  result.plot()   # 四张图一目了然
  ```

**2. 平稳性——为什么它重要、怎么判断**

- **什么是平稳**：均值、方差、自相关结构不随时间变化。一个平稳的时间序列"看起来在任何时间段都差不多"
- **为什么需要平稳**：大多数时间序列模型（ARIMA等）假设数据平稳。不平稳→预测不可靠
- **怎么目测判断**：画图→均值明显上扬/下降（趋势）→不平稳。方差越来越大→不平稳。有明显的季节性波动→不平稳
- **白噪声**：均值为0、方差恒定、无任何自相关的序列。白噪声="无法预测"——如果残差是白噪声→模型已经把能解释的都解释了
- **入职场景**：PM说"DAU降了3%，是不是出问题了？"→你分解时序→发现3%的降幅在残差的正常波动范围内（<2个标准差）→不是异常，是随机波动。PM又说"都连降5天了！"→你检查自相关→连续5天同方向≠异常（正自相关下这是正常行为）

**3. 自相关（Autocorrelation）——时间序列的"DNA"**

- **定义**：今天的值和昨天的值的相关性 = lag-1自相关。和7天前的相关性 = lag-7自相关。`ACF(k)` = 序列和自身滞后k期的相关系数
- **为什么重要**：自相关=0→数据独立→标准统计方法可用。自相关>0（DAU今天高明天也高）→独立性假设违反→普通t检验/回归的p值不准确
- **部分自相关（PACF）**：lag-k的PACF = 移除1到k-1期的影响后，k期前的"纯粹"影响。用于确定AR模型的阶数（D5不需要深究，知道概念即可）
- **Python实操——ACF/PACF图**：
  ```python
  from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
  plot_acf(df['dau'], lags=30)   # 横轴=lag，纵轴=相关系数。蓝色区域=95%CI（不显著）
  plot_pacf(df['dau'], lags=30)
  # ACF缓慢衰减→不平稳（需要差分）。ACF在lag=7有一个尖峰→周季节性
  ```
- **面试考点**："为什么比较两个月的DAU不能用t检验？"→"因为DAU有自相关→违反了t检验的独立性假设→p值被低估→容易'发现'不存在的差异"

**4. 简单预测方法——不需要ML也能做有用的预测**

- **Naive预测**：明天=今天。简单但有时是最好的baseline。"下周DAU？"→"大概和这周一样"
- **季节性Naive**：明天=7天前。"下周一？"→"和上周一差不多"（互联网DAU常用！工作日和周末模式高度重复）
- **移动平均**：明天=过去N天的均值。`df['dau'].rolling(7).mean()`——平滑波动、看趋势
- **指数平滑**：给近期数据更高权重。`df['dau'].ewm(span=7).mean()`——比简单移动平均更敏感
- **prophet（Facebook开源）**：`from prophet import Prophet` → 几行代码做自动分解+预测+置信区间。DA快速出预测结果的首选工具
- **什么时候需要更复杂的方法**：①需要预测置信区间 ②有明显趋势+季节+节假日效应 ③需要解释"为什么是这个预测"

**5. DA日常工作中的时间序列场景**

- **异常检测**：分解时序→残差超过±3σ→可能是异常。不是"DAU跌了"就慌——先看是不是在正常波动范围内
- **环比 vs 同比**：环比=和上期比（日环比、周环比）。同比=和去年同期比。**面试常见陷阱**："这个月GMV环比跌了5%，正常吗？"→你得先看是不是每年这个月都跌（季节性）——如果是，同比才是正确的比较基准
- **基线预测**：给业务设定目标时——先算"如果什么都不做，下个月大概是多少"→季节性Naive或指数平滑做baseline→业务目标=baseline+增量
- **入职场景**：运营说"我们要做双十一活动，预估能涨多少GMV"→你先用过去3个月的GMV时序做baseline预测→"如果不做活动，双十一当天大概X亿。去年双十一活动涨了Y%。今年预计Z亿。"

**6. 入职后和PM沟通时间序列的"人话"**
