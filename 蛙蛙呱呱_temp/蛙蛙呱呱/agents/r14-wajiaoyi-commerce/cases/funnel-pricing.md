# SOP：单品漏斗诊断与定价决策（R14 蛙交易）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：退款率增幅]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 退款率增幅 | `本期退款率 − 基期退款率` | % | ≤ 1.0 | > 1.5 暂停活动 |
| 支付成功率 | `支付成功单 / 下单单` | % | ≥ 98 | < 95 回滚支付配置 |
| 客单价 | `GMV / 订单数` | 元 | 环比不降 3% | 降 > 3% 强制回滚 |

## 3. 分步诊断动作

1. 算漏斗：曝光→详情→加购→下单→支付，找最大损失节点。
2. 查价格：到手价是否破成本线，是否与竞品拉开。
3. 查履约：退款率与描述一致性、物流时效相关性。
4. 做定价实验：小流量 A/B，看转化与毛利双指标。
5. 出决策：定价方案 + 熔断线 + 灰度节奏。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 到手价低于成本线 | BLOCKER | 立即下架 |
| G2 | 退款率增幅 > 1.5% | BLOCKER | 暂停活动并排查 |
| G3 | 退款额度 > 原支付金额 | BLOCKER | 拒绝，退回补正 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
