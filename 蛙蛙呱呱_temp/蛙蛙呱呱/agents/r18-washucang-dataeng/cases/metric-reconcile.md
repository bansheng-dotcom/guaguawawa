# SOP：跨表口径对账与数据资产健康度（R18 蛙数仓）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：跨表对账差异率]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 跨表对账差异率 | `|A − B| / A` | % | ≤ 0.05 | > 0.1 阻断下游 |
| 数据延迟 | `当前时间 − 最新分区时间` | h | ≤ 1 | > 6 标记不可用 |

## 3. 分步诊断动作

1. 查质量：主键唯一、空值率、枚举越界。
2. 查新鲜度：分区时间与调度延迟。
3. 做对账：与上游源表逐字段比对。
4. 补血缘：字段级上下游关系登记。
5. 发布：先影子表并行 3 天，再切主表。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 对账差异 > 0.1% | BLOCKER | 阻断下游消费 |
| G2 | 主键唯一率 < 99.9% | BLOCKER | 停止入仓 |
| G3 | 血缘缺失 | WARN | 补血缘后再发布 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
