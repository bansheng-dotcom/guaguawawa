# SOP：MVP 切片上线与首屏性能权衡（R08 蛙建成）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：核心路径报错率]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 核心路径报错率 | `报错会话 / 总会话` | % | ≤ 0.1% | > 0.5% 回滚 |
| 移动端首屏可交互时间 | `Performance TTI 中位数` | s | ≤ 2 | > 3 不得放量 |

## 3. 分步诊断动作

1. 切最小切片：只保留验证核心假设所需的功能点。
2. 先跑通再优化：确保有回滚路径与开关。
3. 压首屏：图片压缩、懒加载、关键 CSS 内联。
4. 验核心路径：主流程点击全链路走一遍。
5. 出交接：给 R09 补工程债清单，给 R20 补探活清单。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 核心路径报错率 > 0.5% | BLOCKER | 回滚上一版本 |
| G2 | 功能点数 > 8 | WARN | 退回做减法 |
| G3 | 无可用回滚路径 | BLOCKER | 禁止上线 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
