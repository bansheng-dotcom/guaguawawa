# SOP：推荐模型增益评估与多样性守护（R19 蛙智模）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：推荐流多样性降幅]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 推荐流多样性降幅 | `(基期类目熵 − 本期) / 基期` | % | ≤ 5 | > 10 重新加权召回 |
| 实验组转化增益 | `实验组 CVR − 对照组 CVR` | % | > 0 且显著 | 显著负向即回滚 |

## 3. 分步诊断动作

1. 锁实验：参数、数据版本、评估集全部记录。
2. 算增益：A/B 显著性 + 置信区间。
3. 看护栏：多样性与负向指标一起看。
4. 小流量验证：5% → 20% → 50%。
5. 归档：模型卡 + 复现步骤 + 失效条件。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 多样性降幅 > 10% | BLOCKER | 重新加权召回，不得推全 |
| G2 | 实验参数未记录完整 | BLOCKER | 实验作废 |
| G3 | 对照组出现显著负向 | BLOCKER | 立即回滚 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
