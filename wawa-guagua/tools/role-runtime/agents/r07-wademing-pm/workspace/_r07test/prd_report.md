# 蛙得明 · PRD
> 新用户注册后 7 天内不知道如何创建第一个项目，导致激活率偏低

**结论**：给新用户分步引导，让其 10 分钟完成首个项目，目标 7 日激活率从 12% 提升到 20%

## 关键指标

| 指标 | 值 | 说明 |
|---|---|---|
| 门禁 | **PASS** | 8/8 门禁 |
| 北极星 | **7 日激活率** | NSM |
| 基线 | **12%** | 现状 |
| 目标 | **20%** | 预期 |

## 1. 问题与用户
> 要解决谁的真实问题？

- **问题：**新用户注册后 7 天内不知道如何创建第一个项目，导致激活率偏低
- **用户：**SaaS 试用新用户（注册后首次登录）

## 2. 价值主张与范围
> 怎么做、做到什么边界？

- **Before：**无引导，全凭新用户自己摸索
- **How：**分步新手引导
- **After：**10 分钟完成首个项目
- **P0：**分步引导流程
- **不做：**不做自动创建项目、不做个性化推荐

## 3. 指标与验收
> 怎么算成功？验收标准是什么？

- **北极星：**7 日激活率
- **基线 → 目标：**12% → 20%
- **护栏：**引导中途放弃率
| Given | When | Then |
|---|---|---|
| 新用户完成注册 | 首次进入工作台 | 出现分步引导 |

## 4. 承重假设
> 哪些假设不成立会让方案崩塌？

| 假设 | 验证方式 |
|---|---|
| 用户愿意跟随引导 | 小流量实验 |
| 引导不打断核心任务 | 可用性测试 |
| 引导能提升激活率 | A/B 实验 |
