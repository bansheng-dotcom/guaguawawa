来源沉淀：`bzwh321__article-director-public`（对外口径纪律）+ R11「对外发布需授权」红线。

## 一、方法论（什么时候用、核心口径）

广告与新闻稿是「对外口径」，比内部文案多一道法律与授权红线。
两个动作：
- `ad`：校验广告文案——headline/benefit/cta 三件套齐备，cta 在白名单，
  headline/benefit 无绝对化禁词（广告法红线）。
- `press`：校验新闻稿——headline/dateline/lead/body/boilerplate/contact 六段结构齐备，
  dateline 含城市与日期，导语无绝对化禁词。

核心红线：**绝对化用语一律拦截**。「最/第一/绝对/保证/百分百/100%有效/无副作用/
根治/国家级/顶级/全网最低」等广告法红线词，无论主观觉得多合理，命中即 FAIL。

## 二、可执行口径（公式 / 输出键 / 判读规则，与实现逐字对齐）

阈值外置：`pr.cta_types`（7 类）、`pr.ad_required`（3 字段）、
`pr.press_required`（6 字段）、`pr.ad_forbidden`（11 个红线词）。

**ad 校验规则**：
- headline/benefit/cta 任一空 → BLOCKER。
- cta 不在 `cta_types`（点击/注册/购买/咨询/下载/预约/关注）→ BLOCKER。
- headline+benefit 拼接文本命中任一 `ad_forbidden` → BLOCKER。

**press 校验规则**：
- 六段结构任一空 → BLOCKER。
- dateline 不含「20」且不含「—/-」→ BLOCKER（需城市+日期）。
- lead 命中任一 `ad_forbidden` → BLOCKER。

**输出键**：ad → `banned_count`；press → `section_count`（=6）。

## 三、已验证算例（run_tests.py 与 verify_loop.py 全绿，非新编）

- `examples/ad.json`：三件套齐备 + cta=预约 + 无绝对化禁词 → ok=true、banned_count=0。
- `examples/press.json`：六段齐备 + dateline=「北京 — 2026-11-04」+ 导语无禁词
  → ok=true、section_count=6。
- 脏夹具 `ad_dirty.json`：headline=全网最低 + benefit=第一好 + cta=随便
  → ok=false / exit 1。
- 脏夹具 `press_dirty.json`：导语「绝对第一」命中禁词 → ok=false / exit 1。

## 四、实战踩坑（真拦下来的教训）

- **绝对化禁词要子串匹配**：「全网最低」含「最低」，但白名单是「最」单字——
  这里把「最/第一/绝对/保证」等短词直接子串匹配，能覆盖「全网最低/绝对有效」。
- **cta 白名单不拦「预约/关注」**：这两个是内容营销的合法号召，别把它们误当
  广告法禁词，白名单要覆盖。
- **dateline 判据宽松**：城市+日期两种写法（「北京 2026」或「北京 — 2026-11-04」）
  都算过，只要求含年份或分隔符，避免对格式过度苛求。
