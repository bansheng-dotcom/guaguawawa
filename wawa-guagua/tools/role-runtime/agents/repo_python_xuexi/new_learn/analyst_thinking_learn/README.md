# 03analyst_thinking —— 数据分析思维体系

## 这门课是什么

从零开始培养数据分析师的思维方式。不假设你有任何基础——不需要懂SQL、不需要学过统计学、不需要有互联网行业经验。

**目标**：学完之后，面对一个模糊的业务问题，你知道从哪里开始、用什么框架、怎么得到可落地的结论。

## 四个学习阶段

### 阶段一：商业思维（第1-3周）
**核心问题**：一个好的分析师看到数字时，脑子里在想什么？

- W1：指标与度量 —— 不是所有数字都叫指标
- W2：增长分析框架 —— 用户从哪来、到哪去、为什么不留下
- W3：系统化分析 —— 面对陌生问题，用什么框架拆解

### 阶段二：数据工程思维（第4-6周）
**核心问题**：数据从产生到能被分析，中间经历了什么？

- W4：数仓思维 —— 为什么数据要分层、怎么建表
- W5：SQL分析思维(上) —— 用SQL回答"谁是最好的用户"
- W6：SQL分析思维(下) —— 复杂业务问题的SQL解法

### 阶段三：推断思维（第7-9周）
**核心问题**：看到数据变化，怎么判断是真实效果还是运气？

- W7：AB实验基础 —— 从假设检验到实验设计
- W8：AB实验进阶 —— 复杂场景下的实验方法
- W9：因果推断 —— 不能做实验时，怎么接近真相

### 阶段四：整合应用（第10-12周）
**核心问题**：把所有能力整合起来，解决真实问题。

- W10：综合案例分析 —— 模拟真实工作场景
- W11：综合项目 —— 端到端完成一个分析项目
- W12：知识体系巩固 —— 盲区排查与学习路径规划

## 每天的学习结构

每个 notebook 包含7个区块：
1. **核心概念** —— 今天要理解的最重要的东西
2. **知识点拆解** —— 逐一展开，从为什么到怎么做
3. **动手练习** —— 写代码、算指标、做判断
4. **业务场景** —— 真实工作中会遇到的情况
5. **分级检验** —— 初级/中级/高级自检清单
6. **跨模块连接** —— 前置依赖和后续用途
7. **当日小结** —— 一句话带走今天的核心认知

## 学习建议

1. **按顺序学**：每天的课程只依赖前一天和前几周的内容
2. **同步推进**：01 和 03 的对应周一起学，工具和思维互相强化
3. **完成自检**：每天结束前过一遍检验清单，卡住的地方回头重看
4. **查阅 02**：每个专题学完后，去 02 找对应文件做扩展阅读
