# 第15周 每日详细教学规格

> 对应计划：v5.0 第15周 综合项目三 —— 自由选题（含竞品分析）
> 定位：**这是你简历上最能体现"独立分析能力"的项目。** 前两周(W13/W14)是"给定数据和问题"——像入职后leader交给你一个任务。本周是"你自己找数据、自己定问题、自己设计分析方案"——像入职后你自己发现了一个业务机会、主动推动分析
> 角色：数据分析师。本周你是自己的"leader"——从选题到数据到分析到报告，全部自己决策
> 选题要求：选你感兴趣的领域（游戏/电影/股票/房价/美食/运动/教育/医疗/任何）→找到真实数据→做完整分析→输出报告

## W15D1：选题 + 明确分析问题 + 获取数据 + 写分析计划

### 今日任务
**决定"我接下来一周要做什么分析"——并写一份分析计划。** 这是本周最重要的一天。选题选得好=后面6天顺畅。选题选得不好=数据找不到/分析做不下去/想换题——浪费2-3天。

### 具体操作步骤

**Step 1：选题（60分钟）——选什么、怎么选**

**选题的四条标准（每条不符合→风险增大）**：
1. **你感兴趣**：对这个领域有好奇心→分析过程不会枯燥→报告写出来有热情。如果你对足球没兴趣→不要选"五大联赛进球分析"→你会痛苦
2. **能找到数据**：有公开数据集（Kaggle/天池/和鲸/国家统计局/上市公司财报）或可以自己爬（但爬数据有法律风险→优先用公开数据集）。如果你选"分析王者荣耀玩家行为"→没有公开数据→做不了
3. **数据量适中**：几千到几十万行→够分析但不用分布式处理。如果你选"分析全中国所有人的收入"→数据找不到+量太大
4. **能提出有价值的分析问题**：不只是"描述数据"，而是"回答一个可行动的问题"。如果你选"分析全球气候变暖"→数据有但问题太大→一周做不完

**选题方向推荐（每个方向有现成数据集）**：
- **游戏**：Steam游戏数据（销量/评分/价格/标签→Kaggle）→分析"什么特征的游戏卖得好""独立游戏vs大厂的定价策略""好评率和销量的关系"
- **电影**：IMDb/TMDB电影数据（评分/票房/导演/演员/类型/预算→Kaggle）→分析"什么导演的电影投资回报率最高""评分和票房的关系""超级英雄电影是否在衰退"
- **股票/金融**：美股/加密货币历史数据（价格/成交量/波动率→Yahoo Finance API）→分析"什么行业板块在经济周期中表现最好""波动率和收益率的关系""技术指标是否真的能预测"
- **房价**：房价数据（面积/地段/房龄/周边配套→链家/安居客/公开数据）→分析"什么因素对房价影响最大""不同城市的房价趋势对比""学区房溢价值得吗"
- **美食**：餐厅评分数据（评分/价格/菜系/位置/评论→Yelp/大众点评公开数据）→分析"评分和价格的关系(性价比)""什么菜系评分最高""连锁vs独立餐厅的差异"
- **运动**：NBA/五大联赛球员数据（得分/助攻/篮板/薪资→Kaggle）→分析"什么位置的球员薪资最高""数据好=薪资高?有没有被'高估'的球员""主场优势有多大"
- **教育**：学生成绩/教育投入/就业数据（→Kaggle/国家统计局/公开数据）→分析"什么因素影响学生成绩""教育投入和成绩的关系""好大学=好工资?ROI怎么算"
- **医疗**：疾病/医院/药品数据（→WHO/CDC公开数据）→分析"什么疾病的发病率在上升""医疗投入和预期寿命的关系"

**怎么选（决策流程）**：先挑2-3个你感兴趣的→去Kaggle/和鲸搜一下有没有合适的数据集→看数据的"列"是否够丰富（≥8列）→估算"一周能做完吗"（数据几千到几万行→可以。几十万行→也可以但需要注意效率）

**Step 2：明确分析问题（30分钟）——把"感兴趣的topic"变成"可回答的问题"**
- 不好的问题："分析NBA数据"（太模糊→不知道要做什么）
- 好的问题："分析NBA球员的薪资是否合理——哪些球员'物超所值'（数据好但薪资低）、哪些球员'高薪低能'（薪资高但数据差）、什么位置/年龄的球员性价比最高"
- 至少提3-5个具体的子问题：①薪资和综合数据(得分+助攻+篮板+防守)的相关性②哪个位置的球员性价比最高(数据/薪资比)③年轻球员(22-25岁)的薪资是否被低估④球队的薪资总额和胜率的关系⑤有没有"合同年爆发"(合同最后一年数据突然变好)
- 每个子问题标注"这个问题对谁有价值"(球队总经理?球员经纪人?球迷?)和"能回答到什么程度"(有数据→可定量回答/数据不全→定性推测)

**Step 3：获取数据（60分钟）——找到数据+下载+初探**
- 从Kaggle/天池/和鲸下载数据集→读入Python/pandas→跑六板斧(W2D1)
- 记录：数据来源URL/数据量(行数×列数)/各列含义/可能的分析限制(缺失/时间范围/代表性问题)
- 如果数据有问题(缺失太多/关键列没有/数据量太少)→回到Step1换题。别在"不够好的数据"上硬做

**Step 4：写分析计划（30分钟）——你接下来6天的路线图**
```markdown
# 分析计划：{项目名称}

## 1. 分析目标
一句话：{这个项目要回答什么问题}
对这个问题的回答对谁有价值？为什么现在值得分析？

## 2. 数据
- 来源：{URL}
- 规模：{行数×列数}
- 时间范围：{起止日期}
- 核心变量：{列出5-8个最关键的列}

## 3. 分析框架
- 子问题1：{问题}→方法：{描述统计/回归/AB对比}→预期产出：{表/图/结论}
- 子问题2：...
- 子问题3：...
- 子问题4：...

## 4. 竞品/对标分析（如果有）
- 选2-3个对标对象（同行业/同类型）
- 可比指标（列出3-5个）
- 数据来源

## 5. 时间安排
- Day1: 选题+数据获取+分析计划 ✓(今天)
- Day2: 数据清洗+探索性分析
- Day3: 核心分析（子问题1-3）
```

### 用到武器

### 今日交付物
1. 最终选题（一句话+为什么选它）
2. 数据集（已下载+初探过的CSV/连接）
3. 分析计划（包含6个部分→接下来6天的路线图）
4. 初探报告（六板斧→数据规模/质量/关键发现）

### 今日陷阱
1. **选题太大→一周做不完**："分析全球经济"→太大了。缩小到"分析美国科技股过去5年的表现"→可行。缩小到"对比FAANG五家公司的财务指标"→更可行
2. **数据找到了但质量差**：缺失率>30%→可以考虑。缺失率>50%→换数据。关键列缺失(如分析薪资但没有"薪资"列)→直接换
3. **选了不感兴趣的话题**："这个数据很丰富"但你不感兴趣→Day3-4你会不想做→选你真正好奇的话题

## W15D2：数据清洗 + 探索性分析

### 今日任务
**把原始数据洗到可用+做完整的探索性分析(EDA)。** 和W13D1/W14D1同样的清洗流程，但数据是你自己选的→你要独立判断"怎么洗、洗到什么程度、有没有异常"。

### 具体操作步骤

**Step 1：数据清洗（60分钟）——自己判断"怎么洗"**
- 用W4D2-D3的完整清洗框架：
  - 缺失值诊断+处理：每列缺失比例→选策略(删/填/标)。**你自己判断**"这一列缺失率20%→是删还是填"→给出理由
  - 异常值检测+处理：IQR/Z-score/业务规则→**你自己判断**"这个异常值是错误还是真实极端值"→给出理由
  - 重复值检测+处理：全行重复→删。部分重复→**你自己判断**"是真重复还是合理重复"
  - 格式统一：日期/数值/文本→统一格式。**你自己决定**"哪些列需要转换"
- 清洗日志（W4D2模板）：每一步记录"做了什么/处理前行/处理后行/理由"

**Step 2：探索性分析（90分钟）——挖掘数据中的"故事"**
- 用W5D3的完整EDA框架：
  - 描述统计：核心数值列的均值/中位数/标准差/偏度/峰度→判断分布形状。**如果均值远大于中位数→数据右偏→可能被少数极端值拉高**
  - 分布可视化：直方图/箱线图→看分布形状和离群点。小提琴图→看分布的多峰/多模态
  - 类别列分布：value_counts→看各类占比、是否存在严重的类别不均衡
  - 两两关系：散点图矩阵→看变量之间的相关性和聚类。相关性热力图→找"强相关的变量对"(r>0.7→可能有多重共线性→分析时注意)
  - 时间趋势（如果有时间列）：折线图→看时间趋势、季节性、异常波动
- 写250字"我发现的初步故事"：数据告诉了你什么→哪些发现你最感兴趣→接下来Day3要深入分析哪个方向

### 用到武器
W4D2-3(清洗/缺失异常重复/分块/清洗日志)/W5D3(EDA/描述统计/分布可视化)/W4D1(可视化)

### 今日交付物
1. 清洗后的干净数据集（存为parquet→学会生产化）
2. 清洗日志（每步的记录+理由）
3. EDA报告（描述统计+分布+相关性+时间趋势+250字"初步故事"）

### 今日陷阱
1. **过度清洗**：看到异常值就删→结果删掉了"真正的信号"(如超高收入不是错误→是大客户)。每个删除决定都需要理由
2. **EDA时间太长**：做了10张图但每张都没有深入解读→"画了=没看"。每张图写一句话"这张图告诉我什么"
3. **发现"有趣的"但方向跑偏**：EDA中发现A和B相关→很兴奋→Day3开始分析A和B→但A和B和你的分析目标无关→偏离了Day1的分析计划。保持"有趣但不能跑偏"的平衡

## W15D3：核心分析（回答Day1提出的子问题）

### 今日任务
**用W1-W12学到的分析方法——回答你在Day1提出的核心子问题。** 今天是你这个项目的"分析引擎"——大部分的统计、建模、因果推断都在今天。

### 具体操作步骤

**Step 1：子问题1的分析（60分钟）——用最合适的分析方法**
- 根据子问题的类型选方法：
  - 描述/对比→EDA+描述统计+可视化（W5）
  - 分组对比→t检验/ANOVA（W5）+箱线图
  - 相关性分析→Pearson/Spearman相关+散点图（W5）
  - 因果推断→DID/PSM/RDD（W11）→如果数据支持
  - 预测模型→回归/分类（W12）→如果数据适合
  - 漏斗/留存→Cohort/RFM（W10）
- **关键**：不选"最复杂"的方法→选"最能回答问题"的方法。如果简单的描述统计就能回答→不要硬上模型

**Step 2：子问题2的分析（45分钟）**
- 同上。每个子问题→明确"方法+为什么选这个方法+分析结果+一句话结论"

**Step 3：子问题3的分析（45分钟）**
- 同上

**Step 4：将3个子问题的发现串成一个"连贯的故事"（30分钟）**
- 不能"子问题1说A/子问题2说B/子问题3说C"→三者之间没有关系→报告散乱的
- 要找"三个子问题之间的联系"：子问题1发现X→子问题2进一步验证了X→子问题3解释了X的原因。或者：子问题1发现X→子问题2发现"X只对某类群体成立"→子问题3解释"为什么只对这类群体成立"

### 用到武器
W5全周(统计)/W6-7(AB实验)/W10(增长分析)/W11(因果推断)/W12(ML)

### 今日交付物
1. 每个子问题的分析结果（方法+数据+图表+一句话结论）
2. 三个子问题之间的"连贯故事线"（100字→这三个发现加在一起告诉我们什么）

### 今日陷阱
1. **方法选得太复杂**：子问题"A和B相关吗"→不需要跑ML模型→Pearson相关系数+p值足够了。不要为了"炫技"用复杂的模型
2. **每个子问题孤立分析**：三个子问题之间没有联系→报告像"三份小报告拼在一起"。Day1的分析计划就应该设计"子问题之间的关系"
3. **只汇报"统计显著"不汇报"效应大小"**：p<0.05≠重要。效应量有多大？这个发现在业务上值多少钱？

## W15D4：深度分析 + 可视化 + 竞品对标

### 今日任务
**三件事**：①对Day3的核心发现做深度分析（分群、稳健性、边界）②把关键发现用"能放PPT"的图表可视③竞品/对标分析。

### Step 1：深度分析（60分钟）
- 分群分析：核心发现是否对所有群体成立？还是只对某类成立？→按关键维度(如年龄/收入/地区/时间)分群→看效果是否一致
- 稳健性检验：如果你用了回归→换一种模型(如线性→Lasso)→结论是否稳定？如果你用了PSM→换匹配算法→ATT是否接近？
- 边界讨论：你的数据能代表什么？不能代表什么？分析结论的适用范围是什么？

### Step 2：可视化（40分钟）
- 用W4D1学的"能放PPT"的图表：≥4张关键图→每张"结论式标题"+"标注关键发现"。配色统一→排版整齐→能直接截图放到报告里
- 至少包含：①趋势图(如有时间维度)②对比图(柱状/箱线)③关系图(散点+回归线)④分布图(直方图/小提琴)

### Step 3：竞品/对标分析（50分钟）
- 用W9D5的竞品分析框架：选2-3个对标对象→找3-5个可比指标→画对比表→分析"我们/本项目的分析对象在行业中是什么水平"
- 如果是"电影"选题→对标：Netflix/Disney/国内流媒体→对比指标：内容量/评分/用户数/收入
- 如果是"NBA"选题→对标：欧洲篮球联赛/CBA→对比指标：球员薪资/观赏性/商业化程度
- 如果是"房价"选题→对标：不同城市/不同国家→对比指标：均价/收入比/租售比/涨幅
- 竞品分析的核心价值=回答"这个发现是行业共性还是本项目独有"。如果行业共性→说明是结构性问题。如果本项目独有→说明是竞争优势/劣势

### 用到武器
W4D1(可视化/图表叙事)/W11D6(稳健性检验)/W9D5(竞品分析)/W6D6(分群分析)

### 今日交付物
1. 分群分析结果（核心发现在不同分群中的一致性）
2. 稳健性检验结果（换方法/参数→结论是否稳定）
3. ≥4张"能放PPT"的关键图表
4. 竞品/对标分析（对比表+"我们在行业中的位置"）

## W15D5：撰写完整分析报告

### 今日任务

## W15D6：报告润色 + PPT + 3分钟口头汇报稿

### 今日任务
**和W13D6/W14D6同样流程——打磨报告+准备汇报。** 这是第三次做了——应该比前两周更熟练。

### Step 1：报告润色（60分钟）
- 检查清单（和前两周一样）：结论有数字?建议可执行?图表有结论式标题?执行摘要30秒能看懂?
