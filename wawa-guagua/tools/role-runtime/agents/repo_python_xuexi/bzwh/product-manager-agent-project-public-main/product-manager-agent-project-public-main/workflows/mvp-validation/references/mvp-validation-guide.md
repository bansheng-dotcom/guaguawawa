# MVP 与实验验证质量指南

## 1. 好 MVP 的定义

MVP 的价值不是小版本，而是用最低成本验证核心假设。

| 假设类型 | 要问什么 |
| --- | --- |
| 价值假设 | 用户是否真的需要这个结果 |
| 可用性假设 | 用户是否能理解并完成动作 |
| 可行性假设 | 技术或流程是否能支撑 |
| 商业性假设 | 成本、转化、收入或运营是否成立 |

## 2. 实验选择

| 实验 | 适用 |
| --- | --- |
| 访谈 | 问题和场景不清 |
| 假门 | 测兴趣和点击意愿 |
| 低保真原型 | 测理解和流程 |
| Concierge test | 人工模拟服务验证价值 |
| 小流量实验 | 已有基础能力，验证行为数据 |

## 3. 常见反模式

- 把完整产品砍功能叫 MVP。
- 没写失败后怎么办。
- 只验证团队能不能做，不验证用户要不要。
- 实验成本比学习价值还高。
