## 三、v3.0 → v4.0 的核心变化

针对上述矩阵中3个"⚠️"项和不达深度的部分：

| 变化 | 原因 | 具体调整 |
|------|------|---------|
| **W8增加Spark概念** | 美团/腾讯JD要求Hadoop/Spark | W8周三数据管道：Kafka→Flink/Spark→Hive整条链路讲清，不用写Spark代码但要理解架构 |
| **W9/W15强化行业洞察** | 腾讯/小红书JD要求行业/竞品分析能力 | W9周五增加一项"竞品指标对比分析"练习；W15自由选题要求包含竞品对标章节 |
| **W13增加推荐系统实战** | 字节/小红书JD强调内容推荐理解 | W13融入：用番茄小说数据跑一个推荐效果评估的完整流程 |
| **整体深度检查** | 用户反馈"只是提了一嘴" | 每个能力项的"学到什么程度"必须可验证。不是"了解了XX"，而是"能独立做YY" |

## 七、说实话：4个月学完能到什么水平

**能过的**：校招简历筛选 + 初面SQL手写 + 技术面AB实验设计 + 业务面案例分析。你的知识体系能覆盖JD的95%。

**过不了的**：5年经验要求的岗位（腾讯搜索输入法要5年+）、深度行业经验（如天美要深度游戏理解）、管理岗（要带过人）。

**入职后**：能独立完成日常取数、分析、实验设计。会在以下方面需要前3个月加速学习：公司特有的数据架构、复杂的跨部门协作、真实业务压力的决策判断。这是正常的——所有新人都有这个适应期。
