# 社区团购 SQL漏斗分析 — 教程索引

## 这个项目在讲什么

你是美团优选的数据分析师。老板想看：
- 团长在群里分享商品后，用户从点开到下单，卡在哪一步？
- 哪些用户是高价值用户，哪些快流失了？
- 用户买了一次后还会再买吗？
- 哪个团长的"获客能力"最强？

这些问题的答案都在数据库里——但你需要用**SQL把答案挖出来**。

