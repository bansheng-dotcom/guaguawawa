# 05 多重检验校正

---

## 一、白话理解

### 你被自己骗了

你的实验测了7个指标,用α=0.05检验,发现了4个"显著"。

但你有没有想过:**7个指标中至少出现1个假阳性的概率是多少?**

```
P(至少1个假阳性) = 1 - (1-0.05)^7 = 1 - 0.95^7 = 30.2%
```

**将近三分之一!** 这不叫严谨的科学实验,这叫"刷指标碰运气"。

### 超市刮刮卡的类比

你去超市买东西,抽奖:中奖率5%。你抽了7次,中了1次——完全不意外,甚至可以说"运气一般"。

**在A/B实验里,测7个指标相当于你刮了7张卡,其中夹了一张"假阳性"是很正常的。**

如果你测了20个探索指标,1-(1-0.05)^20 = 64%。你有一半以上的概率"发现"至少一个假阳性。

### 社区团购的实际场景

你们团队做了个推荐优化。数据分析师测了15个指标,发现3个"显著"(p<0.05):
- "GMV提升了!" (其实p=0.03,测了15个后不显著了)
- "履约成本下降了!" (其实p=0.04,也是测15个后的假阳性)

产品经理基于这两个"发现"宣布实验成功,全量上线。一个月后回头一看——GMV根本没涨,履约成本也没降。

**这就是p-hacking,数据分析师最该避免的陷阱。**

## 二、核心概念

### 2.1 三种校正方法

| 方法 | 怎么算 | 严格度 | 什么时候用 |
|------|--------|--------|-----------|
| **Bonferroni** | p × m, 跟α比 | 最严 | 医疗/安全——宁可错过不能杀错 |
| **Holm-Bonferroni** | 逐级放宽 | 严但比Bonf好 | 确认性实验——能不能上线 |
| **Benjamini-Hochberg** | 控制FDR | 适中 | 探索性分析——找灵感 |

### 2.2 社区团购场景怎么用

代码里对7个指标标的层级:

```
北极星(GMV、件数):    不做校正 → 有明确先验假设,就测这两个
护栏(履约成本/损耗/退货): 不做校正 → 保守策略,宁误报不漏报
探索(爆品占比/首单转率): BH校正  → 控制FDR,平衡发现与假阳性
```

**为什么护栏不校正?**

因为护栏指标的"假阳性"(错误地标记为恶化)的危害 < "假阴性"(漏掉真实恶化)的危害。

如果履约成本率确实恶化了但你因为做校正而没报告 → 全量上线后履约成本爆炸 → 每个城市的利润都在被吃掉,但你不知道。

**宁可多报几次"可能有风险",也不能错过一次真风险。**

## 三、代码导读

打开 [05_multiple_testing.py](../05_multiple_testing.py):

### FWER计算 (第45行)

```python
fwer = 1 - (1-ALPHA)**m
```
简单直观——"如果不校正,被忽悠的概率有多高"。

### Bonferroni (第55-65行)

```python
p_adj = min(p * m, 1.0)  # m=指标数
sig = p_adj < ALPHA
```

### Holm (第70-85行)

排序后逐级检验:
```python
threshold = ALPHA / (m - k + 1)  # 随排名逐步放宽
```

### BH (第90-110行)

找最大的k满足p(k) ≤ (k/m)×α,拒绝前k个。

## 四、输出解读

```
  指标                原始      Bonferroni   Holm     BH(FDR)   层级
  人均GMV             YES       YES         YES      YES        北极星
  人均件数             YES       NO          YES      YES        北极星
  履约成本率           YES       YES         YES      YES        护栏
  生鲜损耗率           NO        NO          NO       NO         护栏
  退货率               NO        NO          NO       NO         护栏
  首单转化率           YES       YES         YES      YES        探索
  爆品GMV占比          YES       NO          YES      YES        探索
```

**注意人均件数**——原始p=0.002,但Bonferroni校正(p×7=0.014>0.05)后就不显著了。Holm比Bonferroni更powerful,让件数通过了。

这说明:**如果一个指标在Bonferroni校正后勉强不显著,不要直接下结论说"没效果"**——Holm和BH可能都认为它是显著的。结合置信区间和业务价值做综合判断。

## 五、面试怎么讲

**面试官:"你们测多个指标吗?怎么处理多重检验?"**

> "我们按指标层级分别处理:
>
> - 北极星(GMV、件数):不做校正——因为实验是针对性地假设它们会提升。
> - 护栏(履约成本率、损耗率):不做校正——保守策略,宁可误认为恶化,不能漏掉真恶化。
>   因为社区团购薄利,履约成本率只要上涨0.5%就可能吃掉GMV的利润,漏报代价太大。
> - 探索指标(爆品占比、首单转化率):用Benjamini-Hochberg控制FDR——在'发现新洞察'
>   和'控制假阳性'之间取得平衡。探索指标的作用是给下一次迭代找方向,不是直接做上线决策。
>
> 如果我要根据某个探索指标的'显著'来做强结论,我会用Holm-Bonferroni做二次确认。"
