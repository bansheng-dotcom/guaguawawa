# 01 指标体系设计

---

## 一、白话理解

### 老板问你"上个月怎么样"，你怎么回答？

"上个月GMV 120万。" — 老板追问: "好还是不好？"

你需要一个**标尺**——目标值。

- "GMV 120万，比目标85万多41%"
- 但"履约成本率也超了0.3个点"

这就是指标体系的作用：**不仅告诉你"做了什么"，还告诉你"做得好不好"。**

### OSM模型 — 从目标到指标

美团优选保定市年度经营目标:

```
O(Objective):   年GMV增20%，履约成本≤8.5%，损耗率≤5%
S(Strategy):    爆品优化(提转化) + 供给本地化(降成本) + 团长赋能(提人效)
M(Measurement): 选什么指标来衡量S是否在帮O?
```

为什么是OSM而不是"想到什么写什么"？因为指标不能是孤立的——每选一个指标，你必须说明这个指标衡量了哪条策略、服务于哪个目标。否则到年底，团队可能完成了所有指标，但目标没达成——**指标跟目标脱节了。**

### 社区团购的指标体系四层结构

```
北极星指标 — "我们终极追求什么"
    └── 人均GMV + 人均件数
        直接回答: 用户价值有没有提升?

健康度指标 — "有没有为了北极星牺牲利润?"
    └── 履约成本率 + 损耗率 + 退货率
        直接回答: GMV涨了,但利润是不是被成本吃掉了?

规模指标 — "盘子有没有变大?"
    └── 订单量 + 用户数 + 活跃团长数
        直接回答: 增长来自拉新还是复购?

效率指标 — "资源用得值不值?"
    └── 团长人均GMV + 客单价 + 爆品贡献占比
        直接回答: 每个团长的产出在提升吗?
```

**四层的逻辑关系：**
- GMV = 用户数 × 人均GMV（规模 × 北极星）
- 净利润 = GMV × (1 - 履约成本率 - 损耗率 - 退货率) （北极星 × 健康度）
- 运营效率 = GMV / 团长数 （规模 / 投入 = 效率）

## 二、核心概念

### 2.1 北极星指标怎么选？五个标准

| 标准 | 人均GMV | 订单量 | 用户数 |
|------|---------|--------|--------|
| **与营收关联** | 直接: GMV=用户数×人均GMV | 间接 | 间接 |
| **可操作性** | 可通过推荐/定价/供给优化 | 可通过拉新/促销 | 可通过广告/BD |
| **可测量性** | 每日可算 | 每日可算 | 每日可算 |
| **敏感性** | 3-5%变化即有感知 | 受天气/周末影响大 | 慢变量 |
| **不易作弊性** | 难(需同时操作用户数+GMV) | 易(补贴刷单) | 易(虚假注册) |

代码里的打分是简化版，真实场景要拉上业务方一起讨论。

### 2.2 指标不等于KPI

指标是"描述事实的"，KPI是"用来考核的"。

- "人均GMV 22元" = 指标
- "人均GMV必须≥26元，否则扣奖金" = KPI

**你把指标当KPI用，业务方就会想办法"做"到目标值——包括作弊。**

```python
        (month_data['gmv_per_user'] >= 26) &
        (month_data['fulfillment_cost_rate'] <= 8.5)
    )
    hit_rate = daily_target_hits / len(month_data) * 100
```

**关键思路：指标"达成率"不是简单的均值对比，而是看"有多少天同时达标"。**

一天GMV高但履约成本爆了 → 这天不算达标。这种**双条件同时满足的达标率**比单独看每个指标的均值更能反映整体健康度。

## 五、面试怎么讲

**面试官："你怎么设计指标体系？"**

> "我用OSM框架——先明确业务目标(Objective)，再拆解达成目标的策略(Strategy)，最后映射到可测量的指标(Measurement)。
>
> 社区团购的指标体系分四层：北极星(GMV+件数)、健康度(履约成本率/损耗率)、规模(订单/用户/团长)、效率(人均产出)。四层的逻辑关系就是GMV的分解公式：GMV=用户数×人均GMV，净利润还得扣履约成本和损耗。
>
> 选北极星时我用5维度打分(营收关联/可操作性/可测量/敏感性/不易作弊)，最终选人均GMV而非订单量——因为订单量容易被补贴刷单虚增，人均GMV同时衡量了'量'和'质'。"
