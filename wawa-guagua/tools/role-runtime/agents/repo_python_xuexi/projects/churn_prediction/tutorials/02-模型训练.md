# 02 模型训练 — 逻辑回归 + 随机森林

---

## 一、白话理解

### 两个模型，两个角色

**逻辑回归(LR)：** 可解释的基线
- 输出流失概率：0.73 = "有73%的把握这个人要流失"
- 系数可读："recency每增加1天，流失log-odds增加0.06"
- 运行快、不易过拟合
- **如果LR的效果就已经很好 → 问题本身是比较线性的**

**随机森林(RF)：** 追求更高精度
- 200棵树投票："120棵说会流失，80棵说不会 → 预测流失"
- 自动学特征交互："recency高 AND 团长不稳"的联合效应
- 可能过拟合——如果train AUC >> test AUC

### 交叉验证在干什么

```
把训练集切成5份 → 用4份训练,1份验证 → 轮换5次 → 得到5个AUC → 取平均

如果5个AUC差异很大(标准差大) → 模型不稳定
如果5个AUC都很接近 → 模型稳定
```

## 二、核心参数解释

### 逻辑回归的关键参数

```python
LogisticRegression(
    penalty='l2',           # L2正则化 → 防止系数过大
    C=0.5,                  # 正则化强度 → 越小越强 → 越不容易过拟合
    class_weight='balanced', # "流失的样本少,多关注它们"
)
```

**class_weight='balanced'** — 因为流失率只有35%，模型如果不做平衡，会倾向于全部预测"不流失"（这样准确率就有65%了）。balanced自动给少数类（流失）更高的权重。

### 随机森林的关键参数

```python
RandomForestClassifier(
    n_estimators=200,       # 200棵树 → 多=更稳但更慢
    max_depth=10,           # 限制深度 → 防止过拟合
    min_samples_split=50,   # 节点至少50样本才分裂 → 防止学噪音
    min_samples_leaf=20,    # 叶子至少20样本 → 同上
)
```

**为什么限制max_depth？** 如果不限制，树会一直分裂到每个叶子只有一个样本——训练集100%准确，测试集一塌糊涂（过拟合）。

## 三、输出解读

```
逻辑回归:
  训练集AUC: 0.8134    ← 训练集上的表现
  测试集AUC: 0.8218    ← 测试集上的表现(这更重要!)
  5折CV AUC: 0.8116    ← 更稳定的估计

  过拟合检查: Gap = -0.008  ← 训练反而比测试差? 正常的随机波动

随机森林:
  训练集AUC: 0.8652
  测试集AUC: 0.8083    ← 测试集不如LR!
  Gap = 0.057          ← 有一些过拟合

最优模型: LogisticRegression (测试AUC=0.8218)
```

**解读：** 逻辑回归竟然比随机森林好——说明这个数据的流失规律比较"线性"，RF的复杂度反而带来了过拟合。**这不是失败，这是真实ML项目中常见的发现。**
