# 02 生存分析 — Kaplan-Meier + Cox回归

---

## 一、白话理解

### 队列分析只能说"第N个月剩多少人"，生存分析能告诉你"预期活多久"

**Kaplan-Meier曲线：**
- 横轴 = 时间（月）
- 纵轴 = 存活概率（0-100%）
- 每一步台阶下降 = 有人在这个时间点流失了
- 曲线上的"+号" = 删失（观测结束，人还在）
- 曲线降到50%的时刻 = 中位存活期

**删失(Censoring)是什么？**
一个团长注册了8个月，观测结束时（2025年12月）还在活跃。你不知道他第9个月会不会流失——但你知道他"至少活了8个月"。

如果忽略删失（把这类人当成"流失"），存活期会被严重低估。K-M方法正确处理了删失。

### Cox回归：多因素一起看

"一线城市团长活得更久"——是因为一线消费力强，还是因为一线团长密度低（竞争小）？

Cox回归把多个因素同时放进去，输出**风险比（Hazard Ratio）：**

- HR > 1 → 这个因素增加流失风险（危险因子）
- HR < 1 → 这个因素降低流失风险（保护因子）

## 二、代码导读

打开 [02_survival_analysis.py](../02_survival_analysis.py)：

### K-M拟合
```python
from lifelines import KaplanMeierFitter
kmf = KaplanMeierFitter()
kmf.fit(durations=T, event_observed=E)  # T=存活月数, E=是否流失

kmf.median_survival_time_  # 中位存活期
kmf.survival_function_at_times(12)  # 12个月存活概率
```

### 分层K-M（按城市/密度）
```python
mask = leaders['city_tier'] == 'tier_1_new'
kmf_city.fit(T[mask], E[mask], label='一线')
kmf_city.plot_survival_function()
```

### Cox回归
```python
from lifelines import CoxPHFitter
cph = CoxPHFitter()
cph.fit(data, duration_col='observed_months', event_col='is_churned')
cph.summary[['exp(coef)','p']]  # HR和显著性
```

## 三、输出解读

```
中位存活期: 14.2个月

分层K-M:
  一线/新一线: 中位16.1月  (消费力强+供给稳)
  三五线:      中位12.5月  (竞争激烈+供给波动)

Cox回归:
  quality:        HR=0.28 → 团长质量每升1单位,流失风险降72%
  is_tier1:       HR=0.55 → 一线比三五线流失风险低45%
  is_low_density: HR=0.64 → 低密度区流失风险低36%
  is_high_density: HR=1.31 → 高密度区流失风险高31%(p=0.106,不显著)
```

**quality是最强的保护因子** — 团长个人能力比外部环境（城市/密度）更重要。这意味着筛选好团长的ROI高于"铺量"。
