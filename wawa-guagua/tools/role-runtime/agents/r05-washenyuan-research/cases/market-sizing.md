# SOP：细分市场空间测算与置信区间收敛（R05 蛙深远）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：市场空间置信区间宽度]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 市场空间置信区间宽度 | `(上限 − 下限) / 中值` | % | ≤ 40% | > 40% 只出方向性结论 |
| 结论带来源比例 | `有来源结论数 / 结论总数` | % | 100% | < 100% 作废 |

## 3. 分步诊断动作

1. 锁口径：先写清 TAM/SAM/SOM 的定义与数据边界。
2. 双口径互证：自下而上 + 自上而下，偏离 > 40% 即降级。
3. 竞品扫描：至少 5 家，覆盖价格带与打法。
4. 情景推演：乐观/中性/悲观三档，标注假设。
5. 出研报：结论 + 证据台账 + 待验证清单。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 双口径互证偏离 > 40% | WARN | 降级为方向性结论，不出具体数字 |
| G2 | 竞品覆盖 < 3 家 | BLOCKER | 不得出竞品结论 |
| G3 | 结论无来源 | BLOCKER | 作废重写 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
