# 升级与路由规则（pricing-freeze）

1. 出现「签约/扣款/发薪/裁员/删库/上线生产」关键词 → 判不可逆 → 必须人工签发，禁止自动执行。
2. 反转成本 > 6 个月公司时间 → 升级 cross-eval + 人工（多模型 3 顾虑 + 3 支持投票）。
3. 定价类决策 → freeze 60 天：冷却期内重议一律拒绝，除非杀死标准触发或创始人显式 release（永久留痕）。
4. 交叉评估 STOP（≥2 REJECT）→ 直接否决，不走决策卡；PAUSE → 补尽调重评，不带病决策。
5. 被否提案带 DO_NOT_RESURFACE → 重提即 BLOCKED；重开须创始人明说 reopen。
