# R01 蛙全局 · 方法包（Method Pack v1）

## 1. 决策问题

- 典型决策：做不做 / 先做哪个 / 停哪个 / 谁来负责 / 什么条件下撤。
- 决策者：创始人本人；他最怕「押错方向还拖了半年」。
- 成功标准：30 秒能说清「选哪个、为什么、什么信号改主意」。
- 非目标：不替业务做专业判断（交 R03/R05/R06）；不做不可逆动作的自动执行。

## 2. 问题树（MECE）

| 分支 | 要回答 | 需要数据 | 方法 | 产出 |
|---|---|---|---|---|
| Where | 在哪竞争（客户/品类/区域） | 市场容量、增长、份额 | 市场地图、CR3 | 战场选择 |
| How | 靠什么赢（成本/差异/渠道） | 单位经济、能力盘点 | 价值链、战略群组 | 打法 |
| Must-be-true | 必须成立的前提 | 关键假设清单 | 假设检验 | 前提条件 |
| Could-kill | 什么会杀死它 | 风险清单、情景 | 事前尸检、情景树 | 杀死标准 |

**critical branch**：`Could-kill`——多数决策死在没写杀死标准，而不是没想到机会。

## 3. 假设与证伪

- 假设写成「选择 + 机制 + 幅度 + 时限」，例：「先做呼市苹果直采，12 个月内把单公斤成本降 8%，因为去掉一道批发」。
- 每条假设配：支持证据 / 反对证据 / **杀死标准**（指标 + 阈值 + 观察窗口）。
- 至少 2 个竞争解释：是市场β还是我们α；是价格问题还是执行问题。

## 4. 证据分级

| 级别 | 来源 | 用途 |
|---|---|---|
| A | 财报、合同、官方统计 | 可进决策卡 |
| B | 行业报告、竞品公开信息 | 方向与区间 |
| C | 访谈、估算、单点 | 标注 + 敏感性 |

规则：决策卡上每个数字带级别；C 级假设超过 3 条时，决策必须降级为「条件做」。

## 5. 方法与陷阱

**可执行**：`python scripts/consult.py check --stage 2 --input ...`（MECE/假设/杀死标准校验）。

- **可逆性分级**：可逆（快做）/ 半可逆（小步）/ 不可逆（必须签字 + 回滚计划）。
- **事前尸检**：假设 12 个月后失败，写 5 个最可能原因，逐条配监控信号。
- **选项表**：至少 3 个选项（做/不做/条件做），同维度打分，禁止单方案汇报。
- **决策日志**：决策、依据、反对意见、复审日期，四件套落盘。
- 陷阱：用「战略重要」代替「经济成立」；只给一个方案；不写复审日期；把共识当证据。

## 6. 输出契约

```
decision     做/不做/条件做（一句话）
options      3 个选项 + 取舍
evidence     关键数字 + 级别
kill_switch  指标 + 阈值 + 观察窗口
owner        唯一负责人
review_date  复审日期
```

缺 kill_switch 或 review_date → 决策卡不通过。

## 自检 10 问

1. 这是决策问题还是信息问题？
2. 选项够 3 个吗？有没有「不做」？
3. 每个选项的取舍写了吗？
4. 关键假设超过 3 条 C 级吗？
5. 杀死标准有阈值和窗口吗？
6. 谁负责，唯一吗？
7. 什么时候复审？
8. 最可能错在哪？
9. 如果只能给 30 秒，说哪句？
10. 这个决定可逆吗？回滚要多久？
