# 模块A · 愿景与意图分级
> 蒸馏自: 补充技能/alirezarezvani__claude-skills/ceo-advisor.md
>


> 整合自 founder-skills 的战略规划、c-level-agents 的 office-hours / brief。
> 核心主张：**模糊意图先「审问」到能写成一页简报，才谈执行**。

## A1. 目标分层（从模糊到可执行）

| 层 | 内容 | 周期 | 载体 |
|---|---|---|---|
| 愿景 | 1/3 年图景，一句话「做成什么」 | 年度 | 年度规划 |
| 目标 | 可量化结果（北极星/OKR） | 季度～年度 | OKR |
| 策略 | 达成路径选择（选哪条、不选哪条） | 季度 | 战略简报 Options |
| 里程碑 | 版本级增量 | 版本 | ROADMAP |
| 阶段 Phase | 单个有界工作单元（一句话说清） | 天级 | PLAN |
| 任务 Task | 单角色可完成、有验收 | 小时～天 | 任务卡 |

**Phase 范围判定（gsd-core）**：目标一句话说清且不琐碎/不宽泛；所需研究有界；能拆成少量
互不重叠子计划；有可测试的「完成定义」。「不确定就拆」。

## A2. 模糊意图澄清六问（YC 式，advice 前置为审问）

给建议前先书面作答全部六问：
1. **问题**——谁的问题？客户原话怎么描述？（引不出客户原话＝没有真问题）
2. **客户**——ICP 是谁？说出一个今天就会买的真实的人。
3. **分发**——客户第一次在哪听到你？
4. **护城河**——成了之后竞对 6 个月抄不走靠什么？（「执行力更强」不算）
5. **资金**——总成本多少、何时回本、替代用途？
6. **创始人契合**——为什么是你？值不值得花 3 年？

判定灯：🟢全实→进 boardroom；🟡某问虚→先补；🔴→杀掉或重定义。

## A3. 战略诊断补问清单（信息缺口才问）

当前最大瓶颈 / 已试过什么 / 增长阻碍 / 现获客渠道 / 有效无效 / 资源（预算·团队·时间）/
期望时间线。原则：只问真正缺的；找「移除后释放最大增长的单一约束」。

## A4. 意图收敛为一页简报（brief 模板）

```
# 战略简报 <topic>
## 问题  一句话，董事会必须回答的问题
## 选项  ≥2 个（「什么都不做」永远是选项之一）
## 假设  显式列 3 条
## 约束  时间/资金/人力/可逆性（单向门 or 双向门）
## 影响角色
## 成功标准  决策前定：指标+阈值+时限
## 杀死标准  90 天后什么信号=错：指标+阈值+触发动作
```

铁律：先锁「问题+选项+成功/杀死标准」再谈实现；成功/杀死标准**先于决策**写，禁止事后补。

## 已验证算例（run_tests.py S01，已对拍）

- 六问全证据 + 客户原话 → `light=green`；六问全空 → `light=red`（动作=杀掉或重定义）。
- 「分析订单数据趋势并排期 SOP」→ 命中 数据(R06)+运营(R02) 两个职能域 → `boardroom=true`。
- 负例：`options` 只剩 1 条 + `kill_criteria=[]` → `ok=false`；
  `decision_made=true` 且 `success_criteria=[]` → 判 **CRITICAL**（决策先行、标准事后补）。

## 实战踩坑

- 「问题引不出客户原话」是最常见的假问题信号——六问里 `problem.customer_voice`
  单独设门禁，原话缺失直接 red，不进 boardroom。
- 六问清单与选项/假设下限（options_min=2 / assumptions_min=3）以
  `experience/thresholds.json → intent` 为准，本文不手抄数值。
## 意图识别与任务分级 (Intent Routing)
- **CEO 核心职责**：不直接执行任务，而是识别原始需求的意图并进行任务分发与优先级定级。
- **任务定级框架**：
  - **P0 (战略级)**: 影响公司生死存亡、涉及融资、重大危机公关或核心战略转向。需 CEO 亲自决策。
  - **P1 (核心业务级)**: 跨部门的重大业务动作，如新产品立项。由 CEO 分解任务并指派。
  - **P2 (执行级)**: 单一部门日常推进。直接路由给具体角色 (如 R07、R09)，无需介入细节。
- **六问验证**：1.核心痛点 2.预期结果 3.最坏打算 4.所需资源 5.时间节点 6.第一责任人。
