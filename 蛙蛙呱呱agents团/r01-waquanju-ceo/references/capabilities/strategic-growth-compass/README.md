# 战略与增长罗盘

> 归属：R01　消费：r07, r12　版本：v1

## 定位

把公司/产品目标变成可取舍的战略判断：定位、目标市场、商业模式、成本结构、客户信号。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 先写清目标与非目标，再谈路径；两者缺一即不成立
2. SWOT 必须落在具体证据上，不允许只写形容词
3. PESTEL 只保留会改变决策的因子，凑数项删掉
4. 路线图给三档：必做/择机/放弃，并标注依赖与验证点

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
