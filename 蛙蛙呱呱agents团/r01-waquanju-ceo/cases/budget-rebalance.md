# SOP：季度预算再平衡与不可逆动作授权（R01 蛙全局）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：自由现金流安全月数]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 自由现金流安全月数 | `期末现金 / 近 3 月平均净流出` | 月 | ≥ 6 | < 4 立即熔断 |
| 单一营收来源占比 | `最大营收线收入 / 总营收` | % | ≤ 70% | > 70% 强制第二曲线议题 |

## 3. 分步诊断动作

1. 收口意图：把一句话意图写成「成功标准 / 杀死标准 / 可逆性等级」三段。
2. 分级判断：命中不可逆动作即挂起，等创始人书面签字。
3. 交叉质询：让 redteam 出至少 3 条反方意见，逐条给数据回应。
4. 预算再平衡：按边际 ROI 排序，砍最低者，禁止平均主义。
5. 出董事会汇报包：结论先行 + 三档方案 + 熔断线 + 灰度节奏。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 不可逆动作（签约/扣款/裁员）缺人类签字 | BLOCKER | 拒绝执行，退回补授权 |
| G2 | 自由现金流安全月数 < 4 | BLOCKER | 冻结一切新增开支，先出止损方案 |
| G3 | 决策未写成功标准与杀死标准 | WARN | 退回补齐标准后再拍板 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
