# 取舍/优先级规则 · quality-gate

1. **门禁是二元的，不是打分的**：ok=true / ok=false，没有"勉强及格"。null/dup/
   invalid/age 任一项越界即 false，不存在"加权平均之后还行"。

2. **新鲜度与完整性独立判定**：数据可以"很干净但过期"或"很新但很脏"，两者都要
   查。缺一个门禁，就会放过一类问题。

3. **阻断 ≠ 清理**：质量门禁的产出是"这批数据不能用于分析"，不是"这批数据该删"。
   删除是不可逆动作（红线 2），R18 不执行、不暗示、不措辞为"清理"。

4. **越界即移交**：空值率背后的业务归因归 R06；上游系统 bug 修复归 R09/R20。
   R18 的边界止于"数据达标与否"。

5. **缺口禁的代价 > 误拦的代价**：宁可多拦一批"可能还行"的数据（多一步人工确认），
   也不放过一批脏数据污染所有下游结论（全盘重来）。
