# R18 蛙数仓 · 数据工程 · 方法包（Method Pack v1）

## 1. 决策问题

- 典型决策：这条管道能不能上、怎么建。
- 决策者：数据负责人；成功标准：数据可信、可回溯、成本可控。
- 非目标：不做无测试的管道、不做无血缘的模型。

## 2. 问题树（MECE）

| 分支 | 要回答 | 假设 | 数据 | 方法 |
|---|---|---|---|---|
| 模型 | 分层与口径是否清楚 | 模型可解释 | 指标口径 | 分层建模 + 语义层 |
| 测试 | 数据错了能不能发现 | 关键字段有测试 | 数据质量规则 | 唯一/非空/枚举/关联 |
| 依赖 | 血缘是否清楚 | 依赖无环 | DAG | 血缘 + 拓扑 |
| 成本 | 跑得起吗 | 成本在预算内 | 资源用量 | 增量 + 分区 |

**critical branch**：`测试`——资源优先给它。

## 3. 假设与证伪

- H1：关键指标与源系统对账差异 ≤0.5%。
- H2：管道失败后 30 分钟内可恢复。
- 竞争解释（至少 2 个）：数据不对是管道问题，还是源数据问题？；延迟是计算量，还是依赖等待？
- 每条假设必须有**杀死标准**：指标 + 阈值 + 观察窗口。

## 4. 证据分级

| 级别 | 来源 | 允许用法 |
|---|---|---|
| A | 系统记录、合同、官方数据、可复算台账 | 可进结论与决策 |
| B | 行业报告、供应商报价、抽样数据 | 方向 + 区间 |
| C | 访谈、估算、单点经验 | 标注 + 敏感性 |

**规则**：每个结论挂来源；同名不同口径单列；缺什么、影响什么、怎么补，必须写清；C 级超过 3 条时结论降级为「条件成立」。

## 5. 方法与陷阱

- 分层：staging/intermediate/mart，一层一职责。
- 数据测试：唯一/非空/枚举/关联/区间。
- 增量与回填：分区 + 幂等 + 回填校验。
**陷阱清单**：
- 无测试上线
- 全量重跑
- 口径多处定义
- 无血缘
管道结论必须给「对账结果 + 失败恢复」，否则不算可信。

## 6. 输出契约

```
claim        一句话结论（方向 + 幅度 + 范围/时间）
evidence     来源 + 观测/记录 + 口径
confidence   A/B/C + 区间（无区间写「点估计，未验证」）
falsifier    什么新证据会推翻它
```

缺任一项 → 不得进首页；建议缺负责人/阈值 → 行动性不通过。
