> 版本：v1.0 · DRI：蛙数仓（R18） · 生效范围：全部数据管道工件与门禁判据
> 地位：本文件是 R18 的**单一信任源 (Single Source of Truth)**。`engines/spec_ledger.py`

## 北极星指标

| 代号 | 指标 | 定义 / 公式 | 目标 | 容差 |
|---|---|---|---|---|
| PSR | 管道成功率 | 成功批次 / 总批次（按调度批次计） | ≥ 99.5% | 0.005 |
| FSR | 新鲜度达标率 | age_hours ≤ SLA 的批次 / 总批次 | ≥ 99.0% | 0.010 |
| DQR | 质量合格率 | 通过质量门禁的表数 / 纳管表数 | ≥ 98.0% | 0.020 |
| LCR | 血缘覆盖率 | 上下游完整登记的表 / 纳管表数 | = 100% | 0.000 |
| BCR | 回填合规率 | 带审批凭据的回填 / 总回填 | = 100% | 0.000 |
| MTTD | 故障发现时延 | 从异常发生到告警触发的分钟数 | ≤ 15 min | 1.0 |
| DMR | 重复率上限 | 去重后行数 / 总行数的补数 | ≤ 5.0% | 0.005 |
| ORT | 越界行数 | 数值列超出声明区间的行数 | = 0 | 0.000 |

## 8 维发布门禁

| # | 门禁 | 判据 | 阻断级别 |
|---|---|---|---|
| G1 | 结构门禁 | DAG 无环（Kahn 全序）+ 依赖边无悬空 + 任务名唯一 | BLOCKER |
| G2 | 连接门禁 | connector 命名 `source-`/`destination-` 前缀 + 来源≠目的地 + 零凭据字段 | BLOCKER |
| G3 | 转换门禁 | 物化方式 4 枚举 + `ref()` 引用完整 + 不自引用 + incremental 有 unique_key | BLOCKER |
| G4 | 质量门禁 | 行数>0 + 空值率≤0.10 + 重复率≤0.05 + 越界行数=0（须实测） | BLOCKER |
| G5 | 新鲜度门禁 | age_hours ≤ SLA（默认 24h）+ 声明 loaded_at / snapshotted_at | BLOCKER |
| G6 | 增量门禁 | 模式 4 枚举 + 分区 4 枚举 + 增量/cdc 须 watermark + 幂等键 + 增量守恒 | BLOCKER |
| G7 | 目录门禁 | owner/updated_at 非空 + 字段类型 7 枚举 + 字段名唯一 + 血缘无环 | BLOCKER |
| G8 | 发布门禁 | bundle/SARIF/血缘 AST 落盘 + handoff 声明 + DRI=蛙数仓 | BLOCKER |

## 验收口径

1. 门禁判据以本文件为准；代码与文档不一致时**以本文件为基线**并修复代码。
2. 所有量化指标必须是可复算的（SQL 聚合或确定性算子），禁止自报数字直接 PASS。
3. 任何一次发布必须同时产出 8 维门禁结果与伴生消费工件（L07）。
