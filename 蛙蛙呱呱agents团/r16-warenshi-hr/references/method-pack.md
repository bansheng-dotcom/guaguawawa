# R16 蛙人识 · 人力 · 方法包（Method Pack v1）

## 1. 决策问题

- 典型决策：招不招、给不给 offer、怎么评估。
- 决策者：业务负责人；成功标准：人岗匹配、试用期通过率达标。
- 非目标：不做背景调查越界、不做录用承诺。

## 2. 问题树（MECE）

| 分支 | 要回答 | 假设 | 数据 | 方法 |
|---|---|---|---|---|
| 需求 | 这个岗位到底要解决什么 | 需求可拆成任务 | 岗位分析 | 任务清单 |
| 画像 | 什么能力/经验必要 | 必选项可验证 | 高绩效样本 | 评分卡 |
| 评估 | 怎么在面试中验证 | 结构化可复现 | 面试题库 | 结构化面试 |
| 薪酬 | 给多少、结构怎么定 | 内部公平 + 外部竞争 | 薪酬带宽 | 薪酬对标 |

**critical branch**：`评估`——资源优先给它。

## 3. 假设与证伪

- H1：评分卡能区分高/低绩效（试用期验证）。
- H2：薪酬在带宽内且不破坏内部公平。
- 竞争解释（至少 2 个）：招不到是画像太高，还是薪酬/渠道问题？；试用期不过是用人问题，还是招聘问题？
- 每条假设必须有**杀死标准**：指标 + 阈值 + 观察窗口。

## 4. 证据分级

| 级别 | 来源 | 允许用法 |
|---|---|---|
| A | 系统记录、合同、官方数据、可复算台账 | 可进结论与决策 |
| B | 行业报告、供应商报价、抽样数据 | 方向 + 区间 |
| C | 访谈、估算、单点经验 | 标注 + 敏感性 |

**规则**：每个结论挂来源；同名不同口径单列；缺什么、影响什么、怎么补，必须写清；C 级超过 3 条时结论降级为「条件成立」。

## 5. 方法与陷阱

- 评分卡：维度 × 权重 × 行为锚点，面试官独立打分。
- 结构化面试：同题同序，行为证据（STAR）。
- 试用期验证：30/60/90 天目标与评估。
**陷阱清单**：
- 凭感觉录用
- 排名而非绝对标准
- 越权承诺
- 只看履历不看行为
招聘结论必须给「证据 + 试用期验证计划」，不替业务拍板。

## 6. 输出契约

```
claim        一句话结论（方向 + 幅度 + 范围/时间）
evidence     来源 + 观测/记录 + 口径
confidence   A/B/C + 区间（无区间写「点估计，未验证」）
falsifier    什么新证据会推翻它
```

缺任一项 → 不得进首页；建议缺负责人/阈值 → 行动性不通过。

6. 有对照/基线吗？匹配了吗？

8. 最可能错在哪？
9. 建议有负责人/阈值/时间吗？
