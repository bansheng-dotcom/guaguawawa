# 语调三轴（Tone Axes）

> 一句话定位：**「语气不对」不是玄学，是三个刻度调错了。**
>
> 同一句话，把正式度调低、温度调高、能量调低，就从「公告」变成「朋友提醒」。
> 这张卡给的是**三个 1–5 的刻度 + 一套禁词替换表 + 可数的行文指标**，
> 让"像不像我们的口吻"变成可判定的东西。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**
- 「这句话语气不对」「太官方了 / 太皮了」
- 「把这段话改成我们口吻」「统一一下这几篇」
- 「为什么读起来很假」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 小红书字数/标签/埋词 | `r11` 的 `xhs-content-skills` | 那是发布结构 |
| 长文结构与论据 | `r11` 的 `longform-article` | 那是稿件结构 |
| 禁词合规扫描 | `r11` 的 `brand-voice` | 那是终稿校验 |
| 视觉与排版 | `r10` 的 `visual-hierarchy` | 那是视觉 |

**最小可开工输入**：**一段现有文案 + 目标平台**。

## §2 前置输入与最省追问

| 输入 | 是否必需 | 缺失时怎么办 |
|---|---|---|
| 现有文案（≥1 段） | 必需 | 无原文只能给原则 |
| 目标读者 | 必需 | 无读者无法定刻度 |
| 目标平台（小红书/公众号/官网/客服） | 建议 | 缺则按「小红书」默认 |
| 品牌语调基准（若有） | 建议 | 缺则按默认刻度 3/3/3 |

**追问纪律**：最多一轮，只问**这段是给谁看的、发在哪**。

## §3 执行流水线（Workflow）

### Step 1 · 定三个刻度（先定，再改）
每个刻度 **1–5**，改稿前先写下来：

| 轴 | 1（低） | 3（中） | 5（高） | 适用 |
|---|---|---|---|---|
| **正式度** | 口语、可省主语 | 书面但不生硬 | 公文、条款 | 客服 2 / 小红书 2 / 官网 3 / 合同 5 |
| **温度** | 冷静、去人称 | 有"我/你" | 亲密、共情 | 公告 2 / 内容 4 / 客服 4 |
| **能量** | 平实陈述 | 适度强调 | 强号召 | 说明书 2 / 种草 4 / 促销 5 |

**判据**：三个数写不出来 → 说明你还没想清这段要什么感觉，别急着改字。

**阈值**：同一篇内**刻度偏差 ≤1**（比如种草文全篇不该有"正式度 5"的段落）。

### Step 2 · 具体化（把形容词换成事实）
**阈值**：**形容词/程度副词 ≤3 处/千字**，且**每处必须配数字或事实**。

| ❌ 空泛 | ✅ 具体 |
|---|---|
| 这款产品非常好用 | 用了 11 个月还在用（上一支 4 个月进水报废） |
| 性价比超高 | 单价 89 元，同规格均价 130 元 |
| 效率显著提升 | 单次处理从 12 分钟降到 4 分钟 |

**禁用词表**（见到即换）：极致、顶级、业界领先、革命性、颠覆、赋能、闭环、抓手、打通、生态化。

### Step 3 · 控句长与段长（中文节奏）
**阈值**：
- 单句 **≤40 字**（移动端 ≤30 字）；
- 单段 **≤5 行**；
- 一段**只讲一件事**；
- 连续 3 句同长度 → 必须有一句长短变化（否则读起来像机器）。

### Step 4 · 标点与书写规范（中文）
| 规范 | 判据 |
|---|---|
| 中文用全角标点 | 「，。？！」非「, . ? !」 |
| 中英混排加空格 | 「用 Python 写」不是「用Python写」 |
| 数字与单位 | 「3 天」不写「三天」（数据类）；正文可写「三天」 |
| 不用感叹号堆情绪 | 全文 **≤2 个**「！」 |
| 省略号用「……」 | 不用「...」或「。。。」 |
| 不滥用破折号 | 全文 **≤3 处** |

### Step 5 · 三轴反查（改完往回对一遍）
把改完的稿子按三轴再打一次分：**与 Step 1 的设定偏差 ≤1 吗？**
偏差 ≥2 → 说明改过头或没改到点，回 Step 2。

### Step 6 · 抽样双评（确认"像我们"）
找 2 人对同一段独立按三轴打分：
- 两人数值差 **≤1** 且与设定一致 → 通过；
- 差 ≥2 → 该段口吻不稳定，重写（不是改分数）。

## §5 质量门（一票否决）

1. **三轴刻度已设定**，且全篇偏差 **≤1**；
2. 形容词/程度副词 **≤3 处/千字**，每处配数字或事实；
3. 禁用词表内词汇**数量 = 0**；
4. 单句 **≤40 字**、单段 **≤5 行**；
5. 标点规范四项（全角/中英空格/感叹号 ≤2/破折号 ≤3）全过；
6. **抽样双评**两人数值差 ≤1 且与设定一致。

> 本卡无自动门禁。可配合 `python harness.py edit --input <终稿.json>` 做禁词与语调结构扫描（间接）。

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 直接改字不定刻度 | 先定三轴 1–5，再改 |
| EX-02 | 一篇里正式度忽高忽低 | 全篇偏差 ≤1 |
| EX-03 | 用「极致/顶级/赋能」 | 删掉，换成具体事实 |
| EX-04 | 形容词堆叠 | ≤3 处/千字，且配数字 |
| EX-05 | 长句 60 字 | ≤40 字（移动端 ≤30） |
| EX-06 | 一段 8 行 | ≤5 行，一段一意 |
| EX-07 | 三句同长度像机翻 | 长短交替 |
| EX-08 | 中文里用半角标点 | 全角标点 |
| EX-09 | 中文与英文不空格 | 加空格 |
| EX-10 | 感叹号堆情绪（5 个！） | ≤2 个 |
| EX-11 | 双评分数差 2 还硬说一致 | 差 ≥2 就重写该段 |
| EX-12 | 为"活泼"牺牲信息量 | 温度与具体化不冲突，两个都要 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 无品牌基准 | 按目标平台默认刻度，标注「基准待确认」 |
| 术语必须用（B 端合同） | 保留术语但**首次出现加白话解释** |
| 平台限制字数 | 优先砍背景与修饰，不砍事实 |
| 多平台同一内容 | 保三轴一致，只调长短与格式 |
| 用户要求"更夸张" | 说明会降低可信度；可加事实增强而非形容增强 |
| 文案涉及功效/医疗 | 明确不做功效宣称，只写使用体验 |

**明确不做**
- 不做字数/标签/埋词（归 `xhs-content-skills`）、不做 SEO、不承诺转化。
