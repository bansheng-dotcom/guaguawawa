# 小红书笔记结构

> 归属：R11　消费：r10, r12　版本：v1

## 定位

小红书笔记六要素咬合：选题、标题、封面、正文、图片、标签。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 标题 ≤20 字，前 5–10 字放核心词
2. 正文 ≤500 字放正文区，超长拆文字图
3. 标签 3–8 个，复用标题/正文里的词
4. 封面优先真人感（实拍/截图），不是海报感

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
