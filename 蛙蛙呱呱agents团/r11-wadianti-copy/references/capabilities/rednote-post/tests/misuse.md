# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`，无命令门禁），因此本表是**人工评审清单**。
> 每条都由评审者判真假，判不了的写「不可判定」。版本：v2.0.0

## 一、硬门（§5，任一不过即不得交付）

| MU-01 | 标题前 10 字有钩子 | §5 第 1 条 |
| MU-02 | 五段齐全（场景/冲突/解法/证据/行动） | §5 第 2 条 |
| MU-03 | 每段有一句可截图短句 | §5 第 3 条 |
| MU-04 | 互动引导是具体问题 | §5 第 4 条 |

## 二、软门（§6 自检，靠人抓）

| MU-04 | 标题前 10 字能让人停下来 |
| MU-05 | 五段都在，没缺「证据」段 |
| MU-06 | 每段有一句 ≤20 字的可截图短句 |
| MU-07 | 互动引导是一个具体问题 |
| MU-08 | 全篇只讲一件事 |
| MU-09 | 没有用形容词代替具体经验 |

## 三、诚实说明

本卡**没有**可自动断言的门禁：它的输入是判断与决策，不是固定 schema。
写一个「永远 exit 0」的脚本只会制造假绿——这比没有门禁更糟。

> **纪律**：knowledge 卡的价值在「有方法可依」，不在「有分数可刷」。
