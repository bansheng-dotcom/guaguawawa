# R11 蛙点题 · 内容 · 方法包（Method Pack v1）

## 1. 决策问题

- 典型决策：这篇能不能发、怎么改。
- 决策者：增长/品牌负责人；成功标准：主张清楚、证据可核、合规无禁词。
- 非目标：不做投放、不承诺流量。

## 2. 问题树（MECE）

| 分支 | 要回答 | 假设 | 数据 | 方法 |
|---|---|---|---|---|
| 读者 | 写给谁、他关心什么 | 读者画像具体 | 用户访谈/评论 | 读者画像 + 场景 |
| 主张 | 一句话说什么 | 主张单一可记 | 卖点清单 | 主张测试 |
| 证据 | 凭什么信 | 证据可核 | 数据/案例 | 证据分级 |
| 合规 | 会不会踩线 | 禁词为零 | 广告法/平台规则 | 合规扫描 |

**critical branch**：`主张`——资源优先给它。

## 3. 假设与证伪

- H1：读者能在 10 秒内复述主张。
- H2：证据足以支撑主张，不需要「最/第一」等绝对化表述。
- 竞争解释（至少 2 个）：没人看是标题问题，还是渠道问题？；转化低是文案问题，还是产品问题？
- 每条假设必须有**杀死标准**：指标 + 阈值 + 观察窗口。

## 4. 证据分级

| 级别 | 来源 | 允许用法 |
|---|---|---|
| A | 系统记录、合同、官方数据、可复算台账 | 可进结论与决策 |
| B | 行业报告、供应商报价、抽样数据 | 方向 + 区间 |
| C | 访谈、估算、单点经验 | 标注 + 敏感性 |

**规则**：每个结论挂来源；同名不同口径单列；缺什么、影响什么、怎么补，必须写清；C 级超过 3 条时结论降级为「条件成立」。

## 5. 方法与陷阱

- 主张—证据表：每个主张配 1 条证据，缺证据就删主张。
- 禁词/绝对化扫描：发布前机器过一遍。
- 结构：结论先行 + 3 段论据 + 行动号召。
**陷阱清单**：
- 自嗨式形容词
- 绝对化用语
- 证据与主张不匹配
- AI 味排比句
内容交付必须附「合规扫描结果」与「主张—证据表」。

## 6. 输出契约

```
claim        一句话结论（方向 + 幅度 + 范围/时间）
evidence     来源 + 观测/记录 + 口径
confidence   A/B/C + 区间（无区间写「点估计，未验证」）
falsifier    什么新证据会推翻它
```

缺任一项 → 不得进首页；建议缺负责人/阈值 → 行动性不通过。
