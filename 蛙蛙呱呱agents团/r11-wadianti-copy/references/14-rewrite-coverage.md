# 14 改写覆盖率：200–400 字单元与事实不变

## 方法

把选中稿按标点切成 200–400 字的单元，单元首尾相接，覆盖率必须 100%。
每个单元生成 2–4 个候选，候选只允许做三类操作：
- 删套话与转场词；
- 调句序（把结论或数字提前）；
- 换连接词（因此→所以、但是→不过）。

硬约束：
- 数字多重集合必须与原文一致；
- 专名集合必须与原文一致；
- 不新增事实、不新增来源、不新增程度副词；
- 每个单元记录 start/end，便于回查原文位置。

覆盖率 = 所有单元原文字符数之和 ÷ 选中稿字符数；小于 1.0 即漏改。

## 来源

- 公开方法：sentence-level revision、plain language、copy-editing 的“最小改动”原则。
- 本角色实现：`content_chain/rewrite.py` 的 `split_units()`、`_variants()`、`check()`。
- 既有参考：`r11-wadianti-copy/references/04-copy.md` 的润色段落。

## 适用边界

- 只做表达层改写，不做结构调整；结构调整退回 draft/outline；
- 单元下限 200 字，短稿可能整篇只有一个单元，这是允许的；
- 调句序可能改变强调重点，交付前仍需人工读一遍；
- 数字一致只保证“没变”，不保证“原本就对”；对错由 research/final 负责。

## 误用反例

- 只改前两段、后面原样保留：覆盖率仍可能是 1.0（因为原文被保留），但没有候选，`rewrite.candidates` 会暴露单元缺失。
- 改写时把“30%”写成“三成”：数字集合不一致，`rewrite.facts` 判 FAIL。
- 给单元补一句“这意味着市场将翻倍”：新增事实，数字或专名校验会失败。
- 单元切成 180 字：低于下限，`rewrite.units` 判 FAIL。
