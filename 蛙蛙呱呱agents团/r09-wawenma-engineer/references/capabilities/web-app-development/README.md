# 生产级 Web 界面

> 归属：R09　消费：r08, r10　版本：v1

## 定位

生产级界面的实现与审查要点：语义化、响应式、性能与可访问性。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 语义化标签与键盘可达是底线，不靠 div 堆
2. 响应式断点按内容断，不按设备断
3. 首屏资源预算写清楚（体积/请求数）
4. 审查清单：对比度、焦点、表单错误、空状态

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
