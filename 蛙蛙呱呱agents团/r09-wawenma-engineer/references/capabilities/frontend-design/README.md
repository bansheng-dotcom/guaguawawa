# 高质量前端界面

> 归属：R09　消费：r08, r10　版本：v1

## 定位

避免「AI 味」的界面设计原则：克制、层级、真实内容。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 一个页面一个视觉重心，强调色不超过两处
2. 字号阶梯 ≤5 级，间距用同一套刻度
3. 用真实文案长度做布局测试
4. 动效只服务理解，不做装饰性循环

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
