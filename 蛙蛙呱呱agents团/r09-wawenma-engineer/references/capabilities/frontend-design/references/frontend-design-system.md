# 界面设计六件套（frontend-design-system）

> 被 §3、§5、§6 按需引用。版本：v2.0.0（项目自建，v1）

---

## 一、主任务与三眼层级

```markdown
- 给谁用：<角色> 在 <场景> 下
- 完成什么任务：<一句话，动词开头>
- 第一眼：<必须立刻看到的信息>
- 第二眼：<需要时的依据>
- 第三眼：<极少用的入口>
```

**判据**：如果第一眼元素被删掉，用户会不会做错事？不会 → 它不是一级。

| 常见错法 | 后果 |
|---|---|
| 把所有信息做成同样字号 | 没有焦点，用户逐个读 |
| 主操作与取消同样样式 | 误触，且不可挽回 |
| 关键状态藏在二级 | 用户在错误状态下继续操作 |

## 二、间距与字号刻度（硬表）

**间距七档**：`4 / 8 / 12 / 16 / 24 / 32 / 48`

| 关系 | 建议值 |
|---|---|
| 同组元素之间 | 4 或 8 |
| 不同组之间 | 16 或 24 |
| 区块之间 | 32 或 48 |
| 页面边距（移动） | 16 |
| 页面边距（桌面） | 24 或 32 |

**字号 ≤5 级**

| 级 | 值 | 用途 | 行高 |
|---|---|---|---|
| 1 | 28 | 页面标题 | 1.2 |
| 2 | 20 | 区块标题 | 1.25 |
| 3 | 16 | 小标题 / 强调 | 1.4 |
| 4 | **14** | 正文（下限） | 1.5 |
| 5 | 12 | 辅助 / 标注 | 1.5 |

> 出现 13px / 18px / 22px 这类值，基本是"看着差不多"调出来的，不是设计出来的。

## 三、色彩与对比度

| 用途 | 最低对比度 | 说明 |
|---|---|---|
| 正文 | **4.5:1** | WCAG AA |
| 大字（≥18px 粗 / ≥24px） | 3:1 | —— |
| 图标、边框、输入框边线 | 3:1 | 非文本对比 |
| 禁用态 | 可不达 3:1 | **必须另加语义**（如"暂不可用"文案） |

**颜色不能是唯一载体**：错误 = 红 + 图标 + 文字；成功 = 绿 + 对勾 + 文字。
只靠颜色，色盲用户与灰度打印都会失效。

## 四、组件六态矩阵

| 组件 | 默认 | 悬停 | 焦点 | 禁用 | 加载 | 空/错误 |
|---|---|---|---|---|---|---|
| 按钮 | | | 焦点环可见 | 变灰 + 说明 | 转圈 + 禁用 | 失败提示 |
| 输入框 | | | 边框高亮 | 只读态 | —— | 错误文案 + 位置 |
| 列表 | | 行高亮 | 行可聚焦 | —— | 骨架屏 | 空态说明 |
| 表格 | | 行高亮 | 单元格可聚焦 | —— | 骨架屏 | 空态 + 怎么开始 |
| 弹窗 | | —— | 焦点陷阱 | —— | —— | 加载中断处理 |

**空态必须回答两个问题**：为什么是空的？用户下一步能做什么？

## 五、断点与响应式

| 断点 | 必须验证 |
|---|---|
| **375** | 无横向滚动；触控目标 ≥44×44；文字不溢出 |
| **768** | 栅格 1 列 → 2 列；导航折叠 |
| **1280** | 内容最大宽度受限（≤1200px），不无限拉伸 |

**375 无横向滚动**是最容易被忽略、也最容易被用户抱怨的一条。
检查方法：浏览器设备模拟选 375，横向拖动看是否出现滚动条。

## 六、可访问性四条（可判定）

| # | 检查 | 判据 | 常见违规 |
|---|---|---|---|
| 1 | 键盘可达 | Tab 走完全部可交互元素，顺序符合视觉顺序 | 自定义 div 按钮没有 tabindex |
| 2 | 焦点可见 | 每个焦点都有可见环 | `outline: none` 没有替代 |
| 3 | 语义化 | 标题不跳级（h1→h2→h3）；按钮用 `<button>` | 全站 h3 当标题 |
| 4 | 替代文本 | 有意义的图有 alt；装饰图 alt="" | alt 写"图片" |

**额外一条**：表单每个输入都要有可关联的 label（`for` 或包裹），
placeholder 不能替代 label——它一输入就消失。

## 七、评审时的优先级

当页面问题很多，先改哪一个：

| 优先级 | 判据 | 例 |
|---|---|---|
| **P0** | 会导致误操作或不可用 | 主操作与取消同权重、焦点不可见、375 横向滚动 |
| **P1** | 影响理解与效率 | 层级不清、空态缺失、错误提示不具体 |
| **P2** | 影响观感与一致性 | 间距不在刻度内、字号过多 |
| **P3** | 打磨 | 微动效、细节对齐 |

> 先修 P0，再谈"好不好看"。一个能误删数据的漂亮界面，比一个朴素但安全的界面差得多。
