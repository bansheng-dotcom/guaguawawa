# 报告视觉评审清单（REPORT-VISUAL-REVIEW）

> 对应契约：`docs/REPORT-DESIGN-CONTRACT.md`。机器能查的走 `check_report_presentation.py`；
> 本清单只留**必须人读**的判断项，按黄金报告逐条签字。

## 使用方式

1. 先跑机器门禁：`python scripts/check_report_presentation.py --dir <报告目录>`，0 违规才进入人工评审；
2. 对每份黄金报告复制一份下表，逐项填「过 / 不过 / 不适用 + 理由」；
3. 任一「不过」不得发布；「不适用」必须写清为什么。

## 人读评审表

| # | 评审项 | 看什么 | 判定 |
|---|---|---|---|
| V1 | 阅读路径 | 从标题到结论到证据，眼睛是否按 h1→h2→图表→注的顺序走，没有跳回 | 是 / 否 |
| V2 | 结论先行 | 首屏（前 20%）是否给出结论与代价，而不是背景铺陈 | 是 / 否 |
| V3 | 强调克制 | 全篇强调色是否只用于“需要行动/异常”的位置，装饰性用色是否可删 | 是 / 否 |
| V4 | 图文互证 | 每张图是否在正文被解释一次（不是“见图 1”），图是否真的支撑该段结论 | 是 / 否 |
| V5 | 数字可读 | 关键数字是否有单位、口径、对比基准；大数是否用千分位/万/亿 | 是 / 否 |
| V6 | 边界诚实 | 是否写出“这份报告不能回答什么”、数据缺口与未验证结论 | 是 / 否 |
| V7 | 表格可扫 | 表头是否固定语义、列宽是否让数字右对齐、空值是否显式标注 | 是 / 否 |
| V8 | 风格一致 | 是否与所选风格包 sample 的版心、字阶、色彩语义一致 | 是 / 否 |
| V9 | 打印预览 | 按 A4 打印预览，是否出现孤行、图表跨页、表格断头 | 是 / 否 |
| V10 | 删减测试 | 删掉任意一个装饰元素，信息是否不受损；若不受损则应删 | 是 / 否 |
