# R10 风格准入三步

> 目的：以后加一种风格，是**改数据 + 跑基准**，不是改代码。
> 适用：`r10-wachengmei-design`。判据由 `skills/s01_imagegen.py` 的 `_admission()` 实现，不靠感觉。

---

## 第 1 步：写注册表（10 分钟）

在 `experience/style_registry.json` 的 `entries` 里加一条：

```json
{
  "id": "style.<新风格>",
  "axis": "style",
  "level": "experimental",
  "parent": "<渲染到哪个 core>",
  "render_style": "<10 个 core 之一>",
  "aliases": ["中文名", "english-alias"],
  "desc": "一句话特征",
  "positive_recipe": "English prompt recipe, 20–40 words",
  "negative_recipe": "English negative recipe",
  "text_policy_default": "none | overlay-later | render-attempt",
  "aspect_default": "1:1 | 4:3 | 3:4 | 16:9",
  "failure_modes": ["已知会怎么坏"],
  "baseline": {"seeds": 0, "pass": 0, "checked_at": "", "sample": ""}
}
```

硬约束（`run_tests.py` T9 会查）：

- `render_style` 必须 ∈ `thresholds.imagegen.style_types`（10 个 core 之一）。
- `level=core` 的记录，`id` 去前缀后必须出现在 `style_types` 数组里 —— 数组是注册表的投影，不许手写两处。
- `level=extended` 必须有 `parent`、`render_style`、≥1 条 `failure_modes`。
- `level=experimental` **不允许**出现在 `style` 字段（门禁直接 BLOCKER），只能写进 prompt 文本层。

**新条目一律先写 `extended` + `baseline` 全 0。** 不许一上来就写 `core` —— core 是对外承诺。
`experimental` 是**降级区**：3 seed 里不足 2 过才落到这里，此时禁止占用 `style` 字段。

---

## 第 2 步：跑 3 seed 基准（约 10 分钟/条）

同一 `positive_recipe`、同一主体、同一画幅，跑 **3 次**，不能用 1 次的结果下结论。

每次记录：

| 字段 | 怎么判 |
|---|---|
| 图能生成 | 返回真实画面，不是 "The image is generating…" 占位图 |
| 风格锁命中 | 人眼：看得出是这个风格，不是别的 |
| 无文字污染 | 画面里没有乱码字母/自造品牌名 |
| 主体完整 | 无畸形、断肢、糊化 |
| 客观检查（有就做） | 双色/像素族：90% 像素落在多少色桶（duotone ≤120，pixel ≤500） |

三条都满足算 1 个 seed 过线。把 `seeds` / `pass` / `checked_at` / `sample` 写回 `baseline`；
若有客观检查，加 `"objective": ["palette"]`，否则只算「有样张」不算「已验证」。

---

## 第 3 步：按判据定级（`_admission()`，写死）

| 条件 | 建议 level |
|---|---|
| `seeds ≥ 3` 且 `pass ≥ 2` | **core**（可对外承诺） |
| `seeds ≥ 3` 且 `pass < 2` | **experimental**（降级：禁止占 style 字段） |
| `seeds < 3` | **extended**（有样张但不稳定，需人工过目） |
| `seeds = 0` | **extended**（只有声明，未验证；软放行） |

核对命令（只报不改，改 level 必须人工确认）：

```bash
python agent.py imagegen admit      # 列出与判据不一致的条目
```

改完 level 后必须做三件事，缺一不可：

1. `python run_tests.py` —— 100 条全绿（T9 会校验 core 数组 == 注册表投影）
2. `python agent.py imagegen catalog` —— 目录颜色与状态跟着变
3. 同步 3 份镜像（`traeskills` / `wawa-guagua` / `workbuddy专家团`）+ 6 条仓库自检

---

## 禁止事项

1. **不许把 `seeds<3` 的条目升 core** —— 一张样张只能证明"出得来"，不能证明"稳"。
2. **不许为了让目录好看改 `pass`** —— `pass` 是证据，不是指标。
3. **不许把 experimental 塞进 `style` 字段** —— 门禁会拦，绕过等于放弃验收。
4. **不许改 4 份镜像里的 `level`** —— 只改源，再同步。
5. **不许把「白名单里有」当成「能兑现」** —— `pixel` 就在 core 里，实测硬边和限定色板都没达成，`baseline.pass` 记的是 0。

## 当前阻断点（2026-11-11）

`https://trae-api-cn.mchost.guru/api/ide/v1/text_to_image` 无鉴权调用会返回**固定的占位图**
（`The image is generating…`，1832×1832，多次不同 prompt / image_size 的 sha256 完全相同），
所以第 2 步无法在本机跑通。需要：

- 在已登录的 Trae IDE 里触发生成（像 2026-11-11 那批 35 张一样），或
- 提供带鉴权的接口/cookie。

在此之前，27 条 `seeds=0` 的条目保持 `experimental`/`extended`，不对外承诺。
