# 20 角色能力域 / 业务链矩阵

> 目的：回答一个根本问题——报告不能只换角色名，必须换**业务链、指标、方法、证据、图表、决策类型**。  
> 当前 `generate_20_deep_reports.py` 只做到了“同一骨架 + 角色变量替换”，这份矩阵是升级为“角色适配器”的底座。

## 1. 七个角色族

| 族 | 角色 | 共同点 | 不能共用的部分 |
|---|---|---|---|
| 治理/决策 | R01 R02 R04 | 任务、决策、验收 | 业务链、证据类型、裁决方式 |
| 财务/合规 | R03 | 账、税、现金、红线 | 口径、合规门禁、报表勾稽 |
| 研究/分析 | R05 R06 | 问题、证据、归因 | 数据等级、方法、图表 |
| 产品/工程/设计 | R07 R08 R09 R10 R17 R18 | 需求→实现→验收 | 交付物、测试方式、上线风险 |
| 内容/增长/客户 | R11 R12 R13 R14 | 触达→转化→留存/履约 | 指标、渠道、客户生命周期 |

## 3. 三个必须不同的例子

### R06 数据分析

```text
数据 → 口径 → 指标 → 归因 → 行动
```

必须有：口径表、趋势/结构/归因图、显著性/边界。  
不能有：把“客户与复购”套到所有角色。

### R15 供应链

```text
需求 → 询价 → TCO → 合同 → 库存 → 履约
```

必须有：报价同币种、MOQ、关税、库存周转、TCO 对比。  
不能有：只比单价；不能把“客户留存”当主章节。

### R19 模型评估

```text
数据 → 训练 → 评估 → 回归 → 发布 → 监控
```

必须有：评测集、评分器、回归对比、失败样本诊断。  
不能有：用“渠道价差/客户复购”模板。

## 4. 代码架构：从“一个模板”到“角色适配器”

当前问题：

```python
# 所有角色共用同一套 13 个模块
for role in ROLES:
    build_same_13_modules(role)
```

目标：

```yaml
# configs/roles/r15.yaml
id: r15
family: supply_chain
chain:
  - {id: demand, label: 需求, metric: 采购量}
  - {id: quote, label: 询价, metric: 报价}
  - {id: tco, label: TCO, metric: 总拥有成本}
  - {id: contract, label: 合同, metric: MOQ/账期}
  - {id: inventory, label: 库存, metric: 周转}
  - {id: fulfill, label: 履约, metric: 缺货率}
sections:
  - tco_compare
  - moq_risk
  - inventory_turn
  - supplier_concentration
  - contract_terms
  - scenario
  - decision
charts:
  tco: waterfall
  moq: hbar
  inventory: line
gates:
  - tco_must_include_freight_duty
  - quote_currency_must_match
```

生成器：

```python
spec = load_role_spec(role_id)
sections = build_sections_from_spec(spec)
visuals = choose_visuals(spec.metrics, spec.charts)
pack = assemble(spec, sections, visuals)
```

共享的只有：

- 版式；
- 章节结论框；
- 图表渲染；
- 数据口径表；
- 质量门。

**不能共享**的是：

- 业务链节点；
- 指标树；
- 分析方法；
- 证据类型；
- 决策模型；
- 图表语义。

## 5. 迁移顺序

| 阶段 | 内容 | 验收 |
|---|---|---|
| P0 | 20 个角色 spec（本矩阵） | 每个角色有独立 chain/metrics |
| P1 | 3 个族样板：R06 分析、R15 供应链、R19 AI 评估 | 三份报告结构不同 |
| P2 | 20 个角色适配器 | 不再出现“对象与留存”这类硬套 |
| P3 | 质量门：chain 节点/图表/来源 | 缺一项不生成 |

## 6. 一句话

> 现在的代码能生成“20 份同构报告”，但还不能生成“20 个角色的报告”。  
> 区别不在版式，在业务链、指标、方法和证据。
