# 报告产线 v6：新业务研究（采集 → 校验 → 台账 → 成稿）

> 2026-11-15。解决的问题：**只给一句话业务，也要能产出有出处、可复核的可行性研究**。
> v5 之前产线只读本地数据；v6 补上「外部证据」这一段：来源、引文、回抓核对、台账。

---

## 一、为什么不是「让模型直接写」

新业务报告最容易出的问题不是文笔，是**证据链断裂**：数字不知道哪来的、
引文和原文对不上、结论没有反方。所以 v6 把流程拆成四段，每段都可校验：

```
data/sources.json   （每条：id / url / title / date / type / quote）
      │
      ▼  verify：回抓每个 url，quote 必须能在正文命中
data/quote_check.json（ok / mismatch / unreachable）
      │
      ▼  ledger：claims + sources → r05 research ledger
gates/r05_ledger.json（覆盖率、悬空引用、类型白名单、PASS/FAIL）
      │
      ▼  report_compose（market_entry 纲领）
报告 + manifest（research.quotes / research.ledger 一并留痕）
```

**硬规则：有一条 quote 对不上，直接拒绝出报告。** 不是警告，是 fail closed。

---

## 二、方法：研究类四个方法（facts 驱动）

数据不再只有 CSV，还支持「带来源的事实表」`data/facts.json`：
每条事实有 `id / metric / value / unit / period / source_id / grade(A/B/C)`，
假设单独放 `assumptions`（同样带 grade 与 note）。

| 方法 | 产出 | 关键纪律 |
|---|---|---|
| `sizing_multi` | 三条路径的规模 + 区间 + 差异倍数 | 不给单点；产值法/品牌法/人口法必须互证；收敛区间才可做预算 |
| `growth` | 五年 CAGR、供需增速、B/C 端引擎切换 | 用同一口径的两个时点算 CAGR；单一公司增速不代表全行业 |
| `concentration` | CR2 / HHI 上下界 | 「其他」未拆分时只能给界，不能给点值 |
| `unit_econ` | 出厂价、单位成本、净利、保本价、原料敏感性 | 假设逐条声明（出成率/奶价/加工/渠道），并给「涨价 20%」压力测试 |
| `entry_gate` | 进入条件 + 三条杀死条件 | 每条动作都带停止条件 |

`market_entry` 纲领把五个方法串成一类报告：
`规模 → 增长 → 集中度 → 单位经济 → 闸门`，主证据是 `sizing_multi + unit_econ`。

```bash
# 调试用：跳过回抓 / 跳过台账
python guagua.py report research ... --skip-verify --skip-ledger
```

项目目录最小结构：

```
新业务_xxx/
  data/sources.json     # 来源与引文（必须）
  data/claims.json      # 结论与来源映射（台账用）
  data/facts.json       # 事实表 + 假设（方法用）
  raw/                  # 回抓的原文（自动生成）
  gates/r05_ledger.json # 台账结果（自动生成）
```

## 四、这次真跑的结果

选题：**内蒙古特色奶酪零食（奶豆腐/奶皮子/奶条）新业务可行性**

| 项 | 结果 |
|---|---|
| 来源 | 5 个（内蒙古日报/农民日报/中国报告大厅×2/中国食品安全报） |
| quote 回抓 | 5/5 命中，0 mismatch |
| 台账 | 13 条结论 / 5 个来源，覆盖率 100%，R05 **PASS** |
| 事实 | 37 条事实（A/B 级）+ 8 条假设（C 级） |
| 章节 | 7 节 / 4 图 / 5 表 / 密度 66.5 |
| 门禁 | 九条 PASS |

核心结论：

- 规模三条路径 **4—20 亿元**，品牌法与人口法收敛在 **4—6 亿元**；
  产值法（12.5—20 亿）含工业口径，只能当天花板；
- 单位经济：出厂价 57.14 元/公斤、成本 36.00 元、扣 25% 渠道后净利 **6.86 元（12.0%）**，
  保本价 **48.00 元/公斤**；原料涨 20% 净利只剩 **2.06 元**；
- 集中度：CR2 **53.2%**，HHI 1675—3865，双寡头；C 端即食不可正面打；
- 判断：**能做，但只做 B 端（餐饮工业/烘焙）与礼盒，先代工验证，不先建厂**。

## 五、边界（必须先读）

1. **采集仍由 agent 完成**：找来源、写 quote 是人的判断；产线只负责「回抓核对 + 台账 + 计算 + 成稿」。
   它不会自己去搜「哪个行业值得研究」。
2. **quote 校验能防改写，不防断章取义**：引文确实在原文里，但不等于原文结论正确；
   来源分级（A/B/C）只标权威度，不标真实性。
3. **假设是 C 级**：出成率 8:1、奶价 3.0 元/公斤、加工 12 元、渠道 25% 均未取得企业台账，
   报告已逐条声明并做压力测试。
4. **细分口径不存在**：内蒙古「奶酪零食」没有官方统计，规模只能三路互证给区间，不能给点值。
5. **公开信息有偏**：上市公司披露偏 C 端，区域产业数据偏产值，B 端真实价格拿不到。
