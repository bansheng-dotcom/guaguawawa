# R10 灵感检索与版权边界

> 2026-11-11 · R10 不自己乱爬。它要么给可执行检索计划，要么在你的授权下抓公开页面；
> 无论哪种，**版权判断先于使用**。

---

## 一、三种运行模式

| 模式 | 触发 | 需要 | 产出 |
|---|---|---|---|
| **A 离线计划** | `imagegen inspire --need "..."` | 无网络 | 站点清单 + 检索词 + 该看什么 + 版权档位 + `prompt_seed` |
| **B LLM 自带联网** | 把你的大模型 web 工具接上，用计划里的 URL/关键词去搜 | 模型侧联网能力 | 由模型回填「看到了什么」，R10 负责整理成参考条目 |
| **C R10 自己抓** | `imagegen inspire --need "..." --fetch` | 出口可达 | 抓公开 HTML 的 title/description/og:image（`robots.txt` 先查） |

实测 C 模式对 `fontsinuse.com`、`typewolf.com`、`fontshare.com` 可用；对多数被墙域名会返回 `ok=false` 并带原因，不会假装成功。

## 三、版权判断（三档，写进数据里）

| 档位 | 含义 | 允许 | 禁止 |
|---|---|---|---|
| `free-asset` | 明确可商用素材（Unsplash / Pexels / Google Fonts / Fontshare / LottieFiles） | 下载用于成品 | 拿素材站图片直接当品牌 logo 注册 |
| `inspiration-only` | 作品集 / 灵感站（Dribbble / Behance / Awwwards / 站酷…） | 看配色、排版、气质、结构思路 | **复刻具体构图、图形、角色、文案**；直接截取使用 |
| `licensed-only` | 需购买或订阅（图库、商业字体） | 购买后按授权用 | 未授权抓取、转售、再分发 |

硬规则（每次 `inspire` 都会带回 `rights_notice`）：

> 只可参考配色 / 排版 / 氛围，禁止复刻具体构图、图形、角色、文案；
> 素材站素材不得直接当品牌 logo 或主视觉使用；无授权不得转售或再分发。

对应的提示词写法：**参考注入进描述层，绝不把参考图当图生图输入**。`compose` 只接受 `--ref <设计系统>`（本地 DESIGN.md 的配色/字体气质），不接受"照这张画"。

## 四、与提示词的接法

```bash
# 1. 先拿计划（离线可用）
python agent.py imagegen inspire --need "高原蔬菜包装的高级感" --category packaging

# 2. 计划里的 prompt_seed 就是可用的"参考方向"句子
#    "参考方向：包装结构与货架视觉；材质工艺与盒型参考。只借鉴配色与排版气质，不复刻版式。"

# 3. 塞进 compose 的 mood
python agent.py imagegen compose --need "冷凉蔬菜礼盒主图" --style 3d-food \
       --mood "包装结构与货架视觉；材质工艺与盒型参考；只借鉴气质不复刻版式"
```

想更精确，用本地 31 套真实产品的 DESIGN.md 做定调：

```bash
python agent.py imagegen compose --need "..." --style gradient --ref linear
```

## 五、扩展与限制

**加站点**：在 `references/inspiration-sites.json` 的 `sites` 里加一条（`id/name/url/category/access/rights/focus`），无需改代码。

**已知限制**：

1. 登录墙站点（Mobbin / 花瓣 / 古田路9号）只能给链接，抓不到内容；
2. 抓取只读公开 HTML，不下载图片、不带 cookie、先查 `robots.txt`；
3. 不要高频抓取——这是找灵感，不是建索引库；建议一次 3 条以内；
4. 被抓站点的图片版权仍归原作者，`og:image` 只作定位线索，**不落进成品**。
