# 能力链断点分析（2026-11-11）

> 方法：不按「角色够不够」看，按**业务链条**看。
> 一条链上任一环缺失，后面全部空转——就像出图链在「判据 → 出图」之间断了那样。
>
> 现状（v45）：20 角色 / **75 个技能包** / **41 张 knowledge 卡**。

## 四、不建议现在做的

| 项 | 原因 |
|---|---|
| 组织设计 / 绩效 / 薪酬 | 当前是 20 人专家团不是实体公司，需求未触发 |
| 税务与发票 | 强合规领域，AI 只能给边界提示，价值有限、风险高 |
| 模型漂移监控 | 需要线上流量才有意义，现在没有 |
| 备份容量规划 | 同上，等有生产系统再做 |

## 五、一个观察

**重的地方在"生产端"（r10 十张、r08 五张、r11 五张），薄的地方在"经营端"（r12/r13/r14/r16 各 1–2 张）。**

这符合项目长出来的顺序——先把"能把东西做出来"补齐，再补"做出来的东西怎么卖、怎么留客户、怎么算账"。

但现在这个平衡明显偏了：**我们很会做图、做页面、写文案，却不太会定价、看数据、留客户。**

如果接下来只做三件事，我会选：
1. **定价与促销**（交易链起点，直接决定毛利）
2. **埋点与分析方法**（两个缺口一起做，否则所有"效果"都不可信）
3. **客户上手与续约**（客户链两端，直接决定续费率）
