# R10 生图引擎接入与占位图防护

> 2026-11-12 · 针对实测中「接口一直返回同一张图」的问题。
> 一句话：**那不是重试不够，是接口在骗你；重试只会更慢地拿到同一张假图。**

---

## 一、问题的本质

实测 `https://trae-api-cn.mchost.guru/api/ide/v1/text_to_image`：

| 变量 | 结果 |
|---|---|
| 换 prompt（10 种风格） | 返回字节完全相同 |
| 换 `image_size`（square/16:9/4:3） | 完全相同 |
| 轮询同一 URL 64 秒 | 完全相同 |
| MD5 | 恒为 `19a0b822edb11957055e4588c2159058` |

结论：**无鉴权调用恒返回占位图**（1832×1832，内容为 "The image is generating…"）。
任何「重试 N 次」的写法都只是把同一张假图拿 N 次，并把整个任务拖慢几分钟。

---

## 二、三层防护（已实现）

| 层 | 位置 | 作用 |
|---|---|---|
| **指纹识别** | `engines/placeholder_guard.py` → `KNOWN_PLACEHOLDER_MD5` | 精确命中已知占位图 MD5 |
| **兜底识别** | 同文件 `_low_variance()` | 灰度方差 < 6（近似纯色）也判占位 |
| **统一拦截** | `engines/manager.py` 的 `generate()` → `guard_result()` | 引擎返回占位图时 `ok=False`，清空 `image_paths`，不让下游当成品 |

被拦时的错误信息：

```
<engine> 返回占位图：接口返回的是占位图（stub），不是真实生成结果；
重试/换 prompt 都无效，需换到有鉴权的真实引擎（imagegen engines 可查）
```

另外 `imagegen score --dir` 现在也会把占位图标出来（`placeholder_md5: true`）。

## 三、想真出图：两条可走的路

### 路 A：接已有引擎（8 个，见 `imagegen engines`）

```powershell
$env:COMFYUI_URL = "http://127.0.0.1:8188"      # 本地
$env:SILICONFLOW_API_KEY = "sk-..."             # 或任一云端 Key
python agent.py imagegen engines                # 看到 [在线] 即可
python agent.py imagegen generate --input brief.json
```

### 路 B：接你自己的生成器（新增，第九个引擎）

如果你有别的生成通道（MCP、CLI、带鉴权的 HTTP 脚本），不用改代码：

```powershell
$env:R10_IMAGE_CMD = "python D:/my_gen.py"
python agent.py imagegen engines    # 会多出 custom / Custom-Cmd
```

`R10_IMAGE_CMD` 的契约（R10 通过 stdin 传 JSON）：

```json
{
  "prompt": "……",
  "negative_prompt": "……",
  "width": 1024, "height": 1024, "seed": -1,
  "out": "C:/.../r10_custom_<ts>.png"
}
```

你的脚本要做两件事：**读 stdin**，**把图片写到 `out`**（或把路径打印到 stdout）。
最小示例（`my_gen.py`）：

```python
import json, sys
from PIL import Image
payload = json.load(sys.stdin)
Image.new("RGB", (payload["width"], payload["height"]), (10, 120, 60)).save(payload["out"])
```

> 这个例子只是证明链路通，不是生成模型。把它换成你真实的调用即可。

校验：`CommandEngine` 会检查 `out` 是否存在、命令退出码是否 0；任一项不满足就判失败，
不会返回空路径。

## 四、为什么不做「自动重试到成功」

1. 占位图是**确定性返回**，重试没有信息增益；
2. 每次重试有 10–35 秒退避，10 张×6 次就是十几分钟白等；
3. 更危险的是：如果不识别，最终会拿占位图继续跑 `imgops`/验收，产出「假成品」。

所以正确顺序是：**先识别 → 立刻失败 → 告诉你换引擎**，而不是默默重试。
