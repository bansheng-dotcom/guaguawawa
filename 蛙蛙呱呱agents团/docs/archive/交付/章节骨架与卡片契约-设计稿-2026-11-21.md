# 章节骨架与卡片契约（设计稿 v3，待审）

> 2026-11-21 · 目的：把"每节写多少字"换成"每节证明一个判断"，长度由论证决定。
> 本稿不写代码，先确认结构。

## 0. 一句话

**卡片的交付单位是"判断单元"，不是"一节段落"；节由判断单元组装而成，一问可以有多节。**
字数不设总量，只设可读性上限：**单段 ≤300 字**。

---

## 1. 章节骨架（每节固定五块）

| 块 | 回答什么 | 内容 | 硬约束 |
|---|---|---|---|
| **1 结论** | 这一节的判断是什么 | 1 句判断 + 关键数字（≤80 字） | 必须含数字；不含"可能/或许" |
| **2 证据块** | 凭什么 | 1 张图 +（可选）1 张表；每个数字带 refs | 图必须画全量基础数据（多期画多期、多主体画多主体） |
| **3 机理** | 为什么会这样 | 驱动/约束/传导链；能写成"驱动树"最好 | ≥1 条可算的关系（两个度量 + 方向） |
| **4 反例/边界** | 什么情况下不成立 | 反例条件 + 口径/范围边界 | 必须有；找不到反例写"未找到 + 怎么找的" |
| **5 所以/动作** | 读者该做什么 | 1–2 条动作；证据不足写"待验证" | 动作要能落到人/钱/时间 |

**长度规则**：
- 不设每节总字数上限；
- 每块最多 3 段，每段 ≤300 字；
- 写不下 = 判断没拆开 → **拆成下一节**，不是把段落写长。

**图文分工**：
- 图承载数据关系（对比/趋势/构成/分布）；
- 文字只解释"图上看不出来的判断"：为什么、意味着什么、什么条件下失效；
- 文字不复述图上的数字，图不承担论证。

## 2. 卡片契约（v3）：交"判断单元"

一张卡（一个角色、一问或几问）交付：

```json
{
  "schema": "dsh.claims/v3",
  "judgments": [
    {
      "id": "J1",
      "qid": "Q7",
      "claim": "10 万预算只有社区自雇店能打平，平衡点 5.85 万/月",
      "evidence": [
        {"ref": "N1", "value": 5.85, "unit": "万元/月", "period": "2026",
         "source": "S1", "role": "主证"},
        {"ref": "N2", "value": 8.97, "unit": "万元/月", "period": "2026",
         "source": "S1", "role": "对照"},
        {"ref": "N3", "value": 26.81, "unit": "万元/月", "period": "2026",
         "source": "S1", "role": "反例"}
      ],
      "chart": {
        "type": "hbar", "title": "三种形态的盈亏平衡点（万元/月）",
        "source": "原生态宠物号", "refs": ["N1", "N2", "N3"],
        "data_points": 3, "why_visual": "三个值的差距，文字列不出来"
      },
      "mechanism": {
        "drivers": ["毛利率", "固定成本", "人力结构"],
        "chain": "自雇→人力成本低→固定成本 2.72 万→平衡点 5.85 万",
        "causal_level": "A"
      },
      "counter": {"condition": "面积 80㎡、2.5 人", "example_ref": "N3"},
      "boundary": {"caliber": "北京四环内社区底商、2026 年价格", "scope": "单店模型"},
      "action": {"so_what": "先做社区自雇店，10 万预算不做前置仓",
                 "if_insufficient": "缺 3 家门店实测，先按 6 万做保守测算"}
    }
  ]
}
```

### 字段判据（collect 按这个收，不按字数）

| 字段 | 判据 |
|---|---|
| `claim` | 含数字；≤80 字；不含"可能/或许/大概" |
| `evidence` | ≥3 条；每条有 ref/value/unit/period/source；至少 1 条"对照"或"反例" |
| `chart` | 有 type/title/source/refs/data_points；确属不可画填 `chart_skip_reason` |
| `mechanism` | drivers ≥1；chain 非空；causal_level ∈ {A,I,C} |
| `counter` | condition 非空；能指到一条 evidence |
| `boundary` | caliber + scope 都有 |
| `action` | so_what 非空；证据不足时 if_insufficient 非空 |

## 3. 组装：一个问题 → N 个判断 → N 节

```
Q7（经营模型）
 ├─ J1 10万预算只有社区自雇店能打平     → 第 1 节
 ├─ J2 线上/前置仓贡献率只有 12–14%      → 第 2 节
 └─ J3 5.85 万这个数只在自雇结构下成立   → 第 3 节（反例独立成节）
```

- **节数由判断数决定**，不由问题数决定；
- 一个问题只有一个判断时，就一节；
- 判断之间若有依赖（J3 依赖 J1），组装时按依赖排序。

**R01 的活**：审判断、排节序、去重、决定哪些判断进正文、哪些进附录；
**角色的活**：给判断 + 证据块，不写"文章"。

---

## 4. 与现有产线的差异

| 现在 | 设计稿 |
|---|---|
| 卡=一问，交三段长文 | 卡=一问/多问，交 N 个判断单元 |
| 验收看字数（≥1000 / 300–600） | 验收看判断要素（数字/证据/图/机理/反例/边界/动作） |
| 一节一段大文 | 一节五块，单段 ≤300 字 |
| 图由渲染层反推 | 图由判断单元自带，渲染层只校验 data_points |
| 反例可省 | 反例是硬字段；找不到也要写"未找到+找法" |

## 5. 用宠物报告第 1 节验证（同一批数据，按新骨架重排）

**1 结论**：10 万预算下只有社区自雇店能打平，平衡点 5.85 万元/月。

**2 证据块**：三形态对比图（社区自雇 5.85 / 社区雇人 8.97 / 前置仓 46.81 万元/月）+ 成本拆解表。

**3 机理**：三个变量同时起作用——商品毛利率 32%、固定成本 2.72 万、人力结构（老板计薪 0.6 万）。
驱动树：平衡点 = 固定成本 ÷（毛利率 − 变动费用率）。

**4 反例/边界**：5.85 万只在"自雇 + 60㎡ + 四环内底商"成立；80㎡、2.5 人时同营收不成立；这是单店模型，不是品牌模型。

**5 所以/动作**：先做社区自雇店；10 万预算不做前置仓；缺 3 家实测前按 6 万做保守测算。

> 同样的数据，长度差不多，但读者先看到判断，再看证据，再看为什么，最后知道做什么。

2. **一节多图**：允许一节 2 张图吗？（建议允许，但第二张必须是"对照"）
3. **动作块**：每节都要有"所以/动作"，还是只有判断类节要？（建议都要，研究类可写"下一步验证"）
