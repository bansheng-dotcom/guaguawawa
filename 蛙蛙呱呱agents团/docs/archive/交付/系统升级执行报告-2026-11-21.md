## 2. 不是换模板，是换内容模型

这次修的不是“把旧模板换成新模板”，而是把报告拆成一条可替换的内容链：

```
claim（一条判断）
  → slice（同一指标族、同一单位的一组数）
  → encoding（关系：比较 / 构成 / 趋势 / 分布 / 流向）
  → blocks（事实 / 机理 / 反例 / 所以）
  → renderer（按关系选图型、按内容选页型）
```

- **旧稿**（`sections`）走适配器：保留块标签，缺 `strong` 时从 `【事实】/【机理】/【反例】` 前缀还原；
- **新稿**（`claims_v4`）直接产出 claim/slice/encoding，正文最多 7 条，第 8 条起进附录；
- **结构不是固定页序**：`configs/report_structures.yaml` 定义 research / decision / diagnostic / brief 四套模块集合，按任务类型组装；正文、图表、表格仍走同一内容链；
- **附录是模块，不是模板**：数据来源（A）单独一页，支撑判断（B）单独一页，口径与分数单独一节，不再并排塞一页；
- **图型由关系决定**：比较用 `dot`（带基线带），构成用 `share_bar`，增速用 `vbar`，不再一律横条；
- **表格优先收全量**：正文提到的数进“本节全部可回溯数字”表；图只画其中同一指标族的一组。
