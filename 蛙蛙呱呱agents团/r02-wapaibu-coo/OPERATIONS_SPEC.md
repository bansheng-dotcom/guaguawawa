# 蛙蛙呱呱 · 蛙排布 (R02) 全局运营规范账本 (OPERATIONS_SPEC.md)

> 版本: v1.0.0
> 约束标准：全生命周期运营管理红线与质量准则

## 1. 工时与拆解规范
- MAX_TASK_HOURS = 8
- MIN_TASK_HOURS = 0.5
- 超过 8 小时任务必须自动拆解，严禁不可执行的大颗粒粗任务。

## 2. 负载与健康度红线
- URGENT_WEIGHT = 1.2
- 单项目饱和度集中度警戒阈值: 50%
- 单人每周负荷安全红线: 40 小时

## 3. 事故与复盘闭环
- SEV4 / SEV5 严重事故升级时限: 30 分钟内必须上报
- 事故行动项彻底归档闭环时限: 7 天

## 4. 会议与流程防浪费 (Anti-Slop)
- 站会时间盒上限: 15 分钟
- 周会/复盘会时间盒上限: 60 / 120 分钟
- 严禁空洞话术（如“持续跟进”、“逐步优化”等），必须责任到人 (DRI) 并附量化时限。
