# 飞书协作（不接入）

> 归属：R02　消费：r13, r16, r17　版本：v1

## 定位

飞书类协作工具的边界说明：本团队不接第三方 SaaS 账号，只产出可粘贴的结构化内容。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 不保存任何企业账号凭据
2. 会议纪要/审批流以 Markdown 表格交付，人工粘贴
3. 涉及权限与外发的动作一律人工执行
4. 不承诺消息送达状态

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
