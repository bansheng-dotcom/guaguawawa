# 经营运营分析

> 归属：R02　消费：r06, r12　版本：v1

## 定位

用指标树定位经营问题：增长、效率、质量三条线，先定位再归因。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 指标必须带口径（分子/分母/周期），否则不下结论
2. 异常先看同比/环比与基线，再看结构（人群/渠道/品类）
3. 归因分流量/转化/价格/供给四类，每类给一条可验证动作
4. 报告必须写清「本次不解决什么」，防止范围蔓延

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
