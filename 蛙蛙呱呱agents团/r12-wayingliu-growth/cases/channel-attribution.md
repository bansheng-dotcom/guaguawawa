# SOP：多渠道获客归因与预算再分配（R12 蛙引流）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：伪泛粉占比]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 伪泛粉占比 | `无效互动用户 / 新增用户` | % | ≤ 20% | > 40% 立即调整定向 |
| 渠道 ROI | `渠道毛利 / 渠道花费` | × | ≥ 2 | < 1.5 连续 3 天停投 |
| 次留率 | `次日回访用户 / 新增用户` | % | ≥ 25 | < 15 判定渠道无效 |

## 3. 分步诊断动作

1. 统一口径：先对齐归因窗口与去重规则。
2. 拆漏斗：曝光→点击→进店→注册→付费，找最大损失节点。
3. 查质量：伪泛粉、次留、复购三项一起看。
4. 算单位经济：ROI 与回收期双指标。
5. 出预算表：加投/维持/停投三档，附熔断线。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 伪泛粉 > 40% | BLOCKER | 停机复审定向 |
| G2 | 归因窗口不一致 | WARN | 统一归因口径后再比较 |
| G3 | 单位经济为负仍加投 | BLOCKER | 立即停投 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
