# 营销全链路（marketing-toolkit）

> 归属：R12　消费：r11, r10　版本：v1.1（2026-11-17 补齐结构）
> 从目标到渠道到度量的营销方案骨架：一条目标、一组渠道、一套指标、一份预算与停止条件，避免「什么都做一点」。

## §1 何时使用 / 何时不用

**当…时使用**：当要为一个产品/活动做营销方案、分配渠道预算、定义复盘指标时使用；当投放效果说不清、需要先把度量口径定下来时使用。

**不用于**：不写文案（归 R11）、不做视觉物料（归 R10）、不承诺排名与 ROI。

## §2 输入与输出

| 方向 | 内容 |
|---|---|
| 输入 | 业务目标（收入/线索/复购）；预算区间；目标人群与现有渠道数据 |
| 输出 | 渠道矩阵（渠道 × 目标 × 预算 × 预期）；度量口径（北极星 + 过程指标）；停止条件 |

## §3 执行流程

1. 把目标翻成一个北极星指标，并写清基线。
2. 列渠道：自有 / 付费 / 合作三类，每类只留 1–2 个。
3. 配预算：按 20/60/20 分配（探索/主投/机动），写清依据。
4. 定度量：每个渠道一个主指标 + 一个护栏指标。
5. 写停止条件：成本上限、连续 N 天不达标、负反馈超阈值。
6. 交 `harness.py` 校验四要素齐备。

| 用途 | 命令 | 判据 |
|---|---|---|
| 增长诊断 | `python agent.py diagnose diagnose --input <data.json>` | 先有基线再谈投放 |

| 门禁 | `python harness.py plan --input <plan.json>` | 四要素缺失直接 FAIL |

## §6 交付前自检

- [ ] 北极星指标有基线值，不是空口号
- [ ] 每个渠道都有主指标与护栏指标
- [ ] 预算分配有依据，且留了机动额度
- [ ] 停止条件可机器判定（阈值 + 观察窗）

## §7 常见错误对照

| 编号 | 错误 | 正确做法 |
|---|---|---|
| MKT-01 | 渠道铺得太多，每个都没跑透 | 每类只留 1–2 个，先跑主渠道 |
| MKT-02 | 只写目标不写基线 | 没有基线就先补一次诊断 |
| MKT-03 | 停止条件写成「效果不好就停」 | 改成阈值 + 观察窗 |

## §8 异常与降级

| 情况 | 处理 |
|---|---|
| 无历史数据 | 先用行业基准做假设，并标注「待验证」 |
| 预算未定 | 给三档预算（低/中/高）方案，标注各档预期 |
| 归因不可用 | 改用渠道自报 + 抽样核对，结论标注置信度 |
