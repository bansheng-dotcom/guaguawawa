# 营销全链路

> 归属：R12　消费：r11, r10　版本：v1

## 定位

从目标到渠道到度量的营销方案骨架。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 先定单一传播主张，再拆渠道
2. 每个渠道给预算占比、素材规格、衡量指标
3. 漏斗每层有基准与目标，不写空泛 KPI
4. 合规与素材授权单独列一节

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
