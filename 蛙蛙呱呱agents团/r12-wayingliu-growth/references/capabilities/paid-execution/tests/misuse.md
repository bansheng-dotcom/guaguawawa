# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`），本表是**人工评审清单**，逐条判真假。
> 版本：v2.0.0

## 一、硬门（§5，任一不过即不得交付）

| # | 判据 | 出处 |
|---|---|---|
| MU-01 | 一个计划只对应一个目标（禁混目标） | §5 第 1 条 |
| MU-02 | 出价策略三选一且写明；日预算 ≤ 总预算/天数 ×1.5 | §5 第 2 条 |
| MU-03 | 素材轮换有明确触发条件（CTR 连续 3 天下滑 >20%） | §5 第 3 条 |
| MU-04 | 三条止损线写死（CPA>1.5× / 3 天无转化 / 消耗>150%） | §5 第 4 条 |
| MU-05 | 归因口径已声明，且自然流量拆出或标注未拆 | §5 第 5 条 |
| MU-06 | 日复盘只盯三数（消耗/转化/CPA），异常有归因 | §5 第 6 条 |

## 二、软门（§6 自检，靠人抓）

| # | 常见错法 |
|---|---|
| MU-06 | 我的计划没有混目标（拉新和复购分开） |
| MU-07 | 我写明了出价策略，以及为什么不用另外两种 |
| MU-08 | 日预算没超过总预算/天数 ×1.5 |
| MU-09 | 我写了素材轮换的触发条件，不是「感觉疲劳了就换」 |
| MU-10 | 三条止损线我都写死了，并指定了谁执行 |
| MU-11 | 归因口径我声明了，且说清和平台口径的差异 |
| MU-12 | 自然流量我拆出来了，或明确标注「未拆」 |
| MU-13 | 我每天只看三个数，没有盯十几个指标 |
| MU-14 | CPA 超标时我关的是单元，不是整批关 |

## 三、诚实说明

本卡没有可自动断言的门禁：投放效果在平台侧，本地拿不到实时数据。能机器做的只有计划结构校验与归因复算。

## 四、怎么验（没门禁时的替代验证）

1. **双评**：两人独立按 §5 逐条判，一致率 ≥80%；
2. **抽样反查**：随机抽 3 条要求指出具体位置/数字；
3. **对照抽检**：与 `references/paid-runbook.md` 里的 BAD/GOOD 并列看。

> **纪律**：投放的目标不是「花完预算」，是「**知道每一单是谁带来的**」。
