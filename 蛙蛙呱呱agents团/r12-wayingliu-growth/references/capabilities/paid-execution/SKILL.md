# 投放执行与归因（paid-execution）

> **投放最难的不是投出去，是知道「这一单到底是谁带来的」。** 平台各说各的功劳、自然流量混在里面、跨设备断链——不先把口径定死，后面所有优化都是在错误的数字上做决定。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「这批怎么投」
- 「预算怎么分到各渠道」
- 「素材多久换一次」
- 「为什么平台报的 ROI 和我算的不一样」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 策略与实验预注册 | r12 的 `campaign-plan` | 那是方案设计 |
| 素材文案 | r11 的 `tone-axes` | 那是文案 |
| 素材图 | r10 的 `image-prompt-structure` | 那是出图 |
| 显著性判定 | r12 的 `experiment-analysis` | 那是实验 |

**最小可开工输入**：**一个已预注册的 campaign + 各渠道的单价与预算**。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| campaign 方案（含北极星指标） | 必需 |
| 渠道清单与单价（CPC/CPM/CPM 起量） | 必需 |
| 日预算上限与总预算 | 必需 |
| 素材清单（图/文/视频） | 必需 |
| 归因口径（末次点击/首次点击/线性） | 必需 |

**追问纪律**：最多一轮，只问**归因口径用哪个**。这一项不定，后面所有 ROI 都不可比。

## §3 执行流水线（Workflow）

### Step 1 · 定账户结构（三级：计划 / 单元 / 素材）
**计划**=一个目标（拉新/复购/清仓）；**单元**=一个定向组合；**素材**=一个创意。一个计划内不要混目标——混了就无法归因。

**判据**：一个计划只有一个目标；单元按定向拆分

### Step 2 · 定出价策略与预算节奏
出价策略三选一：**成本上限**（稳 ROI，跑不动就死）、**最大化跑量**（先跑后收）、**手动出价**（有经验时最灵活）。日预算按「总预算 ÷ 投放天数 × 1.2」给。

**判据**：出价策略写明；日预算 ≤ 总预算/天数 × 1.5

### Step 3 · 素材轮换规则（防疲劳）
同一素材 **CTR 连续 3 天下滑 >20%** 即换；单个单元并行素材 **3–5 个**（少了跑不动，多了摊薄）。

**判据**：写了轮换触发条件与并行素材数

### Step 4 · 止损线（什么时候关）
三条任一触发即关停该单元：**CPA > 目标 ×1.5**、**连续 3 天无转化**、**预算消耗 > 计划 150%**。

**判据**：三条止损线写死，且有人负责执行

### Step 5 · 归因（口径先定，再看数）
**口径必须与平台一致或可解释**；自然流量单独拆出（用对照组或时间序列基线）；跨设备断链要标注「归因不全」。

**判据**：归因口径写明；自然流量已拆出或标注未拆

### Step 6 · 日复盘三数（只盯三个，别盯十个）
**消耗 / 转化数 / CPA**。三个数一起看：消耗涨而转化不涨 → 素材或定向问题；转化涨而 CPA 涨 → 出价问题。

**判据**：每日只看三数，且异常有归因

## §5 质量门（一票否决）

1. 一个计划只对应一个目标（禁混目标）；
2. 出价策略三选一且写明；日预算 ≤ 总预算/天数 ×1.5；
3. 素材轮换有明确触发条件（CTR 连续 3 天下滑 >20%）；
4. 三条止损线写死（CPA>1.5× / 3 天无转化 / 消耗>150%）；
5. 归因口径已声明，且自然流量拆出或标注未拆；
6. 日复盘只盯三数（消耗/转化/CPA），异常有归因；

> 本卡无自动门禁。可配合 `python agent.py paid plan --input <投放计划.json>` 做结构校验（间接）。

## §6 交付前自检清单

- [ ] 我的计划没有混目标（拉新和复购分开）
- [ ] 我写明了出价策略，以及为什么不用另外两种
- [ ] 日预算没超过总预算/天数 ×1.5
- [ ] 我写了素材轮换的触发条件，不是「感觉疲劳了就换」
- [ ] 三条止损线我都写死了，并指定了谁执行
- [ ] 归因口径我声明了，且说清和平台口径的差异
- [ ] 自然流量我拆出来了，或明确标注「未拆」
- [ ] 我每天只看三个数，没有盯十几个指标
- [ ] CPA 超标时我关的是单元，不是整批关

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 一个计划混多个目标 | 一计划一目标 |
| EX-02 | 不写归因口径 | 先定末次/首次/线性，再看数 |
| EX-03 | 自然流量混进投放 ROI | 用基线或对照组拆出 |
| EX-04 | 素材不轮换直到跑死 | CTR 连降 3 天 >20% 即换 |
| EX-05 | 没有止损线 | 三条写死：CPA/无转化/超消耗 |
| EX-06 | 预算一次给满 | 按天给，日预算 ≤ 总预算/天数×1.5 |
| EX-07 | 只盯 ROI 不盯 CPA | ROI 受客单影响，CPA 更直接 |
| EX-08 | 把平台报的转化当真实 | 平台会重复计跨触点，需去重 |
| EX-09 | 关停整批而非单元 | 关到单元级，保留有效部分 |
| EX-10 | 换素材同时换定向 | 一次只改一个变量 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 无对照组 | 用投放前后时间序列做基线，标注「非实验」 |
| 平台不提供去重数据 | 标注「归因可能高估」，并用订单侧反算 |
| 预算极小（<1000） | 只跑一个渠道一个单元，标注「样本不足以优化」 |
| 素材供应不足 | 优先保主推单元，其余降频 |
| 跨设备占比高 | 标注断链比例，ROI 按区间给 |
| 账户被限流 | 先查违规与素材审核，不盲目提价 |

**明确不做**：不做策略预注册、不写文案、不做视觉、不做显著性判定。
