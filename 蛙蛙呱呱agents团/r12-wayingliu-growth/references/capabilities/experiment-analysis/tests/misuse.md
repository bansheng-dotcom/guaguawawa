# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`），本表是**人工评审清单**，逐条判真假。
> 版本：v2.0.0

## 一、硬门（§5，任一不过即不得交付）

| # | 判据 | 出处 |
|---|---|---|
| MU-01 | 假设可证伪、单指标、方向明确 | §5 第 1 条 |
| MU-02 | 最小样本量已计算，且据此估算时长；算不起时明确放弃 | §5 第 2 条 |
| MU-03 | 分流单元为用户级，且写明是否跨组 | §5 第 3 条 |
| MU-04 | 护栏指标 ≥2 个且各有阈值；护栏恶化即判失败 | §5 第 4 条 |
| MU-05 | 停止规则预设，禁止中途看 p 值决定延长 | §5 第 5 条 |
| MU-06 | 结果分析按「护栏 → 主指标 → 异质」顺序；分组结论不上升为主结论 | §5 第 6 条 |
| MU-07 | 结论区分「不显著」与「无效果」，并给置信区间 | §5 第 7 条 |

## 二、软门（§6 自检，靠人抓）

| # | 常见错法 |
|---|---|
| MU-07 | 我的假设只有一条，且带方向与数字 |
| MU-08 | 我算过最小样本量，并据此估了天数 |
| MU-09 | 如果样本量要跑 3 个月，我明确说了「做不了」而不是硬跑 |
| MU-10 | 分流是按用户分的，不是按会话 |
| MU-11 | 我定了护栏指标，并写清恶化到什么程度算失败 |
| MU-12 | 停止规则我预设在跑之前，跑起来没改 |
| MU-13 | 分析顺序是护栏 → 主指标 → 异质 |
| MU-14 | 分组差异我只写「探索性发现」，没当结论 |
| MU-15 | 我说清了是「不显著」还是「无效果」，并给了置信区间 |

## 三、诚实说明

本卡没有可自动断言的门禁：显著性依赖真实分流数据。可人工复算的只有样本量与停止规则是否被遵守。

## 四、怎么验（没门禁时的替代验证）

1. **双评**：两人独立按 §5 逐条判，一致率 ≥80%；
2. **抽样反查**：随机抽 3 条要求指出具体位置/数字；
3. **对照抽检**：与 `references/experiment-protocol.md` 里的 BAD/GOOD 并列看。

> **纪律**：实验的目标不是「证明我对」，是「**让错误的想法也能被干净地否掉**」。
