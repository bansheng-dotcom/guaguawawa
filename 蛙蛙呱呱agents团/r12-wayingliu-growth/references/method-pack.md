# R12 蛙应流 · 增长 · 方法包（Method Pack v1）

## 1. 决策问题

- 典型决策：投不投、投哪个渠道、预算怎么分。
- 决策者：增长负责人 + 创始人；成功标准：增量 ROI 达标且可复现。
- 非目标：不做品牌广告、不承诺排名。

## 2. 问题树（MECE）

| 分支 | 要回答 | 假设 | 数据 | 方法 |
|---|---|---|---|---|
| 增量 | 投放带来的是增量还是自然量 | 增量可测 | 实验/对照 | 增量实验 + 地理对照 |
| 成本 | CAC/ROI 是否成立 | 回收期 ≤ 目标 | 投放/订单数据 | CAC/LTV + 回收期 |
| 归因 | 哪个渠道真正有效 | 归因可解释 | 渠道数据 | MMM/多触点归因 |
| 留存 | 进来的人会不会留下 | 次月留存 ≥ 目标 |  cohort | cohort 分析 |

**critical branch**：`增量`——资源优先给它。

## 3. 假设与证伪

- H1：该渠道的增量 ROAS ≥ 目标值。
- H2：新增用户的 30 天留存不低于自然用户。
- 竞争解释（至少 2 个）：增长来自投放，还是季节/自然增长？；ROI 高是因为归因口径，还是真实增量？
- 每条假设必须有**杀死标准**：指标 + 阈值 + 观察窗口。

## 4. 证据分级

| 级别 | 来源 | 允许用法 |
|---|---|---|
| A | 系统记录、合同、官方数据、可复算台账 | 可进结论与决策 |
| B | 行业报告、供应商报价、抽样数据 | 方向 + 区间 |
| C | 访谈、估算、单点经验 | 标注 + 敏感性 |

**规则**：每个结论挂来源；同名不同口径单列；缺什么、影响什么、怎么补，必须写清；C 级超过 3 条时结论降级为「条件成立」。

## 5. 方法与陷阱

**可执行**：`python scripts/methods.py ltv-cac --arpu ... --gm ... --churn ... --cac ...`。

- 增量实验：对照组/地理对照/PSA，先定 MDE 与样本量。
- CAC/LTV：按 cohort 算回收期，不用平均值掩盖。
- 预算 20/60/20：探索/主投/机动，按周复盘。
**陷阱清单**：
- 把总量当增量
- 只看 CTR 不看转化
- 归因自说自话
- 预算一次押满
增长结论必须给「增量证据 + 停止条件」，否则只是花钱。

## 6. 输出契约

```
claim        一句话结论（方向 + 幅度 + 范围/时间）
evidence     来源 + 观测/记录 + 口径
confidence   A/B/C + 区间（无区间写「点估计，未验证」）
falsifier    什么新证据会推翻它
```

缺任一项 → 不得进首页；建议缺负责人/阈值 → 行动性不通过。
