# 咨询答案评分卡（Consulting Rubric v0.1）

> 用途：给 20 题金题集打分（0—25），衡量「咨询深度」而不是「报告长度」。
> 打分顺序：先人工标 10 题 → 再让 LLM judge 按本卡打分 → 一致率 <0.7 就改卡，不信任 judge。

## 五维与锚点

### 1. 问题定义（0—5）

| 分 | 锚点 |
|---|---|
| 0 | 直接答问题，没定义决策、没边界 |
| 2 | 有决策问题，但没写「不回答什么」 |
| 4 | 决策问题 + 决策者 + 成功标准 + 边界齐全 |
| 5 | 4 分 + 明确「最可能错在哪」与验证方式 |

### 2. 证据质量（0—5）

| 分 | 锚点 |
|---|---|
| 0 | 无来源或全是「业内认为」 |
| 2 | 有来源，但无分级、无口径 |
| 4 | 来源分级（A/B/C）+ 口径 + 缺口清单 |
| 5 | 4 分 + 冲突单列 + 可回指观测/页码 |

### 3. 分析深度（0—5）

| 分 | 锚点 |
|---|---|
| 0 | 只有描述，没有对照 |
| 2 | 有对照，但没匹配/基线 |
| 4 | 匹配对照 + 同期基线 + 分解或回归 |
| 5 | 4 分 + 不确定性（区间/敏感性）+ 稳健性检验 |

### 4. 洞察力（0—5）

| 分 | 锚点 |
|---|---|
| 0 | 全是常识复述 |
| 2 | 有 1 个非显然判断，但无机制 |
| 4 | 有机制解释 + 至少 1 个竞争解释被排除 |
| 5 | 4 分 + 反直觉发现 + 对决策的明确含义 |

### 5. 行动性（0—5）

| 分 | 锚点 |
|---|---|
| 0 | 只有建议，没有动作 |
| 2 | 有动作，但无负责人/阈值/时间 |
| 4 | 动作 + 负责人 + 阈值 + 时间 |
| 5 | 4 分 + 成本/收益 + 回滚条件 |

## 判定

- **总分** = 五维相加（0—25）。
- **合格线**：18 分；**咨询级**：21 分以上。
- **一票否决**：headline 没有对照/基线/匹配 → 分析深度 ≤2；建议没有负责人/阈值 → 行动性 ≤2。

## 常见错误（直接扣分）

| 错误 | 扣分 |
|---|---|
| 把规格/等级差当区域差 | 分析深度 −2 |
| 用单点同比（报价可能陈旧） | 证据质量 −2 |
| 把「不显著」写成「没影响」 | 分析深度 −2 |
| 只给一个方案 | 行动性 −2 |
| 结论超出证据（相关当因果） | 洞察力 −2 |

## 校准流程

1. 人工标 10 题（2 名评审独立打分，分歧 >3 分讨论）。
2. LLM judge 用同一张卡打 20 题。
3. 计算一致率（±1 分内算一致）；<0.7 改锚点措辞，再校准。
4. 每次改 method pack / skill，跑 20 题，分数下降 >2 分即回滚。
