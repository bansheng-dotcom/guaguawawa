# 高保真可交互原型

> 归属：R08　消费：r10, r09　版本：v1

## 定位

从想法/PRD 到可点击原型：单文件优先、假数据、无真实后端。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 一屏一个主任务，导航不超过两级
2. 所有交互态齐全：默认/加载/空/错误/禁用
3. 用假数据但保持真实字段名与量级
4. 交付附「已知限制」：哪些是模拟、哪些未接

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
