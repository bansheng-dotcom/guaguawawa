# 好结论范例（供报告写作对照）

## 核心原则

**四层分析框架（数据事实→运营逻辑→组织归因→行动建议）是内部推理工具，不得作为子标题出现在输出中。**
输出是完整的段落和分点列表，读者看到的是逻辑，不是框架标注。

## 原则一：结论不超过数据边界

每条结论必须能追溯到本次分析的具体数据字段。数据能说明到哪一层，结论就写到哪一层：
- 数据能说明"是什么"：写事实
- 数据能推断"为什么"：写推断，注明是推断
- 数据无法回答"谁造成的"：不写，改为"需补充[X数据]后确认"
- 组织归因不是必须模块，无数据支撑时跳过

## 原则二：分析链条模板

```
整体指标异动 → 拆解：找到驱动维度 → 归因：对驱动维度追问原因，停在数据边界 → 在边界处标记：还需要什么数据
```
不在边界前停止，不在边界后继续。

## 原则三：输出格式

- 用段落叙述，数字嵌在句子里
- 有多个行动建议时用数字列表
- 禁止出现"①数据事实""②运营逻辑""③组织归因""④业务结论"等标注词

## 范例A：事件性冲击（数据止步于机制层）

> 2024年家具利润率9.76%，同比下降3.89pp是三大品类中降幅最大。月度拆解显示降幅90%以上集中于Q3（7-9月均值6.2%），其余9个月均值12.97%，与2023年差距0.68pp在正常波动。Q3是触发年度利润率下行的单一事件，定价策略本身没有结构性问题。
>
> Q3利润率为何如此低，当前数据可以排除但无法完整回答：促销GMV增量不足以覆盖折扣损失，还是ROI成本端遗漏，是两条不同路径，对应不同干预方向。
>
> 建议：1. 补充Q3促销折扣明细与成本拆解，区分GMV问题还是ROI问题；2. 在确认机制前不调整全年定价策略。

关键点：到"GMV vs ROI"就停，不编审批流程或KPI设计的结论。

## 范例B：慢性结构漂移（数据止步于路径归因）

> 技术品类整体利润率13.22%，总量看似平稳，但子品类结构持续漂移：复印机（利润率17.8%）份额从2023Q1的28%降至2024Q4的21%，连续6个季度下行；设备（14.2%）和电话（11.6%）同期分别扩张5pp和4pp。高利润品类萎缩、低利润品类扩张，这一结构变化在总量指标中完全不可见。

关键点：份额为何持续下行，存在市场竞争与内部结构两条路径，当前数据无法区分，确认前不给出定向建议。

## 范例C：分析到边界后的自然收尾

不声明"当前数据无法区分"或"需补充X后才能继续"；写到数据支撑的最后一步，然后自然给出下一步建议方向，一句话带过。

## 禁用词替代表

| 禁用 | 替代 |
|------|------|
| 需要关注 | 建议[谁]在[时间]前完成[具体行动] |
| 可能存在问题 | 数据显示[X]，原因指向[Y]（待验） |
| 整体趋势良好 | [指标]从X升至Y，主要来自[A]贡献 |
| 后续需要跟进 | 建议[负责方]在[Q几]前完成[核查项] |
| 这一现象值得重视 | 直接陈述问题，接结论 |
| 有待进一步分析 | 需补充[X数据]，当前无法判断 |
