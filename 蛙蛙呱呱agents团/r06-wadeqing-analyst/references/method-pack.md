# R06 蛙得清 · 方法包（Method Pack v1）

## 1. 决策问题

- 典型决策：这个差异是真的吗 / 有多大 / 对谁成立 / 能不能据此行动。
- 决策者：业务负责人 + R01；最怕「拿一个噪声当规律，押上资源」。
- 成功标准：估计值 + 不确定性 + 识别假设 + 证伪条件，四件套齐全。
- 非目标：不发明业务方案（交 R07/R15）；不把相关当因果。

## 2. 问题树（MECE）

| 分支 | 要回答 | 数据 | 方法 | 产出 |
|---|---|---|---|---|
| 数据可用 | 能不能算 | 完整性、口径、时效 | 六维质检、陈旧检测 | 可用/不可用 |
| 描述 | 现在什么样 | 序列、分布 | 描述统计、趋势 | 事实 |
| 识别 | 差异从哪来 | 对照/匹配/断点 | 匹配、DID、断点、分解 | 效应 + 假设 |
| 稳健 | 结论稳不稳 | 子样本、替代口径 | 敏感性、bootstrap | 区间 |
| 决策 | 能不能行动 | 阈值/成本 | 决策曲线 | 建议 |

**critical branch**：`识别`——没有识别策略，描述再漂亮也只是「看着像」。

## 3. 假设与证伪

- 假设写「效应 + 人群 + 幅度 + 条件」，例：「同规格下呼市比北京贵 3—4 元/公斤，因为区域溢价而非规格」。
- 三件套：支持（匹配后差）/ 反对（同规格差缩小）/ 杀死标准（匹配后差 <1 元）。
- 至少 2 个竞争解释：规格/等级、时点、渠道、选择偏差；逐个用数据排除。

## 4. 证据分级

| 级别 | 来源 | 用途 |
|---|---|---|
| A | 官方序列、交易所、全量交易数据 | 可进结论 |
| B | 抽样报价、行业数据 | 方向 + 区间 |
| C | 单点、估算、代理变量 | 标注 + 敏感性 |

规则：每条结论挂观测行；样本 <10 必须报区间或明确「不做推断」；报价窗口内不变的序列标记为陈旧，不做同比。

## 5. 方法与陷阱

**可执行**：`python scripts/methods.py matched --treat ... --control ... --col ...`；`did`；方法门禁 `scripts/method_gate.py`。

- **先质检再算**：缺失/重复/口径/时效/异常/一致性六维，脏数据不进模型。
- **匹配对照**：同品种、同规格、同日、同层级；匹配不了就降级为描述。
- **同期基线**：任何「涨/跌/正常」给 3 年以上同期对照；日度序列自相关，跨年不做显著性推断。
- **分解归因**：加法分解，残差必须为 0；贡献度带方向。
- **不确定性**：区间/自助法/情景三选一，禁止单点进决策。
- 陷阱：n 太小还做回归；多重比较；把「不显著」写成「没影响」；用均值掩盖分布；陈旧报价。

## 6. 输出契约

```
estimate     效应/差异（方向 + 幅度）
ci           区间或「点估计，未验证」
identification  识别假设（匹配了什么、控制了什么）
robustness   替代口径/子样本结果
falsifier    什么数据会推翻
```

缺识别假设或区间 → 不得进首页。
