# 统计方法与分析决策方法论

本文件定义了业务分析、A/B测试、因果推断、自媒体运营及数据可视化的核心算法规则与业务阈值。

## 1. 检验选型与 A/B 实验 (A/B Test Analysis)

基于统计显著性与效应量进行决策。纪律：先算样本量再开实验；结果显著前必须进行 SRM 校验。

### 1.1 检验选型表

| 业务场景 | 统计方法 | 效应量指标 | 适用说明 |
| :--- | :--- | :--- | :--- |
| **两独立样本均值差** (如: 客单价差异) | Welch's T-test | Cohen's d | 适用于连续型数据，默认不假定方差齐性。 |
| **两分类变量独立性** (如: 转化率比较) | 双比例 Z 检验 / Chi-square | Cramér's V | 适用于离散型转化漏斗节点。 |
| **实验组差异与均衡** (A/B 核心) | A/B Test (t/z test) + SRM 校验 | Lift + SRM χ² | 需要同时观测相对提升与样本比例失调。 |

### 1.2 A/B 实验铁律与判读

**执行前置**：
- **功效分析 (Power Analysis)**：必须前置计算所需样本量 (基于 α=0.05, 功效 80%, 以及目标 MDE)。低于所需样本量的实验不能得出统计意义上的拒绝结论。

**判读流程与阈值**：
1. **确认实验设计**：核对分流单元、主指标与护栏指标。
2. **SRM (样本比例失调) 校验**：使用卡方检验 (Chi-square) 核对实际 vs 预期分流比例。
   - **铁律**：如果 SRM 检验 p < 0.01 (例如对于 1:1 分配，χ² > 6.635, df=1)，**立即停止解读**，必须先修复分流管线！
3. **显著性检验**：计算 p 值，并关注**效应量 (Lift 与 Cohen's d / Cramér's V)**。不要只报 p 值。
4. **护栏指标**：如果护栏指标出现显著恶化，即使主指标显著提升，也**决不允许上线** (No-ship)。

## 2. 因果推断 (Causal Inference via DoWhy)

超越相关性，使用结构化因果模型 (DAG) 定量评估干预效果。基于 **Model → Identify → Estimate → Refute** 四步法。

### 2.1 核心四步法

1. **Model (建模)**：构建因果图 (DAG) 明确变量间的因果结构（混淆因子、中介变量、对撞变量）。
2. **Identify (识别)**：应用因果演算 (do-calculus) 识别因果效应。
   - **核心策略**：识别并控制混淆因子 (Confounders)，通常应用**后门准则 (Backdoor Criterion)** 进行分层或调整。决不能控制中介变量或对撞变量。
3. **Estimate (估计)**：计算平均处理效应 (ATE)。
   - 连续处理：线性回归 (Linear Regression), 倾向得分匹配 (Propensity Score Matching) 等。
4. **Refute (反驳/鲁棒性检验)**：必须对估算结果进行敏感性测试。
   - **安慰剂反驳 (Placebo Treatment Refuter)**：将处理变量替换为随机噪声，重新估算。如果结果仍然显著，说明模型存在未观测到的混淆因子，原结果失效。
   - 增加随机混淆因子 (Add Random Confounder) / 数据子集重采样 (Data Subset Refuter)。

## 3. 自媒体运营指标与数据归一化

针对多平台数据，采用脚本优先、本地校验的自动化链路。

### 3.1 归一化逻辑 (Normalization)

跨平台数据必须在进入分析前进行对齐。
- **命名归一化**：将各平台的黑话统一，如：小红书“小眼睛”、B站“播放”、微信“阅读”统一归一化为 `views` (曝光/播放量)；所有“点赞”归一化为 `likes`。
- **时间窗归一化**：明确并统一数据的回溯时间（如 T-1 日终结算数据）。

### 3.2 报警阈值设定 (Alerting Thresholds)

监控日常运营异常，触发阈值即报警，不依赖大模型自由生成。
- **波动率报警**：指标日环比波动超过 ±30%（或自定义业务阈值），触发波动归因排查。
- **断流报警**：核心平台 (如主营抖音/小红书号) T-1 数据缺失或为 0。
- **登录态失效/过期**：同步延迟超过 24 小时，必须改发“异常说明”飞书通知，停止发送“正常日报”。

## 4. 图表可视化 (Data Storytelling & Visualization)

图表是结论的交付载体，必须符合极简主义，让读者在 5 秒内抓住核心信息。

### 4.1 图表极简主义原则 (Minimalism)

- **最大化数据墨水占比 (Data-Ink Ratio)**：移除所有不传递信息的设计元素。
  - 剔除深色背景、无意义的 3D 效果。
  - 网格线透明度设为 0.2 以下（或仅保留主刻度辅助线）。
  - 去除顶部和右侧的边框 (Spines)。
- **视觉层级 (Visual Hierarchy)**：使用颜色高亮最重要的数据点或线，次要数据使用灰色 (De-emphasise)。

### 4.2 结论化标题与排版

- **结论化标题 (Actionable Titles)**：标题必须直接陈述业务发现（例如：“移动端流失率是桌面端的两倍”），绝对不要使用变量名堆砌（例如不要用：“设备类型与流失率的关系图”）。
- **直接标注**：放弃分离的图例 (Legend)，将标签直接标注在数据线末端或条形图上方。
- **选型匹配**：
  - 趋势：线图 (Line)。
  - 比较：条形图 (Bar)。千万避免使用超过 3 个分类的饼图。
  - 关系：散点图 (Scatter)。
