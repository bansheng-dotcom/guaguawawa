# Web 数据可视化

> 归属：R06　消费：r08, r09, r10　版本：v1

## 定位

图表选型与可访问性规范：用最简视图回答一个问题。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 先定问题与比较关系，再选图形；装饰性图表不做
2. 必须有标题、单位、数据来源、时间范围
3. 颜色只用角色色：中性底 + 1 主强调 + 可选对比色
4. 可访问性：alt 文本、对比度、非颜色冗余编码

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
