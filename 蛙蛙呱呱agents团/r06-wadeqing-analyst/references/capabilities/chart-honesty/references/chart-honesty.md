# 图表诚实与选型细则（chart-honesty）

> 四红线 · 选型矩阵 · 标注清单 · 数据墨水比。版本：v1（P1 起步）

---

## 一、四条红线（任一命中即不可发）

### 红线 1：截断轴未标注

**问题**：Y 轴不从 0 起，微小差异被放大成"数倍"。

```
❌ 错例：Y 轴 2.8 → 3.5，A=3.0 的柱高约 1/3 屏，C=3.4 的柱高约 4/5 屏
   → 视觉上 C 是 A 的 2.4 倍，实际只差 0.4 个百分点
✅ 对例：Y 轴 0 → 4，两柱高度差 10%，一眼看出差异很小
```

**容忍条件**：确实需要看细节时可以用截断，但**必须**在图下加一行：
「Y 轴自 2.8% 起，柱高差异被放大；实际 A 3.0%、C 3.4%」。
且**正文禁止**写"大幅领先""数倍于"。

**怎么验**：把 Y 轴拉到 0 重画（见 §三 零轴反看）。

---

### 红线 2：双 Y 轴未说明

**问题**：两个纵轴，通过调刻度让两条线"正好在某点相交"或"看起来同步"。

```
❌ 错例：左轴转化率（2.8–3.5%）、右轴 GMV（100–500 万），未标含义
✅ 允许：左/右轴各自标注量纲与含义 + 说明「两者相关性依据」+ 分开标注图例
```

**更稳的做法**：分两张图。双轴只在「量纲不同且确有相关关系」时用。

---

### 红线 3：类别超限

| 图形 | 上限 | 超了怎么办 |
|---|---|---|
| 饼图 | **≤5 类** | 合并"其他"或改条形 |
| 堆叠条形 | ≤5 段 | 合并小段 |
| 条形图 | ≤8 条 | 排行 Top 8 + 其他 |
| 折线图 | ≤5 条线 | 分组或小倍数图（small multiples） |

**为什么**：超过上限后，人眼无法比较角度/长度，只能读标签——那就失去了图形的意义。

---

### 红线 4：面积 / 3D 误导

```
❌ 按数值放大圆形图标（半径 2 倍 = 面积 4 倍，但人眼读半径）
❌ 3D 柱（前表面与后表面尺寸不同，读数不准）
❌ 用图标大小表示数量
✅ 用长度（条形）或位置（散点/折线）
```

**判据**：所有视觉编码必须是**一维的**（长度/位置/颜色明度）。面积、体积、角度都要避免。

## 二、选型矩阵（问题决定图）

| 问题类型 | 首选 | 次选 | 禁用 |
|---|---|---|---|
| **比较**（谁大谁小） | 横向条形（排序） | 棒棒糖图 | 饼图、雷达图 |
| **趋势**（怎么变） | 折线（时间在 X） | 面积图（≤2 系列） | 密集堆叠柱 |
| **分布**（长什么样） | 直方图 | 箱线图 / 蜂群图 | 只给平均值 |
| **关系**（有没有相关） | 散点 + 趋势线 | 气泡（≤3 维） | 双柱并列 |
| **构成**（占比） | 堆叠条形 | 饼图（≤5 类） | 多层饼、3D 饼 |

**一条硬规则**：**一个问题一张图**。若你想在同一张图里既比大小又看趋势，拆两张。

## 三、零轴反看（最有效的一招）

**步骤**：
1. 把 Y 轴强制从 0 开始重画；
2. 问：**结论还成立吗？**
3. 决策：

| 结果 | 处置 |
|---|---|
| 结论仍成立 | 直接用零轴版，最省事 |
| 结论变弱但仍对 | 用零轴版，正文改用"略高/略低" |
| 结论消失或反转 | 原图必须截断且**明确标注**，正文不得用比较级 |

## 四、标注三件 + 两行脚注

**三件（缺一不可）**：
```
轴标签：是什么
单位：元 / 万元 / % / 人
时间范围：2026-01 → 2026-10
```

**两行脚注**：
```
数据来源：<来源>
样本量：n = <数字>（若有筛选条件也写）
```

> 「来源 + 样本量」是判断可信度的最低要求。没有这两行，图只能当示意。

## 五、数据墨水比（去装饰）

**定义**：数据墨水 / 总墨水。目标是让装饰 ≤30%。

| 元素 | 处置 |
|---|---|
| 网格线 | 去掉，或改成极浅灰（#eee） |
| 图例 | 能直接标在线上/柱上就不放图例 |
| 边框/阴影 | 去掉 |
| 渐变/背景图 | 去掉（除非表达含义） |
| 3D | 去掉 |
| 冗余标签 | 只标关键点，不标每个点 |

**判据**：眯眼看这张图，第一眼看到的是**数据形状**，还是**框线装饰**？

## 六、标题写法

| ❌ 名词式 | ✅ 结论式 |
|---|---|
| 各渠道转化率 | C 3.4% · A 3.0% · B 2.6% |
| 月度收入趋势 | 收入连续三月环比下滑，累计 -12% |
| 用户分布 | 70% 用户集中在 25–34 岁 |

**阈值**：标题**不含比较级词**（大幅/显著/远超/碾压）。
比较交给数字，让读者自己得出"大幅"的结论——或根本不觉得大幅。

## 七、五组 BAD/GOOD 速查

| # | 场景 | ❌ | ✅ |
|---|---|---|---|
| 1 | 三渠道转化率 | 饼图 3 类 + Y 轴截断 | 横向条形 + 零轴 + 结论标题 |
| 2 | 月度收入 | 3D 柱 + 无单位 | 折线 + 单位（万元）+ 时间窗 |
| 3 | 用户年龄 | 只给平均 31 岁 | 直方图 + 中位数 + n= |
| 4 | 投放 ROI vs 花费 | 双轴未标 + 两线相交 | 两张分图，或标注轴含义 |
| 5 | 品类占比 7 类 | 饼图 7 份 | 堆叠条形 Top5 + 其他 |
