# 图表诚实与选型（Chart Honesty）

> 一句话定位：**一张图可以"对"但依然在骗人。**
> 数据没错、代码没错、渲染没错——但 Y 轴从 2.8% 起，视觉上就让 3.4% 看起来是 3.0% 的三倍。
> 这张卡的四条红线是**一票否决**，选型矩阵解决「该用什么图」。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**
- 「这张图会不会误导」「怎么画才清楚」
- 「该用什么图」「饼图行不行」
- 「为什么老板看错了」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 数据本身干不干净 | `r06` 的 `data-validation` | 那是前置校验 |
| 页面整体好不好看 | `r10` 的 `visual-hierarchy` | 那是构图 |
| 报告结构与论点 | `r08` 的 `html-report-presentation` | 那是文档 |
| 结论强度与措辞 | `r05` 的 `claim-strength` | 那是研究表达 |

**最小可开工输入**：**一张图 + 它要回答的一个问题**。

## §2 前置输入与最省追问

| 输入 | 是否必需 | 缺失时怎么办 |
|---|---|---|
| 图（或图的数据） | 必需 | 无图无法判 |
| 这张图要回答的一个问题 | 必需 | 无问题无法判选型对错 |
| 数据是否已校验 | 必需 | 未校验先走 `data-validation` |
| 读者（决策者/同行） | 建议 | 缺则按决策者默认（要结论） |

**追问纪律**：最多一轮，只问**这张图要回答什么**。

## §3 执行流水线（Workflow）

### Step 1 · 四条红线先查（任一命中即不可发）
| # | 红线 | 判据 |
|---|---|---|
| 1 | **截断轴未标注** | Y 轴起点非 0 且未在图下注明 |
| 2 | **双 Y 轴未说明** | 两个纵轴且未标各自含义与量纲 |
| 3 | **类别超限** | 饼图 **>5 类**；条形图 **>8 类** |
| 4 | **面积/3D 误导** | 3D 柱、按数值放大的圆/图标（面积错觉） |

**阈值**：四类计数**必须为 0**（诚实类指标不给缓冲，三级合一归零）。

### Step 2 · 用选型矩阵挑图（问题决定图，不是喜好决定图）
| 要回答的问题 | 用 | 不用 |
|---|---|---|
| 谁大谁小（**比较**） | 条形图（横向、排序） | 饼图、雷达图 |
| 怎么变（**趋势**） | 折线图（时间在 X） | 柱状密集堆叠 |
| 分布长什么样 | 直方图 / 箱线图 | 平均值单柱 |
| 有没有关系 | 散点图（含趋势线） | 双柱对比 |
| 占比构成 | 堆叠条形 / 饼图（**≤5 类**） | 多层饼 |

**判据**：**一个问题只能配一张图**；一张图想答两个问题 → 拆两张。

### Step 3 · 补齐标注三件（缺一不可）
```
轴标签（是什么）+ 单位（元/万元/%）+ 时间范围（哪段）
```
**阈值**：轴标签、单位、时间窗 **三项齐备**；数据来源与样本量写在图下。

### Step 4 · 提数据墨水比（去装饰）
去掉：网格线（留浅色或去掉）、图例（能直接标在图上就标）、边框、阴影、渐变、背景图。
**阈值**：**非数据墨水 ≤30%**（估算：装饰元素面积 / 图总面积）。

### Step 5 · 零轴反看（最有效的一招）
把 Y 轴强制拉到 0 重画一遍：**结论还成立吗？**
- 成立 → 原图可以不截断，直接给零轴版；
- 不成立 → 结论依赖截断放大，必须在图上明示，且正文不得用"大幅""数倍"。

### Step 6 · 一图一结论（标题写结论不写名词）
| ❌ 名词标题 | ✅ 结论标题 |
|---|---|
| 「各渠道转化率」 | 「C 渠道 3.4%，A 3.0%，B 2.6%」 |
| 「月度收入」 | 「收入连续三个月环比下滑，累计 -12%」 |

**阈值**：标题**不含比较级**（大幅/显著/远超），把比较交给副标题或正文。

## §5 质量门（一票否决）

1. **四条红线全为 0**（截断未标 / 双轴未说明 / 类别超限 / 3D 面积误导）；
2. **图形与问题匹配**（比较→条形，趋势→折线，构成→≤5 类）；
3. **轴标签 + 单位 + 时间范围**三项齐备；
4. **数据来源与样本量**写在图下；
5. 做**零轴反看**并记录结论是否成立；
6. **标题是结论句，不含比较级**。

> 本卡无自动门禁。可先用 `python agent.py quality check --input <数据.json>` 校验数据侧（间接）。

## §6 交付前自检清单

- [ ] 这张图只回答一个问题
- [ ] Y 轴从 0 起；若截断，图下已注明并说明原因
- [ ] 没有双 Y 轴；若有，两轴含义与量纲都标了
- [ ] 饼图 ≤5 类，条形图 ≤8 类
- [ ] 没有 3D 柱、没有按数值放大的圆/图标
- [ ] 轴有标签、有单位、有时间范围
- [ ] 图下写了数据来源与样本量
- [ ] 我做过零轴反看，结论没变（或已明示放大）
- [ ] 标题是结论句，没有「大幅」「数倍」
- [ ] 装饰元素不超过图面积的 30%

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | Y 轴从接近最小值起 | 从 0 起；不得不截断就注明 |
| EX-02 | 截断后正文写「大幅领先」 | 写具体数值，比较交读者 |
| EX-03 | 双 Y 轴让两条线"正好相交" | 分两张图，或标注轴含义 |
| EX-04 | 饼图切 7 份 | ≤5 类，多了改条形 |
| EX-05 | 用面积/半径表示数值 | 用长度（条形）或位置 |
| EX-06 | 3D 柱显"高级" | 二维；3D 只增加误读 |
| EX-07 | 缺单位（元？万元？） | 轴上写清单位与口径 |
| EX-08 | 不写时间范围 | 标注数据窗口 |
| EX-09 | 不写样本量 | 图下写 n=？ |
| EX-10 | 标题写名词 | 写结论句 |
| EX-11 | 网格线+阴影+渐变塞满 | 非数据墨水 ≤30% |
| EX-12 | 一张图答三个问题 | 拆成三张，各答一个 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 数据未校验 | 先走 `data-validation`，不带病出图 |
| 类别确实很多（>8） | 合并为「其他」或改排行榜 Top N + 其他 |
| 必须双轴（量纲不同且相关） | 允许，但两轴必须标含义、量纲，且说明相关性依据 |
| 数据点过密 | 聚合或抽样，说明方法 |
| 无法出交互图 | 静态图 + 关键点标注 |
| 数据涉密 | 脱敏（指数化/区间化），仍要标样本量 |
| 读者是决策者 | 一图一结论，副标题给结论句 |

**明确不做**
- 不洗数据、不搭 BI、不美化空信息图、不做印刷色彩管理。
