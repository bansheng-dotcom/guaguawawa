# 分析方法与结论强度（analysis-method）

> **「涨了 20%」是观察，「因为改了落地页」是因果，中间隔着三层推理。** 我们最常犯的错是把第一层当第三层说出去——而且说得很有底气，因为数字是真的。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「这个指标为什么变了」
- 「这两组有没有差别」
- 「能不能说是这个原因导致的」
- 「这个结论能不能对外说」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 数据能不能用 | r06 的 `data-validation` | 那是前置校验 |
| 图怎么画 | r06 的 `chart-honesty` | 那是呈现 |
| A/B 显著性判定 | r12 的 `experiment-analysis` | 那是实验 |
| 行业与竞品 | r05 的 `industry-panorama-research` | 那是外部研究 |

**最小可开工输入**：**一个具体问题 + 一组已校验的数据**。问题不具体就只能做描述统计。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| 要回答的问题（一句可判定的问句） | 必需 |
| 已校验的数据（含口径） | 必需 |
| 时间维度与分组维度 | 必需 |
| 已知的干扰因素（活动/节假日/版本） | 建议 |
| 历史同类结论（用于对比） | 建议 |

**追问纪律**：最多一轮，只问**这个问题要判断什么动作**。答不出动作，分析只会产出一堆数字。

## §3 执行流水线（Workflow）

### Step 1 · 判问题类型（四类，决定方法）
**描述**（是什么）→ 分布与分位；**比较**（两组差多少）→ 分组对比；**归因**（为什么变）→ 拆解 + 排除；**预测**（会怎样）→ 趋势 + 区间。

**判据**：问题归入四类之一，且方法与之匹配

### Step 2 · 先看分布再看均值（均值会骗人）
给出 P50 / P90 / 最大值与长尾形态。均值异常时先查是否有极端值。

**判据**：至少给了中位数与一个分位点

### Step 3 · 比较时用同期群（cohort），别用总池
把用户按首次行为月份分组，同组内比较。**总池比较会被新老结构变化污染**（老用户留存高，但占比在变）。

**判据**：时间序列比较使用同期群，不用全量池

### Step 4 · 归因时做拆解 + 排除（不是找相关）
先按「量 × 率 × 结构」拆解变化；再逐个排除干扰（活动/版本/节假日/口径变更）。**留下无法排除的那一项，才是候选原因**。

**判据**：拆解有算式；排除项逐条列出并给依据

### Step 5 · 结论标强度（三级，不许跳级）
**观察到**：数据直接显示（「转化从 2.0% 到 2.4%」）；**推断**：基于拆解与排除的最可能解释（「主要来自新落地页」）；**因果**：需实验或准实验支撑（「落地页改造使转化提升 0.4pp」）。

**判据**：每条结论标注三级之一，且因果级必须有实验支撑

### Step 6 · 写清「什么证据会推翻这个结论」
每条推断/因果结论配一句反驳条件。写不出 = 结论不可证伪。

**判据**：每条推断以上结论都有反驳条件

### Step 7 · 给行动与不做的事（分析要能落地）
输出「建议做什么」+「建议不做什么」（后者常被忽略，但更重要）。

**判据**：行动项 ≥1 条，不做项 ≥1 条

## §5 质量门（一票否决）

1. 问题归入四类之一，方法与类型匹配；
2. 给出中位数与至少一个分位点（不只均值）；
3. 时间序列比较使用同期群而非全量池；
4. 归因有拆解算式，且干扰项逐条排除并给依据；
5. 每条结论标注三级强度（观察到/推断/因果），因果级须有实验支撑；
6. 每条推断以上结论写明「什么证据会推翻它」；
7. 输出包含行动项与不做项各 ≥1 条；

> 本卡无自动门禁。可配合 `python agent.py quality check --input <数据.json>` 先验数据（间接）。

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 只有均值 | 补中位数与 P90 |
| EX-02 | 总池直接比时间 | 用同期群分组 |
| EX-03 | 相关当因果 | 标强度：观察到/推断/因果 |
| EX-04 | 因果无实验支撑 | 改写成「推断」或补实验 |
| EX-05 | 归因只说可能性 | 给拆解算式 + 排除清单 |
| EX-06 | 不排除活动/版本干扰 | 逐条排除并给依据 |
| EX-07 | 结论不可证伪 | 写「什么证据会推翻它」 |
| EX-08 | 只给行动不给取舍 | 补「不建议做什么」 |
| EX-09 | 分位点缺失导致长尾被忽略 | 看 P90 与最大值 |
| EX-10 | 用「显著」却不给判据 | 给显著性门槛或改说「明显」 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 样本量太小 | 只做描述，标注「不做推断」 |
| 无历史数据 | 只做横截面比较，标注「无趋势」 |
| 口径中途变更 | 分段分析，标注变更点，不跨段比较 |
| 无法排除干扰 | 结论降为「推断」并列出未排除项 |
| 数据含极端值 | 给截尾均值 + 中位数双报 |
| 涉敏感归因 | 只描述现象，不给原因判断 |

**明确不做**：不清洗数据、不画图、不做实验判定、不替决策拍板。
