# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`），本表是**人工评审清单**，逐条判真假。
> 版本：v2.0.0

## 一、硬门（§5，任一不过即不得交付）

| # | 判据 | 出处 |
|---|---|---|
| MU-01 | 问题归入四类之一，方法与类型匹配 | §5 第 1 条 |
| MU-02 | 给出中位数与至少一个分位点（不只均值） | §5 第 2 条 |
| MU-03 | 时间序列比较使用同期群而非全量池 | §5 第 3 条 |
| MU-04 | 归因有拆解算式，且干扰项逐条排除并给依据 | §5 第 4 条 |
| MU-05 | 每条结论标注三级强度（观察到/推断/因果），因果级须有实验支撑 | §5 第 5 条 |
| MU-06 | 每条推断以上结论写明「什么证据会推翻它」 | §5 第 6 条 |
| MU-07 | 输出包含行动项与不做项各 ≥1 条 | §5 第 7 条 |

## 二、软门（§6 自检，靠人抓）

| # | 常见错法 |
|---|---|
| MU-07 | 我把问题归到了四类之一，方法与之匹配 |
| MU-08 | 我给了中位数和分位点，不是只报均值 |
| MU-09 | 时间比较我用了同期群，没有拿全量池直接比 |
| MU-10 | 归因我写了拆解算式，不是只说「可能因为」 |
| MU-11 | 干扰项我逐条排除了，并写了依据 |
| MU-12 | 每条结论我都标了三级强度 |
| MU-13 | 没有实验支撑的，我没写成「导致」 |
| MU-14 | 每条推断结论我都写了反驳条件 |
| MU-15 | 我给了不做的事（不只是要做的） |

## 三、诚实说明

本卡没有可自动断言的门禁：分析质量取决于推理是否站得住，脚本能算数但判不了「这句话该不该说导致」。可做的替代验证是双评 + 反驳条件检查。

## 四、怎么验（没门禁时的替代验证）

1. **双评**：两人独立按 §5 逐条判，一致率 ≥80%；
2. **抽样反查**：随机抽 3 条要求指出具体位置/数字；
3. **对照抽检**：与 `references/analysis-patterns.md` 里的 BAD/GOOD 并列看。

> **纪律**：分析的目标不是「给出解释」，是「**让解释能被证伪**」。
