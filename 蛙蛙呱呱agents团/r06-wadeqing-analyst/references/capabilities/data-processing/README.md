# 数据处理与可视化（data-processing）

> 归属：R06　消费：r18, r02　版本：v1.1（2026-11-17 补齐结构）
> 表格数据的探查、清洗、合并与透视规范：先看数据长相，再动清洗，每一步都留下可复算的口径说明。

## §1 何时使用 / 何时不用

**当…时使用**：当拿到 CSV/Excel 需要做探查、去重、补缺失、合并多表或做透视时使用；当分析结论被质疑「数据干不干净」时，用本卡补数据质量证据。

**不用于**：不用于建数仓管道（归 R18）、不做统计推断（归 R06 的统计技能）、不替代业务口径确认。

## §2 输入与输出

| 方向 | 内容 |
|---|---|
| 输入 | 原始表格（CSV / JSON 行）；主键与时间列约定；业务口径（金额单位、时区、统计期） |
| 输出 | 清洗后的表 + 清洗日志；数据画像（行数/列数/缺失率/重复率/异常值）；透视结果与口径说明 |

## §3 执行流程

1. 探查：行列数、列类型、缺失率、重复率，先出一页画像。
2. 定主键：没有唯一键就先用「自然键组合」，并在日志里写明。
3. 清洗：缺失/重复/异常分别记录处理方式与影响行数，禁止静默删除。
4. 合并：先对齐列名与单位，再 join；记录匹配率与未匹配样本。
5. 透视：一行一个维度组合，合计行显式标注，避免口径混用。
6. 落盘：表 + 日志 + 画像三件套，交 `harness.py` 校验。

## §5 脚本与门禁入口

| 用途 | 命令 | 判据 |
|---|---|---|
| 数据画像 | `python agent.py quality audit --input <csv>` | 缺失/重复/异常逐项打分 |
| 清洗 | `python agent.py quality clean --input <csv>` | 清洗前后行数与处理明细必须可复算 |
| 透视 | `python agent.py explore groupby --input <csv>` | 分组口径与合计行显式 |

## §6 交付前自检

- [ ] 清洗日志记录了每一类处理的影响行数，合计能对上原始行数
- [ ] 缺失/重复/异常没有被静默丢弃
- [ ] 合并步骤给出了匹配率
- [ ] 透视结果的合计行与明细行能对上

## §7 常见错误对照

| 编号 | 错误 | 正确做法 |
|---|---|---|
| PROC-01 | 直接 `dropna()` 不提影响行数 | 先统计影响行数再决定，日志留痕 |
| PROC-02 | join 前没对齐单位（元/万元） | 合并前统一单位并在口径里写明 |
| PROC-03 | 透视表带隐藏筛选 | 导出时去掉筛选，或把筛选条件写进口径 |

## §8 异常与降级

| 情况 | 处理 |
|---|---|
| 编码不是 UTF-8 | 先用 `utf-8-sig` / `gb18030` 试读，记录最终编码 |
| 表过大内存不足 | 改分块读取，先抽样画像再全量 |
| 主键不唯一 | 降级为「自然键组合」，并在结论里声明重复风险 |
