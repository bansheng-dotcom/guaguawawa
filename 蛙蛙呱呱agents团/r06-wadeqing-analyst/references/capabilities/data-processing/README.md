# 数据处理与可视化

> 归属：R06　消费：r18, r02　版本：v1

## 定位

表格数据的探查、清洗、合并与透视规范。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 先做数据画像：行数、缺失、重复、异常值
2. 清洗动作逐条记录（规则+影响行数），可回滚
3. 合并前校验键唯一性与类型一致
4. 透视结果必须能追溯回明细

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
