# 评分表设计与校准（Rubric Calibration）

> 一句话定位：**评分表的唯一验收标准是「两个人打同一分」。**
>
> 大多数评分表失败在两个地方：
> 维度太多（12 个维度，没人能同时想 12 件事）、
> 档位没有锚定样例（"4 分 = 良好"，什么叫良好？）。
> 这张卡给的是**可校准**的写法：维度 3–6、每档有例、一致率算得出来。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**
- 「写个评分表」「怎么给这个打分」
- 「为什么我和他打分差很多」
- 「这个分数怎么解释」「评分结果没人服」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 给某个产物打分 | `r04` 的 `review-anti-collusion` | 那是评审本体 |
| 定阈值该是多少 | `r04` 的 `quantified-taste` | 那是阈值方法 |
| 写规范的对照结构 | `r04` 的 `bad-good-contrast` | 那是写法 |
| 招聘评分卡的具体维度 | `r16` 的 `hiring-scorecard` | 那是领域卡 |

**最小可开工输入**：**要评什么 + 一批已评过的样本（≥5 个）**。

## §2 前置输入与最省追问

| 输入 | 是否必需 | 缺失时怎么办 |
|---|---|---|
| 评分对象与用途 | 必需 | 用途决定维度 |
| 已评样本（≥5，含人工判定） | 必需 | 无锚定样本就写不出档位 |
| 评分者是谁、几个 | 建议 | 缺则按 2 人双评默认 |
| 总分怎么用（排序/分档/一票否决） | 必需 | 缺则按分档默认 |

**追问纪律**：最多一轮，只问**评完用来干什么、手上有没有已评过的样本**。

## §3 执行流水线（Workflow）

### Step 1 · 先定用途（用途决定一切）
| 用途 | 维度数 | 打分方式 | 总分怎么用 |
|---|---|---|---|
| **排序/评优** | 3–4 | 加权分 | 排序，不给绝对等级 |
| **分档**（合格/良好/优秀） | 3–5 | 分档 | 落档 |
| **一票否决**（底线） | 1–2 | 通过/不通过 | 任一不过即拒 |

**判据**：用途说不清 → 不要写评分表（会变成"什么都评一点"）。

### Step 2 · 维度控制在 3–6 个（超过就分组）
**阈值**：单张表 **3–6 个维度**；超过 6 个 → 拆成「主表 + 子表」。

**为什么**：7 个以上维度时，评分者会开始"平均化"（全给 3 分），区分度归零。

### Step 3 · 每档必须配锚定样例（这是可判的唯一前提）
每个维度每个档位，都要有一句**具体的、可指认的**样例：

| 档 | ❌ 无锚定 | ✅ 有锚定 |
|---|---|---|
| 4 | 良好 | 层级字号差 1.5–2×，对齐 1 条轴，间距全在刻度内 |
| 3 | 一般 | 层级差 1.2–1.5×，有 1 处对齐偏离 |
| 2 | 较差 | 层级差 <1.2×，多处对齐不齐 |

**判据**：把锚定句给另一个人，他能用它在真实产物上定位到同一档吗？

### Step 4 · 写死权重与总分口径
- 权重**必须是整数且合计 100**；
- 说明**缺失值怎么处理**（某项无法评时：给中位分？还是整份作废？）；
- 说明**是否允许跨维度补偿**（一项极低能否被其他高分拉平）。

**判据**：总分算法换个人能算出同一个数吗？

### Step 5 · 双评 + 算一致率（唯一验收）
**做法**：2 人独立评 **≥10 个样本**，然后算：

```
一致率 = 完全同档的样本数 / 总样本数
```

| 一致率 | 判定 | 动作 |
|---|---|---|
| **≥80%** | 可用 | 上线 |
| 60–79% | 勉强 | 修锚定样例后重评 |
| <60% | 不可用 | 拆维度/换维度，重写 |

**更严的做法**（≥3 人）：算 Cohen's kappa，**≥0.6** 视为可判。

### Step 6 · 定校准周期（防漂移）
- **每季度**重算一次一致率；
- 触发条件：新类型产物出现、评分者更换、一致率掉到 80% 以下；
- 校准动作：**只改锚定样例与档位描述，不轻易改维度**（改维度等于换表）。

## §5 质量门（一票否决）

1. **用途明确**（排序/分档/否决三选一）；
2. 维度 **3–6 个**，权重合计 **=100**；
3. 每个维度每个档位都有**锚定样例**（具体到可指认）；
4. **总分口径写死**（缺失值处理 + 是否可跨维补偿）；
5. 做过**双评**（≥10 样本），一致率 **≥80%**（或 kappa ≥0.6）；
6. 写明**校准周期**与触发条件。

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 10 个维度 | 3–6 个，超出拆子表 |
| EX-02 | 档位只写「良好/一般」 | 每档配可指认的锚定样例 |
| EX-03 | 权重加不到 100 | 写死整数权重合计 100 |
| EX-04 | 不说缺失值怎么办 | 明确：给中位分 or 整份作废 |
| EX-05 | 允许高分拉平极低分 | 明确底线项不可补偿 |
| EX-06 | 只评一次没人复核 | 双评 ≥10 样本算一致率 |
| EX-07 | 一致率 55% 还上线 | <60% 必须重写 |
| EX-08 | 一致率低就调分数 | 改锚定样例，不改结果 |
| EX-09 | 用途是排序却给绝对等级 | 排序只给排序，不给等级 |
| EX-10 | 评分者就是产出者 | 换人（自评必松） |
| EX-11 | 定完永不复盘 | 每季度重算一致率 |
| EX-12 | 改维度当校准 | 校准只改锚定，不改维度 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 已评样本 <5 | 只写两档（合格/不合格），不做多档 |
| 只有 1 个评分者 | 标注「未双评」，结论仅供参考 |
| 一致率长期 <60% | 说明该维度不可判，删掉或改客观量 |
| 产物差异极大（不可比） | 先分类，同类内评 |
| 评分涉及绩效/晋升 | 转 `r16` 与人评流程，本卡不给个人结论 |
| 用途是一票否决 | 只留 1–2 个底线维度，不设总分 |

**明确不做**
- 不给单个产物打分、不做绩效评价、不替领域判据（视觉/文案/图表各有专属卡）。
