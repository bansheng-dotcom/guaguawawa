# 对照样例库（contrast-library）

> 五类领域的「错例 → 对例 → 差异点 → 阈值」样例。**照抄结构，不要照抄内容**——
> 把例子换成你自己的场景才有训练价值。版本：v1（P1 起步，后续按需扩充）

---

## 一、设计（视觉层级）

**场景**：新用户第一次打开结算页，要在 3 秒内找到「确认支付」。

### ❌ 错例（真实翻车类型）

```
┌──────────────────────────────┐
│ 订单确认                       │ 14px  常规  深灰
│ 商品 A × 1        ¥128        │ 14px  常规  深灰
│ 商品 B × 1        ¥64         │ 14px  常规  深灰
│ 合计              ¥192        │ 14px  常规  深灰
│ [ 取消 ]  [ 确认支付 ]         │ 两个按钮：同尺寸、同填充色
└──────────────────────────────┘
```

**问题**：五行字号/颜色/字重完全相同；主操作与「取消」同权重。

### ✅ 对例

```
┌──────────────────────────────┐
│ 订单确认                       │ 12px  uppercase  灰 #94A3B8
│ 商品 A × 1        ¥128        │ 14px  常规        #0F172A
│ 商品 B × 1        ¥64         │ 14px  常规        #0F172A
│ 合计              ¥192        │ 24px  bold        #0F172A
│ [ 取消 ]  [ 确认支付 ]         │ 取消=描边；支付=填充+反白
└──────────────────────────────┘
```

### 差异点（可指认）

| # | 错在哪 | 改成什么 |
|---|---|---|
| 1 | 标签与正文同字号 | 标签降到 12px 并转灰（#94A3B8） |
| 2 | 合计不突出 | 合计提到 24px + bold（与正文 24/14 = **1.7×**） |
| 3 | 主次按钮同权重 | 支付=填充+反白；取消=描边 |
| 4 | 无对齐轴 | 金额右对齐成一条竖线 |

**阈值**：相邻层级字号差 **≥1.5×**｜主次按钮权重必须不同｜金额列右对齐

### 反看（灰化检验）

把整个页面变灰度：14px 常规灰 vs 24px bold 黑，**主次仍成立** → 判据不依赖颜色，合格。

## 二、文案（具体化）

**场景**：一篇讲「露营灯怎么选」的笔记正文。

### ❌ 错例

> 这款露营灯**非常好用**，**性价比超高**，**品质一流**，亮度**很棒**，续航**很持久**，强烈推荐大家入手。

### ✅ 对例

> 我按三个数选露营灯：**防水 IPX6**（IPX4 只能防溅，营地早上全是露水）、
> **续航按标称除以二**（标 20 小时的多是最低亮档测得）、**色温 2700K**（帐篷里看书不刺眼）。
> 上一支 IPX4 的用了 4 个月进水报废，这支用了 11 个月还在。

### 差异点

| # | 错在哪 | 改成什么 |
|---|---|---|
| 1 | 通篇程度副词 | 换成参数（IPX6 / 2700K / 20h÷2） |
| 2 | 无个人经历 | 加「上一支 4 个月报废」的具体事实 |
| 3 | 「强烈推荐」无理由 | 给可复用的三个判据 |
| 4 | 无时间量 | 加「11 个月还在」的使用时长 |

**阈值**：**形容词 ≤3 处/千字**，且每处必须配数字或事实｜每个结论至少 1 个可核查参数

## 三、图表（诚实性）

**场景**：向创始人汇报「三个渠道的转化率」。

### ❌ 错例

- 用**饼图**展示 7 个渠道占比（标签重叠到看不清）
- Y 轴从 2.8% 起（视觉上 C 渠道「是 A 的 3 倍」，实际 3.4% vs 3.0%）
- 双 Y 轴：左侧转化率、右侧 GMV，且未标注
- 标题写「C 渠道大幅领先」

### ✅ 对例

- 用**条形图**横向排列，按数值排序
- Y 轴从 0 起；若必须截断，在图下注明「Y 轴自 2.8% 起，差异被放大」
- 两个量纲分两张图，或同一张但**明确标注双轴含义**
- 标题写「C 渠道 3.4%，A 3.0%，B 2.6%」

### 差异点

| # | 错在哪 | 改成什么 |
|---|---|---|
| 1 | 饼图 7 类 | 条形图（饼图 ≤5 类） |
| 2 | 截断 Y 轴不标注 | 标注「自 2.8% 起，差异被放大」 |
| 3 | 双轴无说明 | 分图或标注轴含义 |
| 4 | 标题下结论 | 标题给数字，结论放副标题 |

**阈值**：饼图 **≤5 类**｜截断轴**必标**｜双轴仅量纲不同且相关时用｜标题**不含比较级**

## 四、代码（可读性）

**场景**：一个处理退款金额的计算函数。

### ❌ 错例

```python
def calc(d, r):
    t = 0
    for i in d:
        t += i['p'] * i['q']
    if r > 0:
        t = t * (1 - r)
    return t
```

**问题**：名字全是单字母；`r` 是比例还是金额看不出；负数、空列表、超 100% 退款都没处理。

### ✅ 对例

```python
def refund_total(line_items: list[dict], refund_ratio: float) -> float:
    """按退款比例计算应退金额。

    refund_ratio: 0.0–1.0 的比例（0.3 表示退 30%）。
    """
    if not 0.0 <= refund_ratio <= 1.0:
        raise ValueError(f"refund_ratio 必须在 0–1 之间，收到 {refund_ratio}")
    if not line_items:
        return 0.0
    gross = sum(item["unit_price"] * item["quantity"] for item in line_items)
    return round(gross * refund_ratio, 2)
```

### 差异点

| # | 错在哪 | 改成什么 |
|---|---|---|
| 1 | 单字母命名 | `refund_total` / `refund_ratio` / `line_items` |
| 2 | 无类型标注 | 加 `list[dict]` / `float` |
| 3 | 无 docstring | 说明参数含义与取值范围 |
| 4 | 静默接受非法输入 | 越界抛 `ValueError`（值入错误信息） |
| 5 | 空列表未处理 | 显式返回 0.0 |
| 6 | 金额未取整 | `round(..., 2)` 到分 |

**阈值**：命名**不留单字母**（除循环下标）｜公开函数**必有 docstring**｜金额**取整到分**｜非法输入**必须抛错并带值**

## 五、文档（可判定性）

**场景**：团队规范里的一条「接口错误要友好」。

### ❌ 错例

> **错误处理规范**
> 接口返回错误时要友好，不能吓到用户，要让人看懂。

**问题**：什么叫友好？什么叫看懂？谁判？无法执行也无法验收。

### ✅ 对例

> **错误处理规范**
>
> | 场景 | ❌ 错例 | ✅ 对例 | 判据 |
> |---|---|---|---|
> | 网络超时 | 「系统繁忙」 | 「网络超时，已为你保留草稿。稍后重试或点此复制」 | 说清**发生了什么 + 你的数据怎样 + 下一步动作** |
> | 校验失败 | 「参数错误」 | 「手机号需 11 位，你填了 8 位」 | 指出**哪个字段 + 期望什么 + 实际什么** |
>
> **阈值**：错误文案须含 **3 要素**（原因/影响/动作）｜禁止出现「系统繁忙」「操作失败」这类零信息文案

### 差异点

| # | 错在哪 | 改成什么 |
|---|---|---|
| 1 | 只有形容词 | 给 3 类错误的具体文案对照 |
| 2 | 无判据 | 定义「原因 + 影响 + 动作」三要素 |
| 3 | 无禁止项 | 明确禁用的零信息文案清单 |
| 4 | 无法验收 | 给出可对照的判据表 |

**阈值**：错误文案 **3 要素齐备**｜零信息文案**数量 = 0**

## 六、写卡时怎么用这个库

1. **先找同类**：你的主题属于哪一类？照那一节的**四段结构**（错例/对例/差异点/阈值）写。
2. **换场景**：把例子换成你的真实场景，保留结构与阈值口径。
3. **别照抄英文**：开源样例多是英文 tech demo，直接搬会水土不服（中文长度、标点、行业习惯都不同）。
4. **阈值宁保守**：写「≥1.5×」比写「≥3×」好——前者能做到，后者会让人放弃。
5. **每类 1–2 组足够**：对照不是越多越好，多了没人看完。
