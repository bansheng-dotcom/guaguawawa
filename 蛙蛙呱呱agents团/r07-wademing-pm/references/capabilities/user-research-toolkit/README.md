# 用户研究工具箱

> 归属：R07　消费：r05, r11　版本：v1

## 定位

访谈、问卷与可用性研究的执行规范：问题设计、样本、记录与结论。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 访谈问题开放且不带引导，一次只问一件事
2. 问卷先测再发，选项互斥且穷尽
3. 可用性测试至少 5 人，任务写成可观察的完成标准
4. 结论区分「观察到的事实」与「推断」

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
