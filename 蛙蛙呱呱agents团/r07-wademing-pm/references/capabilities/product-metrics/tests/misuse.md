# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`），本表为人工评审清单。版本：v2.0.0

## 一、硬门（§5，任一不过即不得交付）

| # | 判据 |
|---|---|
| MU-01 | 北极星是行为指标（非收入/DAU），一句话说清 |
| MU-02 | 3–5 个驱动指标，与北极星有可写的分解式 |
| MU-03 | 护栏指标 ≥2 个且各有阈值 |
| MU-04 | 每个指标写全四件：定义/口径/来源/频率 |
| MU-05 | 同名不同义的指标已列出并统一 |
| MU-06 | 看板指标 ≤8 个 |

## 二、软门（§6 自检）

| # | 常见错法 |
|---|---|
| MU-06 | 北极星是行为指标，不是收入或 DAU |
| MU-07 | 我能写出驱动指标到北极星的分解式 |
| MU-08 | 护栏至少 2 个，各有阈值 |
| MU-09 | 每个指标都写了定义、口径、来源、频率 |
| MU-10 | 口径里写清「含谁不含谁」 |
| MU-11 | 我把同名不同义的指标列出来了 |
| MU-12 | 看板不超过 8 个数 |
| MU-13 | 我没有把「留存」这种词直接当指标名（要写清几天留存） |

## 三、诚实说明

本卡没有可自动断言的门禁：指标是否承载价值主张只能由业务判断，机器能验的只有分解式能否复算。

> **纪律**：指标体系的目标不是「数更多」，是「**三个人说同一个词时指的是同一个数**」。
