# 来源分级与措辞强度（source-grading）

> 被 §3、§5、§7 按需引用。版本：v2.0.0（项目自建，v1）

---

## 一、问题收窄模板

```markdown
- 对象：<具体品类 / 公司 / 技术>
- 维度：<规模 / 增速 / 集中度 / 份额 / 价格 / 渗透率 —— 只选一个>
- 判定口径：<时间范围 + 地域 + 统计口径>
- 回答它的数字：<能回答它的那一个具体指标>
```

**合格**：2026 年中国大陆 SaaS 客服工具 CR3（按营收，2026 全年）
**不合格**：帮我研究下客服 SaaS

> 判据只有一条：**能不能说出"哪个数字能回答它"**。说不出就是还没收窄。

## 二、来源四级

| 级别 | 定义 | 典型 | 可用性 | 措辞上限 |
|---|---|---|---|---|
| **S** | 一手数据 | 官方财报、平台后台、监管文件、公司公告 | 直接支撑 | "可以确认" |
| **A** | 权威二手 | 行业协会、头部研究机构、招股书、政府统计 | 可支撑，须标日期 | "据 X（日期）" |
| **B** | 媒体 / 自媒体，**能追到原始出处** | 科技媒体转述财报 | 仅作辅助 | "有报道称" |
| **C** | 无法追溯 / AI 生成 / 匿名 | 匿名爆料、"业内消息" | **只作线索** | "待核实" |

**降级规则**：B 级追不到原始出处 → 自动降为 C；
A 级若无发布日期 → 降为 B（不可复核时效）。

## 三、证据条目四要素（缺一不合格）

```json
{
  "id": "E-07",
  "claim": "2026 年中国大陆 SaaS 客服工具 CR3 = 47%",
  "level": "A",
  "source": "中国软件行业协会《2026 上半年 SaaS 市场报告》",
  "date": "2026-08-14",
  "locator": "第 3.2 节，表 7，第 18 页"
}
```

| 要素 | 缺了会怎样 |
|---|---|
| `level` | 无法判措辞强度 |
| `source` | 无法复核 |
| `date` | 无法判断时效（市场数据半年即过期） |
| `locator` | 无法定位（"报告里说的"等于没找到） |

## 四、措辞强度对照（写结论时逐条对照）

| 证据情况 | 可以说 | 不能说 |
|---|---|---|
| 2+ 个 S/A 交叉一致 | 「可以确认…」 | —— |
| 单一 S/A | 「据 X（2026-08），…」 | 「业内公认…」 |
| 仅 B 级 | 「有报道称…，尚未证实」 | 「…是 47%」 |
| 仅 C 级 | 「有说法认为…，**待核实**」 | 任何确定性表述 |
| 无来源 | 只列"待查问题" | 任何结论 |

### 三个必须删掉的句式

1. 「业内普遍认为」—— 等于"我没有来源"；
2. 「大家都知道」—— 同上；
3. 「显而易见」—— 同上。

> **改写方法**：把"普遍认为"换成"据 X（日期）"，或直接降级为"待核实"。

## 五、反证要求（研究 vs 论证的区别）

一份是**研究**还是一份**论证**，区别只在一件事：**有没有列反证**。

| 必列项 | 为什么 |
|---|---|
| 与你结论不一致的来源 | 不列＝选择性引用 |
| 口径差异（为什么两个来源数字不同） | 不解释＝读者无法判断信谁 |
| 你的结论可能错在哪 | 不写＝过度自信 |

**判据**：报告中至少有一个"不利证据"段落。没有它，这份报告就不是研究。

## 六、材料清单与缺口

```json
{
  "acquired": [
    {"item": "2026 上半年 SaaS 报告", "path": "materials/saas-2026h1.pdf", "date": "2026-08-14"}
  ],
  "gaps": [
    {"item": "各厂商营收明细", "impact": "CR3 只能到品类级，无法验证单家份额", "severity": "HIGH"}
  ]
}
```

**铁律**：缺口不写进报告，报告可信度即为零——读者无法判断哪部分没研究。

## 七、与门禁的对应关系

| 门禁 | 覆盖哪一节 | 判不了什么 |
|---|---|---|
| `harness.py plan` | §一 问题收窄（间接）、查询规格 | 判不了问题选得好不好 |
| `harness.py materials` | §六 材料与缺口齐备 | 判不了缺口写得诚不诚实 |
| `harness.py verdict` | §三 证据链非空、§四 措辞 | 判不了来源级别评得对不对 |

> 三道门禁保证"有据、有缺口、不猜测"，**保证不了"结论是对的"**。
> 后者只能靠交叉验证与时间检验。
