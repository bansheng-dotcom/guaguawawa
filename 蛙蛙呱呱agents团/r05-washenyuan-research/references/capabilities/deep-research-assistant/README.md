# 深度研究

> 归属：R05　消费：r01, r07, r11　版本：v1

## 定位

复杂主题的深度研究流程：问题拆解、证据分级、交叉验证、结论与不确定性。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 先写研究问题与不研究什么
2. 每人结论至少两个独立来源
3. 证据分级：一手/二手/推测，推测必须标注
4. 结论写清适用边界与反例

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
