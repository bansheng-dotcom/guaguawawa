# 市场情报雷达

> 归属：R05　消费：r12, r01　版本：v1

## 定位

对竞品/政策/技术做基线对比，只报「相对上次的净变化」。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 先存基线，再谈变化；无基线不报「新增」
2. 每条情报带来源、时间、可信度等级
3. 去重与聚类后再排序，避免同一事件反复占位
4. 变化分级：影响决策/需观察/仅记录

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
