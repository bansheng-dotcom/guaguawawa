# 学术研究与写作

> 归属：R05　消费：r11, r04　版本：v1

## 定位

从选题到投稿的学术写作流水线：论证结构、证据链、审稿回复。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 每个论断对应一条可核验证据，证据不足写成「待验证」
2. 方法与数据先于结论；样本量与统计口径必须交代
3. 审稿回复逐条对账，不合并、不回避
4. 引用格式统一，禁止二手转引冒充原文

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
