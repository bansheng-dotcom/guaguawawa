# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`，无命令门禁），因此本表是**人工评审清单**。
> 每条都由评审者判真假，判不了的写「不可判定」。版本：v2.0.0

## 一、硬门（§5，任一不过即不得交付）

| MU-01 | 每条文献可追溯（有链接或标「不可核」） | §5 第 1 条 |
| MU-02 | 每个主张都是三段论证 | §5 第 2 条 |
| MU-03 | 直接引用与转述已区分 | §5 第 3 条 |
| MU-04 | 结论写明适用范围与局限 | §5 第 4 条 |

## 二、软门（§6 自检，靠人抓）

| MU-04 | 每条文献都有作者/年份/来源 |
| MU-05 | 主论据没有一条是「不可核」的 |
| MU-06 | 每个主张都写了推理段 |
| MU-07 | 直接引用加了引号并给出处 |
| MU-08 | 转述标了「据 X（年）」 |
| MU-09 | 结论写了适用范围和局限 |

## 三、诚实说明

本卡**没有**可自动断言的门禁：它的输入是判断与决策，不是固定 schema。
写一个「永远 exit 0」的脚本只会制造假绿——这比没有门禁更糟。

> **纪律**：knowledge 卡的价值在「有方法可依」，不在「有分数可刷」。
