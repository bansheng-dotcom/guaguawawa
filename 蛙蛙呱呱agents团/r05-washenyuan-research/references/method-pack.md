# R05 蛙深远 · 方法包（Method Pack v1）

> 配套：`SKILL.md` 管「何时用、交什么」；本文件管「怎么想才不浅」。
> 验收：`python scripts/audit_method.py r05` ≥ 80。

## 1. 决策问题

- **典型决策**：进不进这个市场 / 这个赛道值不值得投 / 竞品这步棋我们要不要跟 / 这个价格能不能撑住。
- **决策者**：创始人（R01）或业务负责人；他最怕的是「看完报告还是不知道要不要做」。
- **成功标准**：决策者能在一页内看到「做/不做/条件做」+ 关键假设 + 什么信号会让我们改主意。
- **非目标**：不替他拍板；不写没有来源的确定性结论；不做投资建议。

## 2. 问题树（MECE）

市场类问题默认拆 4 支（互斥穷尽，可按行业调整）：

| 分支 | 要回答 | 需要数据 | 方法 | 证据 |
|---|---|---|---|---|
| 需求 | 谁买、买多少、为什么现在买 | 人口/人均消费/渠道动销 | 自上而下 + 自下而上双口径 | A/B |
| 供给 | 谁在供、成本结构、产能弹性 | 产量/产区/进口/成本 | 成本曲线、集中度 CR3/CR5 | A/B |
| 竞争 | 现有玩家怎么打、进入壁垒 | 份额/价格带/渠道 | 五力、战略群组、价差矩阵 | B |
| 经济性 | 单店/单吨/单客赚不赚钱 | 采购/物流/损耗/费用 | 单位经济、盈亏平衡、敏感性 | B/C |

**critical branch**：通常不是「需求大不大」，而是「**经济性在什么条件下成立**」——资源优先给它。

## 3. 假设与证伪

- 假设必须写成「方向 + 幅度 + 条件」：例「若走产地直采，单公斤成本可降 0.5—0.8 元，前提是年销量 ≥1,500 吨」。
- 每条假设三件套：支持证据 / 反对证据 / **杀死标准**（如「直发损耗连续 2 周 >10% 即证伪」）。
- **至少 2 个竞争解释**：
  1. 价差是区域差 vs 规格差（用同规格同日对照排除）；
  2. 价格下跌是趋势 vs 季节性（用 3 年同期基线排除）；
  3. 增长是行业β vs 自身α（用同店/同区域对照排除）。

## 4. 证据分级

| 级别 | 本角色典型来源 | 允许用法 |
|---|---|---|
| A | 统计公报、部委监测、交易所、海关 | 进结论、进合同 |
| B | 行业协会、研究机构、批发市场报价 | 方向 + 区间 |
| C | 单点访谈、专家口径、估算 | 必须标注 + 敏感性 |

**硬规则**：
- 每个数字挂 S 编号；同名不同口径单列（例：富士苹果 14.00 vs 苹果 13.88）。
- 缺口写「缺什么 / 影响哪个结论 / 怎么补」，不许用「数据有限」一句带过。
- 引用二手结论必须回溯到一手来源；回溯不到就降级为 C。

## 5. 分析方法与陷阱

**可执行**：`python scripts/methods.py matched|did|elasticity ...`（对照/差分/弹性）；方法门禁 `scripts/method_gate.py`。

**默认方法**：
1. **双口径测算**：自上而下（人口×人均×单价）与自下而上（门店×客单×频次），差异 >20% 必须解释。
2. **匹配对照**：同品种、同规格、同日、同层级才允许比较；不能匹配就明说。
3. **同期基线**：任何「涨/跌/正常」给 3 年以上同期对照。
4. **分解归因**：价差/毛利拆成规格、区域、时点、渠道，残差必须为 0。
5. **情景与敏感性**：至少乐观/基准/悲观三档，标出翻转点。
6. **三角验证**：同一结论至少用两个独立来源/两种方法互证；不一致时单列，不取平均。
7. **样本代表性**：检查样本覆盖的品类/区域/时段；覆盖不足时降级为「方向」，不做外推。

**陷阱清单（本行业）**：
- 把规格差当区域差（富士 Φ85+ 与纸+膜袋差 1.9 倍）；
- 把波动小当水平正常（sd 低 ≠ 价格合理）；
- 用单日/单点同比（报价可能 70 天没更新）；
- 用批发价减零售价算毛利（环节/规格都不同）；
- 把相关当因果（n=8 的回归不显著也照写「相关」）。

## 6. 输出契约

每条结论四件套（缺一不进首页）：

```
claim       一句话（方向 + 幅度 + 范围/时间）
evidence    S 编号 + 观测行/页码 + 口径
confidence  A/B/C + 区间（无区间写「点估计，未验证」）
falsifier   什么新证据会推翻
```

**门禁**：headline 必须有对照/基线/匹配；建议必须有负责人、阈值、时间；缺口必须单列。
