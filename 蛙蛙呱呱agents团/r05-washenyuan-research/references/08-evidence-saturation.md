# 08 · 证据饱和与三角验证

> 解决一个问题：**什么时候可以停手写结论，什么时候还差得远。**
> 本文件只讲判据与台账，不放任何行业数字。

## 1. 来源饱和（Saturation）

一条结论要能写进正文，至少满足 **3 个相互独立**的来源同时成立。

「独立」的三条硬定义：

| 维度 | 算独立 | 不算独立 |
|---|---|---|
| 机构 | 不同机构各自采集 | 同一机构的新闻稿与转载 |
| 方法 | 问卷 / 访谈 / 官方统计 / 平台数据 之间 | 同一份问卷换了三个标题 |
| 时间 | 覆盖两个以上统计期 | 同一天的三条快讯 |

判定：

- 3 源且互不冲突 → 可写「结论」，置信度高；
- 2 源 → 只能写「倾向」，置信度中，并列出缺的那一类来源；
- 1 源 → 只能写「单源待证」，不得进摘要与首页。

## 2. 三角验证（Triangulation）

关键数字（市场规模、增速、份额、单价、成本）必须三类互证：

```
官方口径（统计年鉴 / 部门发布 / 交易所披露）
        ×
媒体报道（主流财经媒体，须给日期与原文链接）
        ×
一线证据（访谈原话 / 平台后台截图 / 招投标公告）
```

三类一致 → 直接引用；
两类一致、一类偏差 → 引用多数口径，在边界写清偏差值与可能原因；
三类互不一致 → **不出数**，改写成区间，并标注「口径冲突，待核」。

## 3. 台账模板（结论级）

每条结论留一行，缺列的结论不得进正文：

| 结论 | 官方源 | 媒体源 | 一线源 | 冲突处理 | 状态 | 核验日期 |
|---|---|---|---|---|---|---|
| 例：某品类增速高于大盘 | 年鉴 2024 | 财经媒体 2025-03 | 3 家经销商访谈 | 无冲突 | 可写 | 2026-11-26 |
| 例：某区域需求下滑 | 无 | 1 篇报道 | 1 家门店 | 官方缺位 | 单源待证 | 2026-11-26 |

## 4. 假设-证伪台账（假设级）

研究不是「找证据支持」，是「找证据杀死」。每条假设三列：

```yaml
- hypothesis: 需求下滑来自价格而非口味
  kill_if: 同价位竞品销量持平或上升
  status: 待验证        # 待验证 / 成立 / 已杀死
```

规则：

- 没有 `kill_if` 的假设不进结论；
- 连续两个统计期都没被杀死，也没被证实 → 标「长期待验证」，写进边界，不带入结论；
- 被杀死要留记录（哪条证据杀死的），这是下次同类研究最值钱的部分。

## 5. 常见反例（都是真实踩过的坑）

| 反例 | 为什么错 | 正确做法 |
|---|---|---|
| 三个来源其实是同一份报告 | 不独立，等于单源 | 回溯原始出处，只算 1 源 |
| 用行业常识补缺失数字 | 常识不可核 | 写「待补」+ 取数路径 |
| 官方口径与媒体口径冲突时取好看的那个 | 选择偏差 | 取新口径，写清另一口径差异 |
| 只找支持性证据 | 确认偏误 | 先写杀死标准，再找证据 |
| 访谈 3 个人就算一线证据 | 样本不代表总体 | 标「个案」，不外推到区域 |

## 6. 验收（写结论前逐条打勾）

- [ ] 每条结论有 ≥3 独立源，或明确标「单源待证」；
- [ ] 每个关键数字有官方 / 媒体 / 一线至少两类；
- [ ] 每条假设有杀死标准，且状态已更新；
- [ ] 口径冲突已写进边界，没有静默择一；
- [ ] 缺失项都写了取数路径，没有用常识凑数。
