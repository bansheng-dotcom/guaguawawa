# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`），本表是**人工评审清单**，逐条判真假。
> 版本：v2.0.0

## 一、硬门（§5，任一不过即不得交付）

| # | 判据 | 出处 |
|---|---|---|
| MU-01 | 成本拆成五项，每项有数字来源（禁「大概」） | §5 第 1 条 |
| MU-02 | 毛利率用「到手价」口径复算，不用「售价减进货价」 | §5 第 2 条 |
| MU-03 | 定价方法三选一且有理由，写明为何不用另两种 | §5 第 3 条 |
| MU-04 | 每一档折扣的折后毛利率 ≥15%（或写明地板线与依据） | §5 第 4 条 |
| MU-05 | 价格带偏离主流区间时给出理由 | §5 第 5 条 |
| MU-06 | 压测（退货率 ×2、抽佣 +3pp）后毛利率仍为正 | §5 第 6 条 |

## 二、软门（§6 自检，靠人抓）

| # | 常见错法 |
|---|---|
| MU-06 | 五项成本我都写了，退货率是我自己算过的不是猜的 |
| MU-07 | 毛利是按到手价算的，扣了抽佣与支付手续费 |
| MU-08 | 我说了用哪种定价方法，以及为什么不用另外两种 |
| MU-09 | 每一档折扣我都算了折后毛利率 |
| MU-10 | 折后毛利率最低的那一档还在 15% 以上 |
| MU-11 | 价格带偏离主流时我给了理由 |
| MU-12 | 原价有真实成交记录，不是我编的锚点 |
| MU-13 | 退货率翻倍后还赚钱（或我已说明放弃该类目） |

## 三、诚实说明

本卡没有可自动断言的门禁：定价的输入是成本明细与判断，不是固定 schema。可机器做的只有单件利润复算（`selection profit`），口径是否真实仍靠人核。

## 四、怎么验（没门禁时的替代验证）

1. **双评**：两人独立按 §5 逐条判，一致率 ≥80%；
2. **抽样反查**：随机抽 3 条要求指出具体位置/数字；
3. **对照抽检**：与 `references/pricing-models.md` 里的 BAD/GOOD 并列看。

> **纪律**：定价的目标不是「算出一个数字」，是「**退货一次之后还赚钱**」。
