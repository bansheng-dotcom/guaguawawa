# 定价与促销策略（pricing-strategy）

> **定价错，后面全错——而且错得很安静。** 选品、投放、毛利都是建立在价格上的；价格算错一次，后面三个月的账都对不上，但没有任何门禁会报警。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「这个卖多少钱合适」
- 「满减怎么设计」
- 「打个 7 折还赚不赚」
- 「为什么同行卖得比我便宜还赚钱」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 这个品值不值得做 | r14 的 `smart-product-selector` | 那是选品评分 |
| 投放与渠道 | r12 的 `paid-execution` | 那是买流量 |
| 财税口径 | r03 | 那是财务 |
| 成本怎么降 | r15 的 `analyze-procurement` | 那是采购 TCO |

**最小可开工输入**：**一件商品的成本明细 + 一个目标毛利率**。缺成本就无法定价。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| 成本明细（采购价/物流/包装/平台费/退货率） | 必需 |
| 目标毛利率或竞品价 | 必需 |
| 平台费率（抽佣/支付手续费） | 必需 |
| 促销形式（无/折扣/满减/赠品） | 建议 |
| 价格带与定位（低价/中价/高价） | 建议 |

**追问纪律**：最多一轮，只问**成本明细里有没有平台费与退货率**。这两项最常被漏，漏了算出的毛利是假的。

## §3 执行流水线（Workflow）

### Step 1 · 拆成本底座（五项，缺一不可）
把成本拆成：**采购价 + 头程物流 + 包装 + 平台费（抽佣 + 支付手续费）+ 退货损耗**。退货损耗 = 退货率 ×（来回运费 + 无法二次销售的比例）。

**判据**：五项都写出来，且每项有数字来源

### Step 2 · 算真实到手价与真实毛利率
到手价 = 售价 − 平台抽佣 − 支付手续费 − 运费（若包邮）。毛利率 = （到手价 − 采购 − 包装 − 退货损耗）÷ 到手价。

**判据**：毛利率必须复算，不许用「售价减进货价」的粗算

### Step 3 · 选定价方法（三选一，写理由）
**成本加成**：成本 ÷（1 − 目标毛利率）；**价值定价**：按用户感知价值锚定（适合差异化品）；**竞品锚定**：跟主力竞品同带或略低（适合标品）。

**判据**：选定一种并写清为什么不用另外两种

### Step 4 · 设计折扣阶梯（折后毛利必须为正）
常见阶梯：**满 2 件 9 折 / 满 300 减 30 / 第二件半价**。每一档都要算「折后毛利率」，低于地板线的档位不许上。

**判据**：每一档折后毛利率 ≥ 地板线（默认 ≥15%），且逐档算过

### Step 5 · 检查心理价位（整数、锚点、价格带）
三个检查：**是否落在主流价格带内**（偏离要有理由）、**是否用了有效尾数**（99/98 类）、**是否有可用于对比的锚点**（原价不能是编的）。

**判据**：价格带偏离有理由；原价有真实成交记录支撑

### Step 6 · 压测最坏情形（退货率翻倍 + 平台加佣）
把退货率 ×2、平台抽佣 +3pp，重算毛利率。

**判据**：压测后毛利率仍为正；若为负，说明这个价撑不住波动

## §5 质量门（一票否决）

1. 成本拆成五项，每项有数字来源（禁「大概」）；
2. 毛利率用「到手价」口径复算，不用「售价减进货价」；
3. 定价方法三选一且有理由，写明为何不用另两种；
4. 每一档折扣的折后毛利率 ≥15%（或写明地板线与依据）；
5. 价格带偏离主流区间时给出理由；
6. 压测（退货率 ×2、抽佣 +3pp）后毛利率仍为正；

> 本卡无自动门禁。可配合 `python agent.py selection profit --input <利润参数.json>` 复算单件利润（间接）。

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 用「售价 − 进货价」当毛利 | 按到手价算，扣抽佣/支付手续费/退货损耗 |
| EX-02 | 漏平台抽佣 | 平台费率必须进成本五项 |
| EX-03 | 漏退货损耗 | 退货率 × 来回运费 + 报废比例 |
| EX-04 | 满减不逐档算 | 每一档都要算折后毛利率 |
| EX-05 | 折后亏本冲量 | 地板线 15%，低于即不上该档 |
| EX-06 | 原价虚构做锚点 | 原价必须有真实成交记录 |
| EX-07 | 不考虑价格带 | 偏离主流带要给理由（品牌/差异/组合） |
| EX-08 | 不做压测 | 退货率 ×2 + 抽佣 +3pp 重算 |
| EX-09 | 按成本定价却宣称价值定价 | 方法与价格要对得上 |
| EX-10 | 把赠品当免费 | 赠品成本要计入折后毛利 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 成本明细不全 | 按行业区间估并标注「估算」，且不用于正式定价 |
| 退货率无历史 | 用保守值（品类均值 +5pp）并标注 |
| 竞品价拿不到 | 改用成本加成，标注「未做竞品锚定」 |
| 平台费率会变 | 按当前费率算，并在压测里加 +3pp |
| 清库存场景 | 允许折后毛利为负，但必须写明「清仓」与预计损失额 |
| 订阅/服务类 | 改为按 LTV 与流失率算，本卡需扩展 |

**明确不做**：不做选品、不做投放、不出财务意见、不承诺销量。
