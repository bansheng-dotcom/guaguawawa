# 全渠道电商经营诊断

> 归属：R14　消费：r12, r02　版本：v1

## 定位

店铺经营诊断：流量、转化、客单、复购、库存五条线。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 诊断从漏斗开始：曝光→点击→加购→支付→复购
2. 每层异常给基线对比与可能原因（不超过 3 条）
3. 区分平台侧、商品侧、履约侧问题
4. 结论必须给优先级与验证动作

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
