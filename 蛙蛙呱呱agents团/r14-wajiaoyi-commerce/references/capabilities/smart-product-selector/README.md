# 选品评分

> 归属：R14　消费：r01, r06, r12　版本：v1

## 定位

五维评分 + 利润红线 + 假设卡门禁。

## 怎么用

- 命令：`python agent.py selection score / profit`
- 确定性技能：规则与门禁已写进代码，直接跑即可。

## 执行步骤

1. 五维各 1–5 分，按归一化权重加权（原始权重合计 120%）
2. ≥4.0 强烈推荐 / 3.0–3.9 尝试 / 2.0–2.9 谨慎 / <2 放弃
3. 推荐品必须有假设卡（预期指标 + 验证节点）
4. 毛利率 <30% 警告、<15% 建议放弃

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
