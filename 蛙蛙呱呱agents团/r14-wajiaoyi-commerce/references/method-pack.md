# R14 蛙交易 · 电商 · 方法包（Method Pack v1）

## 1. 决策问题

- 典型决策：这个品能不能做、怎么定价、怎么排期。
- 决策者：电商负责人；成功标准：毛利与周转达标、退货可控。
- 非目标：不做刷单、不承诺爆款。

## 2. 问题树（MECE）

| 分支 | 要回答 | 假设 | 数据 | 方法 |
|---|---|---|---|---|
| 需求 | 有没有人买、多大 | 需求真实 | 搜索/竞品/评论 | 需求验证 + 关键词 |
| 竞争 | 价格带与对手 | 有可进入的缝隙 | 竞品价格 | 价格带矩阵 |
| 毛利 | 扣完退货/履约还剩多少 | 毛利 ≥ 目标 | 成本/退货 | 单位经济 |
| 供应 | 能不能稳定供货 | 货期/起订量可控 | 供应商 | 供应评估 |

**critical branch**：`毛利`——资源优先给它。

## 3. 假设与证伪

- H1：该价格带月销 ≥ 目标，且退货率 ≤ 10%。
- H2：扣履约与退货后毛利率 ≥ 25%。
- 竞争解释（至少 2 个）：卖得好是因为品，还是因为投流？；毛利低是采购价，还是退货/履约？
- 每条假设必须有**杀死标准**：指标 + 阈值 + 观察窗口。

## 4. 证据分级

| 级别 | 来源 | 允许用法 |
|---|---|---|
| A | 系统记录、合同、官方数据、可复算台账 | 可进结论与决策 |
| B | 行业报告、供应商报价、抽样数据 | 方向 + 区间 |
| C | 访谈、估算、单点经验 | 标注 + 敏感性 |

**规则**：每个结论挂来源；同名不同口径单列；缺什么、影响什么、怎么补，必须写清；C 级超过 3 条时结论降级为「条件成立」。

## 5. 方法与陷阱

- 选品评分：市场/增长/竞争/毛利/供应五维加权。
- 价格带矩阵：竞品价格 × 销量，找空档。
- 单位经济：售价 − 采购 − 履约 − 退货 − 平台费。
- **价格弹性**：log-log 回归，`python scripts/methods.py elasticity --input e.csv --price price --qty qty`；弹性 <-1 才考虑降价换量。
- **动销预测**：按周动销率 = 销量 ÷ 到货量；连续 2 周 <75% 即预警，不用月度平均掩盖。
- **品类角色**：引流/利润/冲量/防守四类，按毛利率 × 周转 × 复购打分，不按 GMV 排序。

**陷阱清单**：
- 只看毛利率
- 忽略退货与履约
- 跟爆款不看供应
- 定价不看价格锚
选品结论必须给「验证单量 + 止损线」，不许直接压货。

## 6. 输出契约

```
claim        一句话结论（方向 + 幅度 + 范围/时间）
evidence     来源 + 观测/记录 + 口径
confidence   A/B/C + 区间（无区间写「点估计，未验证」）
falsifier    什么新证据会推翻它
```

缺任一项 → 不得进首页；建议缺负责人/阈值 → 行动性不通过。
