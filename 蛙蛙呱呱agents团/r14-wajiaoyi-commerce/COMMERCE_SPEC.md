# COMMERCE_SPEC.md - R14 蛙交易 · 交易与收入履约统一规格账本 (SSOT)

> **版本**：v12.0  
> **单一信任源 (Single Source of Truth)**：本账本定义商品电商、订单购物车、计量计费、支付结算、电子签约、预约编排与收入对账的全局业务标准、计算口径与 8 维硬门禁。

---

## 一、 北极星指标与核心准则 (North Star & KPI)

| 指标代号 | 指标名称 | 目标基准线 | 统计口径说明 |
| :--- | :--- | :--- | :--- |
| **SRR** | 结算支付成功率 (Settlement Success Rate) | **≥ 99.5%** | 成功支付及结算的订单数占总发起支付意图数的比率 |
| **RDR** | 退款争议率 (Refund & Dispute Rate) | **≤ 0.5%** | 发起退款争议/拒付争议订单数占总已支付订单的比率 |
| **BTA** | 勾稽平衡容差 (Balance Tolerant Accuracy) | **= 0.00** | 交易订单总额与拆分子项、税费、折扣之差绝对值容差必须为 0.00 |
| **SCL** | 电子签合规率 (Signature Compliance Level) | **= 100.0%** | 需签约履约订单中，完成合法电子签及审计链闭环的比例 |

## 二、 交易计算规范与阶梯模型 (Commerce Calculation Models)

1. **价格勾稽公式 (Balance Formula)**：
   - $\text{Total} = \sum (\text{Unit Price} \times \text{Quantity}) + \text{Tax} - \text{Discount} + \text{Shipping}$
   - 所有金额保留两位小数或以最小货币分位 (Cent) 计，禁止出现浮点截断漂移。
2. **用量计量聚合 (Usage Aggregation Types)**：
   - `sum`: 周期内累加总用量
   - `max`: 周期内单次峰值用量
   - `last`: 周期结束时最新用量水位
   - `unique_count`: 周期内唯一调用者/设备计数
3. **阶梯计费模式 (Tiered Pricing Models)**：
   - `graduated` (累进分段递减/增计费)
   - `volume` (达到阶梯全量适用统一定价)
   - `flat_fee` (固定底价模式)
   - `per_unit` (标准单价模式)

## 三、 交易与履约 8 维发布与准入门禁 (The 8-Dimension Gate Matrix)

所有订单创建、支付结算、退款执行与签约交付必须通过以下 8 维硬门禁：

| 门禁 ID | 门禁名称 | 合格阈值 (Threshold) | 破坏后果与处置策略 |
| :--- | :--- | :--- | :--- |
| **GATE-01** | 交易幂等性防护 (Idempotency Key) | **必须具备有效 UUIDv4 或业务流水号** | 缺失直接拦截，防重复扣款与重放攻击 |
| **GATE-02** | 财务勾稽平衡 (Balance Accuracy) | **勾稽容差 = 0.00 (无损精准)** | 差额哪怕 0.01 亦判定严重破损，硬阻断结算 |
| **GATE-03** | 币种与小数精度 (Currency ISO 4217) | **合法 3 位币种且精度符合标准** | 非标准币种或超出精度截断直接驳回 |
| **GATE-04** | 电子签审计链完整性 (Audit Trail) | **具备 SHA256 哈希、签署人时间戳与证据链** | 缺失直接标记签名无效，禁止进入发货/履约 |
| **GATE-05** | 状态机单向跃迁 (Transition Guard) | **严格遵循有向无环或合法有限状态机** | 非法逆向跃迁（如已退款变已发货）立即阻断 |
| **GATE-06** | 退款授权与上限 (Refund Ratio Cap) | **累计退款比例 ≤ 1.0 且大额 (≥20%) 需授权** | 超限或无授权退款强制阻断并告警 |
| **GATE-07** | 计量用量非负 (Non-negative Usage) | **用量值 quantity ≥ 0.0** | 负数用量强制拦截，防止恶意洗账抵扣 |
| **GATE-08** | Webhook 回调安全 (Webhook Security) | **具备签名哈希验证且时间戳误差 ≤ 300s** | 签名不匹配或重放包直接丢弃并记入审计 |

## 四、 角色红线与合规边界 (Non-Negotiable Boundaries)

1. **严禁未经授权超额退款**：累计退款金额禁止大于订单实付金额（退款比例 > 100%），大额退款必须具备授权 handoff；
2. **严禁跳过签署直接放行履约**：标明需签署法律效力协议（如 SLA 或保密条款）的交易，在签署人未全部签署前严禁触发履约状态；
3. **严禁非法负数价格与零元洗账**：商品单价或扣款金额严禁为负数，零元订单必须提供合法的折扣券或 100% 满减凭证；
4. **严禁篡改已结算历史账单**：已结发票与流水记录不得覆写修改，仅支持借贷冲正与反向分录调整。
