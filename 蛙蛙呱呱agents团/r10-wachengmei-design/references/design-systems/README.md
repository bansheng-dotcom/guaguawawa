# 设计与品牌规范素材（DESIGN.md）

本目录收录 31 份品牌 DESIGN.md，作为 R10 视觉设计官的可检索设计系统库。

- **上游来源**：<https://github.com/VoltAgent/awesome-design-md>
- **格式**：Google Stitch DESIGN.md（九段式纯文本设计规范：调性 / 色板 / 字体 /
  组件 / 布局 / 层次 / 反模式 / 响应式 / Agent Prompt 指南）
- **收录用途**：设计参考与令牌基线。**不是**授权素材——品牌名、Logo、字体与图像
  的商用授权需单独确认，R10 不因"库里有"就宣称可直接使用。
- **解析与门禁**：`shared/design_systems.py`；模块说明见
  [`../09-design-systems.md`](../09-design-systems.md)。
- **回归测试**：`tests/test_design_systems.py`（31/31 PASS）。
