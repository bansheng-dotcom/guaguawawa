# 设计系统与图形

> 归属：R10　消费：r08, r09　版本：v1

## 定位

设计系统构建与单图设计：令牌架构、组件规范、图形产出。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 令牌分三层：原始值/语义/组件
2. 语义层是唯一可被业务引用的层
3. 单图设计先定版式骨架，再填内容
4. 导出规范写清尺寸、倍率、色彩空间

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
