# 提示词解剖（prompt-anatomy）

> 六段详解 · 12 组 BAD/GOOD · 负向词库 · 平台规格表。版本：v1

---

## 一、六段结构（照这个填）

```markdown
【1 主体】<物体是什么> + <材质> + <颜色> + <状态/摆放>
【2 环境】<台面/背景/空间> + <有无杂物>
【3 构图】<视角角度> + <主体占画幅比例> + <位置>
【4 光线】<主光方向与软硬> + <补光> + <高光/阴影特征>
【5 材质风格】<表面质感> + <整体调性> + <对比度倾向>
【6 规格负向】<比例> + <像素> + <留白> + <负向词>
```

**填法示例（主图）**

```
【1 主体】哑光深灰金属机身半自动咖啡机，玻璃水箱，托盘上放一只空白瓷杯
【2 环境】浅灰水泥台面，背景同色渐变墙，画面内无其他道具
【3 构图】45° 俯视，主体占画幅 70%，居中略偏下
【4 光线】左前方 45° 柔光箱作主光，右侧白色反光板补光，台面有柔和长条高光
【5 材质风格】金属哑光、玻璃通透；整体冷调、对比克制、留白充足
【6 规格负向】1:1，2400×2400，上方留 1/5 空白；
  负向：无文字、无水印、无 logo、无人物、无多余道具、无畸变、无过曝
```

## 三、负向词库（按类挑，至少 3 条）

**文字类**
```
无文字, 无水印, 无 logo, 无标签, 无价格牌, 无促销贴纸
```

**质量类**
```
无模糊, 无畸变, 无过曝, 无欠曝, 无噪点, 无摩尔纹, 无 AI 塑料感, 无多余手指
```

**构图类**
```
无裁切主体, 无多余道具, 无杂乱背景, 无边框, 无拼贴
```

**风格类**
```
无卡通, 无插画风, 无过度 HDR, 无强滤镜, 无 3D 渲染感, 无霓虹光
```

> **为什么要写负向**：不写，模型会"补全"它认为该有的东西——
> 最常见的是水印、多余道具、过度反光、以及莫名其妙的手。

## 四、平台规格表

| 平台 / 位置 | 比例 | 常用尺寸 | 主体占比 | 特别要求 |
|---|---|---|---|---|
| 淘宝/天猫 主图 | 1:1 | 800×800（建议 1200+） | ≥70% | 白/浅底，无牛皮癣 |
| 京东 主图 | 1:1 | 800×800 起 | ≥70% | 白底优先 |
| 详情页分屏 | 竖版 | 宽 750，高 800–1200/段 | 视段落 | 每段一个卖点 |
| 小红书 封面 | 3:4 | 1242×1660 | 50–65% | 上方留标题位 |
| 小红书 配图 | 1:1 或 3:4 | 1080×1080 / 1242×1660 | 视内容 | 少文字 |
| 抖音 封面 | 9:16 | 1080×1920 | 40–55% | 主体在安全区内 |
| 朋友圈/信息流 | 1:1 或 16:9 | 1080×1080 / 1200×628 | 40–60% | 大留白放文案 |
| App 图标 | 1:1 | 1024×1024 | 60–70% | 内容不贴边（安全区 ≥10%） |
| 官网 Banner | 16:9 或 21:9 | 1920×1080 / 2560×1080 | 30–50% | 左侧留文案区 |

**阈值**：规格必须写进 prompt 第 6 段；**不要出图后再裁**（裁会切主体）。

## 五、四版一致性抽检（怎么判 prompt 可复现）

同一 prompt 连出 4 版，逐项打勾：

| 检查项 | 判据 | 4 版中需 ≥3 版 |
|---|---|---|
| 主体一致 | 形状/颜色/材质无明显跑偏 | ✅ |
| 构图稳定 | 主体中心位置差异 ≤10% 画幅 | ✅ |
| 光线一致 | 主光方向一致（不出现一版左光一版顶光） | ✅ |

**结论**：
- 三项都 ≥3/4 → prompt 可复现，可定稿；
- 某一项 ≤2/4 → 该段写虚了，回六段补（多数是构图或光线写太抽象）。

> **为什么是 4 版**：3 版测不出偶发，5 版成本过高。4 版是抓不稳定的最小成本。

## 六、与相邻能力的分工（别越界）

| 问题 | 归谁 |
|---|---|
| 要出几张图、每张讲哪个卖点 | `ecommerce-designer` |
| 每张图怎么描述（本卡） | `image-prompt-structure` |
| 真的把图生成出来、算成本 | `image-gen-pipeline` |
| 裁剪/压缩/加水印 | `image-ops` |
| 图好不好看 | `visual-hierarchy` |
| 颜色字体是否偏品牌 | `brand-guardian` |

**一句话记法**：**本卡只管"描述得像不像"，不管"画得好不好"。**
