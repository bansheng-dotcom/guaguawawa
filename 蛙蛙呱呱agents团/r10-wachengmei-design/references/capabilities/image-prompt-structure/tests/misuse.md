# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`），本表是**写 prompt 时的常见错法**，
> 由评审者逐条判真假。版本：v2.0.0

## 一、硬门（§5，任一不过即不得作为定稿 prompt）

| # | 错法 | 判据 | 怎么验 |
|---|---|---|---|
| MU-01 | 一张图塞 3 个以上主体 | 一图一主体（≤2 含陪衬） | 数名词 |
| MU-02 | 六段缺段 | 主体/环境/构图/光线/材质风格/规格负向全在 | 逐段对照 |
| MU-03 | 没写负向词 | ≥3 条，覆盖三类以上 | 数条目 |
| MU-04 | 规格没写进 prompt | 比例 + 像素 + 留白 | 看第 6 段 |
| MU-05 | 出图不稳定仍定稿 | 4 版 ≥3 版主体/构图/光线一致 | 连出 4 版 |
| MU-06 | 用「高级感/氛围感」当描述 | 每个形容词换成可执行描述 | 通读找虚词 |

## 二、软门（§6 自检，靠人抓）

| # | 错法 | 问题 |
|---|---|---|
| MU-07 | 主体只写名字不写材质颜色 | 模型会自选材质，多半不对 |
| MU-08 | 光线只写「高级光」 | 方向与软硬不定，四版光线会乱 |
| MU-09 | 构图只写「拍得好看」 | 角度与占比不定，主体会忽大忽小 |
| MU-10 | 靠后处理裁尺寸 | 裁会切主体 |
| MU-11 | 让模型生成图上文字 | 文字必糊，应留后处理 |
| MU-12 | 主图主体占 40% | 应 ≥70%，否则细节看不清 |
| MU-13 | 不留文字位 | 主图/封面应上方留 1/5 |
| MU-14 | 出图有畸变就反复重试 | 加负向词 + 降复杂度，不碰运气 |
| MU-15 | 把 prompt 质量当成品质量 | 好不好看归 `visual-hierarchy` |

## 三、四版抽检怎么做

1. 同一 prompt 连出 4 版（同模型、同参数）；
2. 逐项核：主体是否一致 / 构图是否稳定（主体中心差异 ≤10% 画幅）/ 光线方向是否一致；
3. ≥3 版三项都对 → 可复现，定稿；
4. ≤2 版 → 回 §3 Step 2 补六段（多数是构图或光线写太虚）。

## 四、诚实说明

本卡没有可自动断言的门禁：prompt 好不好只能靠出图结果反过来验。
**不要**为它写一个「格式检查通过」的脚本——那只能验字段齐不齐，验不了描述准不准。

> **纪律**：prompt 的目标不是"写得漂亮"，是"同一段话每次都能出同一类图"。
