# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`），本表是**挑图时的常见错法**，
> 由评审者逐条判真假。版本：v2.0.0

## 一、硬门（§5，任一不过即不得定主选）

| # | 错法 | 判据 | 怎么验 |
|---|---|---|---|
| MU-01 | 只有 1 版就"选" | 候选 ≥2 版（建议 4 版） | 数版数 |
| MU-02 | 硬门没逐版核就排序 | 五条硬门逐版过，淘汰有原因 | 要核对表 |
| MU-03 | 4 版都违规还硬挑 | 过硬门 ≥2 版，否则退回上游 | 数通过数 |
| MU-04 | 结构分不足就定主选 | 加权 ≥72/100 | 复算总分 |
| MU-05 | 意图分 1 还选 | 3 秒盲测需 ≥3 | 做盲测 |
| MU-06 | 无落选原因记录 | 逐条分类（六类之一） | 看原因表 |

## 二、软门（§6 自检，靠人抓）

| # | 错法 | 问题 |
|---|---|---|
| MU-07 | 只看好看不看合规 | 挑中带水印的，上架被下架 |
| MU-08 | 眼看规格不核 | 尺寸/比例错，白出 |
| MU-09 | 结构分高就选不看卖点 | 好图 ≠ 对的图 |
| MU-10 | 删掉落选图 | 失去回灌 prompt 的依据 |
| MU-11 | 落选原因写「感觉不对」 | 无法回灌，下次还错 |
| MU-12 | 不留备选 | 客户改口要重出 4 版 |
| MU-13 | 单人拍板 | 双评主选一致率应 ≥80% |
| MU-14 | 同批反复重出碰运气 | 先回灌 prompt 再出 |
| MU-15 | 用「客户喜欢」当唯一判据 | 可以依客户，但要记录与判据的冲突 |

## 三、反向判据（最容易忽略的一条）

**如果 4 版里不足 2 版过硬门 → 这不是挑图问题。**

此时正确动作是退回上游：
- 负向残留多 → 回 `image-prompt-structure` 补负向词；
- 占比/构图乱 → 回 `image-prompt-structure` 补构图与规格段；
- 都合规但都不好 → 回 `image-gen-pipeline` 提版数或换种子。

在 4 张违规图里硬挑一张，是最常见的自欺。

## 四、双评怎么做

1. 同一批候选，2 人独立按三段筛（不交流）；
2. 比主选是否同一张；一致率 = 同批同选 / 总批数；
3. <80% → 先修结构分锚定（多半是"层级"两人理解不同），再重评。

## 五、诚实说明

本卡没有可自动断言的门禁：选图是取舍，不是合规。
可机器做的只有两件——规格（`imgops info`）与品牌色（`brandcheck check`），其余靠人。

> **纪律**：挑图的目标不是"挑一张最好的"，是"**下次不用再挑**"。
> 落选原因回灌 prompt，才是这张卡的价值所在。
