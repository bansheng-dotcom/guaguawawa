# 出图候选筛选（Image Candidate Selection）

> 一句话定位：**出了四版挑一张，如果说不清为什么，那下次还得再挑一遍。**
>
> 挑图最容易犯的两个错方向相反：
> —— **只看好看**：挑中一版有水印残留的，上架后被下架；
> —— **只看合规**：挑中一版规规矩矩但卖点糊掉的，转化归零。
>
> 这张卡把它们拆成**顺序不可交换的三段**：先硬门、再结构、最后意图。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**
- 「四版挑哪张」「这张还是那张」
- 「为什么每次都要重出好几遍」
- 「客户说这张不行，但说不上为什么」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 写/改提示词 | `r10` 的 `image-prompt-structure` | 那是描述层 |
| 生成更多版本 | `r10` 的 `image-gen-pipeline` | 那是执行层 |
| 单张图好不好看（不比较） | `r10` 的 `visual-hierarchy` | 那是十三条判据 |
| 裁剪/压缩/加水印 | `r10` 的 `image-ops` | 那是后处理 |
| 颜色是否偏品牌 | `r10` 的 `brand-guardian` | 那是令牌比对 |

**最小可开工输入**：**≥2 版候选图（建议 4 版）+ 这张图要说的一个卖点**。

## §2 前置输入与最省追问

| 输入 | 是否必需 | 缺失时怎么办 |
|---|---|---|
| 候选图（≥2 版，建议 4 版） | 必需 | 只有 1 版就不是"选" |
| 该图要传达的一个卖点 | 必需 | 无卖点只能判好看，判不了该不该选 |
| 目标平台与规格 | 必需 | 缺则无法过第一道硬门 |
| 品牌令牌（DESIGN.md） | 建议 | 缺则跳过品牌色核验并标注 |
| 已有的选图记录 | 建议 | 缺则本次建立基线 |

**追问纪律**：最多一轮，只问**这张图要说哪个卖点、发在哪**。

---

## §3 执行流水线（Workflow）

### Step 1 · 硬门（淘汰制，一票否决，不可协商）
逐版过五条，**任一条不过即淘汰**，不进入排序：

| # | 硬门 | 判据 |
|---|---|---|
| 1 | **规格对** | 比例与像素符合平台要求（用工具核，不靠眼看） |
| 2 | **无负向残留** | 无文字/水印/logo/可疑标签；无畸变与多余手指 |
| 3 | **安全区** | 主体未被平台裁切区压到；文字位空着 |
| 4 | **品牌色** | 关键色在 `DESIGN.md` 令牌内（或已标注偏离并获批） |
| 5 | **主体完整** | 主体未被画幅切边，关键细节（材质/接口/logo 位置）可见 |

**阈值**：**五条全过**才进 Step 2。**不设"差一点也行"**。

> **最关键的反向判据**：如果 4 版里 **<2 版**过硬门 →
> 这不是挑图问题，是 prompt 或生成参数的问题。**回 `image-prompt-structure`，不要在这里硬挑。**

### Step 2 · 结构分（排序用，按 visual-hierarchy 六条）
对通过硬门的候选打 1–5 分，**加权求和**：

| 维度 | 权重 | 锚定（5 分） | 锚定（3 分） |
|---|---|---|---|
| 主体占比 | 25 | 符合平台要求（主图 ≥70%） | 略小，细节略糊 |
| 视觉层级 | 25 | 一眼看到主体，陪衬不抢 | 需要找一下 |
| 对比与可读性 | 20 | 主体与背景分离清楚 | 边缘略黏 |
| 留白与文字位 | 15 | 留白可用，能放标题 | 偏挤 |
| 光影质量 | 15 | 有体积感、无脏阴影 | 平光但不脏 |

**阈值**：结构分 **≥18/25**（即 3.6 平均）才可作为主选；否则继续出图。

### Step 3 · 意图分（这张图有没有说清那个卖点）
**判据**：把图给一个不知道背景的人看 3 秒，问他"这张图在强调什么"。

| 结果 | 意图分 |
|---|---|
| 说出与你的卖点一致 | 5 |
| 说出相关但不同 | 3 |
| 说不出 / 说成别的 | 1 |

**阈值**：意图分 **≥3** 才可作为主选。**硬门和结构分都高但意图分 1 → 不能选**——
那是"一张好图，但不是你要的那张图"。

### Step 4 · 排序并定主选/备选（必须留记录）
```
主选：硬门全过 + 结构分最高 + 意图分 ≥3
备选：硬门全过 + 结构分次高（用于 A/B 或客户改口）
落选：逐条记录淘汰原因（哪条硬门 / 哪个维度低）
```

**阈值**：**主选 1 张 + 备选 1 张**，落选版**不删**（留档用于回灌 prompt）。

### Step 5 · 落选原因回灌（这一步决定下次会不会再错）
把落选原因分类，分别回灌：

| 落选原因类型 | 回灌给谁 | 具体动作 |
|---|---|---|
| 负向残留（文字/水印/畸变） | `image-prompt-structure` | 补负向词 |
| 构图不稳（四版差异大） | `image-prompt-structure` | 补构图段的角度与占比 |
| 主体占比不对 | `image-prompt-structure` | 规格段写清占比 |
| 卖点没表达 | `ecommerce-designer` | 检查这张图承担的卖点是否本身不对 |
| 品牌色偏 | `brand-guardian` + prompt 段 5 | 写色值或调整令牌 |
| 全部不错但都不够好 | `image-gen-pipeline` | 提高版数或换模型/种子 |

**阈值**：**每条落选原因都必须归到上表某一类**，归不进去说明判据缺失，要补本卡。

### Step 6 · 双评抽检（验证筛选可复现）
同一批候选给另一个人按同样三段独立筛，比较主选是否一致。

**阈值**：主选一致率 **≥80%**（5 批里 ≥4 批选同一张）；<80% → 结构分锚定不清晰，先修锚定（见 `rubric-calibration`）。

## §5 质量门（一票否决）

1. 候选 **≥2 版**（建议 4 版），且生成参数记录在案；
2. **硬门五条逐版核对**，淘汰版有明确原因；
3. 通过硬门的候选 **≥2 版**（若 <2 → 判定为 prompt/参数问题，退回上游）；
4. 结构分 **≥18/25** 且意图分 **≥3** 才可为主选；
5. **主选 1 + 备选 1**，落选原因**逐条分类**；
6. 双评主选一致率 **≥80%**。

> 本卡无自动门禁。可配合 `python agent.py imgops info`（规格）与
> `python agent.py brandcheck check`（品牌色）做部分机器核对（间接）。

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 只看好不好看 | 先硬门，再结构，最后意图（顺序不可换） |
| EX-02 | 挑中带水印/文字的版 | 负向残留属硬门，一票否决 |
| EX-03 | 眼看规格不核 | 用 `imgops info` 核像素与比例 |
| EX-04 | 4 版都不过硬门还硬挑 | 判为 prompt 问题，退回上游 |
| EX-05 | 结构分高就选，不看卖点 | 意图分 <3 不能选（好图≠对的图） |
| EX-06 | 只留主选，删掉落选 | 落选必留档，用于回灌 prompt |
| EX-07 | 落选原因写「感觉不对」 | 归到六类之一（负向/构图/占比/卖点/品牌/版数） |
| EX-08 | 不找备选 | 客户改口时又要重出 |
| EX-09 | 自己一人说了算 | 双评主选一致率 ≥80% |
| EX-10 | 同一批反复重出 | 先回灌 prompt，再出图；不靠运气 |
| EX-11 | 主体被裁边也算过 | 硬门第 5 条：主体完整，细节可见 |
| EX-12 | 用「客户喜欢」当判据 | 客户偏好可以定，但要记录并说明与判据的冲突 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 只有 1 版候选 | 只做硬门核对，标注「未做比较」 |
| 无法出多版（成本限制） | 至少 2 版；并记录「版数受限，主选可能不是最优」 |
| 无 DESIGN.md | 跳过品牌色硬门，标注「未核品牌」 |
| 盲测找不到人 | 间隔 30 分钟自测，标注「自测盲测，可信度低」 |
| 客户已指定某版 | 仍做硬门核对；若不过，明确告知风险并留书面记录 |
| 候选都不过硬门 | 不出主选；出「prompt 修订建议」退回上游 |
| 涉真实人物/商标 | 硬门加一条：无未授权人脸与商标 |

**明确不做**
- 不写/改提示词、不做生成、不做后处理、不替客户定审美偏好。

## §10 变更记录

- **v2.0.0（2026-11-11）**：新增范式卡，补齐能力链上「出图 → 后处理」之间的断点。
  此前 `visual-hierarchy` 能判**单张**好不好，但没有「**多版怎么比、怎么定、怎么回灌**」的方法，
  导致每次挑图都靠感觉、且落选信息全部丢失。
  核心贡献：**三段顺序不可交换**（硬门一票否决 → 结构分加权 → 意图盲测）
  + **反向判据**（过硬门 <2 版 → 退回 prompt 而非硬挑）
  + **落选六分类回灌**（每条原因必须归到"该改哪张卡"）。
  含 §1–§10、`references/selection-rubric.md`、`tests/misuse.md`。
  **保留 `entry: null`**：筛选取舍靠双评一致率验证，无法自动断言。
