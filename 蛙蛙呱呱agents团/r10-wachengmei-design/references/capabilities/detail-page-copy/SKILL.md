# 详情页分屏文案（detail-page-copy）

> **详情页最常见的病是「每屏都在说好，但没人说清它到底是什么」。** 首屏 3 秒说不清，后面再美也没人看。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「详情页怎么写」
- 「首屏写什么」
- 「卖点怎么排」
- 「详情页跳出高」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 主图与视觉 | r10 的 `ecommerce-designer` | 那是视觉 |
| 投放 | r12 的 `paid-execution` | 那是买量 |
| 品牌语调 | r11 的 `tone-axes` | 那是口吻 |

**最小可开工输入**：**一个产品 + 一个核心购买理由 + 三到五个卖点**。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| 产品与规格参数 | 必需 |
| 目标客户与使用场景 | 必需 |
| 核心购买理由（一个） | 必需 |
| 常见异议（≥3 条） | 必需 |
| 竞品对比信息 | 建议 |

**追问纪律**：最多一轮，只问**客户不买的三个理由是什么**。异议定不下来，异议屏写不出来。

## §3 执行流水线（Workflow）

### Step 1 · 首屏 3 秒（是什么 + 给谁 + 为什么值）
首屏只放三件：**是什么**（一张能看懂的主图）、**给谁**（一句人群）、**为什么值**（一个核心理由）。

**判据**：首屏三者齐备，且不含参数表

### Step 2 · 每屏一个卖点（标题即结论）
每屏标题是结论句（「续航 20 小时，露营两晚不用充」），不是名词（「关于续航」）。

**判据**：每屏标题为结论句，且一屏一卖点

### Step 3 · 图文严格对应（图讲什么字讲什么）
图展示 A，文字必须讲 A。图讲外观、文字讲材质＝错位。

**判据**：每屏图与文指同一事物

### Step 4 · 异议屏（正面回应不回避）
把 ≥3 条常见异议逐条回应：承认顾虑 → 给证据 → 给保障。

**判据**：异议屏 ≥3 条，且有证据与保障

### Step 5 · 参数屏（可扫读，不做堆砌）
参数用表格 + 关键项加粗；只列影响购买决策的，不做全参数搬运。

**判据**：参数表可扫读，关键项 ≤5 个

### Step 6 · 末屏行动（明确下一步）
末屏给：行动（买/加购/咨询）+ 保障（退换/质保）+ 紧急度（若有真实理由）。

**判据**：末屏含行动、保障、真实紧急度


## §4 交付物清单

| # | 交付物 | 载体 |
|---|---|---|
| 1 | 分屏脚本（每屏：标题/正文/图说明） | `.md` |
| 2 | 异议回应表 | `.md` |
| 3 | 参数表（关键项） | `.md` |

## §5 质量门（一票否决）

1. 首屏 3 秒说清「是什么/给谁/为什么值」，不含参数表；
2. 每屏一个卖点，标题为结论句；
3. 图文严格对应（图与文指同一事物）；
4. 异议屏 ≥3 条，每条含承认+证据+保障；
5. 参数屏可扫读，关键项 ≤5 个；
6. 末屏含行动 + 保障 + 真实紧急度；

> 本卡无自动门禁。可配合 `uiux screen` 与 `harness edit`（禁词）做间接校验。

## §6 交付前自检清单

- [ ] 首屏我能在 3 秒说清是什么、给谁、为什么值
- [ ] 首屏没有塞参数表
- [ ] 每屏只讲一个卖点，标题是结论句
- [ ] 每屏的图和文字讲的是同一件事
- [ ] 我写了 ≥3 条异议，每条都给了证据和保障
- [ ] 参数只列影响决策的，能扫读
- [ ] 末屏有明确行动和保障
- [ ] 我的「紧急度」是真有理由的，不是编的

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 首屏放参数 | 首屏只说是什么/给谁/为什么值 |
| EX-02 | 每屏讲多个卖点 | 一屏一卖点 |
| EX-03 | 标题写名词 | 标题写结论句 |
| EX-04 | 图文错位 | 图讲什么字讲什么 |
| EX-05 | 回避异议 | 正面回应 + 证据 + 保障 |
| EX-06 | 参数全搬 | 只列影响决策的关键项 |
| EX-07 | 末屏只说「点击购买」 | 给保障与真实理由 |
| EX-08 | 用「假限时」 | 紧急度必须有真实依据 |
| EX-09 | 全篇形容词 | 每处形容词配数字 |
| EX-10 | 不做人群区分 | 首屏点明给谁 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 缺竞品信息 | 只讲自身，跳过对比屏，标注「未做对比」 |
| 缺异议数据 | 用客服工单高频问题替代，标注「非调研数据」 |
| 参数不全 | 标注「参数待补」，不编造 |
| 多 SKU | 每 SKU 一版首屏，其余共用 |
| 平台限制字数 | 保结论句，砍修饰 |
| 无场景图 | 用文字描述场景，标注「待补图」 |

**明确不做**：不做主图与视觉、不做投放、不做品牌语调、不承诺转化率。
