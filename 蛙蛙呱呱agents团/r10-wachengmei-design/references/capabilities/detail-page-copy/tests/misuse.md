# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`），本表为人工评审清单。版本：v2.0.0

## 一、硬门（§5，任一不过即不得交付）

| # | 判据 |
|---|---|
| MU-01 | 首屏 3 秒说清「是什么/给谁/为什么值」，不含参数表 |
| MU-02 | 每屏一个卖点，标题为结论句 |
| MU-03 | 图文严格对应（图与文指同一事物） |
| MU-04 | 异议屏 ≥3 条，每条含承认+证据+保障 |
| MU-05 | 参数屏可扫读，关键项 ≤5 个 |
| MU-06 | 末屏含行动 + 保障 + 真实紧急度 |

## 二、软门（§6 自检）

| # | 常见错法 |
|---|---|
| MU-06 | 首屏我能在 3 秒说清是什么、给谁、为什么值 |
| MU-07 | 首屏没有塞参数表 |
| MU-08 | 每屏只讲一个卖点，标题是结论句 |
| MU-09 | 每屏的图和文字讲的是同一件事 |
| MU-10 | 我写了 ≥3 条异议，每条都给了证据和保障 |
| MU-11 | 参数只列影响决策的，能扫读 |
| MU-12 | 末屏有明确行动和保障 |
| MU-13 | 我的「紧急度」是真有理由的，不是编的 |

## 三、诚实说明

本卡没有可自动断言的门禁：文案说服力只能由转化与读者测试验证。

> **纪律**：详情页的目标不是「把好话说完」，是「**让不买的人给出一个不买的理由，然后我们回应它**」。
