# 广告法合规与极限词处置（ad-law-compliance）

> 被 §3 Step 7 与 §5 质量门按需引用。**这是本技能包的"一票否决"依据。**
> 本文只给判定方法与替换规则，**不替代法务意见**；具体条文以《广告法》《反不正当竞争法》
> 及平台规则当期版本为准。版本：v2.0.0（项目自建，v1）

---

## 一、九大类红线（命中即必须处理）

| # | 类别 | 典型表述 | 处置 |
|---|---|---|---|
| L1 | 绝对化用语 | 国家级、最高级、最佳、第一、顶级、极致、唯一、首个 | 删或改量化 |
| L2 | 虚假功效 | 治疗、治愈、根治、防癌、降血压、消炎 | 删除，不得替换 |
| L3 | 保健功能越界 | 增强免疫力、改善睡眠（普通食品不得宣称） | 删除；保健食品须有批准文号 |
| L4 | 虚假承诺 | 永久、终身保修、100% 有效、无效退款（无依据） | 改具体条件与时限 |
| L5 | 模糊时限/价格 | 最后一波、限时秒杀（无具体时间）、史上最低 | 改为具体截止时间与真实价格 |
| L6 | 未授权背书 | 驰名商标、国家免检、XX 认证（无证书号） | 删除或补证书编号 |
| L7 | 贬低对手 | 比 XX 品牌好、吊打同行、唯一不含 | 改为自身参数陈述 |
| L8 | 站外导流 | 微信/电话/二维码/外链 | 删除 |
| L9 | 特殊类目 | 医疗/药品/医疗器械/教育/金融/酒类/母婴的越界宣称 | 按类目专项资质要求核对 |

## 二、三档替换法（命中后按序尝试）

| 档 | 做法 | 适用 | 示例 |
|---|---|---|---|
| **A 删** | 直接删除该表述，主张靠画面承担 | 无法量化的主观绝对化 | "全网最好用的保温杯" → "保温杯" |
| **B 改量化** | 换成可核验的具体数字/区间/条件 | 有实测或参数支撑 | "最保温" → "95℃ 热水 6 小时后 ≥ 68℃" |
| **C 改主观感受** | 从"客观最优"改为"用户主观体验" | 无客观依据但有真实反馈 | "最舒适" → "多数用户反馈手感舒适（样本 n=…）" |

> **铁律**：L2/L3 两类**只允许 A 删**，不得用 B/C 变通——功效宣称没有"改写合规"的路径。

## 三、判定流程（每屏文案走一遍）

```
1. 逐句切分（按句号/分号/换行），一句一判
2. 对每句查 L1–L9 关键词与语义
3. 命中 → 记录：句号 / 类别 / 命中词 / 三档替换建议
4. 替换后重扫，直到本屏命中 = 0
5. 全篇命中 = 0 才允许进入 §5 质量门
```

**扫描命令**：`python scripts/verify_delivery.py --file 交付物.md --strict`
（脚本内置常用极限词表；表外命中由模型按本文语义判断补充）

## 四、高频踩坑与正确写法

| 踩坑 | 为什么违规 | 正确写法 |
|---|---|---|
| "行业第一" | L1 绝对化，无法自证 | "2025 年 XX 品类销量第 N（数据来源：XX，统计期：…）" |
| "国家级工艺" | L1 + L6 | "采用 XX 工艺（专利号 ZL…）" |
| "纯天然，无任何添加" | L4 绝对化 + 可能虚假 | "配料表仅含 A、B、C（见包装）" |
| "3 天见效" | L2 功效 + L5 时限 | "连续使用 28 天后，N% 受试者反馈…（测试机构：…，n=…）" |
| "限时秒杀，卖完为止" | L5 模糊时限 | "活动至 2026-11-20 23:59，售完即止" |
| "比某品牌更静音" | L7 贬低对手 | "运行噪音 ≤ 32dB（第三方检测报告编号：…）" |
| "扫码加微信领券" | L8 站外导流 | "在店铺首页领券" |
| 详情页写"改善睡眠"（普通食品） | L3 保健功能越界 | 删除，改述口感/成分/场景 |

## 五、AIGC 标识要求

AI 生成的图片与文案，交付时必须同时做到：

1. **显式标识**：画面可见位置或文案末尾标注"本图由 AI 生成"（平台有专门标识位的按平台位放置）；
2. **隐式元数据**：导出文件保留生成参数/服务商元数据，不主动清除；
3. **自检**：主图位使用 AI 图时，若平台要求真实拍摄，必须改用实拍并在校验报告注明原因。

> 缺任一项 → §5 质量门第 7 条不通过。
