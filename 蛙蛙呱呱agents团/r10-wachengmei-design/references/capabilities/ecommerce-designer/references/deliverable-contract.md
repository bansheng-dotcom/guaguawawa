# 交付契约（deliverable-contract）

> 本文件定义「电商视觉设计」技能包七件套交付物的字段、命名与落盘规则。
> **只被 §4 与 §8 按需引用，不常驻上下文。**
> 版本：v2.0.0（项目自建，v1）

---

## 一、命名规范

```
{平台}_{类目}_{版位}_{位次}_{版本}
```

| 段 | 取值 | 示例 |
|---|---|---|
| 平台 | `tb` 淘宝 / `tm` 天猫 / `jd` 京东 / `pdd` 拼多多 / `1688` / `dy` 抖音 / `ks` 快手 / `xhs` 小红书 / `sph` 视频号 / `amz` 亚马逊 / `tks` TikTok Shop | `tm` |
| 类目 | 类目英文短码，自定但**全项目统一** | `beauty` |
| 版位 | `main` 主图 / `detail` 详情页 / `white` 白底图 / `scene` 场景图 / `poster` 活动图 | `main` |
| 位次 | `01`..`05` / `n1`..`nN`；详情页用 `p01`..`p12` | `01` |
| 版本 | `v1` `v2` …（同一次迭代全文件同版本号） | `v1` |

- 源文件与导出图**同名同版本号**，禁止 `final` / `final2` / `改` 这类命名。
- 交付目录结构：

```
交付物/
├── 00_需求简报.md
├── 01_视觉主张表.md
├── 02_主图矩阵方案.md
├── 03_详情页分屏脚本.md
├── 04_设计系统令牌表.md
├── 05_AI提示词包.md
├── 06_校验报告.md
└── 素材/
    ├── tm_beauty_main_01_v1.png
    └── ...
```

## 二、七件套逐项字段

### 1. 需求简报 `00_需求简报.md`

必含：商品名 / 类目 / 目标平台与版位 / 核心卖点（≥1，带证据）/ 目标人群 / 竞品参考 / **关键假设清单**。

> 关键假设清单是硬要求：每条必须写成
> `假设 N：<内容>｜若此假设不成立，需改 Step M。`
> 缺少"若…不成立"从句的假设视为不合格——它无法被用户一句话驳回。

### 2. 视觉主张表 `01_视觉主张表.md`

表头固定五列 + 一列排序：

| 排序 | 主张句 | 证据（可审核） | 画面载体 | 人群 | 版位 |
|---|---|---|---|---|---|
| 1 | | | | | 首图 |

三条通过条件（每条都能判真假）：
1. **3 秒测试**：句中含 1 个词 + 1 个数字 + 1 个动作；
2. **证据测试**：证据能指向参数/检测/资质/实测，而不是"品质好"；
3. **差异测试**：与竞品首图主诉求不撞车；撞车必须换角度并在表下注明。

### 3. 主图矩阵 `02_主图矩阵方案.md`

每张图固定**十项**，缺一项即不合格：

```
版位 / 转化职责 / 独特点击理由 / 文案（含字数上限）/ 版式骨架 /
视线动线 / 素材需求 / 尺寸规格 / 禁用项 / 与相邻位次不重叠声明
```

位次职责表（零重叠是硬门禁）：

| 位次 | 职责 | 承载问题 |
|---|---|---|
| 01 识别位 | 0.8 秒定生死 | 这是什么？ |
| 02 信任位 | 降低怀疑 | 凭什么信你？ |
| 03 利益位 | 给出购买理由 | 我能得到什么？ |
| 04 对比位 | 消除替代选择 | 为什么不买别的？ |
| 05 场景位 | 人群代入 | 什么时候用？ |
| n 附加位 | 长图/竖图/白底图 | 平台要求 |

### 4. 详情页分屏 `03_详情页分屏脚本.md`

每屏一行：`屏号 / 模块 ID / 本屏目标 / 文案要点 / 版式骨架 / 高宽(px) / 情绪标记`。
必含四类模块：核心主张屏 / 对比屏（含劣势项）/ 适用与不适用清单 / FAQ 三连。
情绪曲线断点必须显式标注（见 `references/detail-page-modules.md`）。

### 5. 设计系统令牌表 `04_设计系统令牌表.md`

四件齐全，禁止"待定"：

| 件 | 必须给 | 判据 |
|---|---|---|
| 网格 | 安全区、基准线、留白率区间、间距档位 | 间距只用 8/16/24/40/64 |
| 色彩 | 主/辅/点缀/中性四档 + 十六进制 | 正文对比度 ≥ 4.5:1 |
| 字体 | 五级字号 + 家族 + 授权状态 | 家族 ≤ 2、主色 ≤ 3、移动正文 ≥ 24px |
| 材质光影 | 投影方向、光向、透视校验 | 全套一致 |

### 6. AI 提示词包 `05_AI提示词包.md`

每条七段：`主体 · 材质 · 光影 · 镜头 · 背景 · 风格 · 约束（含负面词）`。
每段必须实际填写；缺段用"不适用：<理由>"，不得留空。
必须标注：适用平台 / 是否允许 AI 生成 / AIGC 标识方式。

### 7. 校验报告 `06_校验报告.md`

直接粘贴 `scripts/verify_delivery.py` 的输出，并附三样：
- 极限词命中清单（含替换方案三档：删 / 改量化 / 改主观感受）；
- 规格校验逐项结果（像素/比例/体积/格式/最小字号）；
- 修改响应表（微调 / 结构 / 重做 三级，每级写"不动什么 + 影响哪些版位"）。

## 三、迭代响应表的写法

| 级别 | 含义 | 不动什么 | 工期口径 |
|---|---|---|---|
| 微调 | 文案 / 色值 / 位置 | 主张、版式骨架 | 同轮内改 |
| 结构 | 版式 / 屏序调整 | 视觉主张 | 需重排，影响相邻位次 |
| 重做 | 主张变更 | 无 | 回到 §3 Step 2 |

> 每次迭代版本号 +1，**七个文件同步改版本号**，避免混版交付。
