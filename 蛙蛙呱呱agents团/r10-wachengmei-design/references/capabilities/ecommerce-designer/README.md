# 电商视觉设计

> 归属：R10　消费：r14, r12　版本：v1

## 定位

电商主图/详情页的视觉结构：卖点优先级、平台规格、A/B 素材。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 首图只放一个主卖点 + 一个信任元素
2. 详情页按「痛点→方案→证据→参数→服务」排
3. 所有规格按平台最新要求，标注适用平台
4. 素材成套交付：主图/细节/场景/对比，便于 A/B

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
