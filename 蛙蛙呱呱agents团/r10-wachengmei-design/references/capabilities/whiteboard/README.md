# 可编辑白板/架构图

> 归属：R10　消费：r07, r08, r02　版本：v1

## 定位

用白板表达信息架构与关系：节点、边、分组、泳道。

## 怎么用

- 规范形式内化：按下面步骤执行，产物走角色 harness 验收。

## 执行步骤

1. 一张图只回答一个结构问题
2. 节点命名用名词，边用动词
3. 分组不超过两层，跨组关系单独标
4. 导出保留可编辑源（结构 JSON）

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
