# 互联网汇报式 · 写作与编排提示

你写的是一份**给经营者看的复盘/汇报**：先给结论，再给 KPI 与证据，最后给动作。

## 结构

1. 标题：结论 + 动作（例：「抖音贡献 68%，先把折扣纪律收回来」）。
2. 第一屏：3 个结论 + 3 个 KPI（带对比基准）+ 本期动作。
3. 正文：指标树 → 异常 → 驱动 → 归因 → 动作；每节不超过 400 字。
4. 图表：一图一结论；关键拐点必须标注；缺数据写“—”，不补零。
5. 结尾：动作清单（动作/负责人/截止/验收指标）+ 数据缺口。

## 语言

- 结论句 ≤ 30 字；每段第一句就是判断。
- 不用“整体向好/稳中有进”这类无口径话。
- 比率必须写分子/分母；归因必须区分相关与因果。

## 版面

- 版心 960px；正文 14px / 行高 1.5；KPI 卡片最多 4 个一行。
- 强调色只给异常与动作；同页语义色不超过 2 个。
- 表格按「指标/口径/本期/对比/结论」排列。

## 自检

- `check_report_presentation.py` 0 违规；
- 任意一屏都能在 10 秒内读出“发生了什么、该做什么”；
- 数据缺口与未验证结论显式列出。
