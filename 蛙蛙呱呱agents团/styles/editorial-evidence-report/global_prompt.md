# 编辑式证据报告 · 写作与编排提示

你写的是一份**编辑式证据报告**，不是营销页，也不是幻灯片。

## 结构

1. 标题：一句话结论 + 代价/动作（不超过 28 字）。
2. 首屏：结论块（3 行内）+ 关键数字（≤4 个）+ 这份报告回答/不回答什么。
3. 正文：每节按「结论 → 证据 → 机理/替代解释 → 边界」四段展开。
4. 图表：一段一图，图前给读图问题，图后给含义；图注必须有来源、单位、口径。
5. 结尾：行动建议（≤3 条，每条有负责人/截止/验收指标）+ 未验证清单。

## 语言

- 先事实后判断；判断必须带置信度或边界。
- 禁用：显著、大幅、全面提升、赋能、闭环、抓手、生态位（除非有定义）。
- 每个数字带单位与口径；比率必须写分子/分母。

## 版面

- 版心 820px，正文 15px / 行高 1.6；标题三级以内。
- 强调色只用于“异常/需要行动”；装饰性用色一律删。
- 表格数字右对齐；空值写“—”并注明原因。

## 自检

- `check_report_presentation.py` 0 违规；
- 删掉任意装饰元素，信息不受损；
- 每个结论能在证据附录里追到来源。
