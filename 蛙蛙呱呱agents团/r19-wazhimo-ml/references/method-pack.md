# R19 蛙智模 · 机器学习 · 方法包（Method Pack v1）

## 1. 决策问题

- 典型决策：这个模型能不能发、怎么评估。
- 决策者：算法负责人 + 业务；成功标准：离线/在线指标达标且可监控。
- 非目标：不做无评测集的发布、不做数据泄漏的指标。

## 2. 问题树（MECE）

| 分支 | 要回答 | 假设 | 数据 | 方法 |
|---|---|---|---|---|
| 数据 | 训练/评测是否代表真实分布 | 无泄漏、可复现 | 数据卡 | 数据审计 |
| 指标 | 主指标是否对齐业务 | 指标可解释 | 评测集 | 离线 + 在线指标 |
| 回归 | 新模型是否退化 | 旧能力不退化 | 回归集 | 新旧对比 |
| 监控 | 上线后怎么发现漂移 | 漂移可告警 | 监控 | 漂移检测 + 模型卡 |

**critical branch**：`数据`——资源优先给它。

## 3. 假设与证伪

- H1：新模型在主指标上显著优于基线（含置信区间）。
- H2：旧能力回归集不退化。
- 竞争解释（至少 2 个）：提升来自模型，还是数据泄漏/评测集污染？；线上下降是模型，还是流量变化？
- 每条假设必须有**杀死标准**：指标 + 阈值 + 观察窗口。

## 4. 证据分级

| 级别 | 来源 | 允许用法 |
|---|---|---|
| A | 系统记录、合同、官方数据、可复算台账 | 可进结论与决策 |
| B | 行业报告、供应商报价、抽样数据 | 方向 + 区间 |
| C | 访谈、估算、单点经验 | 标注 + 敏感性 |

**规则**：每个结论挂来源；同名不同口径单列；缺什么、影响什么、怎么补，必须写清；C 级超过 3 条时结论降级为「条件成立」。

## 5. 方法与陷阱

- 评测集：输入 + 期望输出 + 评分器，先定后训。
- 回归对比：新旧模型在绿集/红集上的差异。
- 模型卡：数据、指标、限制、监控。
**陷阱清单**：
- 离线即上线
- 数据泄漏
- 只报均值不报区间
- 无回滚
模型结论必须给「回归结果 + 回滚方案」，否则不发布。

## 6. 输出契约

```
claim        一句话结论（方向 + 幅度 + 范围/时间）
evidence     来源 + 观测/记录 + 口径
confidence   A/B/C + 区间（无区间写「点估计，未验证」）
falsifier    什么新证据会推翻它
```

缺任一项 → 不得进首页；建议缺负责人/阈值 → 行动性不通过。
