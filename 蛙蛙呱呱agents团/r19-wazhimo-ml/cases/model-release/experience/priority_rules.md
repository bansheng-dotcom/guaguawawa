# model-release · 取舍与优先级规则

## 判定顺序（先到先裁）

1. **模型卡五要素齐全**：用途/限制/风险分层/许可/已知偏差，任一为空 → BLOCK。
2. **限制不许留空**：模型卡的核心是写清「不能用来干什么」，留空零容忍。
3. **风险分层与许可走白名单**：不在 {low,medium,high} / {proprietary,open_source,
   research_only} 内 → BLOCK。
4. **资产必须可定位**：path 为空 → BLOCK。
5. **资产必须可溯源**：run_id 为空 → BLOCK，无溯源的资产不予接收。
6. **资产类型合法**：不在白名单 → BLOCK。

## 边界

- R19 只产出模型卡与资产证据工件；**模型分发、打包、部署交 R09**。
- 风险与许可的法律效力判定交 R03 AI 治理，R19 只做登记与白名单校验。
- 模型卡是对下游的说明书，不是营销页——效率、效果之类的营销措辞不算数。
