# 采购总拥有成本

> 归属：R15　消费：r14, r03　版本：v1

## 定位

多报价 landed cost 对比 + 生命周期 TCO。

## 怎么用

- 命令：`python agent.py tco compare / lifecycle`
- 确定性技能：规则与门禁已写进代码，直接跑即可。

## 执行步骤

1. landed cost 含货值/起运/主运/保险/关税/不可抵扣税/报关/到港/杂费
2. 用可用数量（扣不良）计算单位成本
3. 资金占用按账期折算进 effective unit cost
4. 仅货值+运费不叫 TCO，至少 3 类成本

## 产出与验收

- 依据可追溯：结论能指回证据或标注为判断
- 产物可复算：数字/口径可被他人重算
- 边界写清：空/错/取消/重试至少覆盖一项

## 常见错误

- 结论先于证据：先有观点再找材料
- 把假设当事实：未验证的口径写成确定结论
