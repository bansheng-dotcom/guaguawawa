# 采购总拥有成本（TCO Analysis）

> 一句话定位：**这个技能存在的意义，是防止「单价低 5% 就下单」，结果运费用汇率吃掉 20%**。
> 比价最贵的失败不是算错，而是**口径不一致**：
> 一家报 CNY 一家报 USD、一家报含税一家报不含税、
> 一家 MOQ 3000 一家 5000、关税率一个 0% 一个 12%。
> 这些不折算，单价根本不可比。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**
- 「这两家哪家便宜」「帮我比个价」
- 「TCO 怎么算」「为什么这家看着便宜其实更贵」
- 「这个报价划不划算」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 采购单/收货单校验 | 本角色的 `po-validate` | 那是单据门禁 |
| 供应商准入与合规 | `r03` + 外部 | 那是合规 |
| 付款与资金安排 | `r03` 的 `cash-runway` | 那是现金流 |
| 合同条款谈判 | 创始人 | 本包不出法律意见 |

**最小可开工输入**：**2 家以上报价（单价 + 数量 + 币种）**。

---

## §2 前置输入与最省追问

| 输入 | 是否必需 | 缺失时怎么办 |
|---|---|---|
| `quotes[]`（≥1，建议 ≥2） | 必需 | 无报价无法比 |
| 每份 `supplier` | 建议 | 缺则自动命名 quote-N |
| `unit_price`（>0） | 必需 | 为 0 或负会被拦 |
| `qty`（>0） | 必需 | 为 0 会被拦 |
| `moq`（起订量） | 必需 | 缺则无法判起订 |
| `currency` | 必需 | 混币种必须先归一（BLOCKER） |
| `annual_rate_pct` | 建议 | 缺则按 0 算资金占用 |

**追问纪律**：最多一轮，只问**几家报价、要不要含运费关税**。

## §3 执行流水线（Workflow）

### Step 1 · 币种归一（不归一，后面全是错）
```bash
python agent.py tco compare --input <报价.json>
```
**实测：一份报价同时有 CNY 与 USD 直接 BLOCKER**。
口径警告原文：`混合币种须先按 FX 归一`。

| 反例 | 正确做法 |
|---|---|
| 一家 USD 1.7 / 一家 CNY 12.5 直接比 | 先按汇率折成同一币种，并在结论里写汇率与日期 |

### Step 2 · 三项本体校验
| 项 | 判据 |
|---|---|
| `unit_price > 0` | 为 0 会被拦（不是"免费"，是漏填） |
| `qty > 0` | 数量为 0 无法算总额 |
| `moq` 满足 | 下单量低于起订量要说明怎么补 |

### Step 3 · 折算五项成本（TCO 的本体）
只比单价是不够的，必须折算：

| 成本项 | 怎么算 | 常见漏项 |
|---|---|---|
| 采购额 | 单价 × 数量 | —— |
| 物流 | 按重量/体积或整柜 | 只算头程漏尾程 |
| 关税 | 采购额 × 关税率（0–50%） | 漏增值税与反倾销 |
| **资金占用** | 采购额 × 年化 × 账期/365 | 账期 90 天不是"免费" |
| 质量与售后 | 不良率 × 返工/退货成本 | 便宜货的隐性成本 |

**资金占用最常被漏**：同样是 12 元，账期 30 天和 90 天的真实成本差
= 采购额 × 年化 × 60/365。年化 6% 时约差 1%。

### Step 4 · 全周期成本
```bash
python agent.py tco lifecycle --input <全周期参数.json>
```
除一次性采购额外，还要加上：备件、维护、能耗、报废/处置。
**判据**：把"三年总成本"算出来，而不是只比首单。

### Step 5 · 出结论（差额 + 依据 + 前提）
结论必须写三样：
1. **差多少**（绝对值 + 百分比）；
2. **差在哪几项**（物流/关税/资金/质量各占多少）；
3. **前提是什么**（汇率、数量、账期）。

只写"B 更便宜"没有价值——下次汇率一变结论就反了。

- **五项折算表必须随结论交付**；只有"哪家便宜"无法复核。

## §5 质量门（一票否决，不过不给交付）

1. **报价 ≥1**（`tco.quotes`）；
2. **币种一致**（`tco.currency`，混合币种 BLOCKER）；
3. **每份 `unit_price > 0`**（`tco.unit_price`）；
4. **每份 `qty > 0`**（`tco.qty`）；
5. **关税率在 0–50%**（`tco.duty`）；
6. **资金年化在 0–30%**（`tco.rate`，>15% 给 WARN）；
7. **结论写明差额、来源项与前提**。

> 验收命令：`python agent.py tco compare --input <报价.json>`
> 命中任一项不过 → 回 §3 对应 Step，**不允许把币种字段删掉假装一致**。

## §6 交付前自检清单

- [ ] 所有报价都已折成同一币种，并记录了汇率与日期
- [ ] 每份报价的单价与数量都大于 0
- [ ] 我看了起订量，下单量够不够
- [ ] 物流算了头程和尾程
- [ ] 关税算了，并确认没有反倾销/增值税漏项
- [ ] 资金占用算了（账期 90 天不等于免费）
- [ ] 质量/售后成本折算进去了
- [ ] 我算的是三年总成本，不只比首单
- [ ] 结论写了差多少、差在哪、前提是什么

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 混合币种直接比 | 先按 FX 归一，记录汇率与日期 |
| EX-02 | 只比单价 | 折算物流+关税+资金+质量五项 |
| EX-03 | 账期当免费 | 资金占用 = 采购额 × 年化 × 账期/365 |
| EX-04 | 只算头程运费 | 头程 + 尾程 + 仓储 |
| EX-05 | 关税按 0 算 | 按实际税率，并查反倾销 |
| EX-06 | 忽略 MOQ | 下单量低于 MOQ 要说明怎么补 |
| EX-07 | 比首单不比全周期 | 算三年总成本（含维护/备件/处置） |
| EX-08 | 结论只说"B 便宜" | 写差额、来源项、前提 |
| EX-09 | 单价填 0 当"待议" | 0 是非法值，先补齐再比 |
| EX-10 | 便宜货不留质量成本 | 不良率 × 返工/退货成本要折算 |
| EX-11 | 汇率用大概数 | 记录来源与日期，便于复核 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| `agent.py` 门禁跑不了 | 按 §6 人工核对，标注「未跑门禁」；**不得据以下单** |
| 只有 1 家报价 | 说明"无法比较"，给"再找 1 家"的建议 |
| 汇率不明 | 给两档汇率（乐观/保守）测算，标注"汇率待确认" |
| 关税不确定 | 按区间测算，标注"税率待确认" |
| 涉及反倾销/配额 | 明确提示需查贸易政策，本包不做政策判断 |
| 供应商资质未知 | 转 `po-validate` 的供应商准入 + `r03` 合规 |

**明确不做**
- 不做采购单/收货单校验（归 `po-validate`）；
- 不做供应商准入合规（归 `r03` + 外部）；
- 不做付款与资金安排（归 `cash-runway`）；
- 不签合同、不出法律意见。
