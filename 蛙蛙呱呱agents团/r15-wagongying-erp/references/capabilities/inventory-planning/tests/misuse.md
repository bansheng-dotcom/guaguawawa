# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`），本表为人工评审清单。版本：v2.0.0

## 一、硬门（§5，任一不过即不得交付）

| # | 判据 |
|---|---|
| MU-01 | 日均销量用中位数（非均值），并给出 P90 与波动比 |
| MU-02 | 安全库存 = 日均 × 交期 × 波动系数，参数有来源 |
| MU-03 | 补货点 = 日均 × 交期 + 安全库存，且触发动作明确 |
| MU-04 | 单次批量在起订量与 6 周销量之间 |
| MU-05 | 滞销（30 天）与呆滞（90 天）各有定义与处置动作 |
| MU-06 | 资金占用与周转天数按 SKU 计算 |

## 二、软门（§6 自检）

| # | 常见错法 |
|---|---|
| MU-06 | 我用的日均是中位数，不是均值 |
| MU-07 | 我给了 P90 和波动比 |
| MU-08 | 安全库存我按公式算了，参数有来源 |
| MU-09 | 补货点我算出来了，触发动作也明确了 |
| MU-10 | 我的批量没超过 6 周销量 |
| MU-11 | 我区分了滞销和呆滞，处置动作不同 |
| MU-12 | 我按 SKU 算了资金占用和周转天数 |
| MU-13 | 我没有用「感觉快没了」当补货信号 |

## 三、诚实说明

本卡没有可自动断言的門禁：参数合理性只能由真实销量波动与缺货率回看。

> **纪律**：库存计划的目标不是「不缺货」，是「**用最小的资金占用买到可接受的缺货率**」。
