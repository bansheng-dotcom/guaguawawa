# 负向测试集（misuse cases）

> **本卡是 knowledge 卡**（`entry: null`），本表为人工评审清单。版本：v2.0.0

## 一、硬门（§5，任一不过即不得交付）

| # | 判据 |
|---|---|
| MU-01 | 资质合规五项逐条核对，任一不过即拒 |
| MU-02 | 四维评估基于试单数据（质量/交付/成本/配合），非凭介绍 |
| MU-03 | 分级 A/B/C 明确，关键物料禁止 100% 单源 |
| MU-04 | 冻结与退出条件写死并指定责任人 |
| MU-05 | 评估台账字段齐全且季度复评 |
| MU-06 | 单源物料必须有 6 个月内引入第二家的计划 + 安全库存 |

## 二、软门（§6 自检）

| # | 常见错法 |
|---|---|
| MU-06 | 五项资质我逐条核过，不是「看着挺正规」 |
| MU-07 | 我做过试单，有不良率与准时率数据 |
| MU-08 | 成本我按 TCO 算的，不是只比单价 |
| MU-09 | 我给了 A/B/C 分级和配额 |
| MU-10 | 关键物料我没有让它单源 |
| MU-11 | 冻结和退出条件我写死了，也指定了谁执行 |
| MU-12 | 我有季度评估台账 |
| MU-13 | 单源物料我列了引入第二家的时间计划 |

## 三、诚实说明

本卡没有可自动断言的门禁：资质与质量只能通过文件核验与抽检验证，可自动化的只有 TCO 计算（另一张卡）。

> **纪律**：准入的目标不是「找到最便宜的」，是「**找到换得掉的**」。
