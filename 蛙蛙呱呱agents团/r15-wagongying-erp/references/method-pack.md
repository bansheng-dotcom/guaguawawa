# R15 蛙供应 · 供应链 · 方法包（Method Pack v1）

## 1. 决策问题

- 典型决策：选哪个供应商、自建还是外包、库存怎么定。
- 决策者：供应链负责人 + 创始人；成功标准：总成本最低且供应可控。
- 非目标：不做无报价的比价、不做无回滚的切换。

## 2. 问题树（MECE）

| 分支 | 要回答 | 假设 | 数据 | 方法 |
|---|---|---|---|---|
| 成本 | 总拥有成本是多少 | TCO 可算 | 报价/运价/关税 | TCO 对比 |
| 时效 | 能不能按时到 | 履约可验证 | 时效记录 | 履约分析 |
| 风险 | 断供/质量/合规 | 风险可量化 | 供应商资质 | 风险矩阵 |
| 弹性 | 旺季能不能扩 | 产能有弹性 | 产能数据 | 产能核对 |

**critical branch**：`成本`——资源优先给它。

## 3. 假设与证伪

- H1：直采的有效单位成本比现采低 ≥10%。
- H2：切换后 4 周内到货准时率 ≥95%。
- 竞争解释（至少 2 个）：便宜是因为价格，还是因为少算了损耗/运费？；断供是供应商问题，还是我们预测问题？
- 每条假设必须有**杀死标准**：指标 + 阈值 + 观察窗口。

## 4. 证据分级

| 级别 | 来源 | 允许用法 |
|---|---|---|
| A | 系统记录、合同、官方数据、可复算台账 | 可进结论与决策 |
| B | 行业报告、供应商报价、抽样数据 | 方向 + 区间 |
| C | 访谈、估算、单点经验 | 标注 + 敏感性 |

**规则**：每个结论挂来源；同名不同口径单列；缺什么、影响什么、怎么补，必须写清；C 级超过 3 条时结论降级为「条件成立」。

## 5. 方法与陷阱

**可执行**：`python scripts/methods.py safety-stock --sigma ... --lead ...`。

- TCO：货值 + 物流 + 关税 + 资金占用 + 质量风险。
- 库存模型：安全库存 = z × σ × √LT。
- 履约仿真：旺季峰值下的到货与缺货。
**陷阱清单**：
- 只比单价
- 忽略装载率
- 忽略质量与退货
- 切换无回滚
供应结论必须给「切换计划 + 回滚条件」，否则不执行。

## 6. 输出契约

```
claim        一句话结论（方向 + 幅度 + 范围/时间）
evidence     来源 + 观测/记录 + 口径
confidence   A/B/C + 区间（无区间写「点估计，未验证」）
falsifier    什么新证据会推翻它
```

缺任一项 → 不得进首页；建议缺负责人/阈值 → 行动性不通过。
