# R13 蛙可成 · 客户成功 · 方法包（Method Pack v1）

## 1. 决策问题

- 典型决策：这个客户会不会流失、要不要升级处理。
- 决策者：客户成功负责人；成功标准：续约率/健康分达标，风险客户有干预。
- 非目标：不做降价承诺、不替客户做业务决策。

## 2. 问题树（MECE）

| 分支 | 要回答 | 假设 | 数据 | 方法 |
|---|---|---|---|---|
| 使用 | 用得多不多、深不深 | 使用度可量化 | 产品数据 | 健康分/使用分层 |
| 支持 | 问题多不多、解决快不快 | 工单趋势可读 | 工单系统 | 工单分析 |
| 价值 | 客户是否拿到结果 | 价值可举证 | QBR/案例 | 价值复盘 |
| 关系 | 关键人是否稳固 | 关系链清晰 | CRM | 关系图谱 |

**critical branch**：`价值`——资源优先给它。

## 3. 假设与证伪

- H1：健康分 <60 的客户，90 天内流失概率 ≥30%。
- H2：完成价值复盘的客户，续约率提升 ≥10 个百分点。
- 竞争解释（至少 2 个）：流失是因为产品，还是客户业务收缩？；健康分低是使用问题，还是上手问题？
- 每条假设必须有**杀死标准**：指标 + 阈值 + 观察窗口。

## 4. 证据分级

| 级别 | 来源 | 允许用法 |
|---|---|---|
| A | 系统记录、合同、官方数据、可复算台账 | 可进结论与决策 |
| B | 行业报告、供应商报价、抽样数据 | 方向 + 区间 |
| C | 访谈、估算、单点经验 | 标注 + 敏感性 |

**规则**：每个结论挂来源；同名不同口径单列；缺什么、影响什么、怎么补，必须写清；C 级超过 3 条时结论降级为「条件成立」。

## 5. 方法与陷阱

- 健康分：使用 30 / 支持 25 / VOC 25 / 互动 20，三色区间。
- QBR：价值回顾 + 目标对齐 + 风险清单。
- 流失归因：按客户分层，不平均化。
**陷阱清单**：
- 只信客情
- 平均化看流失
- 把续约当结果而不是过程
- 风险客户不升级
客户结论必须给「干预动作 + 负责人 + 时间」，否则只是描述。

## 6. 输出契约

```
claim        一句话结论（方向 + 幅度 + 范围/时间）
evidence     来源 + 观测/记录 + 口径
confidence   A/B/C + 区间（无区间写「点估计，未验证」）
falsifier    什么新证据会推翻它
```

缺任一项 → 不得进首页；建议缺负责人/阈值 → 行动性不通过。
