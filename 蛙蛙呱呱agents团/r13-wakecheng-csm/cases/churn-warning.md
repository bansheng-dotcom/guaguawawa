# SOP：高净值客户流失预警与挽回（R13 蛙客成）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：月度活跃净留存]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 月度活跃净留存 | `(期初 MRR + 扩张 − 流失 − 降级) / 期初 MRR` | % | ≥ 100 | < 95 启动挽回 |
| 平均健康分 | `加权（使用频次/工单/续约意愿）` | 分 | ≥ 70 | < 60 全量排查 |

## 3. 分步诊断动作

1. 算健康分：使用深度、工单情绪、续约意愿三项加权。
2. 筛 at_risk：分数 < 60 或使用断崖式下滑。
3. 排优先级：按 ARR × 流失概率排序，先救大头。
4. 定挽回动作：48h 内一对一触达，出书面方案。
5. 闭环：VOC 进需求池，SLA 缺口进流程整改。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | NDR < 95% | BLOCKER | 启动专项挽回并上报 R01 |
| G2 | P1 工单首响 > 8h | WARN | 升级值班，补 SLA |
| G3 | 续约前 30 天无触达记录 | WARN | 强制排期触达 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
