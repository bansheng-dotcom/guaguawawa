# R03 蛙守线 · 方法包（Method Pack v1）

## 1. 决策问题

- 典型决策：这个业务/品类/门店赚不赚钱 / 能不能扩 / 现金能撑几个月 / 这个报价能不能接。
- 决策者：创始人 + 业务负责人；最怕「账面赚钱、现金断掉」。
- 成功标准：给出「单位经济 + 三情景 + 现金拐点」三件套，且每个假设可被一句话驳回。
- 非目标：不做税务筹划结论；不替业务定战略；不签合同。

## 2. 问题树（MECE）

| 分支 | 要回答 | 数据 | 方法 | 产出 |
|---|---|---|---|---|
| 收入 | 量×价×结构 | 销量、价格带、退货 | 量价拆解、同店 | 收入桥 |
| 成本 | 固定/变动/半变动 | 采购、物流、损耗、人力 | 成本卡、贡献毛利 | 成本桥 |
| 营运资金 | 存货/应收/应付 | 周转天数 | CCC | 现金占用 |
| 资本 | 投入/回收/融资 | Capex、账期 | 回收期、IRR | 资金计划 |

**critical branch**：成本里的**损耗与履约**，通常是被低估最狠的一块。

## 3. 假设与证伪

- 假设例：「损耗从 8% 降到 5%，单公斤成本降 0.22 元，毛利率 +3 个百分点」。
- 三件套：支持证据（历史损耗台账）/ 反对证据（旺季损耗反弹）/ 杀死标准（连续 4 周损耗 >7%）。
- 竞争解释：毛利变化是采购价、售价还是结构导致？必须用桥接拆开。

## 4. 证据分级

| 级别 | 来源 | 用途 |
|---|---|---|
| A | 银行流水、发票、合同、ERP | 可进模型 |
| B | 行业毛利/费用率区间 | 做基准 |
| C | 估算、访谈 | 标注 + 敏感性 |

规则：模型里每个假设单元格标 A/B/C；C 级超过 30% 的模型不得用于对外融资材料。

## 5. 方法与陷阱

**可执行**：`python scripts/methods.py runway --cash ... --burn ...`。

- **三表联动**：利润表→资产负债表→现金流量表，勾稽不平不出报告。
- **单位经济**：单公斤/单店/单客，拆到「变动成本 + 分摊固定成本」。
- **三情景**：乐观/基准/悲观，标出**翻转点**（哪个假设一变，结论反了）。
- **现金跑道**：按月推演，给耗尽月份与触发线（<3 个月必须融资/降本）。
- 陷阱：用收入代替回款；把 Capex 当 Opex；单点预测；把「规模效应」当默认；忽略账期。

## 6. 输出契约

```
unit_econ    单公斤/单店：售价 − 变动成本 − 分摊 = 贡献毛利
scenarios    乐观/基准/悲观 + 翻转点
cash         现金拐点月份 + 触发线
assumptions  每条带级别 + 可驳回方式
```

缺翻转点或现金拐点 → 不通过。
