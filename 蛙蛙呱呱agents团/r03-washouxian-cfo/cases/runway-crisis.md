# SOP：现金跑道压缩与渠道止损（R03 蛙守先）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：现金可支撑月数]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 现金可支撑月数 | `期末现金 / 月均净烧钱` | 月 | ≥ 9 | < 4 启动止损预案 |
| 烧钱倍数 | `净烧钱 / 净新增 ARR` | × | ≤ 2.0 | > 3.0 冻结扩张 |
| CAC 回收期 | `CAC / 月毛利/客户` | 天 | ≤ 30 | > 45 暂停该渠道 |

## 3. 分步诊断动作

1. 先做勾稽：三表差异 > 0.1% 一律先查账，不进入分析。
2. 算跑道：期末现金 / 月均净烧钱，给出耗尽月份。
3. 算烧钱倍数：净烧钱 / 净新增 ARR，> 3x 冻结扩张。
4. 渠道止损：按 CAC 回收期排序，>45 天当日停投。
5. 出决策书：止血方案 + 融资窗口 + 熔断线，交 R01 拍板。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 跨表勾稽差异率 > 0.1% | BLOCKER | 阻断结账，先查差异 |
| G2 | 现金流安全月数 < 4 | BLOCKER | 启动止损预案并上报 R01 |
| G3 | 报告出现未标注模拟的财务数字 | BLOCKER | 作废并重出，标注数据来源 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
