## 复现

```bash
cd 底稿版
python collect_national.py   # L1/L2/L5，写入 data_daily/weekly/futures.csv
python collect_local.py      # L4，抓 HTML 并抽句到 digest_local.txt
python build_master.py       # 装配 1,196 点 → data/底稿指标.json
python build_ledger.py       # 40 条结论 → data/证据台账_底稿.json
python render_dossier.py     # 渲染三份 HTML
```

门禁：`python ../run_gates.py`（R05/R06/R15/R04，输出在 `../gates/`）。

## 口径提醒

- 价格单位统一元/斤：零售取元/500 克，批发取元/公斤 ÷2。
- 全国是批发价、内蒙是零售价，**只能比变化率，不能直接相减**。
- 证据 A 级（牛/羊/鸡/鱼/蛋）可进合同；B 级（鸭/虾）只做方向；C 级（鹅）只做情景。
- 国庆 10/01—10/07 无数据，按交易日口径处理，不插值。
