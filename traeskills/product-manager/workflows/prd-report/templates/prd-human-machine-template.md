# PRD-人机翻译模板

> 用途：把用户想法整理成“人能判断、机器能执行”的需求文档。复杂需求默认融合产品发现、战略、指标、发布分期和假设攻击；轻量需求可以裁剪，但不能删除真正问题、范围、不在范围、验收标准。
