# PM 质问与思考 Prompt Changelog

## 0.3 - 2026-07-01

- 将提问前经验调用收敛为 `pre-question` L1 Gate，只读取索引、偏好和纠错摘要。
- 明确轻量质问不打开大量经验卡，问题来自当前场景和 L1 Gate 约束。

## 0.2 - 2026-07-01

- 增加提问前 `experience-rag: pre-question`，问题必须来自真实场景和历史经验。
- 输出结构新增“发问依据”，避免固定问题库和抽象发问。

## 0.1 - 2026-07-01

- 将原平铺流程目录化。
- 明确少问、推演式生成问题、可默认推进。
