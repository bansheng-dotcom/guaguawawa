# SOP：新功能冷启动未过门禁的迭代决策（R07 蛙得名）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：PRD 门禁得分]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| PRD 门禁得分 | `通过门禁数 / 总门禁数 × 100` | 分 | ≥ 80 | < 60 禁止进开发 |
| 主流程跳失率增幅 | `上线后跳失率 − 上线前跳失率` | % | ≤ 2% | > 5% 停止扩量 |

## 3. 分步诊断动作

1. 过八门禁：定位未过项，判断是缺判据还是缺数据。
2. 切 MVP：把范围砍到能验证核心假设的最小集。
3. 定指标：北极星 + 过程指标 + 反指标三件套。
4. 排优先级：RICE 打分，解释每个因子取值依据。
5. 出 PRD：用户故事 + 验收 + 埋点清单。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | PRD 缺验收判据 | BLOCKER | 退回补验收标准 |
| G2 | 北极星指标无法定义 | BLOCKER | 退回定义指标 |
| G3 | 需求变更 > 3 次 | WARN | 冻结迭代 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
