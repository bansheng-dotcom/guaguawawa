# 升级与路由规则（quarterly-boardroom）

1. 记分卡指标数 5-15：<5 说明没管到点，>15（如 40 个 KPI）=看数而非管数，只保留红线项。
2. 议程只含红项：绿项进议程 = 跑偏（看到红线只看红）。
3. Rocks 出现「60% 完成」→ 判不合格：二元 done/not_done。
4. 复盘触发条件：90 天查点 / 杀死标准触发 / 决策被推翻 / 季度全量，四者其一。
5. 事后补的标准不可打分：只有 pre_committed=true 的标准才允许 WIN/PARTIAL/LOSS/MIXED。
6. LOSS → 必须新增 boardroom 或 brief，否则复盘不闭环。
