## 零、v6.1 版本变更

### v6.0 → v6.1 核心变化（2026-05-30审计后补全）

| 变化 | 原因 | 具体调整 |
|------|------|---------|
| **🔥 W5新增时间序列分析（W5D6.5）** | 面试必问——DA每天面对带时间戳的数据，"DAU跌了3%是不是异常"需要时序分解+季节性判断。原课程完全缺失 | 时序分解(trend/seasonal/residual)、ACF/PACF、平稳性、季节性Naive预测、异常检测、环比vs同比陷阱 |

| **🔥 W12 ML扩展（新增W12D4.5）** | 2-3万DA面试必问XGBoost/聚类/SHAP。原课程只有2天ML（逻辑回归+决策树+评估指标）→广度不够 | XGBoost/LightGBM、聚类(K-means/层次/DBSCAN)、SHAP、特征工程(编码/缩放/交叉/时间特征) |
| **🔥 W2.5D4新增测试与调试** | 生产代码不能只靠"看输出对不对"→需要pytest+assert做数据防御。原课程完全缺失 | pytest基础、数据assert模式、pandas测试、排错技巧 |
| **🔥 W7D5扩展AB平台化思维** | 入职后用的是公司已有的实验平台→需要知道怎么验证平台算对了、怎么提改进需求、CUPED的三种模式 | 平台验证、需求文档模板、平台CUPED模式选择、使用边界 |
| **🔥 W8新增现代数据栈工具（W8D5.5）** | 字节/美团JD要求"熟悉dbt/Airflow等数据工具"。原课程只有crontab+手动脚本→面试被问"怎么部署到生产"答不上来 | dbt(SQL版本管理+测试)、Airflow(DAG调度)、GitLab CI/CD(自动测试部署) |

| **W8/W9/W14-W16强化沟通协作** | 2-3万DA和1.5万的分水岭=沟通影响能力 | 模拟汇报+追问、CR邮件、需求对齐沟通 |
| **W16面试冲刺强化** | 面试准备贯穿课程 | 每两周SQL限时小测、W13起每周末模拟面试 |
