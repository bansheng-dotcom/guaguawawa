# 技术翻译报告工作流拓扑

## 1. 目标

把技术内容翻译成用户能判断、技术角色能接手的说明。

## 2. 拓扑图

```mermaid
flowchart TD
  A["输入: 需求 / PRD / 技术方案"] --> B["N1 明确读者和决策"]
  B --> C["N2 写用户影响"]
  C --> D["N3 拆前端/后端/Agent影响"]
  D --> E["N4 写数据、权限和失败兜底"]
  E --> F{"G1 是否能拍板或接手?"}
  F -- 否 --> F1["补缺口或只问 1 个关键问题"]
  F -- 是 --> G["输出技术翻译报告"]
```

## 3. 输出包

| 产物 | 作用 |
| --- | --- |
| 技术翻译报告 | 给用户和技术角色共读 |
| 影响矩阵 | 拆用户、前端、后端、Agent、运营影响 |
| 数据权限失败图 | 说明数据来源、权限和失败处理 |
| 兜底方案 | 自动化失败时怎么处理 |
