# Reports Folder

这个目录是产品管理 person 的备用汇报归档区。

优先规则：面向具体项目的正式产出应该放到项目根目录，例如：

```text
<项目根目录>/产品经理工作报告/
<项目根目录>/项目管理/决策记录/
```

只有在没有明确项目根目录、报告属于 person 自身建设、或需要跨项目临时归档时，才放到这里。

## 推荐结构

```text
reports/
├── <项目名或主题>/
│   ├── decisions/
│   ├── worklog/
│   ├── artifact-maps/
│   └── archive/
```

## 命名规则

```text
YYYY-MM-DD-主题-报告类型.md
```

报告类型建议：

- `项目理解汇报`
- `决策汇报`
- `技术翻译汇报`
- `状态汇报`
- `交接汇报`
- `文件地图`

## 存档要求

- 开头写清这份报告帮用户决定什么。
- 涉及决策时必须有选项、利弊、推荐和兜底。
- 涉及项目事实时必须能回到来源文件。
- 涉及用户偏好时必须写清触发语境。
