# 竞品分析报告质量指南

## 1. 好竞品分析的定义

好竞品分析回答“我们该怎么决定”，不是回答“别人做了什么”。

| 模块 | 必须回答 |
| --- | --- |
| 决策问题 | 为什么现在看竞品 |
| 竞品范围 | 为什么选这些对象 |
| 对照维度 | 比较什么，不比较什么 |
| 证据 | 来源、日期、适用范围 |
| 洞察 | 对我们意味着什么 |
| 取舍 | 学什么、不学什么、怎么差异化 |

## 2. 常见维度

- 目标用户和场景。
- 核心任务流程。
- 信息架构和页面入口。
- 定价、商业模式、增长机制。
- AI/自动化能力边界。
- 数据、权限、协作和导出。
- 失败兜底和信任机制。

## 3. 来自 pm-skills 的可吸收做法

| 方法 | 在本地竞品分析里怎么用 |
| --- | --- |
| competitor-analysis | 比强弱项、目标用户、场景和差异化，不只列功能 |
| competitive-battlecard | 当报告面向销售、老板或外部竞争时，补定位、异议处理和 win/loss 判断 |
| market-segments / ICP | 先定义我们和竞品分别服务谁，避免拿不同用户场景硬比 |
| customer-journey-map | 对比关键旅程节点、情绪、痛点和机会 |
| growth-loops / GTM motions | 只在增长或商业化是决策点时使用 |
| market-sizing / sentiment-analysis | 需要数据支撑时转入数据分析或市场研究，不在 PM 报告里伪造数据 |

## 4. 常见反模式

- 罗列截图，没有产品判断。
- 只看头部竞品，不看替代方案。
- 只学功能，不问为什么。
- 来源过期却不标日期。
- 把竞品做法当成需求成立证据。
