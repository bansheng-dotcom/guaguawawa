# 04 团长流失预警 — 4信号规则引擎

---

## 一、跟项目四的区别

项目四是"用户流失预测"（ML模型，2万样本）。
这里是"团长流失预警"（规则引擎，500样本）。

样本量小的场景,基于规则的预警比ML更可靠、更可解释。

---

## 二、4个预警信号

| 信号 | 条件 | 权重 | 逻辑 |
|------|------|------|------|
| GMV连续3月下降 | 最近3个月GMV递减 | 3分 | 持续衰退 |
| GMV骤降>15% | 近3月均值 vs 前3月均值 | 3分 | 突然恶化 |
| 出现无订单月 | 最近3月中有GMV=0的月 | 4分 | 濒临停业 |
| 用户数连降 | 活跃用户数持续减少 | 2分 | 用户流失前兆 |

**总分0-12分,>7=高风险,4-7=中风险,<4=低风险**

---

## 三、关键验证

```
高风险组实际流失率 >> 低风险组实际流失率
```

如果这个前提不成立,说明信号选错了。代码里做了这个检查。
