## 二、逐图拆解

打开 [06_python_visualization.py](../06_python_visualization.py)：

### 图1: 整体漏斗（左上）

```python
ax1.barh(i, users, bar_height, color=color, alpha=0.85)
```
水平柱状图。4个颜色代表4个阶段（蓝→绿→橙→红，从看到到下单越来越接近成交）。每个柱子上标注了用户数和转化率。

### 图2: 城市漏斗对比（右上）

```python
ax2.plot(range(len(users_list)), users_list, 'o-', color=color, linewidth=2.5)
```
折线图。绿色=一线，红色=三五线。两条线几乎完全重叠——说明用户行为没有城市差异。

### 图3: RFM散点图（左下）

```python
sc = ax3.scatter(rfm_sample['recency_days'], rfm_sample['frequency'],
                 c=rfm_sample['monetary'], cmap='RdYlGn', alpha=0.6)
```
X轴=最近购买天数（越小越好），Y轴=购买频次（越大越好），颜色+大小=消费金额。右上角=高价值用户群（最近买过+频次高+金额大）。

### 图4: 品类GMV（中下）

```python
bars = ax4.barh(range(len(category_data)), category_data['total_gmv'].values, ...)
```
水平柱状图。7个品类各自的GMV贡献，标注了毛利率。蔬菜水果贡献最大。

### 图5: 团长GMV TOP10（右上）

```python
colors_leader = ['#E74C3C' if t == 'tier_1_new' else '#3498DB' for t in leader_gmv['city_tier']]
```
红色=一线团长，蓝色=三五线团长。一眼看出TOP团长以三五线为主（蓝色多）——跟美团优选用户分布吻合。

### 图6: 履约成本对比（右下）

三组柱状图（红=履约成本，橙=损耗，蓝=配送距离），一线 vs 三五线对比。

## 三、关键代码

### 从SQLite读取数据
```python
conn = sqlite3.connect('data/community_groupbuy.db')
df = pd.read_sql('SQL语句', conn)
```
pandas可以直接执行SQL并把结果转成DataFrame。数据分析的标准操作流：**SQL做聚合 → pandas做可视化。**

### matplotlib非交互模式
```python
matplotlib.use('Agg')
```
`Agg`是matplotlib的后端渲染器，用于生成PNG图片。在服务器端、没有GUI的情况下必须设。如果在Jupyter里跑，改成`%matplotlib inline`。

### 中文字体
```python
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei']
```
Windows系统用SimHei来正确显示中文。如果没这行，所有中文都会变成方块。

### 子图布局
```python
fig = plt.figure(figsize=(20, 14))
ax1 = plt.subplot(2, 3, 1)  # 2行3列,第1个
ax2 = plt.subplot(2, 3, 2)  # 第2个
...
```
`subplot(2,3,N)` 创建2行3列的网格，N=1到6。

## 五、面试怎么讲

**面试官："SQL分析完结果后怎么呈现？"**

> "我不直接贴SQL结果——那没人看得懂。我会用Python做可视化：
> pandas读SQLite → 聚合计算 → matplotlib/seaborn画图 → 输出PNG。
>
> 社区团购的漏斗分析我做成了6合1仪表盘：左上漏斗看整体转化、右上城市漏斗对比、中间RFM看用户分层、下方品类GMV和团长排名、右下履约成本对比。
>
> 画图的目的是让业务方（产品、运营）能一眼看出问题在哪——不用解释p值，他们看到'漏斗在加购→下单掉了8%'就知道要去排查什么。
>
> 另外我还做了Tableau版本的看板，但Python版本的好处是可以完全自动化——每周跑一遍脚本自动生成周报图表。"
