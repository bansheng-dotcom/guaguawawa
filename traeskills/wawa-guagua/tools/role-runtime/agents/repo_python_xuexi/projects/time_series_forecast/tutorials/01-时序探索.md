# 01 时序探索 + 季节分解

## 核心概念

**趋势(Trend):** GMV长期走向——是在增长还是下降？
**季节(Seasonal):** 每周/每月的周期性波动——周末总是比工作日高
**残差(Residual):** 去掉趋势和季节后剩下的——特殊事件（暴雨、大促）

`statsmodels.seasonal_decompose` 一键拆出三个组件。

### 时间序列的"不可随机拆分"法则

训练集/测试集划分必须按时间顺序——不能随机shuffle。
前335天训练，后30天测试 → 模拟"用历史预测未来"。
