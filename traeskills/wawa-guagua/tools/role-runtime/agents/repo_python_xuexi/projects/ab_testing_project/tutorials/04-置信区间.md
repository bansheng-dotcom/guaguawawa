# 04 置信区间

---

## 一、白话理解

### p值的盲区

上一步告诉你:GMV提升了1.96%,p=0.0003,显著。

但你老板想知道:**"最好的情况提升多少?最坏呢?会不会上线后效果变负?"**

p值只能回答"可信不可信",回答不了"效果多大、范围多宽"。

### 天气预报类比

天气预报:"明天气温比今天高2°C,置信区间1°C到3°C。"

- "高2°C" = 点估计(就像GMV lift=1.96%)
- "1°C到3°C" = 95%置信区间
- 如果置信区间是"-1°C到5°C",说明不确定——实际可能降温也可能升温

**在社区团购场景,置信区间比p值更重要**,因为:

1. GMV涨了但CI下限是负的→可能上线后反而跌→不敢全量
2. 履约成本率涨了但CI上限很高→说明最坏情况下成本可能涨很多→需要评估容忍度
3. 损耗率的CI很宽→样本量不够,不确定性太大

## 二、核心概念

### 2.1 置信区间的三个判断

```
情况A: GMV变化 +2%, 95%CI = [+0.8%, +3.2%]
  → CI完全在0右边。最坏情况也是正的。放心。

情况B: GMV变化 +2%, 95%CI = [-0.5%, +4.5%]
  → CI跨过0。效果方向对但不确定性大。要么增样本,要么评估-0.5%能否接受。

情况C: GMV变化 +2%, 95%CI = [-3%, +7%]
  → CI很宽。样本量严重不足。先别上线,继续测。
```

### 2.2 参数法 vs Bootstrap

代码里两种方法都做了:

| | 参数法 | Bootstrap |
|------|--------|-----------|
| 原理 | 假设正态,用t分布算CI | 从原始数据重抽样5000次,取2.5%和97.5%分位数 |
| 优点 | 快,经典 | 不依赖分布假设,更稳健 |
| 缺点 | 依赖正态性假设 | 慢,小样本下不稳定 |

**如果两种方法结果一致,说明你的数据用参数法没问题。如果不一致,倾向于信Bootstrap。**

### 2.3 社区团购的"实际重要阈值"

代码里设了两个阈值:
- GMV: CI下限必须>0.5%才认为有业务价值
- 履约成本率: 恶化不能超过0.3%(因为毛利只有15-20%,成本上涨会吃掉利润)

这里体现的是:**统计显著≠业务有价值。** 一个GMV提升0.1%但p<0.001的实验在技术层面"显著",在业务层面可能毫无意义——社区团购的薄利模式决定了对效果精度的要求比电商更高。

## 三、代码导读

打开 [04_confidence_interval.py](../04_confidence_interval.py):

### 参数法CI (第55-75行)

```python
se = np.sqrt(var_c/n_c + var_t/n_t)
t_crit = stats.t.ppf(0.975, df_welch)
ci_lift_lower = (diff - t_crit*se) / mean_c * 100
```

### Bootstrap CI (第85-105行)

```python
for i in range(5000):
    c_sample = np.random.choice(control_vals, size=n_c, replace=True)
    t_sample = np.random.choice(treatment_vals, size=n_t, replace=True)
    bootstrap_lifts[i] = (t_sample.mean()/c_sample.mean() - 1)*100

ci_lower = np.percentile(bootstrap_lifts, 2.5)
ci_upper = np.percentile(bootstrap_lifts, 97.5)
```

从原始样本里有放回地抽5000次,每次算一个lift,最后取lift分布的分位数。

## 四、输出解读

跑完后重点关注:

```
Forest Plot:
  人均GMV:  +1.96% [+1.45%, +2.47%]  → CI排除0,下限>0.5% → 有价值
  人均件数:  +2.01% [+1.22%, +2.80%]  → CI排除0 → 显著
  履约成本率: +2.82% [+1.93%, +3.71%]  → CI排除0,但是坏方向 → 需解决
  生鲜损耗率: +0.75% [-0.15%, +1.65%]  → CI跨0 → 无显著变化
```

**核心解读:**

履约成本率CI[+1.93%,+3.71%]——即使在最好的情况下(CI下限),履约成本也会涨1.93%。这说明履约成本上升是稳健的坏消息。结合GMV提升只有1.96%,**净利润可能反而下降**。

→ 需要分城市看(模块06):是全线履约成本都涨,还是只有低线城市涨?

## 五、面试怎么讲

**面试官:"p值和置信区间有什么区别?为什么两个都要?"**

> "p值是二元的——告诉你'能不能信'。置信区间告诉你'效果多大、范围多宽',回答了'值不值得做'。
>
> 比如我遇到过一个情况:GMV lift=1.96%,p=0.0003(很显著)。但95%CI是[-0.1%,+4.0%]——CI跨0,说明效果方向虽然有正的趋势,但最坏情况可能是负的。这种情况下我不会直接建议全量,而是建议增样本继续测,直到CI下限>0为止。
>
> 反过来,履约成本率CI[+1.93%,+3.71%]——在最乐观情况下也会恶化。这告诉我'即使再测,履约成本大概率还是会涨',与其继续测,不如直接排查算法为什么推了那么多远距离供应商的商品。
>
> p值+CI两个一起看,才能做出靠谱的业务决策。"
