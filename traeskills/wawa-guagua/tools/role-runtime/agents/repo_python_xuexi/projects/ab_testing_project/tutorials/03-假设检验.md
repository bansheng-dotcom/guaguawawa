## 一、白话理解

### 你看到的差异,是真实还是运气?

跑完实验,数据出来了:

```
人均GMV: 运营25.23元 vs 算法25.73元 → 算法高了1.96%
```

你高兴地跑去跟产品经理说算法赢了。

但你想过没有:**如果那天恰好天气特别好,大家都想做饭,下单量本来就高呢?** 如果你抽到的实验组用户恰好是高频用户呢?

1.96%的差异,**到底是算法真的牛,还是运气?**

假设检验就是用数学来回答这个问题。

### 用团长业绩做类比

你管10个团长。这个月你给其中5个团长换了新的培训方法,另外5个维持原样。月底发现新方法组的GMV平均高了3%。

- 是培训方法真的有效?
- 还是你选的那5个团长恰好是top performer?

如果你把这5个团长的名字写在纸条上,放帽子里抽——每次抽5个,抽1000次,看"培训组比对照组高3%"在第几次抽到的人里出现。如果只有很少的几次(比如<50次),说明"3%的差异不太可能是碰巧",培训确实有效。

**这个"很少的次数"/"总共抽的次数"的比例,就是p值的直观解释。**

## 二、核心概念

### 2.1 p值到底是什么

> **p值 = 如果两个算法效果完全相同,观察到当前差异(或更极端差异)的概率**

不是"算法更好的概率",也不是"差异不显著的概率"。

**关键理解:**
- p=0.0003: 如果算法和运营真的一样,你只有万分之三的概率看到这么大差异 → 太低了,倾向于认为"算法真的更好"
- p=0.88: 如果算法和运营真的一样,你有88%的概率看到当前差异 → 很正常,倾向于认为"其实没差异"
- p=0.04: 如果算法和运营真的一样,4%的概率看到 → 确实低,但不太稳

**常见误解:**

| 误解 | 正确理解 |
|------|---------|
| "p=0.03说明算法有97%的概率更好" | p值不是概率,不描述算法好坏的概率 |
| "p>0.05说明没效果" | 可能是样本不够大,效果太小,或者确实没效果 |
| "p值越小=效果越大" | p值受样本量影响巨大,n=10万时0.1%的差异也能p<0.001 |
| "p<0.05就上线" | 还要看CI(模块04)、护栏指标(履约成本/损耗率)、细分分析(模块06) |

### 2.2 三种检验方法在社区团购中的应用

| 方法 | 适用指标 | 为什么 |
|------|---------|--------|
| **t检验** | GMV、履约成本率、损耗率、退货率、爆品占比 | 近似正态,大样本下CLT保证 |
| **Mann-Whitney U** | 人均件数 | 件数是计数型数据(1,2,3...15),分布不规则 |
| **卡方检验** | 首单转化率 | 二分类(转化/未转化) |

### 2.3 为什么件数要用Mann-Whitney U?

件数的分布长这样:
```
件数=1: ████████          (很多人只买1个爆品)
件数=2: ██████████████
件数=3: ████████████████████ ← 最多人买3-4件
件数=4: ██████████████████
件数=5: ██████████
...
件数=15: █ (偶尔有团购大单)
```

这是典型的**右偏+离散分布**。用t检验不如Mann-Whitney U稳定——后者比较的是秩(rank)而非原始值,不依赖正态假设。

### 2.4 效应量: p值的必要搭档

代码里同时输出了p值和效应量:

- t检验 → Cohen's d: d=0.2小/0.5中/0.8大
- M-W U → Rank-Biserial相关性: 0.1弱/0.3中/0.5强

在社区团购里,即使GMV的d值很小(比如0.05),只要样本量够大、p<0.05,仍然可信。但你需要意识到"效果很小",业务决策时要综合考虑。

## 四、输出解读

```
  人均GMV             t-test          3.34e-04    YES     +1.96%
  人均件数             Mann-Whitney U  2.15e-03    YES     +2.01%
  履约成本率           t-test          1.82e-06    YES     +2.82%  ← 注意!
  生鲜损耗率           t-test          1.21e-01    NO      +0.75%
  退货率               t-test          1.56e-01    NO      +1.01%
  首单转化率           Chi-squared     3.45e-08    YES     +10.73%
  爆品GMV占比          t-test          1.08e-02    YES     +1.47%
```

关键解读:

**(1) 北极星(GMV):** p=0.0003,显著。算法比运营好。

**(2) 护栏(履约成本率):** p<0.001,显著,**但方向是坏的**——履约成本率上升了2.82%。这意味着算法推荐了更多远距离供应商的商品。GMV涨了但履约成本也涨了,净利润未必改善。**等模块04的CI分析来确认严重程度。**

**(3) 损耗率+退货率:** 不显著,没有明确恶化——好消息。

**(4) 首单转化率:** 算法组首单转化率高了10.7%,效果很大——个性化推荐对新用户更友好。

**初步判断: 效果有,但履约成本率上升是隐患。需要分城市看(模块06)来做最终判断。**

## 五、面试怎么讲

**面试官:"解释一下p值。p=0.03是什么意思?"**

> "p=0.03意味着:如果两个策略其实完全一样(零假设为真),我们只有3%的概率观察到当前这么大的差异。
>
> 翻译成人话就是:'这个差异不太像是运气导致的'。所以我们倾向于拒绝零假设,认为策略间确实存在差异。
>
> 但p值不告诉我们效果的大小。在我做的推荐策略实验中,GMV lift=1.96%,p=0.0003——效果其实只有2%,但因为样本量大(40000用户),p值非常小。所以p值要配合效应量和置信区间一起看,单独的p值给不了完整结论。"

**面试官:"t检验和Mann-Whitney U什么时候用哪个?"**

> "t检验假定数据近似正态分布。Mann-Whitney U不依赖这个假设,基于秩的比较。
>
> 在社区团购A/B实验里,GMV和履约成本率这类连续指标,大样本下用t检验没问题(中心极限定理)。
> 但件数(1到15件)是计数型+右偏分布,用Mann-Whitney U更合适——我不会因为它'不是正态'就硬套t检验。
>
> 实际工作中,我两种方法都会跑。如果结论一致(都显著或都不显著),更有信心;如果不一致,优先信Mann-Whitney U的结果。"
