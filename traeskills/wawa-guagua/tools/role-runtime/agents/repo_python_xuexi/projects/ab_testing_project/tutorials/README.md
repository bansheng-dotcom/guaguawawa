# 社区团购「今日爆品」A/B实验 — 完整教程索引

## 这个项目在讲什么

你是美团优选的数据分析师。首页「今日爆品」坑位(每天6-8个核心SKU)是最大的流量入口，
目前由各城市运营团队手动选品——今天推什么,全靠运营经验和供应商排期表。

产品经理想把选品逻辑换成算法个性化推荐。城市运营团队不乐意了：
"我干这行三年了,本地人爱吃啥、今天市场上什么便宜,我心里有数。算法懂个屁。"

老板问你：**"到底算法准还是运营准?能不能用数据说话?"**

这就是这套A/B实验要做的事 — **用统计方法把"我觉得"变成"数据证明"。**

## 跟你简历的关联

这个项目的设计逻辑**直接对照你在拼多多买菜的实际经验**：

| 你的简历经验 | 项目中的对应 |
|-------------|------------|
| 商品分层模型覆盖18种场景 | 爆品选品策略 — 分城市等级效果差异 |
| 量价利监控模型 | 护栏指标:履约成本率+生鲜损耗率 |
| 生鲜损耗率降15% | 实验的护栏指标 — 算法有没有推高损耗品? |
| 本地直采占比提升20% | 辛普森悖论根因 — 低线城市供给约束导致算法失效 |
| 区域生鲜GMV年环比增22% | 实验效果归因 — 一线城市算法提升明显 |

**面试官问你"有没有做过A/B实验",你可以用这个项目回答,而且所有细节都能跟你拼多多的经历对上。**

## 学习路径

```
实验前:  01 实验设计  → 需要多少用户?跑多久?用什么指标评判?
         02 AA验证    → 分流系统公平吗?(两拨用户一样吗?)

实验后:  03 假设检验  → 算法真的赢了吗?p值告诉你什么
         04 置信区间  → 效果多大?最坏情况会怎样?
         05 多重检验  → 测了7个指标,有几个是真显著?

深入:   06 辛普森悖论 → 整体有效=所有城市都有效?
                         └─ 一线城市+8%,三五线-2% ← 这就是为什么分城策略重要

输出:   07 综合报告  → 把一切串成老板看得懂的报告
```
