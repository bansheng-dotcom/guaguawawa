# 04 Python经营看板

---

## 一、这个模块干什么

把前面三个模块的结果做成**老板能一眼看懂的图**。

三屏结构：
- **高管概览屏**（左上+右上）：GMV趋势、北极星达成——老板只看这两张
- **经营分析屏**（中间）：履约成本/损耗趋势、品类占比——运营经理看
- **异动监控屏**（下方）：团长分层、城市对比——BD团队看

---

## 二、6张图的布局逻辑

```
┌──────────────────────┬──────────────────────┐
│ 图1: GMV月度趋势      │ 图2: 北极星达成       │
│ 柱子=每月GMV          │ 绿色=达标(≥26元)     │
│ 红线=环比变化          │ 黄色=接近            │
│ 异常标注:暴雨/中秋/双11│ 红色=未达标          │
│ → 高管概览(钱)        │ → 高管概览(北极星)   │
├──────────────────────┼──────────────────────┤
│ 图3: 履约成本&损耗率  │ 图4: 品类GMV占比      │
│ 红线=8.5%履约上限     │ 饼图                  │
│ 橙线=5%损耗上限       │ → 经营分析(品类)      │
│ → 经营分析(护栏)     │                      │
├──────────────────────┼──────────────────────┤
│ 图5: 团长分层贡献     │ 图6: 城市维度对比     │
│ 堆积柱状图            │ 绿=一线 蓝=三五线      │
│ 绿色=头部20%         │ → 异动监控(城市)      │
│ → 异动监控(团长)     │                      │
└──────────────────────┴──────────────────────┘
```

## 三、代码导读

打开 [04_dashboard.py](../04_dashboard.py)：

### 图1: 双轴图（第60-80行）

```python
ax1.bar(months, monthly['gmv_wan'], ...)  # 柱子=GMV
ax1b = ax1.twinx()                          # 创建第二个Y轴
ax1b.plot(months, monthly['mom_gmv_change'], 'o-', color='#E74C3C')  # 红线=环比
```

`twinx()` 让你的图有两个Y轴——左边是GMV(万元)，右边是环比变化(%)。

### 图3: 双线+双红线（第105-115行）

```python
ax3.fill_between(months, monthly['fulfill_cost_rate'], alpha=0.3, color='#E74C3C')
ax3.axhline(y=8.5, color='red', linestyle='--')  # 履约成本红线
ax3.axhline(y=5.0, color='orange', linestyle='--')  # 损耗率橙线
```

`fill_between` 填充区域，`axhline` 画水平参考线。

### 颜色选择

- 绿色(#2ECC71) = 好(达成/增长)
- 红色(#E74C3C) = 坏(未达成/成本上升)
- 蓝色(#3498DB) = 中性(规模/基础数据)

## 五、面试怎么讲

**面试官："你们的数据看板是怎么做的？"**

> "我搭了三屏结构：高管概览(核心KPI趋势+北极星达成)、经营分析(履约成本/损耗趋势+品类结构)、异动监控(团长分层+城市对比+异常标记)。
>
> 技术实现是用Python matplotlib出的图，优势是可以完全自动化——每天跑一次脚本更新看板图表，不需要手工做日报。
>
> 如果团队有Tableau或PowerBI，同样的结构和数据源可以直接迁移过去。核心不是工具，是看板的结构设计——三屏分别对应三个角色(老板/运营/BD)的信息需求。"
