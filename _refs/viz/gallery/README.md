# 48 图静态参考画廊

本目录使用虚拟业务数据，把 48 条提示词转成可以直接观察的图表样张。它用于检查图形选择、结论标题、视觉样式、数据标注和解释边界，不代表真实业务结论。

## 本地查看

在仓库根目录运行：

```shell
python -m http.server 8000 --directory gallery
```

浏览器打开 `http://127.0.0.1:8000/`。

也可以直接打开 `index.html`。画廊使用随仓库保存的 ECharts 文件，不依赖远程脚本。

## 显示规则

- 宽屏每行 3 图，中等宽度每行 2 图，窄屏每行 1 图。
- 金额使用千分位，比例按图表语义保留必要小数。
- 地图使用虚拟业务分区 GeoJSON，不依赖远程边界文件。
- 数据全部为虚拟示例，不应引用为真实统计结论。
