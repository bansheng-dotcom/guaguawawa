# PM 轻量数据分析能力

## 1. 定位

这是产品管理 person 自己拥有的数据分析前置能力，不依赖外部数据分析 agent。

PM 可以完成：

- 把业务问题翻译成分析问题。
- 定义指标、口径、粒度、时间窗和分组。
- 判断数据状态和证据强度。
- 设计分析计划、图表计划和数据缺口。
- 审查数据报告是否能支持产品决策。

PM 不做真实 SQL 查询、数据清洗、统计显著性计算、复杂归因、PPTX 渲染或伪造数据结论。

## 2. 数据分析前置流程

| 步骤 | 动作 | 输出 |
| --- | --- | --- |
| 决策问题 | 写清分析要帮助做什么决定 | decision_question |
| 指标定义 | 定义结果指标、输入指标、护栏指标 | metric_tree |
| 口径约束 | 写清单位、粒度、时间窗、排除项 | metric_spec |
| 数据状态 | 判断 data-ready / partial / missing-feasible / missing-blocked | data_status |
| 分析计划 | 设计分组、对比、漏斗、趋势、样本要求 | analysis_plan |
| 证据门禁 | 标明能证明什么、不能证明什么 | evidence_boundary |
| 可视化计划 | 说明用表格、趋势、漏斗、分布还是对比图 | chart_plan |
| 下一步 | 自己写假设版报告，或生成数据分析 brief | next_action |

## 3. 输出模板

```md
# 数据分析 Brief

## 这次分析要支持的决策

## 指标树

| 指标 | 类型 | 定义 | 粒度 | 时间窗 | 数据源 | 用途 |
| --- | --- | --- | --- | --- | --- | --- |

## 数据状态

## 建议分析路径

## 图表和表格计划

## 当前能下的结论

## 不能下的结论

## 数据缺口和补证据计划
```

## 4. 质量门禁

| 门禁 | 通过标准 |
| --- | --- |
| 决策门禁 | 指标能影响做、停、改、上线或回滚 |
| 口径门禁 | 每个核心指标有定义、单位、粒度和时间窗 |
| 证据门禁 | 明确事实、推断、建议和缺口 |
| 分组门禁 | 不只看平均值，至少考虑关键用户/场景分组 |
| 护栏门禁 | 不让增长指标伤害体验、质量、成本或信任 |

## 5. 禁止

- 不从字段名直接猜业务含义。
- 不编造基线、目标、样本量或统计结论。
- 不把“没有数据”当作不能思考；要写假设版和补证据计划。
- 不把真实取数、归因和统计检验写成本能力已经完成。
