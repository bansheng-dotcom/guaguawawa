# 数据可视化提示词图鉴（高雅人士天团 · 图表标准）

本技能内置 **48 条经过人工审核的作图提示词全文**（43 个单一数据图表 + 5 个组合图），落在 `upstream/prompts/`，合集版在 `upstream/PROMPTS.md`，机器可读索引在 `upstream/prompts/index.json`。

**用法铁律：不要自己凭空写作图提示词。** 先按下方「选型表」定位图种编号，再读 `upstream/prompts/<编号>-<英文名>.md`，把其中的 `【】` 占位替换成真实字段与业务问题，然后把完整提示词交给作图执行方（自己或下游工具）。

---

## 一、什么时候启用

- 「这份数据该用什么图」——图表选型与替代方案
- 「帮我把这张图做专业/做好看」——美化规则与重点标注
- 「检查这张图」——口径、比例尺、标注遮挡、误导性审查
- 汇报/报告/看板需要成套图表规格
- 需要可直接复制执行的作图提示词（Excel / Python / HTML-ECharts）

**不启用**：需要完整归因与证据链的报告（走 qiuqiu-data-analysis）、需要产品判断（走 qiuqiu-product）。

## 四、一条提示词必须同时约束的六件事（审查清单）

任何交付的图表，按这六问逐条自检——这也是修复缺陷的入口：

1. **数据能不能画**：字段、单位、粒度、缺失值、统计口径是否一致？（缺失值不擅自补零）
2. **图形合不合适**：业务问题与数据结构是否匹配？什么情况下必须换图？
3. **计算对不对**：汇总、排序、分母、累计、统计区间是否合理？（瀑布图必做「起点+贡献=终点」对账）
4. **标注清不清楚**：重点值、异常点、转折点、样本量、解释边界放在哪？
5. **视觉专业不专业**：颜色、留白、坐标轴、边框、字体、图例；禁用 3D、装饰渐变、重阴影、彩虹色。
6. **结果怎么验收**：返回什么（成品文件 / 可运行代码 / 汇总数据），成品应检查什么。

## 五、制作流程（五步）

1. **定问题**：这张图要回答哪一句业务问题（写成结论句的雏形）。
2. **验数据**：字段核对 → 口径确认 → 缺失与异常处理方式声明；不可画时先停下来说明。
3. **选定图种**：按选型表命中文档，读该 prompt 全文。
4. **替换占位并执行**：`【文件名】【工作表】【类别字段】【指标字段】【业务问题】【输出工具】` 等全部落实，不留占位符。
5. **交付与自检**：返回「图表成品/可运行代码 + 用于作图的汇总数据 + 一句核心发现 + 排序/配色/标注说明」，再按六问复盘。

---

## 六、硬性规则

- 先保证数据与统计口径正确，再讨论美观。
- 标题写结论，副标题补时间、单位、口径。
- 普通信息克制，只突出真正需要读者看到的差异（一个主色 + 一个强调色）。
- 不为强行作图伪造数据；不把相关关系写成因果；不以美观为由改指标口径。
- 标签拥挤时优先加空间/筛选/拆图，不靠缩小字号硬塞。
- 不覆盖原始数据文件；不能直接产出文件时，明确说明并给可运行代码或编号步骤，不谎称已生成。
