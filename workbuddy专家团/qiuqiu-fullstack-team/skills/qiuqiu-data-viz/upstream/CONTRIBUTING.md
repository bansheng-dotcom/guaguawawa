# 参与改进

这个项目欢迎基于真实做图问题提出改进建议。当前优先通过 GitHub Issue 收集问题和证据，再决定是否修改公共提示词。

## 适合提交的问题

- 图表与业务问题不匹配；
- 字段、单位、粒度或统计口径容易被误解；
- 百分比、累计值、样本量或统计区间计算错误；
- 标签、图例、标题或注释出现遮挡和歧义；
- 颜色、比例尺、双轴或图形面积可能误导；
- 提示词缺少必要的输出、检查或拒绝条件。

## 提交时请提供

1. 图表名称和对应编号；
2. 想回答的业务问题；
3. 数据结构、字段、单位和必要口径；
4. 当前结果的问题；
5. 建议增加、删除或改写的规则；
6. 脱敏截图、虚拟数据或可复现步骤。

请勿上传个人信息、公司机密、真实客户数据、访问令牌或其他敏感内容。

## 评审标准

改动进入公共版本前，需要同时满足：

- 不改变原始数据含义；
- 适用于不止一个特定页面或数据集；
- 能明确说明适用与不适用场景；
- 不以缩小字体、堆叠标签或装饰效果掩盖结构问题；
- 有检查项或示例证明修改解决了原问题；
- 不破坏其他图表提示词的口径和命名一致性。

## 许可证边界

仓库目前没有开源许可证。请优先提交问题描述、脱敏复现和规则建议，不要直接提交来源不明或受版权限制的大段材料。
