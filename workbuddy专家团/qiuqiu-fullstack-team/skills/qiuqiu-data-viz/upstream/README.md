# AI 数据可视化提示词图鉴

一套面向 AI 做图的数据校验、图表选择、专业美化与数据标注提示词标准。

![Prompts](https://img.shields.io/badge/prompts-48-2f6bff)
![Language](https://img.shields.io/badge/language-简体中文-159b83)

![AI 数据可视化提示词画廊预览](assets/gallery-overview.png)

这个项目收集并持续优化“让 AI 制作数据图表”的规范提示词。它既可以作为 AI 做图时的引用标准，也可以帮助刚接触数据可视化的人理解：一张图在制作之前要检查什么、应该怎样标注、如何避免误导，以及怎样判断成品是否合格。

## 你可以用它做什么

- **直接做图**：选择一种图表，复制对应提示词，替换 `【】` 中的内容。
- **约束 AI 输出**：把提示词作为图表生成 Agent、数据分析工作流或课程课件的视觉合同。
- **学习可视化**：从“什么时候用、需要准备什么、怎么检查”理解每种图的基本方法。
- **审查图表**：用提示词中的检查项发现口径错误、标签遮挡、比例尺误导和无效装饰。
- **继续优化规范**：通过 Issue 提交真实做图中的问题、截图和改进建议。

## 30 秒开始

不需要安装软件：

1. 打开 [完整提示词图鉴](PROMPTS.md)。
2. 按业务问题选择图表。
3. 复制提示词，并替换其中的 `【文件名】`、`【字段】`、`【业务问题】` 等占位内容。
4. 上传 Excel、CSV 或数据表，让 AI 直接生成文件或返回完整可运行代码。

如果只想查一种图，可以进入 [`prompts/`](prompts/) 使用独立提示词文件。

## 一条提示词解决哪些问题

每条提示词尽量同时约束六件事：

1. **数据是否能画**：字段、单位、粒度、缺失值和统计口径是否一致。
2. **图形是否合适**：业务问题与数据结构是否匹配，何时应该换图。
3. **计算是否正确**：汇总、排序、分母、累计值和统计区间是否合理。
4. **标注是否清楚**：重点值、异常点、转折点、样本量和解释边界放在哪里。
5. **视觉是否专业**：颜色、留白、坐标轴、边框、字体和图例如何处理。
6. **结果如何验收**：返回什么文件、表格或代码，以及成品应该检查什么。

## 使用示例

假设你要比较不同产品的销售额：

1. 打开 [`prompts/01-vertical-bar-chart.md`](prompts/01-vertical-bar-chart.md)。
2. 把文件、工作表、类别字段、指标字段和业务问题填入提示词。
3. 指定使用 Excel、Python 或 HTML/ECharts。
4. 要求 AI 同时返回图表、汇总数据和检查结论。

提示词会要求 AI 先核对统计口径，再处理排序、配色、数据标签和异常说明，而不是只调用一个默认图表函数。

## 可视化画廊

[`gallery/`](gallery/) 提供 48 张图的静态参考画廊。画廊数据均为虚拟示例，只用于检查图形选择、专业美化、数据标注和解释边界。

本地预览：

```shell
git clone https://github.com/bzwh321/ai-data-visualization-prompts.git
cd ai-data-visualization-prompts
python -m http.server 8000 --directory gallery
```

## 设计原则

- 先保证数据和统计口径正确，再讨论美观。
- 标题优先表达结论，副标题补充时间、单位和口径。
- 普通信息保持克制，只突出真正需要读者看到的差异。
- 缺失值不擅自补零，相关关系不自动解释成因果关系。
- 标签拥挤时优先增加空间、筛选对象或拆图，不靠缩小字体硬塞。
- 不使用 3D、装饰渐变、重阴影和彩虹色掩盖信息。
- 每次新增规则都应来自真实问题、人工审图或可复现的失败案例。

## 如何参与优化

如果你遇到某种图表的标签遮挡、口径歧义、错误计算或表达不清，可以阅读 [贡献指南](CONTRIBUTING.md)，然后提交 Issue。

一个有价值的改进建议通常包括：

- 使用的图表和业务问题；
- 数据字段、单位与结构；
- 当前提示词生成结果的问题；
- 期望增加或修改的规则；
- 脱敏后的截图、数据样例或复现步骤。
