# 03｜怎么让 AI 制作一张专业的分组柱状图

## 学会什么

在同一类别下比较两到三个同单位系列，同时让读者区分“组内差异”和“类别之间的差异”。

## 什么时候用

适合每个类别包含 2～3 个可比系列，例如今年与去年、实际与目标、男性与女性。不适合系列过多或量纲不同。

## 需要准备

- 类别字段、系列字段和指标字段
- 汇总方式、单位和系列顺序
- 重点类别或重点系列
- 输出工具与格式

## 提示词

```text
请读取【文件名】的【工作表】，以【类别字段】为分组，以【系列字段】区分【2～3】个系列，对【指标字段】按【汇总口径】计算，制作分组柱状图并回答【业务问题】。开始前检查各系列单位和统计口径是否一致；若系列超过 3 个、类别过多或量纲不同，请先说明并建议拆图、小多图或其他方案，不要把不可比数据放进同一组。

请使用【Excel/Python/HTML-ECharts/其他工具】直接创建图表：纵轴从 0 开始；同组柱之间距离小于组间距离；所有类别中的系列顺序和颜色保持完全一致；类别按【业务顺序/重点指标降序】排列。整体采用白色或近白背景、深色文字和两到三个协调的系列色，重点对象只通过一个强调色或描边突出，不使用 3D、渐变、阴影和厚重网格。

标题写成结论句，副标题写明统计期间、单位和系列口径。优先在关键类别上直接标注两组数值及差值或变化率；如果全部标注会拥挤，只保留最大差异、异常类别和最新一期的标签，其余通过悬停或数据表提供。金额使用千分位，比例保留【1】位小数，标签不得遮挡柱体或互相重叠。

完成后返回：另存的图表文件或可运行代码、分组汇总数据、差异最大的三个类别，以及配色、排序和标签取舍说明。
```

## 你会得到

一张系列顺序稳定、组内差异清楚的分组柱状图，并附带重点差异清单。

## 怎么检查

- 所有系列单位一致，颜色顺序没有变化。
- 组内和组间距离能够被清楚区分。
- 没有因为标签过多而遮挡柱体。
- 图表结论由可见数据支持。
