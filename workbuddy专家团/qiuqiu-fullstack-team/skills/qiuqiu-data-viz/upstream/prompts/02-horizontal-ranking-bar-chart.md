# 02｜怎么让 AI 制作一张清晰的排名横条图

## 学会什么

用横条图展示 Top N 排名，兼顾长类别名称、精确数值和重点对象标注。

## 什么时候用

适合类别较多、名称较长，或读者需要快速查看高低排名的场景。不适合有严格时间顺序的数据。

## 需要准备

- 类别字段、排名指标和统计口径
- 展示 Top N 还是全部类别
- 是否有需要特别强调的对象
- 输出工具与格式

## 提示词

```text
请读取【文件名】的【工作表】，按【指标字段】的【求和/平均值/其他口径】计算【类别字段】的数值，制作一张排名横条图，展示【Top N/全部类别】并回答【业务问题】。请先处理缺失值、重复类别和单位，核对排序方向；如果类别具有连续时间顺序，先停止并说明为什么不适合按排名重排。

请直接使用【Excel/Python/HTML-ECharts/其他工具】创建并美化图表：默认按数值从高到低排列，最大值位于最上方；为左侧类别名称预留足够空间，不随意截断或强制多行；条形长度必须与数值一致，正负值同时存在时以 0 为共同基线。采用简洁专业的白色或近白背景，普通条形使用同一主色或灰阶，只用一个强调色突出【Top1/指定类别/异常类别】。

请在每个条形末端直接标注数值和单位，金额使用千分位，比例保留【1】位小数；重点条形增加一条不超过两行的结论注释。标题使用结论句，副标题注明统计期间、Top N 规则和数据口径；不保留重复图例，不使用彩虹色、3D、阴影或装饰图标。

完成后返回：新图表文件或可运行代码、排序后的图表数据、核心发现，以及未展示类别的数量和处理方式。标签、条尾数值或类别名出现裁切时必须调整画布后再交付。
```

## 你会得到

一张可直接用于排名汇报的横条图，以及完整排序数据和 Top N 说明。

## 怎么检查

- 排名顺序和数值完全一致。
- 类别名、条尾数值没有裁切。
- 未展示类别和 Top N 规则已说明。
- 颜色只突出真正需要关注的对象。
