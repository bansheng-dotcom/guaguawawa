# 32｜怎么让 AI 制作一张日历热力图

## 学会什么

按真实星期和月份排列每日数据，识别周期性、连续高低值和异常日期。

## 什么时候用

适合跨周、跨月的每日强弱数据。不适合日期不连续或只有少量时点的情况。

## 需要准备

- 日期字段、指标字段和汇总口径
- 日期范围、单位和缺失日期含义
- 重点日期或异常阈值
- 输出工具与格式

## 提示词

```text
请读取【文件名】的【工作表】，按【日期字段】汇总【指标字段】，制作日历热力图，分析周内周期、连续高低值和异常日期并回答【业务问题】。先生成完整日期序列，明确区分“真实 0 值”和“缺失日期”；核对时区、统计日边界、重复日期和单位。日期过少或不连续时停止并建议折线图。

请使用【Python/HTML-ECharts/其他工具】直接创建：日期按真实星期位置和月份边界排列；使用可解释的单色明度阶梯，异常高值或用户指定日期使用强调边框，不使用彩虹色。图例写清色阶区间、单位、0 值和缺失值颜色；月份和星期标签完整，方格大小与间距统一。

只标月份、星期、极值、连续异常区间和【指定日期】，精确日值放入悬停提示或旁表；标题使用结论句，副标题注明日期范围、聚合方式、单位和缺失值处理。标签不得塞入每个小方格或遮挡月份边界。

完成后返回：新图表文件或可运行代码、完整日期数据、缺失日期清单、最高最低日期、周期性发现和色阶说明。
```

## 你会得到

一张日期对齐正确、缺失值和 0 值可区分的日历热力图。

## 怎么检查

- 月份边界和星期位置正确。
- 缺失日期没有被当作 0。
- 色阶图例能够解释数值。
- 重点日期可识别但未挤满标签。
