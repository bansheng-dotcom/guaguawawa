# 19｜怎么让 AI 制作一张可读的热力矩阵图

## 学会什么

用颜色深浅展示两个维度交叉后的高低模式，并同时保证色阶、单元格数值和轴标签可读。

## 什么时候用

适合二维分类轴与一个数值组成的矩阵，例如星期×时段、产品×地区、变量相关矩阵。

## 需要准备

- 行字段、列字段、数值字段
- 聚合口径、排序和色阶含义
- 重点单元格或阈值
- 输出工具与格式

## 提示词

```text
请读取【文件名】的【工作表】，以【行字段】和【列字段】构建矩阵，将【数值字段】按【汇总口径】填入单元格，制作热力图并回答【业务问题】。先检查重复组合、缺失组合、单位和聚合口径；缺失值必须与真实的 0 区分。若矩阵很小且需要精确读取全部数值，请说明普通数据表可能更合适。

请使用【Excel/Python/HTML-ECharts/其他工具】直接创建图表：行列按【业务顺序/数值模式/聚类结果】排列并说明；使用可解释的单色连续色阶或以 0 为中心的发散色阶，不使用彩虹色。色标必须显示最小值、最大值和关键阈值；只用边框或强调色突出【峰值/异常单元格】，不改变其真实色阶。

单元格空间足够时直接标数值，文字颜色根据底色自动切换深浅；矩阵过密时只标重点值并保留悬停信息。轴标签完整可读，优先扩大画布或缩短措辞，不旋转成难以阅读的角度。标题使用结论句，副标题注明时间、单位、聚合和缺失值处理。

完成后返回：新图表文件或可运行代码、矩阵数据、色阶范围、最高/最低单元格、缺失组合和排序说明。
```

## 你会得到

一张颜色与数值对应清楚、重点单元格可识别的热力图。

## 怎么检查

- 色阶和数值方向一致，没有使用彩虹色。
- 缺失值与 0 的显示不同。
- 数字和底色对比足够。
- 行列顺序有业务或分析依据。
