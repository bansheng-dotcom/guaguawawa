# 独立提示词目录

本目录将完整图鉴拆成 48 个可单独引用的 Markdown 文件。每个文件包含：

- 学会什么；
- 什么时候用；
- 需要准备；
- 可直接复制的提示词；
- 你会得到什么；
- 成品怎么检查。

## 分组

| 编号 | 分组 |
| --- | --- |
| 01～14 | 基础比较、趋势与构成 |
| 15～26 | 分布、关系与统计 |
| 27～36 | 业务过程、贡献与时间 |
| 37～43 | 层级、空间、网络与特殊图 |
| 44～48 | 复杂组合图 |

程序或 Agent 可以读取 [`index.json`](index.json) 获得提示词 ID、标题、难度、分组和相对文件名。
