# 25｜怎么让 AI 制作一张规范的森林图

## 学会什么

用水平点区间比较多个估计值、效应量或回归系数及其置信区间。

## 什么时候用

适合每个项目都有点估计、下界和上界，并存在明确无效应基线的场景。

## 需要准备

- 项目名称、估计值、区间下界和上界
- 效应量单位、置信水平
- 无效应基线 0 或 1
- 分组、排序和输出工具

## 提示词

```text
请读取【文件名】的【工作表】，使用【项目字段】、【估计值】、【下界】和【上界】制作森林图，比较各项【效应量/均值/回归系数】及其【置信水平】区间并回答【业务问题】。先核对上下界顺序、单位、置信水平和效应量类型；明确无效应基线为【0/1】。若缺少区间、不同项目使用不同效应尺度且未转换，请停止作图。

请使用【Python/HTML-ECharts/其他工具】直接创建：采用水平点区间布局，点表示估计值，细线和端帽表示区间；增加清晰但克制的无效应竖线。项目按【业务顺序/估计值/分组】排列，普通项使用主色或灰色，重点估计使用强调色；分组标题和留白清楚，不使用粗柱、3D、渐变或装饰阴影。

请在点旁直接标估计值，右侧以统一格式显示“估计值【下界，上界】”；标题使用结论句，副标题说明效应量、单位、置信水平、样本和无效应基线。只对区间跨越基线、最强效应或指定项目增加简短注释；不得把区间未跨线直接改写成因果结论。

完成后返回：新图表文件或可运行代码、排序后的估计表、跨越无效应基线的项目、核心发现和解释边界。
```

## 你会得到

一张估计值、区间和无效应基线清楚的森林图。

## 怎么检查

- 无效应基线与效应量类型匹配。
- 置信水平和单位已经写明。
- 区间、端帽和标签没有遮挡。
- 图表没有把统计关联写成因果。
