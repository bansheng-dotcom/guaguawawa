# 渭河-专家团

跨产品策略、数据洞察、可视化表达与报告叙事的 Team 型专家团。适用于把模糊业务问题整理为可决策、可执行、可复盘的咨询成果。

## 团队构成

| 成员 | 角色 | 主要职责 |
|---|---|---|
| 渭总管 | 决策整合总监 | 编排协作、识别跨域依赖、汇总最终建议 |
| 渭有品 | 产品策略顾问 | 需求澄清、MVP、指标、PRD、验收与取舍 |
| 渭究因 | 数据洞察分析师 | 假设驱动分析、取数计划、归因、证据链 |
| 渭作图 | 数据可视化设计师 | 图表选型、字段编码、阅读路径、图表质检 |
| 渭叙事 | 报告叙事主编 | 报告结构、逻辑审校、叙事编辑、终稿门禁 |

## 适用场景

- 把业务问题拆成产品、数据、图表和报告交付方案。
- 分析需求并明确数据支撑、指标与管理层汇报结构。
- 审阅并升级已有分析报告、仪表盘、PPT 或复盘材料。

## 使用示例

- 请把我的业务问题拆成产品判断、数据分析、图表表达和报告交付方案。
- 请分析这份需求，明确需要哪些数据，并设计一份管理层报告结构。
- 请审阅我的分析报告，优化逻辑、图表选择和面向管理层的叙事表达。

## 内置技能

| 技能 | 分配角色 | 来源 |
|---|---|---|
| weihe-product-strategy | 渭有品 | product-manager-agent-project（产品管理控制器） |
| weihe-data-analysis | 渭究因 | data-analysis-report-agent（假设驱动数据分析） |
| weihe-data-viz | 渭作图 | ai-data-visualization-prompts（48 图提示词图鉴） |
| weihe-article | 渭叙事 | article-director（多 Agent 文章写作工作流） |
| weihe-consulting | 渭总管 | 团队协作工作流与输出模板 |

## 分类说明

专家团的主要交付物是跨产品、数据、内容表达的“决策咨询成果”，因此使用 `12-IndustryConsultant`，而非只归入产品设计或数据智能。

## 头像

当前团队、主理人与成员统一使用现有头像文件。可按需替换为 PNG/JPG 格式的 512×512 图像，单张不超过 500KB。
