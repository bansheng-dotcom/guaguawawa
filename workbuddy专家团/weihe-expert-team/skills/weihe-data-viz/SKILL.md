# 数据可视化提示词图鉴

本技能收录 48 个可视化提示词包，来自 `ai-data-visualization-prompts` 开源图鉴。每个提示词文件包含：学会什么、什么时候用、需要准备、可直接复制的提示词、你会得到、成品怎么检查。

## 文件索引

- `prompts/index.json`：全部 48 个提示词的 ID、标题、难度和相对文件名，程序化查找入口。
- `PROMPTS.md`：完整图鉴（48 图汇总）。
- `prompts/{NN}-{chart-type}.md`：单图提示词，按编号引用。

## 分组

| 编号 | 分组 | 适用图表 |
|---|---|---|
| 01-14 | 基础比较、趋势与构成 | 柱状图、横条图、堆叠图、折线图、面积图、饼图、环形图 |
| 15-26 | 分布、关系与统计 | 直方图、斜率图、散点图、气泡图、箱线图、小提琴图、热力图 |
| 27-36 | 业务过程、贡献与时间 | 瀑布图、帕累托图、漏斗图、仪表图、甘特图、K线图、桑基图 |
| 37-43 | 层级、空间、网络与特殊图 | 树图、旭日图、地图、网络图、玫瑰图 |
| 44-48 | 复杂组合图 | 双轴柱线图、KPI 趋势拆解、小倍数图等 |

## 使用流程

1. 明确业务问题与数据结构（比较/趋势/构成/分布/关系/过程）。
2. 在 `prompts/index.json` 中按编号定位最匹配的图表提示词。
3. 读取对应 `prompts/{NN}.md`，将【字段】占位替换为用户真实数据字段与口径。
4. 输出图表时附带：汇总数据、一句核心发现、排序/配色/标注说明。
5. 用该文件的“怎么检查”清单做质量门禁：坐标起点、单位口径、重点标注、标签不重叠、无误导编码。

## 输出规范

- 每张图先给业务问题与图表类型匹配理由，再给字段映射。
- 数据不完整时给出占位策略与缺口，不虚构数值。
- 需要空间数据/地图时先核实合规、边界和坐标来源。
- 所有图表标题写成结论句，副标题补充统计时间、单位与口径。
