# 39｜怎么让 AI 制作一张区域分级设色地图

## 学会什么

把地区指标匹配到可靠地图边界，用颜色深浅展示空间分布和区域差异。

## 什么时候用

适合地域本身是分析问题核心的省、市、区县比较。仅做地区排名时横条图通常更直接。

## 需要准备

- 地区名称或标准行政区代码
- 指标、单位和聚合口径
- 本地 GeoJSON 或可靠地图边界
- 分级方法、重点区域和输出工具

## 提示词

```text
请读取【文件名】的【工作表】，按【地区字段】汇总【指标字段】，使用【本地 GeoJSON/可靠地图边界文件】制作区域分级设色地图，分析空间分布并回答【业务问题】。先标准化地区名称或行政区代码，检查无法匹配、重复、缺失地区和单位；没有可靠边界文件或地域不是问题核心时停止，并建议排名横条图。

请使用【Python/HTML-ECharts/其他工具】直接创建并完成专业美化：数值通过可解释的单色明度阶梯映射，分级使用【等距/分位数/自然断点/业务阈值】并说明；缺失地区使用中性灰，不能与真实 0 混淆。重点区域使用强调描边或点标，不使用彩虹色、3D、浮雕和远程依赖导致离线失效的地图资源。

只标重点区域、最大最小值和用户指定区域，完整排名放在旁边列表；图例写清区间、单位、分级方式和缺失值。标题使用结论句，副标题注明时间、地理层级、指标口径和数据来源；小区域标签重叠时使用局部放大或旁表。

完成后返回：新图表文件或可运行代码、地区汇总表、地图匹配成功率、未匹配地区、分级区间、重点区域和地图来源说明。
```

## 你会得到

一张地图匹配、色阶和缺失地区含义清楚的区域地图。

## 怎么检查

- 地区匹配成功率和未匹配项已说明。
- 0 值与缺失值颜色不同。
- 色阶区间、单位和分级方法明确。
- 地图可离线使用或资源来源稳定。
