# 46｜怎么让 AI 制作一张谨慎使用的双轴柱线图

## 学会什么

在共享类别或时间上同时展示一个绝对量和一个比率，并防止双轴范围制造虚假相关。

## 什么时候用

适合数量与比率存在明确解释关系且必须在同图阅读。不满足时应拆成上下两张图。

## 需要准备

- 共享类别或时间
- 柱形指标、折线指标及各自单位
- 业务关系、轴范围和重点时点
- 输出工具与格式

## 提示词

```text
请读取【文件名】的【工作表】，以【类别/时间】为横轴，用柱形展示【绝对量指标】，用折线展示【比率或不同单位指标】，制作双轴柱线图并回答【业务问题】。先核对两个指标的时间、样本和业务关系；如果只是碰巧同向、没有解释关系，或拆成上下两图更清楚，请优先拆图。不得为了让两条趋势看起来吻合而调整轴范围。

请使用【Excel/Python/HTML-ECharts/其他工具】直接创建：柱绑定左轴且左轴从 0 开始，折线绑定右轴并采用有业务依据的范围；轴标题、刻度颜色和单位与系列对应。柱和线使用两种稳定颜色，唯一重点时点使用强调色；去掉多余图例、3D、渐变、阴影和密集网格。

请直接标注重点柱值、折线终点、拐点和异常时点；标题使用克制的结论句，副标题注明两个指标、单位、轴范围和统计口径。若标题涉及关系，只能写“同步变化/背离”等数据事实，不自动写成因果。

完成后返回：新图表文件或可运行代码、两个指标数据、轴范围及理由、重点时点、核心发现和“是否应拆图”的判断。
```

## 你会得到

一张左右轴对应明确、不会刻意制造相关的柱线图。

## 怎么检查

- 柱形、折线与左右轴对应清楚。
- 左轴从 0 开始。
- 右轴范围有业务依据。
- 标题没有夸大两个指标的关系。
