# 41｜怎么让 AI 制作一张地理流向图

## 学会什么

在地图上用有方向的连线展示城市或区域之间的迁移、运输或交易流量。

## 什么时候用

适合有可靠起终点坐标、方向和权重的少量主要通道。流线过多或地域不重要时不适合。

## 需要准备

- 起点、终点、经纬度和流量
- 方向、单位、时间范围和 Top N 规则
- 地图资源、重点通道和输出工具

## 提示词

```text
请读取【文件名】的【工作表】，使用【起点】、【终点】、对应经纬度和【流量字段】制作地理流向图，展示【迁移/运输/交易】的主要通道并回答【业务问题】。先检查起终点坐标、方向、重复路线、缺失坐标、流量非负和单位；没有可靠坐标、流线过多或地域不是问题核心时停止并建议桑基图或排名图。

请使用【Python/HTML-ECharts/其他工具】和【本地/稳定地图资源】直接创建：线宽映射流量，方向只采用清晰箭头或单一方向编码，不同时堆叠多种动画；保留【Top N】主通道，其他流线低透明度或合并。主通道使用强调色，其余使用弱色，起终点符号清楚，不使用 3D 地球、粒子特效、渐变和闪烁。

请直接标注核心起点、终点和主通道数值，完整路线放在旁表或悬停；图例说明线宽、方向和单位。标题使用结论句，副标题注明时间、Top N、坐标来源和流量口径；流线交叉严重时调整曲率、分面或拆图，不得形成不可读的线网。

完成后返回：新图表文件或可运行代码、路线表、坐标问题、Top N 通道、未展示流量占比和布局说明。
```

## 你会得到

一张方向和流量映射清楚的地理流向图。

## 怎么检查

- 起终点坐标和方向正确。
- 线宽与流量一致。
- 主通道有数值标注。
- 流线没有交叉成不可读的网络。
