# 07｜怎么让 AI 制作一张强调量级变化的面积图

## 学会什么

用面积图在展示趋势的同时强调量级或累计规模，并控制填充透明度和基线，避免视觉面积夸大变化。

## 什么时候用

适合非负的单一主系列或明确的累计量。不适合存在负值、多系列严重遮挡或需要精确比较点值的情况。

## 需要准备

- 时间字段、指标字段和统计口径
- 单位、时间粒度和是否为累计值
- 重点时点或业务事件
- 输出工具与格式

## 提示词

```text
请读取【文件名】的【工作表】，按【时间粒度】汇总【指标字段】，制作一张面积图，展示【业务指标】随时间的量级变化并回答【业务问题】。开始前核对指标是否为非负值、是否属于累计量或规模指标、时间间隔是否连续；若存在负值、需要比较多个重叠系列或重点是精确点值，请停止并建议使用折线图或其他更合适的图。

请使用【Excel/Python/HTML-ECharts/其他工具】直接创建图表。纵轴从 0 开始，折线保持清晰，面积填充使用主色的低透明度版本，不能遮住网格、标签和参考线；只保留一个主系列，必要的比较系列改用细折线而不是第二块厚重面积。背景保持白色或近白，删除 3D、渐变背景、阴影、粗边框和密集网格。

标题使用结论句，副标题注明时间、单位、汇总方式及“累计/当期”口径。直接标注起点、终点、峰值、谷值和【指定事件】，并在重点区间使用浅色背景带或短注释；不要给所有时间点都添加标签。金额使用千分位，比例保留【1】位小数，标注不能覆盖面积边界。

完成后返回：新图表文件或可运行代码、时间汇总数据、关键时点、核心结论，以及你对基线、透明度和标注的处理说明。
```

## 你会得到

一张既能看趋势又能感受量级的面积图，以及关键时点和口径说明。

## 怎么检查

- 指标不存在被面积图隐藏的负值。
- 纵轴从 0 开始，面积没有夸大差异。
- 填充不会遮挡线条、参考值或标签。
- “累计值”和“当期值”口径已明确。
