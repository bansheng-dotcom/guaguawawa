# 42｜怎么让 AI 制作一张可读的关系网络图

## 学会什么

用节点和边展示关系结构、中心节点和社群，同时控制“毛球图”和标签拥挤。

## 什么时候用

适合节点、边、可选方向和权重明确的关系数据。节点或边过多时需要筛选或聚合。

## 需要准备

- 节点 ID、节点名称和节点指标
- 来源节点、目标节点、边权重和方向
- 核心节点或社群规则
- 输出工具与格式

## 提示词

```text
请读取【文件名】中的节点表和边表，使用【节点ID/名称】、【来源节点】、【目标节点】和【边权重】制作关系网络图，分析核心节点、社群和结构并回答【业务问题】。先检查孤立节点、自环、重复边、方向、权重和无法匹配的节点；节点或边超过可读上限时，按【权重阈值/Top N/社群聚合】筛选并说明未展示范围。

请使用【Python/HTML-ECharts/其他工具】直接创建：节点大小只映射【一个明确指标】，边宽只映射【一个权重】，方向用箭头或边类型表示；普通节点和边使用低对比颜色，核心节点或重点社群使用强调色。锁定近似正方形或与网络原始坐标一致的绘图区比例，X、Y 方向使用相同缩放比例，不能为了填满横向卡片而把网络压扁、拉宽或拉长。若画布较宽，应增加左右留白或使用居中的方形绘图区，而不是非等比缩放节点坐标。

布局运行后固定终态，不能持续抖动；图例必须放在绘图区之外或预留的独立区域，不能覆盖节点、边或节点标签。避免边线穿过大量标签，不使用 3D、发光、粒子和装饰动画。

只标核心节点、指定节点和必要社群名称，其他节点通过悬停或旁表识别；标题使用结论句，副标题注明筛选规则、节点和边的编码口径。对中心性结果只按实际计算方法解释，不把连接多自动写成“最重要”或因果影响。

完成后返回：新图表文件或可运行代码、节点表和边表、筛选前后规模、核心节点及计算口径、未匹配项和布局说明。
```

## 你会得到

一张重点节点可识别、布局稳定的关系网络图。

## 怎么检查

- 节点和边能够正确匹配。
- 节点大小、边宽各自只表达一个指标。
- 绘图区保持合理纵横比，节点间相对距离和网络形状没有被非等比压缩。
- 图例与绘图区分离，没有压住节点或标签。
- 标签和边线没有形成毛球。
- 力导布局最终保持稳定。
