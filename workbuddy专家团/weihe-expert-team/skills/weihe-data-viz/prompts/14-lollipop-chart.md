# 14｜怎么让 AI 制作一张适合排名的棒棒糖图

## 学会什么

用细茎和圆点展示类别排名，减少普通柱图的大面积色块。

## 什么时候用

适合中等数量类别的排名或数值比较。不适合需要强调从零累计体量或类别过多的情况。

## 需要准备

- 类别字段、指标字段和汇总口径
- 排名方向、单位和重点类别
- 输出工具与格式

## 提示词

```text
请读取【文件名】的【工作表】，按【类别字段】汇总【指标字段】，制作棒棒糖图展示【Top N/全部类别】并回答【业务问题】。请先核对汇总口径、单位、正负值和排序规则；如果类别过多导致圆点拥挤，先保留 Top N 并说明未展示范围。

请使用【Excel/Python/HTML-ECharts/其他工具】直接创建图表：类别按数值排序，细茎从共同基线连接到圆点，茎线保持低对比且不能加粗成柱形；普通圆点使用主色或灰色，只用强调色突出【Top1/异常对象/指定类别】。背景保持简洁，不使用 3D、渐变、阴影和厚重网格。

请在圆点外侧直接标注数值和单位，类别名称放在共同基线一侧并保持对齐；标题使用结论句，副标题注明统计时间、Top N 规则和口径。只为重点圆点增加简短注释，不在茎线上叠加长文字。

完成后返回：新图表文件或可运行代码、排序数据、核心排名结论和未展示类别说明。
```

## 你会得到

一张适合轻量排名展示的棒棒糖图。

## 怎么检查

- 茎线足够细，不会被误读为柱形。
- 圆点、数值与相邻类别没有碰撞。
- 排序和 Top N 规则正确。
- 强调色只用于真正需要关注的点。
