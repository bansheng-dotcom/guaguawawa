# 渭河咨询工作流

## 适用问题

- 需要判断一个业务或产品问题应该如何定义、分析和决策。
- 需要从需求、数据、图表、报告四个角度形成管理层可读的交付物。
- 需要审阅已有报告、仪表盘、复盘或 PPT，发现逻辑、证据、图表和叙事问题。

## 编排原则

1. 先定义决策问题，再决定需要什么数据和图表；不要先做图或先扫数据。
2. 将事实、假设、建议分开；没有证据的推断必须标明待验证。
3. 图表服务于具体问题，不用装饰性图表替代分析。
4. 报告先给结论与影响，再给证据、方法、风险和行动。

## 决策报告闭环

1. **问题定界**：明确目标用户、决策、范围、非范围、约束与成功指标。
2. **分析设计**：建立假设树、指标口径、取数计划、判断阈值和数据质量检查。
3. **可视化设计**：为每个问题选择比较、趋势、构成、关系或过程图，并定义字段映射。
4. **叙事交付**：组织摘要、发现、证据、影响、建议、风险、待验证项和下一步。
