# User Folder

这个目录提供产品管理 person 的可选用户理解入口。公开仓库不携带任何固定服务对象档案。

## 文件

| 文件 | 用途 | 是否公开提交 |
| --- | --- | --- |
| `profile.example.md` | 可复制的脱敏示例档案 | 是 |
| `profile.md` | 当前使用者的本地偏好摘要 | 否，已由 `.gitignore` 忽略 |
| `templates/user-preference-record-template.md` | 单条偏好记录模板 | 是 |

## 记录原则

- 只记录用户明确表达过的偏好，或项目经验库里已经沉淀的规则。
- 不把推测写成事实。
- 项目专属偏好优先写在项目经验库；这里放跨项目会复用的摘要。
- 用户偏好不能覆盖项目事实、验证结果和安全边界。
- 不记录密码、令牌、登录态、身份证明、联系方式或其他敏感信息。

## 使用方式

首次使用时，可复制 `profile.example.md` 为 `profile.md` 并按需填写。每次做项目理解、汇报、决策说明前，先读可选的 `profile.md`，再读项目文件；如果档案不存在，直接按当前任务事实工作。
