# SOP：自动化流水线吞吐与异常自愈（R17 蛙织网）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：死信重试次数]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 死信重试次数 | `同一消息重试计数` | 次 | ≤ 1 | > 3 报警停工单 |
| 悬空连线数 | `指向不存在节点的边数` | 条 | 0 | ≥ 1 禁止发布 |

## 3. 分步诊断动作

1. 画流程图：节点、触发器、失败分支三件套齐全。
2. 查连线：悬空边清零，异常分支必须有出口。
3. 加重试：指数退避 + 死信队列。
4. 护凭据：密钥走环境变量或密钥库。
5. 上线：先灰度一条业务线，观察 3 天再扩。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 出现悬空连线或未接失败分支 | BLOCKER | 禁止发布 |
| G2 | 凭据明文出现在流程定义 | BLOCKER | 立即轮换密钥 |
| G3 | 涉及资金/删除无人工审批 | BLOCKER | 补审批门 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
