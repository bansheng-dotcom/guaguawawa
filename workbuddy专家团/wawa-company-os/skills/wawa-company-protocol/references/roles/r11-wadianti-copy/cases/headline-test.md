# SOP：爆款标题测试与跳失率归因（R11 蛙点题）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：进店后首跳跳失率]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 进店后首跳跳失率 | `首跳离开会话 / 进店会话` | % | ≤ 8% | > 15% 修正标题歧义 |
| 违禁词命中数 | `命中平台违禁词表次数` | 处 | 0 | ≥ 1 禁止发布 |

## 3. 分步诊断动作

1. 定选题：先确认人群与场景，不写泛泛主题。
2. 写钩子：前 3 秒给出冲突或利益点。
3. 查合规：过违禁词表与平台规则。
4. 做 A/B：同选题两条标题，看点击与跳失双指标。
5. 定稿归档：把有效钩子结构写回选题库。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 违禁词命中 | BLOCKER | 禁止发布，改写 |
| G2 | 标题承诺与正文不符 | BLOCKER | 判为标题党，退回重写 |
| G3 | 字数超出平台区间 | WARN | 按平台重剪 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
