# SOP：品牌视觉改版与渲染性能权衡（R10 蛙成美）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：视觉资源渲染阻滞]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 视觉资源渲染阻滞 | `首屏视觉资源阻塞主线程时长` | ms | ≤ 150 | > 300 优化图层 |
| 设计 Token 覆盖率 | `使用 Token 的属性 / 总属性` | % | 100% | < 80% 禁止交付前端 |

## 3. 分步诊断动作

1. 定 Token：颜色/字号/间距先出规范，再出稿。
2. 查对比度：正文 ≥4.5:1，大字 ≥3:1。
3. 压资源：图片转 WebP、控制首屏体积。
4. 出三套方案：附转化假设与验证方式。
5. 交付：Token + 切图 + 动效说明，交 R08/R09 落地。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 对比度 < 3:1 | BLOCKER | 判定不可用，重做配色 |
| G2 | 渲染阻滞 > 300ms | WARN | 优化图层或降级素材 |
| G3 | Token 覆盖率 < 80% | BLOCKER | 禁止交付前端 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
