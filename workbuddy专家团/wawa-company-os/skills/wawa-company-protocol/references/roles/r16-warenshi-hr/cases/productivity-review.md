# SOP：人效评估与编制决策（R16 蛙人事）

## 1. 逻辑导图

```text
[异常/诉求输入] → [L1 数据与证据真实性] → [L2 维度下钻：人均产值增速差]
                → [L3 外部锚点对齐] → [决策指令] → [护栏熔断] → [阶梯灰度]
```

## 2. 核心指标口径

| 指标 | 公式 | 单位 | 目标 | 告警 |
| :--- | :--- | :---: | :---: | :--- |
| 人均产值增速差 | `人均产值增速 − 人力成本增速` | 个百分点 | ≥ 0 | 转负触发预警 |
| 关键岗位单点依赖数 | `无备份人选的 key role 数` | 个 | 0 | ≥ 1 立即补备份 |

## 3. 分步诊断动作

1. 算人效：人均产值与人效增速差。
2. 查合规：合同、证照、社保是否齐全。
3. 盘关键岗位：是否有备份人选与文档。
4. 出编制建议：加编/维持/优化三档，附成本。
5. 闭环：能力模型与培训计划落地。

## 4. 门禁（不满足即阻断）

| 编号 | 触发条件 | 判定 | 处置 |
| :---: | :--- | :---: | :--- |
| G1 | 合同/证照到期未续 | BLOCKER | 立即整改 |
| G2 | 薪酬核算差错 | BLOCKER | 48h 内全量复核 |
| G3 | 人效增速差转负 | WARN | 冻结新增编制 |

## 5. 归因路径

- **L1 数据层**：先排除脏数据、断流、重复计数，确认是真实异动。
- **L2 经营层**：按维度下钻，锁定贡献度 ≥70% 的因子（本角色主维度见 KPI 表）。
- **L3 商业层**：对齐外部锚点，区分内因外因；未接入外部数据时只声明口径，不虚构大盘数字。

## 6. 禁用词与反例

- ❌「大幅提升」「表现良好」「值得期待」等无数据锚定的形容词。
- ❌ 只给建议不给阈值；只给阈值不给回滚动作。
- ❌ 把历史个案当通用结论，不做样本量说明。
