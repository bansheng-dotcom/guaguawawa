## 二、 核心执行规范

### 1. PII 敏感信息与安全门禁 (Privacy Gate)
* **拦截范围**：身份证号、手机号、银行卡号、邮箱、API Key/Secret、内网私有 IP。
* **处置机制**：
  * 自动脱敏：`138****5678`，`[REDACTED_API_KEY]`。
  * 阻断规则：若正文包含未脱敏的明文密钥或信用卡号，报告强制挂起并标记为合规告警。

### 2. 跨智能体协同工单机制 (TaskTicket Protocol)
所有智能体在出具报告的 `Next Actions` 时，必须由系统底层自动解析并序列化为标准工单：
```json
{
  "ticket_id": "TICKET-R03-R12-55BCA522A8",
  "source_role": "r03",
  "target_role": "r12",
  "action_directive": "命中熔断的渠道当日 0 点停止投放，交由 R12 复核定向",
  "priority": "P0",
  "status": "dispatched"
}
```
* **自动协同**：工单生成后直通目标智能体的待办任务队列，实现从“口头建议”到“机器接单”。

### 3. 算力 Tokenomics 成本归因与 ROI 对账
* **计量标准**：以行业生产级模型单价（Input $3/1M, Output $15/1M，汇率 7.25）对账。
* **本地算力折算**：离线 Python 计算按 `2.0 ms/Token` 当量折算。
* **商业透明度**：每份报告底部的“审计追溯抽屉”中必须显式登记：
  * 算力成本 (USD/CNY)
  * 计算当量 (Tokens)
  * 商业效益对账比 (ROI Ratio)

### 4. 熔断触发的策略自进化闭环 (Policy Evolution Loop)
* **触发条件**：任一智能体执行判定为 `FAIL` 或 `BLOCKED`，或 KPI 越过 Kill-Switch。
* **自进化机制**：系统自动生成 `EVO-ROLE-TIMESTAMP-HASH` 提案：
  * 自动将阈值收紧 15%；
  * 处置窗口从默认 72 小时缩短至 24 小时；
  * 将权限从部门级提升至**“创始人强制签字”**。
* **闭环沉淀**：提案写入报告正文专节与全球账本，由创始人一键核准注入。

### 5. CEO 全球决策资产仪表盘 (Global Cockpit)
* **数据源**：`workspace/governance/decision_ledger.jsonl`。
* **自动化生成**：运行 `python agents/scripts/upgrade/global_dashboard.py`。
* **产物索引**：
  * [HTML 交互大屏](agents/workspace/reports/CEO_GLOBAL_DECISION_INDEX.html)
  * [Markdown 总裁快报](agents/workspace/reports/CEO_GLOBAL_DECISION_INDEX.md)

## 三、 验证与工程纪律

1. **零破坏回归**：治理态注入后，全量 20 个角色的 Manifest 契约测试、19 角色报告门禁、228 条自动化测试断言必须 100% 全绿。
2. **纯标准库实现**：治理模块 `agents/shared/governance.py` 纯基于 Python 标准库实现，不增加任何重量级第三方依赖。
3. **不可逆底线保留**：资金划拨、对外签约、生产数据库不可逆变更，依旧坚守“仅创始人亲自签发生效”的最高准则。
