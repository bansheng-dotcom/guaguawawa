## 2. 假设契约

`draft["assumption_records"]` 每条假设都有：

```json
{"value": 5.0, "source": "method:economics", "sensitivity": "unknown"}
```

来源三类：

- `assumption:<id>`：数据假设（`data/assumptions.json`）
- `method:<key>`：方法假设（finding 自己声明）
- `declared:<section>`：本节显式声明

`s09_interpret` 只允许**有记录且有 source** 的假设值；没有记录 → 报错，不再默认放行。

---

## 3. 公式契约

`_explainable` 已删除任意 `a/b` 与 `(a/b-1)*100`：

| 允许 | 说明 |
|---|---|
| 等于 ref | 直接引用 |
| ref 的 %/‰ 换算 | 单位换算 |
| 两值之差/和 | 可复算的加减 |
| 派生量作为 ref | `derived` 已登记的公式结果 |

**不再允许**：拿 refs 里任意两个数相除，凑出一个比率。

实测：v9 market/ops 仍 PASS——因为比率类数字都能由 `derived` 或 ref 直接解释；不能解释的会被拦。
