## 0.1 内容层已产品化（2026-11-19 晚）

原先把 `facts/charts/kit` 放在 `workspace/seasoning_v3`，且 `kit.py` 依赖 `sample_fruit/build.py`，所以只能算模板。
现在固化进 core，不再依赖任何 workspace 样例：

| 模块 | 作用 |
|---|---|
| `core/flow_report.py` | 项目化构建器：读 `facts.py` + `charts.py`（+ 可选 `prose_specs.py`）→ HTML/PDF/文笔分 |
| `core/report_theme/kit.py` | 自包含页构造器（封面/摘要/目录/节页/动作/附录/尾页）+ `to_pdf` |
| `core/report_theme/chartkit.py` | SVG 基元 + 通用图型（hbar / grouped_bar / range_bar / share_bar） |
| `templates/flow-report/` | 复制即用的三件套模板（facts / charts / prose_specs） |

入口：

```bash
python guagua.py report flow --project workspace/<项目> --out workspace/<项目>/out --pdf --prose-hard
```

`--prose-hard` 把文笔门禁变成硬闸：不达标退出码非 0、`flow_manifest.json` 写 `ok=false`；
不加时只记分。酒水这份 100 分，加不加都过——**但交付稿应该加**，否则门禁只是装饰。

酒水这份 `report_flow_all.html/pdf` 现在就是这条命令产出的（18 页、14 节、13 图、文笔 100）。
CI 的 `[22] flow-project` 会用模板跑软/硬两遍，验「软过、硬拦」两态。

## 3. 差在哪、怎么补

### 3.1 来源 27/50（差 23 条）

现在 27 条全部有 URL 与逐字 quote（这是上一版就核过的）。要过 50 条，缺的是：
- 分香型（酱/浓/清）产量与收入：协会或统计局分项；
- 各价格带的单品批价/成交价（800—1500、500—800、300—500 各 2—3 个 SKU）；
- 券商研报原文（不是媒体转述）3—5 篇；
- 啤酒/葡萄酒的独立成本与渠道数据 3—5 条；
- 即时零售、抖音酒水的平台口径数据 3—5 条。

补法：按 `source_ledger.json` 的字段加行，每条必须有 `url` 与 `quote`；不接受只有标题的「检索入口」。

### 3.2 双地图（0/2）

v3 的两张图是「全国产地地图 + 内蒙古区域地图」。酒水版对应的是：
- **全国产区地图**：仁怀（茅台）、宜宾（五粮液）、汾阳（汾酒）、泸州（泸州老窖）、宿迁（洋河）、亳州（古井）；
- **区域销区地图**：以华北/华东/华南三个销区为例，或落到内蒙古（需要本地酒水销售数据）。

两张图都要求每个点位有来源；产区点位可从公司年报「注册地/生产基地」取，销区数据需要另找。
