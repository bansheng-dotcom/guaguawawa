## 四、三条必须带走的口径提醒

1. **上市公司数据与协会规上口径不能混算**。2025 年协会口径白酒销售收入同比 -7.5%、利润 -13.1%；但 19 家上市酒企里 18 家营收下滑，五粮液 -54.55%（收入确认时点调整后的重述数）。报告分别列示，没有取平均。
2. **飞天没有倒挂，倒挂的是次高端与普五**。飞天出厂 1169 元、批价 1500 元，批价高于出厂价；真正的倒挂在普五（出厂 1019、批发 850，倒挂 16.58%）。「价格体系失守」指批价贴住指导价、渠道价差归零，不是飞天亏损。
3. **「60% 企业倒挂」「900 天周转」来自协会调研样本**，不是全行业普查；经销商端的渠道库存月数没有公开数据，已写进报告边界。

## 五、这份报告没有回答的（缺数据，不编）

| 缺口 | 影响哪条结论 | 需要什么数据 |
|---|---|---|
| 渠道库存月数 | 「渠道吃不下更多货」只能定性 | 经销商库存/动销台账，或第三方渠道调研 |
| 分香型（酱/浓/清）结构 | 无法判断香型轮动 | 协会分香型产量与收入 |
| 餐饮渠道规模与占比 | 营销节只能排除餐饮，不能量化 | 餐饮渠道酒水销售额 |
| 线上 CAC / 佣金 / 投流 ROI | 无法算线上单位经济 | 平台后台或代运营报价 |
| 区域实测毛利与获客成本 | 「轻资产服务」的保本线算不出 | 你自己的门店/分销流水 |

## 六、要把「经营分析」升级成你自己的版本，需要补什么

现在是行业级经营分析（上市公司 + 协会口径）。要变成**你能用来做决策的经营分析**，补一份数据即可：

`data/unit_econ.csv`，列：
`月份, 渠道(经销/餐饮/电商/即时零售), SKU, 出厂价, 进货价, 批发价, 零售价, 销量, 库存量, 销售费用, 履约成本`

- 有这 12 列，就能算：单店/单渠道毛利、周转天数、保本销量、费用率、负毛利 SKU 名单。
- 只有零售价与进货价也能出「加价率与倒挂分析」，但报告会明确写「不含保本」。
- 把文件放进 `D:\蛙蛙呱呱\酒水赛道调研_2026-11-19\data\`，重跑：

```bash
python guagua.py report "我的酒水生意经营分析" --dir ..\酒水赛道调研_2026-11-19 --out ..\交付\酒水经营分析_20261119 --pdf
```
