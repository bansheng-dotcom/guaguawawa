# 报告产线升级 · P10 Gate 报告（补 falsifier）

> 日期：2026-11-17
> 依据：P9 Gate 的发现——**门禁一开，v9 头条全被降级，因为 section 没有 falsifier。**
> 状态：**P10 完成：每个 section 都有可证伪条件，4 个 lens 头条恢复 actionable。**

---

## 1. 问题

P9 的 `claim_gate` 规则是对的：

```
headline 必须 actionable + falsifier + verified/grade≤B
```

但 v9 的 `Finding` 只有 `boundary/so_what`，没有 `falsifier`；frame 装配出的 section 也没有。  
结果：**所有头条都被降级**——门禁没有错，是产线缺字段。

## 2. 修法

| 文件 | 改动 |
|---|---|
| `core/analysis_methods.py` | `Finding` 新增 `falsifier: str = ""` |
| `core/report_compose.py` | `_section_from()` 输出 `falsifier`；所有 section 兜底“方向反转即作废” |
| `core/claim_gate.py` | 优先取第一条带 falsifier + refs 的 section；再取 finding/section falsifier |

兜底 falsifier：

> 若下一期数据与「本节判断」方向相反，本节判断作废。

有专属 falsifier 的方法保留专属；没有的才用兜底。
