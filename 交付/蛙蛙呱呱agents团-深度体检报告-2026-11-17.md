**这是一个骨架完整、但一致性已经失守的仓库。**

### P0-4　契约校验抛异常时默认判"通过"

**实测**：`r11`–`r15` 的 `review.py:49-56`（五个角色都有两处同样写法）：

```python
try:
    contracted = contracts.validate_output(skill, action, result)["ok"]
except Exception:
    contracted = True        # ← 异常 = 契约符合
```

**影响**：契约模块缺失、schema 损坏、字段类型不匹配导致校验器崩溃时，评审器会给出 `PASS`。这直接破坏"生成与校验分离"的可信度。
**修法**：`except Exception` → `contracted = False` + `failure_category="contract_error"`，并把异常摘要写进 issues。
