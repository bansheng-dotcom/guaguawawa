## 1. 逐方法 falsifier

`core/analysis_methods.py` 新增 `FALSIFIERS`，`collect()` 与 `methods.run()` 都会写入 `Finding.falsifier`：

| 方法 | 证伪条件（摘要） |
|---|---|
| structure | 下期涨跌方向反转，或离散度收敛到 5% 以内 |
| momentum | 下期环比与同比同向，或拐点消失 |
| trajectory | 新增 3 期后斜率翻转 |
| contribution | 下期贡献方向反转 |
| economics | 损耗/冷链比假设低 2pp、净利转正 |
| transmission | 产地→批发价差方向反转 |
| arbitrage | 扣运费/损耗后价差为负 |
| breakeven | 零售价跌破保本价，或提价后销量下滑 >20% |
| forecast | 实际值落在区间外 |
| risk | 补数后缺口消失，或波动收敛到阈值内 |
| sample | 样本补到每组所需量后显著性改变 |
| ledger | 来源-结论映射变化 |

没有专属条件的方法，仍由 `report_compose` 补“方向反转”兜底。

## 2. 完整 ClaimCard 接入

`claim_gate` 现在除了三条硬规则，还会构建完整 `ClaimCard`：

```json
{
  "comparability": {
    "same_product": "yes | n/a",
    "same_period": "yes | unknown",
    "same_unit": "yes | unknown",
    "same_channel": "n/a"
  },
  "rivals": [{"name": "口径/时点差异", "status": "partially_ruled",
              "evidence": "引用同项目来源；期次与单位已记录"}],
  "falsifier": "若下期方向反转…",
  "confidence": "medium",
  "grade": "A|B|C",
  "actionable": true,
  "headline": true,
  "decision": "…",
  "owner": "r01"
}
```

`claim_card.validate()` 的结果写进 `manifest.claims`：

- `full_schema_ok`
- `card_errors`
- `card`

### 默认审计，可选硬门禁

- `REPORT_CLAIM_CARD_GATE=0`（默认）：只审计，不因 comparability/rivals 降级；
- `=1`：完整 schema 不过 → 头条降级。

### 当前发现

pipeline 第一条 claim 跨多个期次/单位，`same_period=unknown`、`same_unit=unknown`，所以：

```json
{"actionable": true, "full_schema_ok": false,
 "card_errors": ["actionable=true 但比较不可比：same_period, same_unit"]}
```

**这不是代码错，是 claim 还没做可比性收敛。**  
四个 lens 在三条硬规则下仍 `actionable=true`；打开 `REPORT_CLAIM_CARD_GATE=1` 才会因可比性降级。
