## 2. Quote 门禁：从“整库”到“按断言 + 默认 strict”

水果 pipeline 项目（CI 样本）现在：

| 指标 | 值 |
|---|---|
| 来源 | 32 |
| 有 quote | 23 |
| 稳定可复现 | 20 |
| 反爬（S15/S17/S18） | 3 |
| 本报告实际引用且未核验 | **11 条**：S11 / S13 / S14 / S17 / S18 / S19 / S22 / S27 / S28 / S29 / S30 |

实测：

| 模式 | 结果 |
|---|---|
| `strict`（默认） | **阻断**，点名 11 条，退出码 2 |
| `warn` | 报告可渲染，但 `manifest.ok=false`、`quotes_ok=false` |
| `off` | CI 快速路径，`quotes_ok=true` |

**关键变化：** 以前 `manifest.ok` 只看渲染/逐节校验；现在 `report build` 的 `ok = 渲染 ok 且 coverage=COMPLETE 且 quotes.ok`。有 gap 的报告不会再被当成“合格”。
