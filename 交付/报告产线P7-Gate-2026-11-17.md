| 曾通过、当前反爬（S15/S17/S18） | **3** |
| 页面无引用值 / JS / 403 | **9** |
| 合计 gap | **12** |

`report build` 默认 `strict`：引用到 gap 就不出报告；`warn` 可出稿但 `manifest.ok=false`。
`report gaps --project <dir>` 直接列出 12 条及原因：

```bash
python guagua.py report gaps --project 内蒙古水果三城调研_2026-11-16
```

**合法关闭方式：** 换源 / 降级为假设 / 标 void。
**不允许：** 标题当 quote、大意当引文、unreachable 改 ok。
