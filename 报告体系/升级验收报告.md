## 附件｜批注层（人的判断）已上线

### 做了什么

- `annotations.md`：按 `## s2-x` 锚点挂批注，每条尾部带 8 位数据指纹 `<!-- hash: xxxxxxxx -->`。
- 构建时逐条比对指纹：
  - 无指纹 → 首次挂载，自动写入；
  - 指纹一致 → `已复核`；
  - 指纹不一致 → `⚠ 数据已更新，请复核`，**批注保留、不删**。
- 命令：`python -m reportkit.cli annotate <case> --anchor s2-1 --text "……"`

### 失效检测实测

把全国鸡蛋 11-11 由 9.57 改为 9.62（模拟来源修订）后重建：

```
stale blocks: 3   （s2-1 两条 + s2-6 一条）
```

## 附件二｜三个补强项（affected / 分区 / 分级）

### A. `affected`：改了源，精确列出影响面

```bash
python -m reportkit.cli affected nmg_protein_2026Q4
```

改一条 `farm_daily`（全国鸡蛋 11-11）后的输出：

```json
{
  "changed_sources": ["farm_daily"],
  "sections": [{"id":"s2-1","label":"2.1 全国日度","claims":["C1","C2"]},
               {"id":"s2-6","label":"2.6 传导缺口","claims":["C4"]}],
  "claims": ["C1","C2","C4"],
  "annotations": [{"anchor":"s2-1"},{"anchor":"s2-1"},{"anchor":"s2-6"}],
  "tables": 2
}
```

**价值**：以前改一个数，只能重看整份报告；现在直接告诉你「2 张表、3 条结论、3 条批注要看」。
未改数据时输出为空（`changed_sources: []`），不产生噪声。

### B. 分区缓存：只重算变化的月份

日度观测按 `YYYY-MM` 分片，每片存聚合片段（n / sum / sumsq / min / max / first / last / up / down），
片级 hash 不变则复用。

实测（改 11 月一条观测）：

```
改 2026-11 → recomputed=2026-11  reused=2026-09,2026-10
改回 9.57  → recomputed=2026-11  reused=2026-09,2026-10
```

`backfill` 命令 = `add-obs` + `build`，自带分区重算与 manifest 记录。

**诚实说明**：1,192 条数据下全量重算本来就是秒级，这一项当前的价值在**机制**（补历史、回填、增量）而不在速度；
数据量上一万条后才会体现为真实收益。

### C. 分级阈值：热力图不再"永远红"

| 证据级 | 价格序列 | 区域分化 | 规格 | 上游 |
|---|---|---|---|---|
| A | 30 | 14 | 6 | 4 |
| B | **4** | **4** | **4** | **4** |
| C | **2** | **2** | **2** | **2** |

热力图里鸭肉从 `1/30` 变成 `1/4`，鹅肉 `1/2`——**同一个数据，用符合它证据级别的尺子去量**。

覆盖率从 34.4% 升到 **37.5%**（升幅来自别名补全：育肥牛→牛肉、鲜蛋装车→蛋类、羔羊→羊肉等被正确归位）。

剩下的 20 个红/黄格是**真实缺口**，不是口径问题：

| 缺口 | 格数 | 补法 |
|---|---|---|
| 区域只有 3 个市场（全区/呼市/乌兰察布） | 7 | 加赤峰、包头、通辽周报 |
| 上游报价不足（仅 11 条产地） | 7 | 敖汉/通辽周度出场价入库 |
| 鸭/鹅/虾无序列 | 6 | 自建双周采价 |
