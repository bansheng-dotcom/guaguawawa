# 设计交付规范（design-handoff）

> **「图给你了」不等于交付。** 交付的标准是：工程不问一句话就能做出来。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「设计稿怎么交给工程」
- 「切图怎么给」
- 「工程师总来问尺寸」
- 「改稿了怎么同步」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 设计好不好看 | r10 的 `visual-hierarchy` | 那是判据 |
| 代码实现 | r09 的 `web-app-development` | 那是工程 |
| 设计令牌 | r10 的 `design-system` | 那是令牌体系 |

**最小可开工输入**：**一份可交付的设计稿 + 目标端（Web/小程序/App）**。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| 设计稿（含所有状态） | 必需 |
| 目标端与断点 | 必需 |
| 字体与色值来源（令牌或手填） | 必需 |
| 图标与插图源文件 | 建议 |

**追问纪律**：最多一轮，只问**要交付到哪几个断点**。断点不定，标注无法完整。

## §3 执行流水线（Workflow）

### Step 1 · 标注四件（尺寸/间距/色值/字重）
每个可见元素标：宽高、与相邻元素间距、色值（十六进制）、字号与字重、行高。

**判据**：四件齐备，且间距用统一刻度

### Step 2 · 状态与断点齐备
每个组件至少 6 态（默认/悬停/焦点/禁用/加载/空或错）；每屏至少 3 断点（375/768/1280）。

**判据**：六态齐全；断点不少于 3 档

### Step 3 · 资源命名与导出（可被程序找到）
命名：`<模块>_<元素>@<倍率>.<ext>`，如 `btn_primary@2x.png`。**导出 SVG 优先**，位图给 1x/2x/3x。

**判据**：命名遵循规则；可矢量的不用位图

### Step 4 · 交互动效说明（时长与缓动）
每个动效标：触发、时长（150–300ms）、缓动曲线、是否尊重减弱动效。

**判据**：每个动效三项齐备

### Step 5 · 变更单（改了什么、影响谁）
改稿必须出变更单：改了哪个页面/组件、影响哪些断点、是否影响已开发部分。

**判据**：每次改稿有变更单，且标注影响面

### Step 6 · 验收：工程复述一遍
让工程用一句话复述「这个页面要做什么、有几个状态」。复述不出＝交付不完整。

**判据**：工程能独立复述结构与状态


## §4 交付物清单

| # | 交付物 | 载体 |
|---|---|---|
| 1 | 标注图（四件齐备） | `.md` / 设计工具 |
| 2 | 资源包（按命名导出） | 文件夹 |
| 3 | 动效说明 | `.md` |
| 4 | 变更单 | `.md` |

## §5 质量门（一票否决）

1. 每个元素标注尺寸/间距/色值/字重四项；
2. 每个组件覆盖 6 态；每屏 ≥3 断点；
3. 资源命名遵循 `<模块>_<元素>@<倍率>`，可矢量优先 SVG；
4. 每个动效标注触发/时长/缓动，且尊重 reduced-motion；
5. 每次改稿产出变更单并标注影响面；
6. 工程能独立复述页面结构与状态（不需要再问）；

> 本卡无自动门禁。可配合 `imgops info` 核导出图规格（间接）。

## §6 交付前自检清单

- [ ] 每个元素我都标了尺寸、间距、色值、字重
- [ ] 每个组件 6 态都画了（包括加载和空态）
- [ ] 375/768/1280 三档都给了
- [ ] 切图命名是按规则来的，不是 `1.png`
- [ ] 能用 SVG 的我没给 PNG
- [ ] 动效标了时长和缓动，也标了减弱动效行为
- [ ] 我出了变更单，写清影响哪些已开发部分
- [ ] 我让工程复述过一次，他能说清结构

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 只给一屏主状态 | 6 态 + 3 断点全给 |
| EX-02 | 间距靠目测 | 标注具体数值，且落在刻度里 |
| EX-03 | 切图命名 1.png | `模块_元素@倍率` |
| EX-04 | 全给 PNG | 可矢量优先 SVG |
| EX-05 | 色值手填且与令牌不符 | 用令牌色值，手填要有理由 |
| EX-06 | 动效口头描述 | 标时长/缓动/减弱行为 |
| EX-07 | 改稿不通知 | 出变更单 + 标影响面 |
| EX-08 | 让工程自己猜悬停态 | 悬停/焦点必须画 |
| EX-09 | 导出缺倍率 | 1x/2x/3x 都给 |
| EX-10 | 交付后不答疑 | 指定答疑人与时限 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 无设计工具 | 给文字版标注表 + 令牌引用，标注「无标注图」 |
| 工程只需要局部 | 只交该模块，但状态与断点不能省 |
| 动效无法实现 | 给降级方案（直接切换），并标注 |
| 图标非原创 | 标注来源与授权，可商用才交 |
| 多端共用 | 一套标注 + 各端差异表 |
| 紧急上线 | 先交主流程 + 六态，其余补交并标注 |

**明确不做**：不做设计判据、不做代码实现、不做令牌体系、不做版权判断。
