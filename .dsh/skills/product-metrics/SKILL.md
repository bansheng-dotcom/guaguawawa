# 产品指标体系（product-metrics）

> **指标体系最贵的失败不是指标错，是「同名不同义」。** 市场说的活跃是月活、产品说的是周活、财务说是有付费行为的——开会时三个人都在说「活跃在涨」。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「该看哪些指标」
- 「北极星怎么定」
- 「为什么两个部门数不一样」
- 「这个数要不要进看板」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 埋点怎么埋 | r18 的 `event-tracking-design` | 那是采集 |
| 怎么分析变化 | r06 的 `analysis-method` | 那是分析 |
| 财务指标 | r03 | 那是财务 |
| 客户健康分 | r13 的 `qbr-health` | 那是客户侧 |

**最小可开工输入**：**产品当前的核心价值主张 + 已有的数据能力清单**。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| 核心价值主张（一句话） | 必需 |
| 现有可采集事件 | 必需 |
| 各部门当前在用的指标名 | 必需 |
| 业务阶段（拉新/留存/变现） | 必需 |
| 已知的口径分歧 | 建议 |

**追问纪律**：最多一轮，只问**当前阶段最重要的是拉新、留存还是变现**。阶段不定，北极星就没法定。

## §3 执行流水线（Workflow）

### Step 1 · 定北极星（一个，且是价值不是收入）
北极星 = **用户获得价值的行为频次**，如「每周完成 ≥1 次有效任务的人数」。**不要用收入/DAU 当北极星**——它们是结果，不可直接驱动。

**判据**：北极星是行为指标，且一句话说清

### Step 2 · 拆 3–5 个驱动指标（能分解北极星）
驱动指标必须能解释北极星：如「任务创建数 × 完成率 × 周活跃天数」。**乘法关系可验证**：改变一个，北极星应可预测变化。

**判据**：驱动指标与北极星有可写的分解式

### Step 3 · 定 2 个护栏指标（防赢指标输全局）
护栏 = 不能变差：如退款率、客诉数、毛利率、加载时长。

**判据**：护栏 ≥2 个且各有阈值

### Step 4 · 每个指标写四件（禁「众所周知」）
**定义**（怎么算）+ **口径**（含谁不含谁）+ **来源**（哪个表/事件）+ **频率**（日/周/月）。

**判据**：四件齐备，无指标只写名字

### Step 5 · 消歧同名指标（开会前先对齐）
把所有同名不同义的指标列出来，统一成一个并标注废弃别名。

**判据**：同名冲突已列出并统一

### Step 6 · 看板只放 ≤8 个数
看板小于等于 8 个：1 北极星 + 3–5 驱动 + 2 护栏。其余进明细报表。

**判据**：看板指标 ≤8，且分类清晰

## §5 质量门（一票否决）

1. 北极星是行为指标（非收入/DAU），一句话说清；
2. 3–5 个驱动指标，与北极星有可写的分解式；
3. 护栏指标 ≥2 个且各有阈值；
4. 每个指标写全四件：定义/口径/来源/频率；
5. 同名不同义的指标已列出并统一；
6. 看板指标 ≤8 个；

> 本卡无自动门禁。分解式可人工验证，这是最硬的自检。

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 北极星用收入 | 用价值行为频次 |
| EX-02 | 北极星是 DAU | DAU 是结果，不可直接驱动 |
| EX-03 | 驱动指标无法分解 | 写分解式，乘法可验证 |
| EX-04 | 无护栏 | ≥2 个护栏 + 阈值 |
| EX-05 | 指标只写名字 | 四件：定义/口径/来源/频率 |
| EX-06 | 口径不写排除项 | 写清含谁不含谁 |
| EX-07 | 同名不同义 | 列消歧表并统一 |
| EX-08 | 看板 20 个数 | ≤8 个 |
| EX-09 | 留存不写天数 | 写「次日/7 日/30 日留存」 |
| EX-10 | 每月换北极星 | 北极星至少稳定 2 个季度 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 无埋点 | 先用后端事件（订单/支付）替代，标注覆盖不足 |
| 无历史数据 | 先建基线，指标只做前瞻 |
| 多产品线 | 各线一个北极星，公司层再看汇总 |
| 口径历史变更 | 列新旧两套口径并标注切换日 |
| 数据延迟大 | 标注「T+1/T+7」，避免日更决策 |
| 指标体系已存在但混乱 | 不减量，先消歧 + 补四件 |

**明确不做**：不做埋点实现、不做分析方法、不做财务指标、不做客户健康分。
