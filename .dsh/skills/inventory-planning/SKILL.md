# 库存计划与补货（inventory-planning）

> **「总缺货」和「总压货」往往是同一个原因：没有补货点，只有感觉。** 感觉偏保守就压货，感觉偏乐观就缺货，而两种感觉都出现在同一个人身上。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「要不要补货」
- 「安全库存定多少」
- 「为什么总缺货」
- 「压了好多货怎么办」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 比价 | r15 的 `analyze-procurement` | 那是成本 |
| 供应商准入 | r15 的 `supplier-onboarding` | 那是准入 |
| 单据校验 | r15 的 `po-validate` | 那是单据 |
| 资金影响 | r03 的 `cash-runway` | 那是现金流 |

**最小可开工输入**：**一个 SKU 的日均销量 + 供应商交期**。缺任一项算不出补货点。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| 日均销量（含波动） | 必需 |
| 供应商交期（天） | 必需 |
| 现有库存与在途 | 必需 |
| 单次订货成本与起订量 | 必需 |
| 需求波动系数（周内/季节） | 建议 |

**追问纪律**：最多一轮，只问**交期几天、销量波动多大**。这两项决定安全库存。

## §3 执行流水线（Workflow）

### Step 1 · 算日均销量与波动（用 P50 与 P90）
日均销量取近 4–8 周中位数；**波动用 P90/P50 比**，比越大安全库存越高。

**判据**：给出日均、P90 与波动比

### Step 2 · 算安全库存（交期 × 波动）
`安全库存 = 日均销量 × 交期 × 波动系数`，波动系数按 P90/P50 取 1.2–2.0。

**判据**：公式写明，参数有来源

### Step 3 · 算补货点（提前触发，不等见底）
`补货点 = 日均 × 交期 + 安全库存`。**库存降到补货点即下单，不是降到 0**。

**判据**：补货点算出，且触发动作明确

### Step 4 · 定补货批量（平衡订货成本与资金占用）
起订量与实际需求取较大者，但 **单次批量 ≤ 6 周销量**（再多就是压货）。

**判据**：批量在起订量与 6 周销量之间

### Step 5 · 识别滞销与呆滞（分两档处理）
**滞销**：30 天销量 < 安全库存的 1/3；**呆滞**：90 天无销量。滞销 → 促销/组合；呆滞 → 清仓/退货/报废，并记损失。

**判据**：两档都有定义与处置动作

### Step 6 · 算库存资金占用（进财务口径）
`占用 = 库存数量 × 单位成本`；`周转天数 = 平均库存 ÷ 日均成本`。按 SKU 算，不只算总。

**判据**：资金占用与周转天数按 SKU 算出

## §5 质量门（一票否决）

1. 日均销量用中位数（非均值），并给出 P90 与波动比；
2. 安全库存 = 日均 × 交期 × 波动系数，参数有来源；
3. 补货点 = 日均 × 交期 + 安全库存，且触发动作明确；
4. 单次批量在起订量与 6 周销量之间；
5. 滞销（30 天）与呆滞（90 天）各有定义与处置动作；
6. 资金占用与周转天数按 SKU 计算；

> 本卡无自动门禁。公式可人工复算，这是最硬的自我验证。

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 用均值算日均 | 用中位数 + P90 |
| EX-02 | 安全库存拍脑袋 | 日均×交期×波动系数 |
| EX-03 | 等库存见底才补 | 降到补货点就补 |
| EX-04 | 批量越大越省 | ≤6 周销量，再多是压货 |
| EX-05 | 滞销与呆滞一个处置 | 两档不同动作 |
| EX-06 | 只算总库存周转 | 按 SKU 算 |
| EX-07 | 忽略在途 | 补货点要考虑在途库存 |
| EX-08 | 大促不调参数 | 大促前上调安全库存 |
| EX-09 | 呆滞不记损失 | 报废/清仓损失要入账 |
| EX-10 | 一次定完不复盘 | 每季度按实际销量重算 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 无历史销量（新品） | 用同类品销量替代，标注「替代基准」 |
| 交期不稳定 | 取最长交期算安全库存，标注「按最坏交期」 |
| 起订量远大于需求 | 接受压货或改小包装，标注取舍 |
| 仓储空间受限 | 以空间为约束反推批量，标注「空间约束」 |
| 多仓 | 分仓各算补货点，不共用 |
| 资金紧张 | 降安全库存（接受更高缺货率），标注「资金约束」 |

**明确不做**：不做比价、不做供应商准入、不做单据校验、不做资金决策。
