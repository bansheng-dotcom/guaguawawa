# 供应商准入与评估（supplier-onboarding）

> **供应商最贵的不是单价，是「换不掉」。** 单源、无备选、资质不全——平时省下的钱，会在一次断供里全部还回去。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「要不要用这家供应商」
- 「供应商怎么评估」
- 「怎么分级」
- 「要不要换供应商」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 比价与 TCO | r15 的 `analyze-procurement` | 那是成本分析 |
| 采购单/收货单 | r15 的 `po-validate` | 那是单据校验 |
| 合同条款 | 创始人 + r03 | 那是法务财务 |
| 库存计划 | r15 的 `inventory-planning` | 那是库存 |

**最小可开工输入**：**一个候选供应商 + 要供的物料 + 预计月量**。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| 候选供应商清单 | 必需 |
| 物料规格与质量要求 | 必需 |
| 预计月量与交期要求 | 必需 |
| 资质材料（营业执照/认证） | 必需 |
| 现有供应商与该物料的关系（是否单源） | 必需 |

**追问纪律**：最多一轮，只问**这个物料现在是不是单源**。单源是最高风险项，决定准入节奏。

## §3 执行流水线（Workflow）

### Step 1 · 资质与合规五项（不过即拒）
**主体合法**（营业执照在期）、**经营范围**匹配、**质量认证**（如 ISO/3C，按品类）、**财务健康**（无重大诉讼/失信）、**合规声明**（无强制劳动/环保处罚）。

**判据**：五项逐条核对，任一不过直接拒

### Step 2 · 四维试单评估（先小单再放量）
**质量**（不良率/抽检合格率）、**交付**（准时率/交期弹性）、**成本**（TCO 而非单价）、**配合**（响应速度/问题处理）。**先试单，不直接放量**。

**判据**：四维都有试单数据，不是凭介绍

### Step 3 · 定分级与配额（A/B/C 三级）
**A 主力**（≥60% 配额，双源中的主）、**B 备选**（20–40%）、**C 观察**（≤15%，试单期）。**单一物料禁止 100% 单源**。

**判据**：分级明确；关键物料至少双源

### Step 4 · 写冻结与退出条件
**冻结**（暂停下单）：质量连续 2 批不合格 / 交付准时率 <80% / 资质过期。**退出**：整改无效 / 重大合规问题 / 价格长期高于市场 20%。

**判据**：冻结与退出条件都写死，且有责任人

### Step 5 · 建立评估台账（季度评一次）
台账含：四维得分、批次不良率、准时率、价格变动、事件记录。按季度复评并调整分级。

**判据**：台账字段齐全，季度复评有记录

### Step 6 · 单源风险处置（最高优先级）
若该物料目前单源：**6 个月内必须引入第二家**，并先做小批量试单；同时建安全库存兜底。

**判据**：单源物料有双源计划与安全库存

## §5 质量门（一票否决）

1. 资质合规五项逐条核对，任一不过即拒；
2. 四维评估基于试单数据（质量/交付/成本/配合），非凭介绍；
3. 分级 A/B/C 明确，关键物料禁止 100% 单源；
4. 冻结与退出条件写死并指定责任人；
5. 评估台账字段齐全且季度复评；
6. 单源物料必须有 6 个月内引入第二家的计划 + 安全库存；

> 本卡无自动门禁。可与 `analyze-procurement`（TCO）和 `po-validate`（单据）交叉核对。

## §6 交付前自检清单

- [ ] 五项资质我逐条核过，不是「看着挺正规」
- [ ] 我做过试单，有不良率与准时率数据
- [ ] 成本我按 TCO 算的，不是只比单价
- [ ] 我给了 A/B/C 分级和配额
- [ ] 关键物料我没有让它单源
- [ ] 冻结和退出条件我写死了，也指定了谁执行
- [ ] 我有季度评估台账
- [ ] 单源物料我列了引入第二家的时间计划

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 只看单价准入 | 按 TCO + 四维评估 |
| EX-02 | 凭供应商介绍就放量 | 先小批量试单 |
| EX-03 | 不查资质有效期 | 五项逐条核，含有效期 |
| EX-04 | 关键物料单源 | 至少双源，A/B 分级 |
| EX-05 | 无冻结条件 | 三条冻结触发写死 |
| EX-06 | 不设退出 | 三条退出条件 |
| EX-07 | 台账只记价格 | 记质量/交付/成本/配合 + 事件 |
| EX-08 | 一次准入永久有效 | 季度复评调整分级 |
| EX-09 | 试单量大到无法承受损失 | 试单量控制在 1–2 周用量 |
| EX-10 | 不记不良批次 | 逐批记录不良率与原因 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 新供应商无历史 | 只做 C 级 ≤15% 配额，观察 2 个季度 |
| 独家供应（专利/资质壁垒） | 建安全库存 + 找替代规格，标注「结构性单源」 |
| 小批量采购无议价力 | 接受高价但保交期，标注「成本换确定性」 |
| 跨境供应商 | 增加清关与汇率风险项，账期缩短 |
| 资质材料拿不到 | 至少核主体合法与经营范围，其余标注「未核」 |
| 紧急断供应急 | 先保交付（临时采购），事后补准入流程 |

**明确不做**：不做比价、不做单据校验、不签合同、不做法律判断。
