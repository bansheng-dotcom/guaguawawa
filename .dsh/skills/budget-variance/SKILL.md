# 预算与差异分析（budget-variance）

> **「花超了」是结论，不是原因。** 超 20 万可能来自单价涨了、买多了、还是买了贵的替代品——三种原因对应三种完全不同的动作，而它们在一张总额表里长得一模一样。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「这个月为什么超支」
- 「预算和实际怎么对」
- 「这项费用还该不该花」
- 「下季度预算怎么定」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 三表勾稽与对账 | r03 的 `model-audit` | 那是审计 |
| 现金流跑道 | r03 的 `cash-runway` | 那是资金 |
| 经营整体诊断 | r02 的 `business-ops-analysis` | 那是经营面 |
| 采购单价 | r15 的 `analyze-procurement` | 那是 TCO |

**最小可开工输入**：**一份预算表 + 一份实际表**（同科目、同期间）。缺任一份只能做总额对比，拆不出原因。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| 预算表（科目级） | 必需 |
| 实际表（同科目口径） | 必需 |
| 期间与币种 | 必需 |
| 业务量指标（订单数/人数/GMV，用于拆数量差异） | 必需 |
| 上期同科目数据 | 建议 |

**追问纪律**：最多一轮，只问**有没有业务量指标**。没有它只能拆到科目级，拆不到价格与数量。

## §3 执行流水线（Workflow）

### Step 1 · 对齐科目与期间（先修口径，再算差异）
确认三件事：科目层级一致、期间一致（自然月/财务月）、币种一致。口径不一致时先修口径，**否则算出的差异是假的**。

**判据**：科目/期间/币种三项都对齐，且写明口径

### Step 2 · 算总额差与差异率
总额差 = 实际 − 预算；差异率 = 总额差 ÷ 预算。按科目逐行列，并按金额降序排。

**判据**：逐科目算，不只给总差异

### Step 3 · 三段拆差异（价格 / 数量 / 结构）
对每个重大差异科目做三拆：**价格差异**=（实际单价 − 预算单价）× 实际量；**数量差异**=（实际量 − 预算量）× 预算单价；**结构差异**= 总额差 − 价格差 − 数量差。

**判据**：三段相加必须等于总额差（可复算）

### Step 4 · 标出「可解释」与「需追责」两类
可解释：业务量增长带来的合理增长、一次性投入、汇率波动。需追责：单价超市场、采购量超需求、用了更贵的替代品。

**判据**：每个重大差异都归到两类之一

### Step 5 · 出整改清单（每条含动作 + 责任类型 + 验证指标）
整改动作要能被下月数据验证：如「把 A 供应商单价谈回 12.5」，验证指标=下月该科目单价。

**判据**：每条动作有验证指标与回看时间

### Step 6 · 反推预算假设（预算本身错了吗）
如果连续两月同一科目都超支且拆不出价格/数量原因，说明**预算假设错了**，不是执行问题。

**判据**：写明是「执行偏差」还是「预算假设错误」

## §5 质量门（一票否决）

1. 科目 / 期间 / 币种三项口径已对齐并声明；
2. 逐科目算差异，不只给总额；
3. 每个重大差异做了价格/数量/结构三段拆解，且三段可加总回总额；
4. 重大差异归入「可解释」或「需追责」两类之一；
5. 每条整改动作都有验证指标与回看日期；
6. 判断了差异性质：执行偏差 vs 预算假设错误；

> 本卡无自动门禁。三段差异加总可人工复算，这是本卡最硬的自我验证。

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 只给总差异 | 逐科目列，按金额降序 |
| EX-02 | 口径不一致直接算 | 先修科目/期间/币种 |
| EX-03 | 不做三段拆解 | 价格差 + 数量差 + 结构差 = 总额差 |
| EX-04 | 三段加不上总额 | 结构差就是兜底项，必须复算 |
| EX-05 | 把增长当超支 | 区分业务量驱动与效率问题 |
| EX-06 | 整改写「加强管控」 | 写具体动作 + 验证指标 |
| EX-07 | 从不怀疑预算假设 | 连续两月同科目超支要怀疑预算 |
| EX-08 | 忽略汇率 | 多币种要按同期汇率折算 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 无业务量指标 | 只拆到科目级，标注「未拆价格/数量」 |
| 预算科目比实际粗 | 按实际科目归并预算，标注归并规则 |
| 期间不一致（财务月 vs 自然月） | 统一到财务月并说明调整 |
| 多币种 | 按同期汇率折算，标注汇率与日期 |
| 一次性大额支出 | 单列并标注「一次性」，不摊入常规差异 |
| 无历史数据 | 只做本期差异，标注「无环比」 |

**明确不做**：不记账、不做审计、不算税务、不批预算。
