# 出图提示词结构（Image Prompt Structure）

> 一句话定位：**你脑子里那张图，和模型生成的那张图，差的不是模型，是描述的结构。**
>
> 「高级感的咖啡机商品图」这句话里，模型要知道六件事才能落地：
> 什么主体、放哪、怎么拍、什么光、什么材质、出多大。
> 六件事缺一件，它就会自己编——编出来的通常不是你要的。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**
- 「帮我写个出图的提示词」
- 「为什么每次出的图都不一样」
- 「这张图差点意思」「不够高级」
- 「主图/详情页/种草图怎么描述」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 要几张图、每张说什么 | `r10` 的 `ecommerce-designer` | 那是主图矩阵与分屏脚本 |
| 真的把图生成出来 | `r10` 的 `image-gen-pipeline` | 那是执行与调 API |
| 图上加字/裁剪/压缩 | `r10` 的 `image-ops` | 那是后处理 |
| 判断成品好不好看 | `r10` 的 `visual-hierarchy` | 那是十三条判据 |
| 检查是否偏品牌 | `r10` 的 `brand-guardian` | 那是令牌比对 |

**最小可开工输入**：**一个具体主体 + 用在哪（平台/位置）**。

## §2 前置输入与最省追问

| 输入 | 是否必需 | 缺失时怎么办 |
|---|---|---|
| 主体（具体到型号/材质/颜色） | 必需 | 「一个杯子」→ 追问材质与色 |
| 用途位置（主图/详情/种草/广告） | 必需 | 决定比例与留白 |
| 目标平台 | 必需 | 决定尺寸与文字安全区 |
| 参考图或风格锚点 | 建议 | 缺则用「干净背景 + 自然光」默认 |
| 是否要留文字位 | 建议 | 缺则按主图默认留上方 1/5 |

**追问纪律**：最多一轮，只问**主体材质颜色、用在哪**。

## §3 执行流水线（Workflow）

### Step 1 · 一图一主体（先减再加）
**阈值**：一张图 **1 个主体**，最多 1 个陪衬物（用于衬托尺度）。
**判据**：把 prompt 里的名词数一遍，>3 个独立物体 → 拆图。

> 多主体是"图看起来乱"的第一原因。模型会把每样都画得平均，没有主次。

### Step 2 · 写六段（缺一段模型就自己编）
| 段 | 必答 | ❌ 虚 | ✅ 实 |
|---|---|---|---|
| **1 主体** | 是什么、什么材质、什么颜色、什么状态 | 一个咖啡机 | 哑光深灰金属机身、玻璃水箱、空杯放上托盘 |
| **2 环境** | 放哪、背景是什么 | 好看的背景 | 浅灰水泥台面，背景是同色渐变墙，无杂物 |
| **3 构图** | 主体占多大、什么角度 | 拍得好看 | 45° 俯视，主体占画幅 2/3，居中偏下 |
| **4 光线** | 主光方向、软硬、有无反光 | 高级光 | 左前方 45° 柔光箱，右侧补白反光板，台面有柔和高光 |
| **5 材质与风格** | 表面质感、整体调性 | 高级感 | 金属哑光、玻璃通透；整体冷调、对比克制、留白充足 |
| **6 规格与负向** | 比例、尺寸、留白、不要什么 | 高清 | 1:1，2400×2400，上方留 1/5 空；负向：无文字、无水印、无logo、无多余道具、无人物 |

**阈值**：**六段齐备**；负向词 **≥3 条**；平台规格**写明数字**。

### Step 3 · 负向词必须写（最省力的一步）
不写负向，模型会自己加：文字、水印、奇怪反光、多余道具、模糊、畸变。

**阈值**：负向至少覆盖四类：
```
文字类：无文字、无水印、无 logo、无标签
质量类：无模糊、无畸变、无过曝、无噪点
构图类：无裁切主体、无多余道具、无杂乱背景
风格类：无卡通、无塑料感、无过度 HDR
```

### Step 4 · 平台规格对照（写错尺寸白出）
| 平台/位置 | 比例 | 常用尺寸 | 特别要求 |
|---|---|---|---|
| 淘宝/天猫 主图 | 1:1 | 800×800 起（建议 1200+） | 白底或浅底，主体占 ≥70% |
| 详情页 | 竖版 | 宽 750，高度不限 | 分段出图，每段一个卖点 |
| 小红书 封面 | 3:4 | 1242×1660 | 上方留标题位 |
| 抖音/快手 封面 | 9:16 | 1080×1920 | 安全区内放主体 |
| 广告 横版 | 16:9 或 1.91:1 | 1200×628 | 大留白放文案 |
| App 图标 | 1:1 | 1024×1024 | 内容不贴边，留安全区 |

**阈值**：规格**必须写进 prompt 第 6 段**，不能靠后处理裁。

### Step 5 · 四版一致性抽检（验证 prompt 是否可复现）
同一组 prompt 连出 **4 版**，检查：
- **主体是否一致**（形状/颜色/材质没跑）；
- **构图是否稳定**（主体位置差异 ≤10% 画幅）；
- **光线方向是否一致**（不能一版左光一版顶光）。

**阈值**：4 版里 **≥3 版**在上述三点上一致 → prompt 可复现；≤2 版 → 六段里有段写虚了，回 Step 2 补。

### Step 6 · 交付前对一遍判据（不判好看，只判规格）
用 `visual-hierarchy` 的六条硬门查成品：层级/对齐/对比度/留白/375 无横向滚动（若用于网页）。
**本卡只保证「图按你说的生成了」，不保证「图好看」**——后者归 `visual-hierarchy`。

## §5 质量门（一票否决）

1. **一图一主体**（独立物体 ≤2，含 1 个陪衬上限）；
2. **六段齐备**（主体/环境/构图/光线/材质风格/规格负向）；
3. **负向词 ≥3 条**，覆盖文字/质量/构图/风格四类中至少三类；
4. **平台规格写进 prompt**（比例 + 尺寸 + 留白要求）；
5. **四版一致性抽检 ≥3/4**；
6. **每个模糊形容词都换成可执行的描述**（"高级感"→"冷调、对比克制、留白充足"）。

> 本卡无自动门禁。可配合 `python agent.py imgops info --input <成品>` 核对尺寸与通道（间接）。

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 只有一句「高级感商品图」 | 六段结构化，每段可执行 |
| EX-02 | 一张图塞三个主体 | 一图一主体，多主体拆图 |
| EX-03 | 写「好看的背景」 | 写具体：浅灰水泥台面 + 同色渐变墙 |
| EX-04 | 写「高级光」 | 写方向 + 软硬：左前 45° 柔光箱 + 右侧反光板 |
| EX-05 | 不写负向词 | ≥3 条，覆盖文字/质量/构图 |
| EX-06 | 规格靠后处理裁 | 规格写进 prompt，直接出对尺寸 |
| EX-07 | 用「氛围感/质感」 | 换成冷调/哑光/通透等可执行词 |
| EX-08 | 只出一版就定稿 | 出 4 版，≥3 版一致才算可复现 |
| EX-09 | 主图主体占 40% | 主图主体占 ≥70% 画幅 |
| EX-10 | 不留文字位 | 上方留 1/5（主图/封面） |
| EX-11 | 忽略平台安全区 | 按平台安全区放主体 |
| EX-12 | 把 prompt 当成品判据 | 出图质量归 `visual-hierarchy`，本卡只管可复现 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 无出图能力 | 只交 prompt，标注「未出图」 |
| 主体是复杂人像 | 六段之外补「姿态 + 服装 + 表情」，并标注「人像一致性有限」 |
| 需要严格品牌色 | prompt 写色值，出图后用 `brand-guardian` 核 |
| 需要图上文字 | 不让模型生成文字（易糊），文字留后处理 |
| 平台规格不明 | 给 1:1 与 3:4 两版，标注待确认 |
| 出图有畸变/多余手部 | 加负向词并降低复杂度，不要靠多次重试碰运气 |
| 涉及真实人物/商标 | 拒绝生成；改用不具名替代 |

**明确不做**
- 不调 API、不做后处理、不判好看、不做版权与肖像合规判断。
