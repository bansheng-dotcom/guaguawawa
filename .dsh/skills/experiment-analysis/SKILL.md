# 实验设计与结果分析（experiment-analysis）

> **「不显著」和「没效果」是两件事，而我们常把它们混着说。** 样本不足导致的不显著，会被读成「这个方向不行」，然后一个好想法就被埋了。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「跑个 A/B 看哪个好」
- 「这个差异算显著吗」
- 「实验要跑多久」
- 「为什么实验没结论」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 投放与预算 | r12 的 `paid-execution` | 那是执行 |
| 归因与拆解 | r06 的 `analysis-method` | 那是事后分析 |
| 策略方向 | r12 的 `campaign-plan` | 那是方案 |
| 产品需求 | r07 的 `prd-authoring` | 那是需求 |

**最小可开工输入**：**一个可证伪假设 + 一个主指标 + 现有基线转化率**。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| 可证伪假设（如果做 X，Y 会 Z） | 必需 |
| 单一主指标 | 必需 |
| 基线值与最小可检测效应（MDE） | 必需 |
| 分流比例与实验单元 | 必需 |
| 护栏指标（不能变差的那个） | 必需 |

**追问纪律**：最多一轮，只问**最小可检测效应是多少**。不问这个，样本量无从算，实验必然跑成「不显著」。

## §3 执行流水线（Workflow）

### Step 1 · 写可证伪假设（一条，且带方向）
格式：**「如果 <改动>，<主指标> 会从 <基线> 提升到 <目标>」**。方向不明（「有影响」）或指标多个，都不合格。

**判据**：假设一条、方向明确、指标单一

### Step 2 · 算最小样本量（先算再跑）
用基线率 p 与 MDE 算：样本量 ≈ 16 × p(1−p) / MDE²（每组，α=0.05、power=0.8 的常用近似）。**算出来如果是 3 个月，就说明这个实验做不了**，改做定性或放弃。

**判据**：样本量算出来了，并据此估算时长

### Step 3 · 定分流与实验单元
用户级分流（不是会话级）；同一用户始终在同一组；分流比例通常 50/50，样本紧张时可用 80/20（但要接受更长周期）。

**判据**：分流单元=用户；且写明用户是否会跨组

### Step 4 · 定护栏指标（防止赢了主指标输了全局）
护栏 = 不能变差的指标：如退款率、客诉数、页面加载时长、毛利率。**护栏恶化超过阈值，无论主指标多好都判失败**。

**判据**：护栏指标 ≥2 个，且各有阈值

### Step 5 · 预设停止规则（防偷看）
三种停止：**到样本量停**、**护栏恶化立即停**、**主指标提前达显著且超过 X 天**（可选）。**禁止中途反复看 p 值再决定继续**——那是 p-hacking。

**判据**：停止规则写死，且不允许中途因「看着不错」延长

### Step 6 · 结果分析顺序：护栏 → 主指标 → 异质
先看护栏是否恶化；再看主指标是否达显著（给 p 值与置信区间）；最后看分组差异（但分组只能探索，不能用来宣称结论）。

**判据**：分析按三序，且不把分组结论当主结论

## §5 质量门（一票否决）

1. 假设可证伪、单指标、方向明确；
2. 最小样本量已计算，且据此估算时长；算不起时明确放弃；
3. 分流单元为用户级，且写明是否跨组；
4. 护栏指标 ≥2 个且各有阈值；护栏恶化即判失败；
5. 停止规则预设，禁止中途看 p 值决定延长；
6. 结果分析按「护栏 → 主指标 → 异质」顺序；分组结论不上升为主结论；
7. 结论区分「不显著」与「无效果」，并给置信区间；

> 本卡无自动门禁。可配合 `python agent.py experiment design --input <实验.json>` 做结构校验（间接）。

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 假设写「有影响」 | 写「从 A 到 B」带方向 |
| EX-02 | 多主指标挑一个报 | 单主指标，其余为护栏 |
| EX-03 | 不算样本量就开跑 | 先算，算不起就放弃 |
| EX-04 | 中途反复看 p 值 | 预设停止规则，不看过程 |
| EX-05 | 会话级分流 | 用户级分流 |
| EX-06 | 无护栏指标 | 至少 2 个护栏 + 阈值 |
| EX-07 | 赢主指标输退款率还判成功 | 护栏恶化即失败 |
| EX-08 | 把「不显著」说成「没效果」 | 区分两者，给置信区间 |
| EX-09 | 分组挖出显著就当结论 | 标注「探索性」 |
| EX-10 | 样本不足仍下结论 | 标注「证据不足」 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 流量太小 | 改为序贯或多因素设计，或转定性 |
| 无法用户级分流 | 改用准实验（前后对比 + 排除），标注「非随机」 |
| 护栏指标拿不到 | 至少保留退款率或客诉数一个 |
| 实验被业务打断 | 记录中断点，结论降为「证据不足」 |
| 同时有多个实验 | 做正交分层，或排队不并行 |
| 基线不稳（新业务） | 先观察 2 周建立基线，再开实验 |

**明确不做**：不做投放执行、不做归因拆解、不替代策略决策、不承诺提升幅度。
