# 阈值设计法（Quantified Taste）

> 一句话定位：**`bad-good-contrast` 说「每条原则要配一个数字」，这张卡回答「那个数字该是多少」。**
>
> 阈值定错比不定更糟，因为它会把人带向错误行为：
> —— **定太高**：没人做到 → 整条规范被放弃 → 等于没写；
> —— **定太低**：90% 的产物都过 → 没有区分度 → 等于没门槛；
> —— **不可测**：「专业度 ≥8 分」谁打这个分？
>
> 这张卡给一套可复用的定阈方法：**三级分档 + 可达性反推 + 区分度检验 + 校准周期**。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**
- 「这个指标定多少合适」
- 「规范写了 95%，但没人达标」
- 「这个门槛形同虚设」
- 「怎么知道改完有没有变好」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 写规范的对照结构 | 本角色的 `bad-good-contrast` | 那是写法，不是定数 |
| 视觉/图表/文案的具体判据 | `r10` / `r06` / `r11` 各自专属卡 | 本卡只管「定数的通用方法」 |
| rubric 怎么打分与校准 | 本角色的 `rubric-calibration` | 那管评分过程 |
| 给某个产物判分 | `r04` 评审报告 | 本卡不定个案 |

**最小可开工输入**：**一条模糊要求 + 一批现有产物（或历史数据）**。

## §2 前置输入与最省追问

| 输入 | 是否必需 | 缺失时怎么办 |
|---|---|---|
| 要量化的那条要求 | 必需 | 无原文无法定数 |
| 现有产物的分布（至少 5 个样本） | 必需 | 无从反推可达性，只能给定「行业惯例值」并标注 |
| 测量方式（怎么量） | 必需 | 不可测的阈值一律降级为「参考」 |
| 谁执行、多久复量 | 建议 | 缺则默认「每次交付量 + 每季度校准」 |

**追问纪律**：最多一轮，只问**手上有没有 5 个以上现有产物、谁来量**。

## §3 执行流水线（Workflow）

### Step 1 · 先定「量什么」再定「多少」
把要求转成一个**可计数的量**：

| 模糊要求 | ❌ 不可测 | ✅ 可测 |
|---|---|---|
| 文案要具体 | 「具体度」 | 每千字形容词数 / 每结论的参数个数 |
| 代码要可读 | 「可读性」 | 单函数行数 / 单字母变量数 / docstring 覆盖率 |
| 响应要快 | 「快」 | P95 延迟 ms / 首屏可见 ms |
| 图表要诚实 | 「不误导」 | 截断轴未标注图数 / 双轴未说明图数 |

**判据**：这个量能用**两个人数出同一个数**吗？数不出就换量。

### Step 2 · 三级分档（地板 / 目标 / 优秀）
**永远不要只给一个数。** 一个数只有「过/不过」，会让人卡在线上。

| 档 | 含义 | 用来干什么 | 达不到怎么办 |
|---|---|---|---|
| **地板** | 不可低于，低于即拒收 | 一票否决 | 必须改 |
| **目标** | 应该达到 | 正常交付标准 | 记录并说明原因 |
| **优秀** | 标杆值 | 评优、对外案例 | 不要求所有人 |

**示例（文案形容词密度，每千字）**

```
地板 ≤6 处   → 超过即拒收（说明通篇靠形容词撑）
目标 ≤3 处   → 正常交付
优秀 ≤1 处   → 标杆
```

### Step 3 · 反推可达性（拿现有产物跑一遍）
把最近 5–20 个产物按 Step 1 的量算一遍，得到分布。

**判据**：
- 若**地板线**已经卡掉 >50% 的历史产物 → 地板定太高，先降到历史 P50 附近；
- 若**目标线**有 >80% 的产物轻松达到 → 目标定太低，提到 P70 附近。

> 这一步是本卡和「拍脑袋定阈值」的分水岭。
> 没有分布就不定阈值——只给「行业惯例值」并明确标注「未经本团队数据校准」。

### Step 4 · 检验区分度（能不能分开好坏）
阈值的作用是**分开**，不是**好看**。

| 检验 | 做法 | 结论 |
|---|---|---|
| 玻璃地板 | 90% 产物都过地板 | 地板太低，失去否决作用 |
| 天花板 | 无人能达到目标 | 目标太高，会被放弃 |
| 无差异 | 优等与差等产物在这个量上数值接近 | 这个量测错了，回 Step 1 |

**判据**：拿 3 个你认为「好」和 3 个「差」的产物，这个量必须能把两组分开。分不开 → 换量。

### Step 5 · 写明测法（谁量、怎么量、量几次）
每个阈值必须配三句话：

```
怎么量：<工具/步骤，能复现>
谁来量：<角色>（不可是产出者本人）
何时量：<每次交付 / 每周 / 每季度>
```

**不可测的阈值一律降级为「参考」**，不进 §5 质量门。

### Step 6 · 定期校准（分布会漂移）
- 校准周期：**每季度**或**产物分布明显位移时**；
- 校准依据：新技术/新平台/新客群会整体抬高或压低分布；
- 校准动作：重跑 Step 3，只调**目标与优秀**，**地板不轻易动**（地板动了等于标准倒退）。

## §5 质量门（一票否决）

1. 阈值对应的量**可被两人独立数出同一个数**；
2. 有 **三级分档**（地板/目标/优秀），不是单一数值；
3. 有**分布回测**（≥5 个历史产物实测），或明确标注「行业惯例值·未校准」；
4. 有**区分度检验**（好/差各 3 个能被分开）；
5. 每个阈值配**测法三句**（怎么量/谁量/何时量）；
6. 写明**校准周期**。

> 本卡无自动门禁。**任一项不过即不得写进其他卡的 §5 质量门**，只能作为「参考」。
> 可配合 `python agent.py harness materials --input <材料.json>` 校验交付材料齐备（间接）。

- [ ] 没有出现「专业度 ≥8 分」这种无法数出来的阈值

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 只给一个阈值 | 三级分档：地板/目标/优秀 |
| EX-02 | 阈值拍脑袋定 | 拿历史产物分布反推 |
| EX-03 | 地板定得过高（卡掉一半） | 地板先贴历史 P50，再逐步抬 |
| EX-04 | 目标定得过低（90% 都过） | 目标贴 P70，让「变好」有指引 |
| EX-05 | 用不可数的量（专业度/质感） | 换成可计数的量（个数/比例/毫秒） |
| EX-06 | 不分好差都能过 | 做区分度检验，分不开就换量 |
| EX-07 | 产出者自己量 | 换人量，避免自评 |
| EX-08 | 不写测法 | 写清怎么量/谁量/何时量 |
| EX-09 | 定完永不复盘 | 每季度或分布位移时校准 |
| EX-10 | 为了「看起来严格」抬高标准 | 阈值服务于行为，不服务于姿态 |
| EX-11 | 把参考值写进质量门 | 未校准的只做参考，不做一票否决 |
| EX-12 | 同时改多个阈值 | 一次只调一个，便于观察行为变化 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 没有历史产物 | 给「行业惯例值」并**明确标注未校准**，不进质量门 |
| 量确实不可数（如"高级感"） | 只写结构判据，明确「审美不在此列」 |
| 样本量 <5 | 只给两档（地板/目标），不做优秀档 |
| 数据涉密无法回测 | 由熟悉分布的人给区间，标注「专家判断」 |
| 阈值引发大面积返工 | 先看是不是量测错了，而不是马上降标准 |
| 多团队标准不一致 | 统一量定义与测法，再各自校准数值 |

**明确不做**
- 不判断审美高下（偏好不是阈值）；
- 不替代领域判据（视觉/图表/文案各有专属卡）；
- 不给单个产物打分（归 `r04` 评审报告）。
