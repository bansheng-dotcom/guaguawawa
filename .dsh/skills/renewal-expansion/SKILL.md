# 续约与增购（renewal-expansion）

> **续约谈判最贵的错误不是降价，是「没有准备就让步」。** 客户一说贵就降 10%，下次他一定接着说贵——因为你教过他这是有效的。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「这个客户快到期了怎么谈」
- 「要不要给折扣」
- 「怎么提涨价」
- 「客户说要走怎么办」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 健康分怎么算 | r13 的 `qbr-health` | 那是存量度量 |
| 客户上手 | r13 的 `customer-onboarding` | 那是激活 |
| 合同与条款 | r03 + 创始人 | 那是法务 |
| 定价策略 | r14 的 `pricing-strategy` | 那是定价 |

**最小可开工输入**：**一个到期客户 + 健康分 + 当前合同金额与用量**。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| 客户健康分与趋势 | 必需 |
| 当前合同额、用量、席位使用率 | 必需 |
| 到期日与决策链（谁是决策者） | 必需 |
| 续约目标（保底/目标/理想） | 必需 |
| 可给的让步空间（价格/账期/服务） | 必需 |

**追问纪律**：最多一轮，只问**让步空间有多大、谁有审批权**。没有授权上限的谈判必然超让。

## §3 执行流水线（Workflow）

### Step 1 · 排优先级（按健康分 × 金额）
四象限：**高健康高金额**（重点保）、**高健康低金额**（增购）、**低健康高金额**（重点救）、**低健康低金额**（标准流程，不投人力）。

**判据**：每个客户归入四象限之一，资源按象限分配

### Step 2 · 准备价值复盘（用客户自己的数）
复盘只讲三件：**用了什么 / 得到什么（客户口径的数） / 下一步能多得到什么**。**不许讲我们产品的功能列表**。

**判据**：复盘含客户侧数字 ≥2 个，且不含功能罗列

### Step 3 · 定三档方案（保底/目标/理想）
保底=不让客户走的最低条件；目标=正常预期；理想=含增购。**三档都要提前算好金额与毛利**，谈判时不现算。

**判据**：三档方案与金额都提前写好，毛利都算过

### Step 4 · 设计让步阶梯（每次让步必须换东西）
让步清单：**价格 / 账期 / 服务时长 / 增购量 / 案例授权 / 转介绍**。规则：**每让一步，必须换回一项**（更长年限、更大用量、案例授权）。

**判据**：每一次让步都对应换回项，且让步总额不超授权

### Step 5 · 定涨价话术（涨价要给理由与新价值）
涨价三件套：**新价值（已交付的增量）+ 时间（提前 60 天告知）+ 选择（多年锁定旧价）**。

**判据**：涨价有理由、有提前期、有锁定选项

### Step 6 · 流失挽回边界（什么时候放弃）
三条放弃条件：**健康分持续下滑 ≥2 季度**、**续约价低于地板线**、**客户明确不接受任何合作形式**。放弃也要做「体面退出」（结清 + 数据导出 + 可回来）。

**判据**：放弃条件写死；放弃时给出体面退出方案

## §5 质量门（一票否决）

1. 客户按「健康分 × 金额」归入四象限，资源按象限分配；
2. 价值复盘含客户侧数字 ≥2 个，且不罗列功能；
3. 三档方案（保底/目标/理想）提前写好金额与毛利；
4. 让步必须逐项对应「换回什么」，且总额不超授权上限；
5. 涨价有理由、提前 ≥60 天告知、并提供多年锁定选项；
6. 放弃条件写死（健康分/地板价/客户明确拒绝），且有体面退出方案；

> 本卡无自动门禁。续约金额与毛利可人工复算，这是最硬的自我验证。

## §6 交付前自检清单

- [ ] 我按健康分×金额给客户排了象限，不是按感觉
- [ ] 我的复盘讲的是客户得到的数，不是我们的功能
- [ ] 三档方案的金额和毛利我都提前算好了
- [ ] 我每次让步都换回了东西（年限/用量/案例/转介绍）
- [ ] 让步总额没超过我的授权上限
- [ ] 涨价我给了理由，提前 60 天说，还给了锁定选项
- [ ] 我写清了什么情况下放弃，以及放弃时怎么体面退出
- [ ] 我没有在客户一说贵就降价

| EX-08 | 不体面退出 | 结清 + 数据导出 + 可回来 |
| EX-09 | 所有客户同一套话术 | 按象限分话术 |
| EX-10 | 把增购当默认 | 先确认健康分高再谈增购 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 无健康分数据 | 用用量与工单数替代，标注「近似」 |
| 无让步授权 | 只谈多年锁定与增购，不降价 |
| 客户已决定走 | 只做体面退出与原因访谈 |
| 大客户关键人更换 | 先重建关系，再谈商务 |
| 合同期未到 | 做中期复盘，为续约铺垫 |
| 多产品打包 | 按产品分别算毛利，不混谈 |

**明确不做**：不算健康分、不做客服、不签合同、不承诺未交付能力。
