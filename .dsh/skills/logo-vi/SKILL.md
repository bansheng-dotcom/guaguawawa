# Logo 与图标变体（Logo & Icon Variants）

> 一句话定位：**这个技能存在的意义，是防止「大图很漂亮，缩到 16px 就成一团」**。
> Logo 最贵的失败不是不好看，而是**不可用**：
> 小尺寸糊、单色不可辨、深色背景反白崩、favicon 直接拿主 logo 缩。
> 这些问题在设计稿上看不出来，一上线全暴露。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**
- 「设计个 logo」「这个标志怎么样」
- 「favicon 怎么做」「app 图标要几套」
- 「为什么我们 logo 在手机上糊」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 完整 VI 体系（字库、色彩手册、全渠道规范） | 创始人 + 品牌设计 | 那是品牌体系，不是单个标志 |
| 设计令牌与设计系统 | 本角色的 `design-system` | 那是色彩字体间距体系 |
| 印刷工艺与包装结构 | 外部 | 本包只做数字端 |
| 商标检索与注册 | 法务 / `r03` | 本包不做法律判断 |

**最小可开工输入**：**品牌名 + 一句调性**（如"可信、克制"），或**一个现有标志**做评审。

## §2 前置输入与最省追问

| 输入 | 是否必需 | 缺失时怎么办 |
|---|---|---|
| 品牌名（中/英） | 必需 | 无名字无法做字标 |
| 标记类型（字标/图形/组合） | 必需 | 缺则按"字标优先"默认并标注 |
| 调性关键词（2–3 个） | 建议 | 缺则标注"调性未定"，给保守方案 |
| 主色 | 建议 | 缺则给建议色并标注"需品牌确认" |
| 使用场景（App 图标 / 网站 / 印刷） | 建议 | 缺则按数字端三档默认 |

**追问纪律**：最多一轮，只问**品牌名、标记类型**。

## §3 执行流水线（Workflow）

### Step 1 · 定标记类型（先选类型，再画）
```bash
python agent.py logo logo --input <Logo设计包.json>
```
类型必须在白名单内：**wordmark（字标）/ lettermark（字母标）/ pictorial（图形标）/ abstract（抽象标）/ combination（组合标）**。

门禁实测：类型不在白名单、或结构缺失即 FAIL（`logo_dirty`）。

| 类型 | 适合 | 不适合 |
|---|---|---|
| wordmark | 名字短、好读 | 名字长、跨语言 |
| lettermark | 缩写有辨识度 | 缩写撞车多 |
| pictorial | 具象可联想 | 抽象业务 |
| abstract | 科技/平台 | 需要快速理解 |
| combination | 想同时要字与图 | 小尺寸场景多 |

- **产出**：标记类型 + 选择理由
- **过关条件**：`agent.py logo logo` 退出码 0

### Step 2 · 尺寸阶梯可辨（16/32/64/128 逐档验）
**必须逐档看**，不能只看大图：

| 档 | 场景 | 判据 |
|---|---|---|
| 16px | favicon | 轮廓仍可辨（不必看清细节） |
| 32px | 任务栏/标签页 | 主特征可辨 |
| 64px | 列表/卡片 | 细节开始显现 |
| 128px | 详情页/启动图 | 完整呈现 |

**做法**：16px 版本通常是**专门画的简化版**（去细节、加粗笔画），不是把大图缩下来。

- **产出**：四档位图 + 每档可辨性判断
- **过关条件**：16px 下仍能认出是同一个标志

### Step 3 · 单色与反白变体（三套起步）
| 变体 | 用途 | 要求 |
|---|---|---|
| 全彩 | 主用 | 主色 + 辅助色 |
| 单色黑 | 单色印刷 / 传真 / 印章 | 纯黑，无渐变 |
| 反白 | 深色背景 | 纯白，背景对比 ≥4.5:1 |

**反白最容易崩**：很多 logo 有细线条，反白后消失。必须单独验。

- **产出**：三套变体
- **过关条件**：单色版无渐变、反白版在深底上对比 ≥4.5:1

### Step 4 · favicon / app-icon 变体
```bash
python agent.py logo favicon --input <图标变体.json>
```
- favicon：16 / 32 / 48 三尺寸 + `.ico` 与 `.png` 两格式；
- app icon：iOS / Android 各自的安全区内缩（内容不要贴边）；
- **不要把主 logo 直接缩成 favicon**，要出简化版。

- **产出**：多端变体清单
- **过关条件**：`agent.py logo favicon` 退出码 0

### Step 5 · 使用禁区与最小留白
- **最小留白**：标志四周留白 ≥ 标志高度的 1/4（或一个"字宽"单元）；
- **禁区**：不要拉伸、不要加投影、不要换色、不要叠加图形、不要在花背景上直接用全彩版。

## §5 质量门（一票否决，不过不给交付）

1. **标记类型在白名单内**（`logo logo` 门禁）；
2. **四档尺寸都出图**，且 16px 仍可辨；
3. **三套变体齐备**（全彩 / 单色黑 / 反白）；
4. **单色版无渐变**，反白版对比 ≥4.5:1；
5. **favicon 是简化版**，不是主 logo 缩放（`logo favicon`）；
6. **app icon 内容不贴边**，留足安全区；
7. **最小留白与禁区已写明**。

> 验收命令：`python agent.py logo logo` + `python agent.py logo favicon`
> 命中任一项不过 → 回 §3 对应 Step 重做，**不允许只交大图充数**。

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 只交大图，没有小尺寸 | 四档 16/32/64/128 都出 |
| EX-02 | 直接把大图缩成 16px | 16px 专门画简化版（去细节、加粗笔画） |
| EX-03 | 只有全彩一套 | 全彩 + 单色黑 + 反白，三套起步 |
| EX-04 | 单色版用灰度过渡 | 单色必须纯黑/纯白，无渐变 |
| EX-05 | 反白直接反转颜色 | 细线条反白会消失，要重新调线宽 |
| EX-06 | favicon 用主 logo 缩放 | 单独出简化版，`.ico` + `.png` |
| EX-07 | app icon 内容贴边 | 留安全区，避免被圆角裁切 |
| EX-08 | 没定最小留白 | 留白 ≥ 标志高度 1/4，写进规范 |
| EX-09 | 标志里有渐变/阴影/描边特效 | 主标志保持可单色还原 |
| EX-10 | 在主色未确认时定稿 | 标注"色值待品牌确认"，给替代方案 |
| EX-11 | 拿现成图标库改一改当 logo | 侵权风险；要么原创，要么用明确可商用素材 |
| EX-12 | 承诺"商标能注册" | 本包不做商标检索；提示需法务核查 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| `agent.py` 门禁跑不了 | 按 §6 人工核对，标注「未跑门禁」；**不得标记"可交付"** |
| 无设计工具（只能出文字方案） | 给标记类型 + 结构描述 + 尺寸规范，标注"未出图" |
| 品牌主色未定 | 给 2–3 套配色建议并标注"待确认"，不定稿 |
| 只能出单色（印刷优先） | 先定单色版，再从单色推全彩（顺序反过来更容易失败） |
| 名字过长跨语言 | 建议 combination 或 lettermark，不用长 wordmark |
| 客户要求"照 XX 品牌做一个" | 可借鉴类型与结构，不复制其图形资产 |
| 涉及商标注册问题 | 明确说本包不检索，建议法务核查 |

**明确不做**
- 不做完整 VI 体系（字库/手册/全渠道）；
- 不做印刷工艺与包装结构；
- 不做商标检索与注册判断；
- 不做设计令牌体系（归 `design-system`）。
