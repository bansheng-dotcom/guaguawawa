# 达人合作与联盟（kol-collab）

> **达人合作最常见的亏是「付了坑位费，卖了三单，还找不到原因」。** 因为 brief 只写了卖点，没写「必须怎么讲」和「不许怎么讲」。

## §1 何时用 / 何时不用

**该用（用户真实会这么说）**

- 「怎么找达人」
- 「brief 怎么写」
- 「佣金给多少合适」
- 「这次合作值不值」

**不该用，转给谁**

| 用户其实想要 | 转给 | 理由 |
|---|---|---|
| 投放 | r12 的 `paid-execution` | 那是买量 |
| 文案 | r11 的 `tone-axes` | 那是文案 |
| 合同与付款 | r03 + 创始人 | 那是法务财务 |
| 视觉素材 | r10 的 `image-prompt-structure` | 那是出图 |

**最小可开工输入**：**一个产品 + 一个预算区间 + 一个目标（曝光/带货/品牌）**。

## §2 前置输入与最省追问

| 输入 | 是否必需 |
|---|---|
| 产品与核心卖点（≤3 个） | 必需 |
| 预算区间与结构（坑位费/佣金） | 必需 |
| 目标（曝光/带货/品牌背书） | 必需 |
| 候选达人清单 | 必需 |
| 合规红线（禁提词/医疗功效等） | 必需 |

**追问纪律**：最多一轮，只问**目标是曝光还是带货**。这决定佣金结构，也决定该找哪种达人。

## §3 执行流水线（Workflow）

### Step 1 · 筛人四维（匹配度/内容力/带货力/风险）
**匹配度**（受众重合）>**内容力**（能不能讲清）>**带货力**（历史转化）>**风险**（负面记录）。**匹配度不过关，后面三项都白搭**。

**判据**：四维都打分，且匹配度为一票否决项

### Step 2 · brief 四件（卖点/必提/禁提/交付物）
**卖点** ≤3 个；**必提**（必须说的话，如规格、售后）；**禁提**（极限词、医疗功效、竞品贬低）；**交付物**（几条内容、什么形式、什么时候交）。

**判据**：四件齐备，禁提项 ≥3 条

### Step 3 · 佣金结构（三种，按目标选）
**纯佣**（无坑位费，佣金 15–30%）／**坑位费 + 低佣**（品牌曝光）／**固定费**（品牌背书）。按目标选，不混用。

**判据**：结构三选一，且与目标一致

### Step 4 · 验收规则（什么算交付完成）
验收 = **交付物齐备 + 内容保留 ≥30 天 + 发布时间在窗口内**。**不含「带来多少单」**——那是效果，不是交付。

**判据**：验收三条件写死，且不含效果

### Step 5 · 归因与结算（口令/专属链接/UTM）
必须给可归因的入口：专属口令、专属链接或 UTM。**没有归因入口的合作，事后无法评估**。

**判据**：归因方式写死，且可核

### Step 6 · 合规红线与托底
六条：不用绝对化用语、不宣称医疗功效、不贬低竞品、不虚构体验、AI 生成须声明、未成年人相关禁提。

**判据**：六条红线写进 brief，并要求达人确认

| # | 交付物 | 载体 |
|---|---|---|
| 1 | 筛选表（四维打分） | `.md` |

| 4 | 验收与归因规则 | `.md` |

## §5 质量门（一票否决）

1. 四维筛选（匹配度一票否决），非只看粉丝量；
2. brief 四件齐备：卖点 ≤3 / 必提 / 禁提 ≥3 / 交付物；
3. 佣金结构三选一且与目标（曝光/带货/背书）一致；
4. 验收 = 交付物 + 保留 ≥30 天 + 窗口内发布，不含效果；
5. 归因入口写死（口令/专属链接/UTM）；
6. 六条合规红线写进 brief 并要求确认；

> 本卡无自动门禁。brief 合规可人工核；归因可用 `paid-execution` 的口径核。

## §6 交付前自检清单

- [ ] 我筛人不只看粉丝量，匹配度不过关的我直接排除了
- [ ] brief 里卖点不超过 3 个
- [ ] 我写了「必提」（规格/售后），不只是卖点
- [ ] 我写了 ≥3 条禁提（极限词/功效/贬低竞品）
- [ ] 佣金结构是按目标选的，没有混用
- [ ] 验收标准不含「卖了多少单」
- [ ] 我给了可归因入口（口令/链接/UTM）
- [ ] 我把六条合规红线写进去了，并要求达人确认

## §7 易犯错误对照表

| # | 易犯错法 | 正确做法 |
|---|---|---|
| EX-01 | 只看粉丝量 | 四维筛，匹配度一票否决 |
| EX-02 | 卖点写 8 个 | ≤3 个，多了记不住 |
| EX-03 | 只写卖点不写必提 | 必提规格与售后 |
| EX-04 | 不写禁提 | ≥3 条禁提 |
| EX-05 | 把销量写进验收 | 验收＝交付物+保留期+窗口 |
| EX-06 | 无归因入口 | 口令/链接/UTM 三选一 |
| EX-07 | 佣金结构混用 | 纯佣/坑位+低佣/固定费 三选一 |
| EX-08 | 不要求合规确认 | 六红线要达人书面确认 |
| EX-09 | 合作后不复盘 | 按归因数据复盘 ROAS |
| EX-10 | 一次性找 20 个 | 先小批量 3–5 个测 |

## §8 降级与边界

| 触发情况 | 处置 |
|---|---|
| 无归因能力 | 最低保底：专属口令 + 客服核对，标注「粗归因」 |
| 达人要求改 brief | 必提与禁提不可改，卖点可协商 |
| 预算极低 | 只做纯佣，找腰部以下 |
| 达人拒绝提供数据 | 只验收交付物，标注「效果不可评」 |
| 涉医疗/功效 | 明确拒绝该类内容，改做使用体验 |
| 多平台同发 | 按平台分别定交付物与窗口 |
| 合作翻车（负面） | 按合同处置，同时暂停该达人全渠道 |

**明确不做**：不做投放执行、不写文案、不签合同、不承诺销量。
